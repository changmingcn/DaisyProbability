# 第一篇　极限：不能做完无穷，怎么谈论无穷

CENTER: 极限不是"算完无限"的本事，而是"先提出候选答案，再用误差标准去证明"的一种说法

我们来看一队越排越长的数。每一个都比前一个多加一点点，加的那一点点一次比一次小：

CENTER: **1，　1+[[1/2]]，　1+[[1/2]]+[[1/4]]，　1+[[1/2]]+[[1/4]]+[[1/8]]，　……**

规律是这样的：每次新加的那一块，都是上一块的一半。加到第 n 块的时候，总和正好是

CENTER: **1 + [[1/2]] + [[1/4]] + [[1/8]] + …… + [[1|2^n]] ＝ 2 − [[1|2^n]]**

FIG: fig-01-partial-sums.png | 每走一步，就把"剩下的那段距离"走掉一半。所以永远还剩一点点。

不管 n 是几，这个等式都成立。n 越大，2 和总和之间那一点点差就越小。于是我们很容易冒出一个念头：要是就这么一直加下去、加到"无穷次"，是不是就正好到 2 了？

问题恰恰从这儿开始：**无限次的加法，真的能"做完"吗？**

BOX[remember]: 必须记住 :: 我们永远不能完成无穷次计算。// 极限没有替我们做完它，只是让我们不必做完它。

## 零、先认两个生字

后面要用到两个小学课本里没有的写法。它们看着唬人，其实就是两个缩写。

### 生字一：右下角的小号码

一队数排好以后，我们要能指着说"第 3 个""第 100 个"。每回都写"第几个"太啰嗦，数学家就给每个数发了一个门牌号，写在字母的右下角：

FIG: fig-02-subscript.png | a~1~ 念作"a 一"，就是这队数里的第 1 个；a~n~ 念作"a n"，就是第 n 个。

所以 a~n~ 三个笔画连起来，意思只有一个：**这队数里的第 n 个数**。右下角那个小小的 n，不是乘、不是次方，就是个号码。

### 生字二：两根竖线

我们经常要说"这两个数差多少"。差多少和谁大谁小无关——5 和 3 差 2，3 和 5 也差 2。数学里把"差多少"写成两根竖线：

FIG: fig-03-absolute-value.png | 把两个数都点在数轴上，中间那一段有多长，就是它们相差多少。

BOX[remember]: 两根竖线读作"相差" :: | a~n~ − L | 念作：**第 n 个数，离 L 有多远**。// 它永远不是负数——距离没有负的。// 它的正式名字叫"绝对值"，但你现在只要记住"距离"两个字就够了。

## 一、无穷不是一个可以走到的"最后一步"

我们常有一个朴素的想象：一步、两步、三步……一直走，等"第无穷步"走完，答案就在那儿等着。

可这句话本身就是自相矛盾的。**无穷不是一个特别大的整数。**不管你走到第几步，都还能再走一步。所以根本不存在"最后那一个无穷步"，也就不存在"把无穷次操作全做完"这回事。

如果我们把极限理解成"做完无穷次计算以后得到的那个数"，那极限从一开始就没法操作：既然那无穷次计算永远做不完，那个结果也就永远算不出来。

数学的办法不是把这个困难藏起来，而是**干脆换一个问题来问**。

## 二、跳出计算：把"到达"改写成"保证"

我们不再问："无穷次计算全做完以后，结果到底是什么？"

我们改问：

CENTER: **"要是先提一个可能的目标值，那么不管别人把误差要求定得多苛刻，我们能不能只用有限次计算，就把结果稳稳送进那个误差范围里？"**

假设一队数是 a~1~，a~2~，a~3~，……，我们猜它奔着 L 去。这时候妹妹出场了。

BOX[dialog]: 妹妹出招，姐姐接招 :: **妹妹：**"我只允许这么小的误差 —— ε。"// **姐姐：**"好。我给你一个关口 N。从第 N 个数往后，每一个都离 L 不到 ε。一个都不会跑出去。"

写成一行就是：不管妹妹给出多小的 ε，姐姐都能找出一个有限的号码 N，使得只要 n 比 N 大，就一定有

CENTER: **| a~n~ − L | ＜ ε**

FIG: fig-04-epsilon-N.png | 妹妹画出那条误差带（橙色虚线之间），姐姐回答一个关口 N。灰点是关口以前的，可以随便乱跑；关口以后的蓝点，一个都不许出带。

这里头，**没有任何一步需要做无穷次操作**。妹妹每提一个具体的误差要求，姐姐就给一个具体的、有限的号码。她可以一次比一次苛刻，可以永远提下去；但姐姐每一次的回答，都只牵扯有限步。

于是，一件"做不完的无限的事"，被改写成了"无穷多个各自都能兑现的有限的承诺"。

BOX[remember]: 顺序不能反 :: 一定是**妹妹先给 ε，姐姐再找 N**。// 我们不是证明"在某一个精度下看起来差不多"；// 我们是证明"不管精度要求收紧到什么地步，总有一个有限的办法能满足它"。

### 为什么 ε 和 N 要用两个不同的字母

因为它们是两个人的东西。**ε 是妹妹的**，她说多小就多小，姐姐无权过问。**N 是姐姐的**，是听完她的要求以后才决定的。所以 N 会随着 ε 变——她要求越苛刻，姐姐给的关口就越靠后。

顺带一提：ε 是一个希腊字母，念作"艾普西龙"。数学家用它专门表示"一个很小的正数"，纯粹是习惯，没有别的道理。

## 三、极限值不是算出来的：先猜，后证

这里有一个特别重要、又特别容易被漏掉的顺序：**极限的定义，不会自动替我们把 L 算出来。**

定义只是一把尺子，是一个检验标准。我们必须先从算出来的结果里、从式子的变形里、从图里，或者从已经知道的道理里，看出一个可能的目标值，然后把它端出来当候选。

所谓"猜"，不是闭着眼睛蒙，而是**先发现一个合理的候选**。接下来才轮到证明：让妹妹随便给 ε，姐姐都能据此找出合适的 N，并且严格推出误差真的小于 ε。只有这一关过了，这个候选值才拿到"极限"这个身份。

BOX[key]: 先猜，后证 :: 极限值 L 不是在"第无穷步"被算出来的。// 它是**先被提出来，再被误差保证所确认**的。

那怎么猜呢？有一招特别好用，用的正是五年级学的简易方程——第二篇第四节会教。

## 四、循环小数：我们早就在偷偷用极限

回头看看每天都在用的循环小数，会发现这套想法我们其实早就接受了。

写下 0.333… 的时候，我们显然没有、也不可能真的写完无穷多个 3。严格地说，这个记号代表的是一队有限小数：

CENTER: **0.3，　0.33，　0.333，　0.3333，　……**

如果 a~n~ 表示小数点后写了 n 个 3 的那个有限小数，那么

CENTER: **a~n~ ＝ [[1/3]] ×（1 − [[1|10^n]]）**，　　**| [[1/3]] − a~n~ | ＝ [[1|3\times 10^n]]**

右边那个数是多少呢？写 1 个 3，差[[1/30]]；写 2 个 3，差[[1/300]]；写 3 个 3，差[[1/3000]]……**每多写一个 3，差就缩小到原来的[[1/10]]。**

所以：每一个有限小数都不等于[[1/3]]——一个都不等于。但它们和[[1/3]]的差，可以小于妹妹说的任何一个正数。于是我们就把这一队有限小数的极限，定义成 0.333… 所表示的那个实数，并且证明它等于[[1/3]]。

**那个省略号，不是说"我们已经把无穷多个 3 写完了"，而是在指着一个由有限步骤构成的极限过程。**

### 那 0.333… × 3 呢

妹妹这时候会挑一个特别好的刺。

BOX[dialog]: 妹妹挑刺 :: **妹妹：**"可我们天天在算 0.333… × 3 呀。刚才说无穷次计算做不完——那这道题到底是怎么算出来的？"// **姐姐：**"问得好。我们确实没有先把无穷个 3 写完。我们偷偷换了一样东西去乘。"

先看那条**走不通**的路。要是把 0.333… 读成一道没做完的题，算法就只能是这样：来来来，我先做无穷次计算，0.3、0.33、0.333……一路做到"最后那一步"，得出一个数；然后再把这个数乘以 3。

第一节已经说过了：**没有"最后那一步"这回事。**所以这条路不是难走，是根本没有这么一步可走。真要按这个读法，0.333… × 3 我们一辈子也算不出来。

可我们明明一秒钟就算出来了。那我们实际做的是什么呢？是下面这三步——做得太顺手，顺手到从来没人注意过：

- **第一步，改口。**先不把 0.333… 当算式，把它当一队数的极限：0.3、0.33、0.333、……
- **第二步，认账。**上面刚刚证过：这队数的极限是[[1/3]]——一个我们早就认识的数，它在数轴上有一个定死的位置。
- **第三步，才轮到乘。**要乘的根本不是"写 3 的那个过程"，而是**那个数**：[[1/3]] × 3 ＝ 1。

这就是"偷偷用极限"那个"偷"字的意思。**极限替我们把一个永远做不完的过程，换成了一个可以拿去用的数。**换完以后剩下的，是一道二年级的乘法。

BOX[remember]: 记号不是任务，是名字 :: 0.333… 长得像一道没做完的题，// 其实它是**一个数的名字**——那队有限小数的极限。// **既然是数，它就能像别的数一样参加计算。**// 省略号里那无穷多个 3，一个也不用写出来。

### 那 0.999… ＝ 1 呢

一样的道理，不是魔术。写 n 个 9 得到的有限小数，和 1 相差多少？

CENTER: 写 1 个 9 → 差[[1/10]]　　写 2 个 9 → 差[[1/100]]　　写 n 个 9 → 差 [[1|10^n]]

每一个有限阶段都比 1 小，**一个都没到 1**。但这个差能小于任何一个正数，所以这队数的极限就是 1。

BOX[remember]: 一个常见的误会 :: 队里每一项都没到 1，// 不妨碍整队数以 1 为极限。// 极限说的是"所有有限阶段一起指向哪里"，// 不是"某一项终于变成了什么"。

## 五、总结：极限怎样让我们严肃地谈论无穷

它的道理可以收成三个环节，一环扣一环：

- **第一，承认限制。**我们不能完成无穷次计算，也没有一个可以走到的"第无穷步"。
- **第二，提出候选。**我们跳出一步步算的过程，根据结构和规律，先猜一个目标值 L。
- **第三，给出证明。**面对妹妹提出的任何 ε，姐姐都用一个有限的 N 建立保证，从而确认 L 真的是极限。

所以，极限不是"完成无穷"的神话，也不是把"越来越接近"含含糊糊说一遍。它是一次严格的逻辑转换：把"做完无穷次操作以后会怎样"这个没法执行的问题，换成"每一个有限精度的要求，是不是都能在有限步里被满足"这个可以证明的问题。

BOX[key]: 这一篇的一句话 :: 我们不需要、也不可能完成无穷。// 我们先猜出目标，再证明：**每一个有限精度的要求，都能在有限步骤内得到满足。**

BOX[key]: 回头望一眼那块地 :: 开篇留下两列数：0.24、0.2925、……和 0.43、0.3875、……，一列只涨，一列只跌，互相越靠越近。// 当时只能含糊地说它们"挤向一个地方"。现在你有正经的问法了：**这两队数，有没有极限？**// 谁说了算？ε–N 说了算——妹妹随便要多准，姐姐都得拿出一个有限的关口。// 那块地的案子，从这一篇起，才算正式立案。

## 加餐：机器的极限

这一节是给想多看一点的孩子的。看不懂可以直接跳到第二篇，不影响。

前面说的是"一队数"。还有一种情况：一台机器，你投进去一个数 a，它吐出来一个数，记作 f(a)。

我们想说这么一件事："当投进去的数越来越靠近 c 的时候，吐出来的数越来越靠近 L。"

道理和前面**一模一样**，只是"算得足够多次"要换成"投得足够准"：

FIG: fig-05-epsilon-delta.png | 妹妹先说"吐出来的要多准"，姐姐再回答"那你投进去要多准"。

BOX[dialog]: 换成机器以后 :: **妹妹：**"我要求吐出来的东西，离 L 不超过 ε。"// **姐姐：**"好。那你投进去的 a，只要离 c 不超过 δ 就行——δ 我来给。"

δ 也是个希腊字母，念作"德尔塔"。为什么要换一个字母？因为它管的是**另一端**：ε 管出口的准，δ 管入口的近。两个人管两头，不能混用一个名字。

注意这里说的仍然不是"a 有没有真的到达 c"，也不是"某个无限过程有没有终于结束"。说的是：**我们能不能靠控制入口的距离，来保证出口的误差。**

一队数用的是 ε–N 的说法，机器用的是 ε–δ 的说法。两套说法背后是同一个念头：**用有限的控制，回应任意精度的要求。**

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 数列极限：对任意 ε＞0，存在正整数 N，使得当 n＞N 时，| a~n~ − L | ＜ ε。记作 lim a~n~ ＝ L。// 函数极限：对任意 ε＞0，存在 δ＞0，使得当 0＜| a − c |＜δ 时，| f(a) − L | ＜ ε。// 那个"对任意"写作 ∀，"存在"写作 ∃。你现在读到的每一句"不管妹妹怎么说"，就是 ∀；每一句"姐姐能给出"，就是 ∃。
