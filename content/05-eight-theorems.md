# 第五篇　同一件事的八种说法

CENTER: 八个吓人的名字，讲的是同一句话：数轴上没有洞

第三篇末尾我们说，"数轴上没有洞"有很多种说法。现在来看看有多少种。

答案是：至少八种，而且它们**全都是同一件事**——任意一个成立，其余七个都跟着成立。这在数学里有个说法，叫**等价**。

FIG: fig-21-eight-theorems.png | 八个名字，一个内核。它们不是八条道理，是一条道理的八件衣服。

## 一、先备几个词

下面八句话里会用到几个点集的说法。都很朴素，一个一个来。
### 邻域

FIG: fig-09-neighborhood.png | 妹妹的误差圈换个正式名字，就叫邻域。

一个点 p 的**邻域**，就是"离 p 不超过某个距离"的所有点凑成的那一小段。第一篇的误差圈，正式名字就是它。

### 开集与闭集

只需要最短的说法：

- **开集**：这片地里每一个点，都能在自己周围画一个小圈，整个圈还在这片地里面。（比如"比 0 大、比 1 小的所有数"。）
- **闭集**：这片地**装得下自己所有的聚点**——一个不漏。（比如"从 0 到 1，两头都要"。）

FIG: fig-11-open-closed.png | 边界线算不算自己的，就是这两者的区别。

BOX[remember]: 闭集最有用的一句话 :: **在闭集里挑一队数，只要它有极限，这个极限还在这个闭集里。**// 跑不出去——这就是"闭"字的意思。

### 区间套

一段套着一段，**后一段整个在前一段里面**，而且**长度越来越短，想多短有多短**——这样一串段子，叫一个**区间套**。第二篇第六节砍出来的那一串，就是区间套；第三篇第二节 √2 那一队小数**关住的那些格子**，也是。

### 开覆盖

拿一堆开集，把一片地**严严实实盖住**（每个点至少被某一个盖着），这堆开集就叫这片地的一个**开覆盖**。堆里可以有无限多个。

FIG: fig-14-compactness.png | 上：妹妹扔下无限多个圈，盖住了整段。下：姐姐只挑出 6 个，照样盖得住。

BOX[task]: 小练习：这几个词，摆一摆就懂 :: **（1）**下面各是开集、闭集、两者都是、还是两者都不是？// 　比 0 大比 1 小的数　／　从 0 到 1 两头都要　／　只有 0 这一个点　／　所有整数　／　整条数轴　／　什么都不含的空集// **（2）**上题里"只有 0 这一个点"和"所有整数"，各有聚点吗？// **（3）**把 1、[[1|2]]、[[1|3]]、[[1|4]]…… 这些点凑成一堆。它是闭集吗？**再添上哪一个点**，它就是闭集了？// **（4）**在数轴上造一个区间套，套住 0.5，**至少画 4 层**。（"长度不越来越短会怎样"留到第七节 A3。）// **（5）**给"从 0 到 1，两头都要"造一个开覆盖，**只用 3 个开集**。// **（6）**给"比 0 大、比 1 小"造一个开覆盖，让它**挑不出有限几个**盖得住。// 　（提示：拿这样一串开集——"比 0.1 大比 1 小"、"比 0.01 大比 1 小"、"比 0.001 大比 1 小"……// 　每一个都盖不到最左边那一小截。要是只挑有限几个，其中总有一个最靠左的，// 　它左边就还漏着。**注意④要求"两头都要"，这一题正好说明那个要求不是摆设。**）

## 二、八句话


先把它们用白话说一遍。名字都很唬人，意思一个比一个朴素。

TABLE:
| 编号 · 名字 | 说的是什么 |
| ① 确界原理 | 一堆数只要不空、又有上界，就一定有一个**最小的上界** |
| ② 单调有界定理 | 一队数只涨不跌，又始终不越过某条线，那它**一定奔向某个数** |
| ③ 区间套定理 | 一段套一段、越套越短（想多短有多短），那么**正好有一个点**被所有段子套住 |
| ④ 有限覆盖定理 | 一段（两头都要）被无限多个开集盖住，总能挑出**有限几个**仍然盖得住 |
| ⑤ 聚点定理 | 有界的一片地方里挤着无限多个点，那**一定有聚点** |
| ⑥ 致密性定理 | 一队被困住的数，一定能挑出一小队奔向某个数 |
| ⑦ 柯西准则 | 一队数有极限，**当且仅当**关口以后任意两项都近 |
| ⑧ 戴德金分割 | 把数轴切一刀，切口上**正好站着一个数** |

其中⑥你已经证过了——就是第二篇第六节那个砍一半。

BOX[remember]: 先看懂⑦为什么最有用 :: 第二篇证过：**有极限 ⇒ 关口以后任意两项都近。**// ⑦说的是**反过来也对**：只要关口以后任意两项都近，这队数就**一定有极限**。// 这句话厉害在哪？// 第一篇说过，极限值要**先猜出来**才能证。// 可⑦让你**不必先猜**——你只要检查这队数自己内部靠不靠拢，就能断定它有极限。// **答案是什么可以以后再说，先确定它存在。**

## 三、先把第①个证出来


八个里得先站稳一个。我们选①，因为**用第三篇的小数写法，它能一位一位地造出来**。

（这也正好回答第三篇的习题 C4：妹妹问"上界有无穷多个，凭什么保证里面有一个最小的"。）

BOX[key]: 造一个最小的上界 :: 给一堆数（不空，有上界）。我们一位一位把它的上确界写出来。// // **整数位。**把整数一个个看过去：太小的整数肯定不是上界（因为这堆数不空，总有数比它大）；太大的整数肯定是上界。// 所以中间有个分界。**a~0~** 就取**最后一个"还不是上界"的整数**。// // **第一位小数。**在 a~0~ 和 a~0~+1 之间有十个刻度。同样地，前面几个还不是上界，后面几个是。// **a~1~** 就取**最后一个"还不是上界"的刻度上的那个数字**。// // **一直下去。**得到一个无限小数 x ＝ a~0~.a~1~a~2~a~3~……// 记住造法给了我们两件事：截到第 n 位的那个数（叫它 x~n~）**不是上界**；而 x~n~ ＋ [[1|10^n]] **是上界**。

造出来了，还得验它真的是"最小的上界"。**两条都要验**，缺一条都不算。

BOX[key]: 验第一条：x 是上界 :: 反证。假如这堆数里有个 s 比 x 大。// 可是 x~n~ ＋ [[1|10^n]] 是上界，所以 s 不超过 x~n~ ＋ [[1|10^n]]。// 而 x~n~ 又不超过 x。所以 **s 不超过 x ＋ [[1|10^n]]**。// 这对**每一个** n 都成立，而 [[1|10^n]] 想多小有多小。// 所以 s 不可能真的比 x 大。**矛盾。**

BOX[key]: 验第二条：比 x 小的都不是上界 :: 取任意一个比 x 小的数 y。// x~n~ 就是 x 砍掉后面几位，n 越大，x~n~ 越接近 x。所以**总有某个 x~n~ 比 y 大**。// 而按造法，x~n~ **不是上界**——也就是说这堆数里有个数超过 x~n~。// 那个数当然也超过 y。// **所以 y 不是上界。**

两条都验过了。**x 就是最小的上界。①证毕。**

BOX[task]: 妹妹该挑的一根刺 :: 第三篇立过一条规矩：**不许以无穷多个 9 结尾**。// 可上面这个造法，有时偏偏就会造出一串 9 来。// 你自己试试：拿"所有比 1 小的数"这一堆。// 整数位：0 还不是上界（0.5 比它大），1 是上界，所以 a~0~ ＝ 0。// 第一位：0.9 还不是上界（0.95 比它大），所以 a~1~ ＝ 9。第二位还是 9……// **造出来的是 0.999…，可我们的规矩不许这么写。**// // 这算不算把自己的规矩打破了？// 不算——因为第一篇早就证过 **0.999… ＝ 1**。造法指的位置是对的，只是报名字的方式不合规矩，改写成 1.000… 就行。// **但你能发现这一点，比会背这个证明重要得多。**

BOX[remember]: 这个证明的分量 :: 它不是文字游戏。它说的是：// **"最小的上界一定存在"这件事，是小数写法白送给我们的。**// 换句话说——只要你接受"实数就是无限小数"，就等于接受了"数轴上没有洞"。// 这两件事本来就是一回事。

## 四、把其余七个串起来


站稳了①，剩下的就是接力。每一步都不长。

### ① ⇒ ②（有上确界 ⇒ 单调有界必收敛）

BOX[key]: 证明 :: 设这队数只涨不跌，而且都不超过某条线。// 由①，它们有一个最小的上界 M。姐姐来证这队数奔向 M。// 妹妹给 ε。因为 **M − ε 比 M 小，所以它不是上界**——那就有某一项 a~N~ 超过了 M − ε。// 又因为只涨不跌，N 以后的每一项都不小于 a~N~，也就都超过 M − ε；// 而 M 是上界，它们又都不超过 M。// 所以 N 以后：**M − ε ＜ a~n~ ≤ M**，离 M 不到 ε。**证毕。**

### ② ⇒ ③（单调有界 ⇒ 区间套钉住一个点）

BOX[key]: 证明 :: 一串套着的段子，左端点记作 a~1~，a~2~，……，右端点记作 b~1~，b~2~，……// 因为后一段在前一段里面，所以**左端点只涨不跌**，而且都不超过 b~1~。由②，左端点奔向某个数 p。// 同理**右端点只跌不涨**、都不小于 a~1~，奔向某个数 q。（②的"只跌不涨"版本是习题 B5，证法一模一样。）// 而段子长度想多短有多短，所以 p 和 q 之间的距离比任何正数都小——**p 就是 q**。// 这个点被每一段套着。**证毕。**

### ③ ⇒ ⑥（区间套 ⇒ 致密性）

**这一步你已经做过了。**第二篇第六节那个"不停地砍一半"，用的正是③：砍出来的段子一层套一层、越砍越短，于是钉住一个点，那个点就是聚点。

现在你终于知道那一步凭什么了——**凭的就是③，而③来自②，②来自①，①来自小数写法。**一条链子，从头到尾没有断口。

### ③ ⇒ ⑤（区间套 ⇒ 聚点定理）

一模一样的砍法。有界的地方里挤着无限多个点，砍一半，至少一半里还是无限多个点，一直砍下去，钉住的那个点就是聚点。

### ③ ⇒ ④（区间套 ⇒ 有限覆盖）

这一步最漂亮，而且用的还是砍一半。

BOX[key]: 证明（反证法） :: 假设这一段被一堆开集盖住了，但是**怎么挑有限几个都盖不住**。// // **砍一半。**两个半段里，至少有一个也是"挑有限几个盖不住"的——因为要是两半都能用有限几个盖住，把这两批合起来（还是有限几个）就把整段盖住了，和假设矛盾。挑那个坏的半段。// // **一直砍。**得到一串越套越短的坏段子。由③，它们钉住一个点 p。// // **可是 p 也被盖着呀。**盖住 p 的那个开集，按开集的定义，**包含 p 周围的一整个小圈**。// 段子想多短有多短，所以总有某一层的**整段**都躺进了那个小圈里。// 那一层只用**一个**开集就盖住了——一个也是有限个！// 可我们挑的每一层都是"有限几个盖不住"的。**矛盾。**// 所以假设错了：**一定能挑出有限几个。证毕。**

### ⑥ ⇒ ⑦（致密性 ⇒ 柯西准则）

这是最有用的一步：**不用先猜出答案，也能断定极限存在。**

要用到第四篇的两件工具：**三角不等式**（从 A 到 C 不会比"先到 B 再到 C"更远），和**把 ε 掰成两半**。忘了的话翻回去看一眼。

BOX[key]: 证明 :: 设这队数满足柯西条件。// // **第一步：它被困住。**取 ε ＝ 1，有个关口 N；N 以后的项都离 a~N+1~ 不到 1，全挤在一小段里。而 N 以前只有**有限多项**，有限多个数总有最大最小。所以整队被困住。// // **第二步：它有聚点。**由⑥，能挑出一小队奔向某个数 p。// // **第三步：整队都奔向 p。**妹妹给 ε。// 姐姐把 ε **掰成两半**：柯西条件给一个关口 N~1~，使 N~1~ 以后**任意两项**的距离都不到 ε 的一半。// 小队奔向 p，所以小队里总有一项 a~k~（号码 k 比 N~1~ 大）离 p 不到 ε 的一半。// 现在随便取 N~1~ 以后的一项 a~n~。从 a~n~ 到 p，先走到 a~k~ 再走到 p：// 前半段不到 ε 的一半（两项都在 N~1~ 后面），后半段也不到 ε 的一半。// 加起来**不到 ε**。**证毕。**

BOX[remember]: 又是那两个常备动作 :: 这个证明里，第四篇第七节那两个动作**又出现了**：// **取靠后的那个关口**（这次要同时满足柯西条件和子列的要求），// 和**把 ε 掰成两半**（一半留给 a~n~ 到 a~k~，一半留给 a~k~ 到 p）。// 学会这两下，ε–N 证明就没有什么可怕的了。

### ⑧ 和 ① 是一回事

BOX[key]: 两个方向都只有一句话 :: **⑧ ⇒ ①：**要找一堆数的上确界？就在数轴上切一刀：// 左边放"不是上界的数"，右边放"是上界的数"。// 由⑧，切口上正好站着一个数——**它就是最小的上界。**// // **① ⇒ ⑧：**切了一刀以后，左边那堆数有上界（右边随便一个数都是），// 由①它有最小的上界——**那个数就站在切口上。**

## 五、"先证存在，再算是多少"

⑦最值钱的地方，是它**不要求你先猜出答案**。这背后是一个贯穿两册书的**方法**，值得单独说一次。

### 顺序反了会出什么事

第二篇第四节我们用过一招：设和是 S，列个方程解出来。当时提醒过"这只是猜"，还欠下一笔账没还——**这一招什么时候会翻车。**现在有了八条定理，可以还了。

BOX[key]: 不先确认存在，会出人命的 :: 那一招用在 1 + [[1/3]] + [[1/9]] + …… 上，解出 **S ＝ [[3/2]]**，漂亮又好用。// 现在把同一招用到 **1 ＋ 2 ＋ 4 ＋ 8 ＋ ……** 上试试。// 设这个和是 S。把括号外提一个 2：// **S ＝ 1 ＋ 2 × (1 ＋ 2 ＋ 4 ＋ ……) ＝ 1 ＋ 2S**// 解这个方程：**S ＝ −1**。// // 一堆正数加起来，得到 **−1**？// // 方程本身一步没算错。错在**最开始那四个字**：// **"设这个和是 S"——它已经假设了 S 存在。**// 可这一串越加越大，根本没有极限。// **对一个不存在的东西列方程，什么荒唐结论都推得出来。**

错的不是方程，是**顺序**——"设它是 S"这四个字，已经偷偷假设了它存在。第二篇那时候我们手上还没有任何工具能判定"它到底存不存在"，所以只能先记一笔账；**八条定理就是用来还这笔账的**。

BOX[remember]: 正确的顺序 :: **第一步：先证明极限存在。**（常用②单调有界、⑥致密性、⑦柯西准则。）// **第二步：**这时候才可以"两边取极限"，把它的性质推出来。// **顺序反了，第二步就是空中楼阁。**

### 一个漂亮的例子：怎么开平方

想算 √2，有一个又快又老的办法：

CENTER: **a~1~ ＝ 1，　　a~n+1~ ＝ [[a_{n} + 2 ÷ a_{n}|2]]**

（白话：拿手上这个数，和"2 除以它"，取平均。）

算几步看看：

TABLE:
| n | a~n~ | a~n~ 的平方 |
| 1 | 1 | 1 |
| 2 | 1.5 | 2.25 |
| 3 | 1.416666… | 2.006944… |
| 4 | 1.4142156… | 2.0000060… |
| 5 | 1.4142135… | 2.0000000… |

四步就准到小数点后六位——**计算器开平方用的就是这个办法**。

现在的问题是：**它奔向的那个数，凭什么正好是 √2？**

BOX[key]: 第一步 —— 先证它有极限 :: **它只跌不涨**（从第 2 项起）：// 只要 a~n~ 的平方不小于 2，就有 2 ÷ a~n~ ≤ a~n~，取平均只会变小。// **它有下界**：每一项的平方都不小于 2。// （这两句的代数验证见下面的加餐。）// // 只跌不涨 ＋ 有下界 ⇒ 由**②单调有界定理**，// **这队数一定有极限。**记它作 L。

BOX[key]: 第二步 —— 这才轮到算它是多少 :: 既然 L 存在，就可以**对递推式两边取极限**了。// 左边 a~n+1~ 奔向 L；右边 [[a_{n} + 2 ÷ a_{n}|2]] 奔向 [[L + 2 ÷ L|2]]。// 两边相等：// **L ＝ [[L + 2 ÷ L|2]]**// 整理：2L ＝ L ＋ 2 ÷ L，也就是 L ＝ 2 ÷ L，于是 **L × L ＝ 2**。// 再加上每一项都是正的，所以 **L ＝ √2**。**证毕。**

BOX[key]: 这一步为什么是合法的 —— 八条定理真正的底气 :: **正因为有这八条，我们才能放心大胆地做极限**：在一个式子两边同时取极限时，用不着提心吊胆"左边是个极限、右边却早已不成立"——完备性事先担保了两边都存在，这一步才站得住。// // 没有这个担保，"两边取极限"就是 1 ＋ 2 ＋ 4 ＋ 8 那个笑话。

BOX[remember]: 请把两步的分工看清楚 :: **第一步（②）只说"它存在"，一个字也没说它是几。**// **第二步才把它是几解出来**——而且用的是最省事的办法：列个方程。

BOX[task]: 加餐：把第一步的两句话验一验 :: **（甲）每一项的平方都不小于 2。**// 提示：对任何两个正数 x、y，都有 (x − y)^2^ ≥ 0，展开就得到 (x ＋ y)^2^ ≥ 4xy。// 取 x ＝ a~n~、y ＝ 2 ÷ a~n~，这时 xy ＝ 2，于是 (x ＋ y)^2^ ≥ 8。// 两边除以 4，正好是 a~n+1~ 的平方不小于 2。// **（乙）从第 2 项起只跌不涨。**// 提示：a~n+1~ ≤ a~n~ 等价于 2 ÷ a~n~ ≤ a~n~，也就是 a~n~ 的平方不小于 2 —— 甲已经给了。

BOX[key]: 为什么这是高等数学最要紧的习惯之一 :: 小学到中学，"求极限"总是**先算出一个数**。// 可越往上走，越多的东西**根本算不出闭合的式子**——// 圆周率、e、大多数积分、大多数微分方程的解，都是如此。// **数学的办法是：先证明它存在，给它起个名字，再去研究它的性质。**// 八大定理的全部用处就在这里：// **它们从不告诉你答案是多少，只告诉你答案存在。**// 而很多时候，**"存在"就已经够用了。**

## 六、这一圈说明了什么


我们走了这么一条链：

CENTER: **小数写法 ⇒ ① ⇒ ② ⇒ ③ ⇒ ④、⑤、⑥ ⇒ ⑦**，而且 **① 和 ⑧ 互通**

BOX[key]: 要诚实：我们证了什么，没证什么 :: **证了的：**从小数写法出发，①成立；并且①一路推出了其余七个。// **没证的：**要说它们**互相**等价（任意一个都能推回其余），还需要把箭头反过来再走一遍。// 那些反向的证明大多不难，但很啰嗦，这一册不写。// 我们只给了⑧⇒①这一个反向的例子，让你看见"互相"是什么意思。// **知道自己证到了哪一步，比多背两个定理重要。**

那么，这件事为什么值得大惊小怪？

BOX[remember]: 因为它把八件事变成了一件事 :: 你不需要分别相信八条道理。// **你只需要相信一条**——数轴上没有洞——剩下七条白送。// 而"数轴上没有洞"，第三篇已经告诉你它是从哪来的：// **是我们规定"实数就是无限小数"的那一刻，一起买下来的。**

CENTER: 从第一篇到这里，我们其实一直在做同一件事：

CENTER: **把一个做不完的过程，换成一串做得完的承诺。**

CENTER: 极限是这样，无限小数是这样，砍一半也是这样。
