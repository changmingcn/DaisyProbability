# 第五篇　同一件事的八种说法

CENTER: 仙女八姐妹：八个名字，八样拿手活，说的却是同一句话——数轴上没有洞

第三篇我们约定：**实数就是无限小数**。这个约定把数造了出来，可要是从此**拿"写法"当家底**，麻烦跟着就来：

- **假句子案**：有人写下"**0.333…的后面再补一个 4**"拿给我们，我们还得先花功夫说明这个写法是错的——它说的是**先把 3 循环无穷次，循环完了再写一个 4**；可"循环完了"这四个字本身就做不到，那个 4 也就没有位置可站。麻烦在于**初看很难看出来**，就像 2 月 30 日，月、日俱全，日历上偏偏没有这天。要是不小心收下它，后面全得跟着错。
- **重名案**：0.999… ＝ 1，一个数，有两种写法（第一篇证过）。这就像你请**鲁迅**先生吃饭，门口来了位**周树人**先生——那正是鲁迅的本名，你却拦着不让进，岂不是闹了大笑话？
- **错读案**："0.35 比 0.4 大，因为 35 比 4 大"——拿整数的规矩去读小数。

这样的麻烦无穷无尽，更让人不安的是：**保不齐有些错误的写法，我们根本没认出来。**还有一件更大的麻烦：要是哪条定理的证明里写着"**看这个数的第七位**"，那哪天换一种造实数的办法（长大以后你会见到，真有别的造法），这条定理连同它后面整套书的推论，就得**从头重修一遍**。

**而最伤的一案还不在写法上。**前三案不过是名字取得不好，这一案伤的是**你早就会做的事**：请把 0.333… 和 0.777… 加起来。

竖式加法是**从最右边一位开始**的，可这两个数没有最右边那一位——这件事第三篇第五节说过了。那**从左往右**呢？

BOX[dialog]: 一位一位往下加，加得下去吗 :: **妹妹：**"那就从左边加。第一位，3 加 7 得 10——我写下 0，往前进一位。"// **姐姐：**"再看第二位。3 加 7 还是得 10，又得往前进一位——**进到你刚写下的那个 0 上头，它变成 1 了。**"// **妹妹：**"那我把它改成 1。"// **姐姐：**"第三位又是 10，又要进位，**这回改的是第二位**。你每写下一位，下一位就回过头来改它——**而'下一位'是没有尽头的。**"

所以这条路上，**没有哪一位是定得下来的**：你写下的每一位，都可能被后面的进位改掉，而"后面"永远还有。第三篇说的是**从右往左走不通**（没有起点），这里说的是**从左往右也走不通**（没有一位能收工）。**两头都堵死了。**

那还有一条路：这两个数都是循环小数，先化成分数——0.333… 是 [[1/3]]，0.777… 是 [[7/9]]，加起来是 [[10/9]]，除出来正好 1.111…。

**可这扇门只对循环小数开着。**π 加上"自己乘自己等于 2 的那个数"，两个都不是分数，**化不过去**。

CENTER: **连加法都撑不住，这样的家底不能要。**

于是有一个想法：**能不能不揪着写法不放，而是找出实数最本质的几条性质——从此推理和证明，只许引用这几条？**

就像办生日聚会，担心小伙伴拿不拿得动伴手礼。**只需按"五岁以上的孩子都拿得动"去挑礼物**，不必把名单从 A 到 Z 问一遍：Ada 拿得动吗？Bella 拿得动吗？……一路问到 Zoe。**对一条性质说一句话，顶得上把整张名单问一遍。**换造法也一样：新造法只需过一场**入学考**——验它满足这几条性质——**全部学分自动承认**，一条定理都不用重修。

这一篇干的就是这件事。实数最本质的性质有**两条**，第三篇都已经露过脸：**第一条，谁大谁小说得清**（第三篇第五节）；**第二条，数轴上没有洞**（第三篇第七节）。第一条分数也有，第二条分数没有——所以真正要费力气说清楚的，是第二条。它的说法至少有八种，而且**全都是同一件事**——任意一个成立，其余七个都跟着成立。这在数学里有个说法，叫**等价**。而小数写法在这一篇只出场**一次**：第三节用它一位一位把第②条证出来——那就是小数这个造法自己的**入学考**。从第四节起，定理的证明**再也不看第几位是几**，只引用这八条。

**先铺一条街。**这一篇通篇用一个画面：把数轴想成一条**铺满砖的长街**——"没有洞"，就是**砖缝里掉不下任何东西**。分数街就不是这样，它处处有裂缝：第四篇你见过一队数，每一项都是分数，它们挤向的那个位置上，分数街**什么都没有**。

那么，这几条最本质的性质，到底长什么样？

先数一数手上有什么：**就两条**——**谁大谁小说得清**、**数轴上没有洞**。往后所有的推理，只许用这两条。

可眼下它们还只是两句白话，**没法拿去检验谁**。要把它们**较真地写下来**，能用的材料就这么多：

- 第一条给的是**说话用的词**——谁在左边、谁在右边、谁比谁小。除了这些词，我们没有别的可用。
- 第二条要断的是**一件事**——该有数的地方，真的有数。

**那就只剩一条路可走：拿第一条的词，去把第二条说出来。**

照这条路写出来的那句话，有个名字，也有个人。**她不是八条里随便挑出来的一个——她就是那两条性质较真写下来的样子。**

**现在请出第一位。**

CENTER: **① 戴德金分割**

名字很唬人，本事却只有一样——**她只会一个法术**：

在数轴上随手一刀切下去，左边一堆、右边一堆，**左边每个数都比右边的小**。她说：

CENTER: **切口上正好站着一个数。**

就这一句话，再没别的了。刀刃落在砖上，掉不进缝里——**这就是"没有洞"最直白的一种说法**。我们给这个法术起个名字，叫**切一刀**。

**回头数一数她用了哪些词**：左边、右边、谁比谁小——**全是第一条给的**；而她断言的那件事——切口上站着一个数——**正是第二条**。**一个多余的字也没有。**这就是刚才说的"较真写下来的样子"。

BOX[dialog]: 就这一下？ :: **妹妹：**"绕了这么老半天，就换来这么一句话？"// **姐姐：**"先别急着嫌少。你看看这一句话能兑现多少东西。"

**她能办的第一件事：把前面几篇欠的账，一次结清。**

前面几篇里，凡是我们说过"**挤向的那个位置上真有一个数**"的地方，靠的都是这一条。最典型的一处在**第二篇第六节**：证**被困在一段里的数列至少有一个聚点**，砍到最后那句"这些段子越套越小，最后正好钉住一个点"——当时只能说画出来一目了然，**现在它有了根据**。ε–N 那套语言本来就没毛病，一直缺的就是这一句：**挤到的地方，真有东西在。**

**她能办的第二件事：反着来。**

别的性质都只会**检查**一条已经铺好的街；这一位**反过来读，就成了铺街的办法**——**要说清楚一个数是谁，就说清楚这一刀切在哪。**比如"自己乘自己等于 2 的那个数"：左堆放所有自己乘自己小于 2 的，右堆放剩下的。这一刀比划完，那个数就说清楚了——**它就是切口上站着的那一个**。从头到尾一个小数位都没提。

（①在这一册的来路，第三节和第四节会交代：先用小数写法把第②条证出来，再看出②和①其实是一回事。**眼下先把这一刀记住：刀落在砖上，不落在缝里——"数轴上没有洞"，说的就是这件事。**）

**而她不是一个人来的。**

CENTER: **同一件事，还有另外七种说法。**

八条彼此等价——**任意一条成立，其余七条都跟着成立**。这一篇往后就管这八条叫**「仙女八姐妹」**：**同一个来历**（就是那两条性质），**长相各不相同**，而且**各有各的拿手活**。刚才请出来的这一位，是仙女八姐妹里的**大姐**——往后我们就叫她**大仙女**。

八位里，有的最合用来对付一队越涨越高的数（比如③——**只涨不跌、又始终不越过某个数，就一定有极限**）；有的合用来对付一段套一段；有的合用来对付挤成一团的点。

CENTER: **八位说的是同一件事；可真要办事的时候，你得挑对人。**

还有一句要紧的话，先说在前头：**说是"法术"，可她们一点也不神。**这八位的本事**不是变出来的，是证出来的**——第三节先请出大仙女的二妹，当着你的面把她的本事从小数写法一位一位造出来；第四节再由她一个接一个把其余六位请到场。**看完那两节你会发现：这八位从头到尾，没有一样东西是白给的。**

**要证一件事的时候，就从仙女八姐妹里挑最合手的那一位来帮忙。**（别和姐姐妹妹搞混了：**仙女八姐妹是这八条定理**，姐姐妹妹还是那两个人。）

**全家福在第二节，八位一起亮相。**

### 费这么大劲，到底换来了什么

绕了这么一大圈——先说"别揪着写法不放"，再摆出两条性质，又请出一把切一刀。**值不值？**

下面四件事，你现在当场就办得成。**以前要么办不成，要么得费大得多的劲。**

**其一：省了什么——一桩旧案，三行结掉。**

篇首那桩**重名案**：0.999… 和 1 是不是同一个数？第一篇是**数着位**证出来的。现在换个办法：

- 0.999… 的第 n 个截断是 0.99…9，离 1 差 [[1|10^n]]。所以 1 和 0.999… 之间的距离，**比任何正数都小**。
- 而**比任何正数都小的距离只能是 0**（第三篇第五节那句，我们早就给它起过名字）。
- 距离是 0，那就是同一个数。**完了。**

**从头到尾一个数位都没数。**写法上那些麻烦——有多少个 9、循环完了还能不能再写——**压根没进这个证明**。

**其二：以后还得再来一遍吗——你亲手发一张学分。**

篇首许过一个愿：换一种造实数的办法，只要它过得了入学考，**前面的证明一个字都不用改**。那时候还只是句空话。可你手上刚刚就多了一种新造法——**切一刀**。**当场考它。**

- **第一条，谁大谁小说得清吗？**说得清：**谁的左堆装得更多，谁就更大。**
- **第二条，数轴上没有洞吗？**要验的是——拿这些用刀定出来的数**再切一刀**，切口上还站着一个数吗？**站着**：把左边那些数各自的左堆**全倒在一起**，倒出来的还是一个左堆，它定出来的那个数，正好站在新刀口上。

两条都过了。**于是前面每一篇里的证明，对"切一刀"造出来的数，一个字都不用改。**

请体会这件事的分量：那些证明当初是**盯着小数写法**做出来的，可它们从头到尾只用了那两条——**所以它们根本不在乎数是怎么造出来的**。**辛苦一次，一劳永逸。**（这场入学考我们是**比划着**办的；真要一板一眼地验，得从分数出发重来一遍，那是长大以后的事。）

**其三：一件工具，连开两把锁。**

就说③这一件——只涨不跌、又始终不越过某个数，那就一定有极限。刚才你已经拿它开了一把锁：

**篇首那道加法。**照第三篇第五节那个办法——**截到第 n 位相加**，再让 n 越来越大——得到 1.0，1.10，1.110，1.1110，……　这队数**只涨不跌**，又**始终不超过 2**（两个数都不到 1）。由③，**它一定挤得到一个数**。第三篇当时只教了这个办法，可没说它一定挤得到；**以前你只能相信，现在你证得出来。**

同一句话，转身就开第二把锁：

第三篇第二节，为了说清 1，1.4，1.41，1.414，…… 真的**挤得到一个数**，那里造队、报关口、写 **ε–N**，从头到尾都在数位上打转。现在只要：这队数**只涨不跌**，又**始终不超过 2**（每一项自己乘自己都不到 2，所以每一项都不到 1.5）。由③，**它一定有极限**。三行。

（说清楚：③只给你"**有**极限"；那个极限**自己乘自己等于 2**，还得另证。**可"存在"这一半，以前花掉了整整一节。**）

**一件工具，两把锁，而且第二把上一个数位都没看**——这正是篇首说的：从第四节起，证明再也不看第几位是几。

**其四：它防住了什么——你的直觉会骗你。**

BOX[dialog]: 密，就等于没有洞吗 :: **妹妹：**"可分数明明密密麻麻啊——随便挑两个分数，中间还塞得下无数个分数。这么密，凭什么说它有洞？"// **姐姐：**"因为**密**和**没有洞**根本是两句话。**密**说的是：两个数中间还有数。**没有洞**说的是：一队越挤越拢的数，挤得到一个数身上。分数街**过头一条，不过第二条**。"

证据就在手边：1，1.4，1.41，1.414，……**每一项都是分数，两两之间还塞得下无数个分数——可它们挤向的那个地方，一个分数也没有。**（第三篇那张"三次搬家"的图，第二行画的正是这件事：点密得看不见缝，偏偏那两个位置是空的。）

**这就是费这么大劲最要紧的理由：光凭"感觉挺密的"，感觉会骗你。**把话说到那两条上，才骗不了。

BOX[remember]: 四件事，四样好处 :: **省事**——旧案一个位都不用数，三行结掉。// **一劳永逸**——换一种造法，验两条，前面全部学分自动承认。// **一件工具反复用**——③开了两把锁，还把第三篇那一整节压成三行。// **不被直觉骗**——"挤得密"不等于"没有洞"，这件事只有把话说准了才分得清。// // 四件事用的都是那两条性质。// **这就是为什么值得费这么大劲：力气花在地基上，上面盖什么楼都省。**

## 一、先备几个词

下面八句话里会用到几个点集的说法。都很朴素，一个一个来。
### 邻域

FIG: fig-09-neighborhood.png | 妹妹的误差圈换个正式名字，就叫邻域。

一个点 p 的**邻域**，就是"离 p 不超过某个距离"的所有点凑成的那一小段。第一篇的误差圈，正式名字就是它。

### 开集与闭集

只需要最短的说法：

- **开集**：这片地里每一个点，都能在自己周围画一个小圈，整个圈还在这片地里面。（比如"比 0 大、比 1 小的所有数"。）
- **闭集**：这片地**装得下自己所有的聚点**——一个不漏。（比如"从 0 到 1，两头都要"。）

FIG: fig-11-open-closed.png | 边界线算不算自己的，就是这两者的区别。

BOX[remember]: 闭集最有用的一句话 :: **在闭集里挑一队数，只要它有极限，这个极限还在这个闭集里。**// 跑不出去——这就是"闭"字的意思。

### 区间套

一段套着一段，**后一段整个在前一段里面**，而且**长度越来越短，想多短有多短**——这样一串段子，叫一个**区间套**。还有一条不起眼、却少不了的要求：**每一段都两头都要**（这四个字不是摆设，第七节 A3 会让你看见去掉它有多糟）。第二篇第六节砍出来的那一串，就是区间套；第三篇第二节 √2 那一队小数**关住的那些格子**，也是。

### 开覆盖

拿一堆开集，把一片地**严严实实盖住**（每个点至少被某一个盖着），这堆开集就叫这片地的一个**开覆盖**。堆里可以有无限多个。

FIG: fig-14-compactness.png | 上：妹妹扔下无限多个圈，盖住了整段。下：姐姐只挑出 6 个，照样盖得住。

BOX[task]: 小练习：这几个词，摆一摆就懂 :: **（1）**下面各是开集、闭集、两者都是、还是两者都不是？// 　比 0 大比 1 小的数　／　从 0 到 1 两头都要　／　只有 0 这一个点　／　所有整数　／　整条数轴　／　什么都不含的空集// **（2）**上题里"只有 0 这一个点"和"所有整数"，各有聚点吗？// **（3）**把 1、[[1|2]]、[[1|3]]、[[1|4]]…… 这些点凑成一堆。它是闭集吗？**再添上哪一个点**，它就是闭集了？// **（4）**在数轴上造一个区间套，套住 0.5，**至少画 4 层**。（"长度不越来越短会怎样"留到第七节 A3。）// **（5）**给"从 0 到 1，两头都要"造一个开覆盖，**只用 3 个开集**。// **（6）**给"比 0 大、比 1 小"造一个开覆盖，让它**挑不出有限几个**盖得住。// 　（提示：拿这样一串开集——"比 0.1 大比 1 小"、"比 0.01 大比 1 小"、"比 0.001 大比 1 小"……// 　每一个都盖不到最左边那一小截。要是只挑有限几个，其中总有一个最靠左的，// 　它左边就还漏着。**注意⑤要求"两头都要"，这一题正好说明那个要求不是摆设。**）

## 二、八句话


**仙女八姐妹的全家福**——八位一起亮相，先用白话各说一句。名字一个比一个唬人，意思一个比一个朴素。

| ③ 单调有界定理 | 一队数只涨不跌、又始终**不超过某一个实数**（或者只跌不涨、又始终**不小于某一个实数**），那它**一定有极限** | **行军检**：只进不退、前有墙拦，必定抵达某处，不会永远在路上 |
| ④ 区间套定理 | 一段套一段（**每段两头都要**）、越套越短（想多短有多短），那么**有而且只有一个点**被所有段子套住 | **包围检**：包围圈越缩越小，最后恰好圈住一个点 |
| ⑤ 有限覆盖定理 | 无限多个开集盖住一段（**两头的端点也盖住了**），那就用不着这么多——**总能挑出有限几个，照样盖得住** | **撑伞检**：无限把伞盖一段街，挑有限几把照样盖得住 |
| ⑥ 聚点定理 | 有界的一片地方里挤着无限多个点，那**一定有聚点** | **拥挤检**：有限的街段塞进无限多人，必有一处挤爆 |
| ⑦ 致密性定理 | 一队被困住的数，一定能挑出一小队**奔向某个极限** | **突围检**：被围住的无限队伍，总能挑出一支小队齐奔一点 |
| ⑧ 柯西准则 | 一队数有极限，**当且仅当**关口以后任意两项都近——而且是**要多近有多近**（妹妹说多近，姐姐就能给出一个关口） | **收拢检**：队伍自我收拢，脚下必有砖接住——不踩空 |

八条定理，就是给"这条街掉不掉东西"做的**八种体检**——八位各查一样，查的却是同一件事。

FIG: fig-21-eight-theorems.png | 同一条街的八种体检。八个名字，一个内核：砖缝里掉不下任何东西。

其中⑦你已经证过了——就是第二篇第六节那个砍一半。反过来的话同样要紧：**换到分数街，八项体检在同一个位置全部不及格**——裂缝就在"自己乘自己等于 2"那儿，第四篇末尾请你收好的那队分数，就是打穿八条的那颗子弹。现在名单发齐了，第七节 C3 请你亲手打三枪。

BOX[remember]: 八句话，其实是同一句话的八种说法 :: 回头看这张表：**每一句都在用"比大小"的词**——// ①的**左边右边**、②的**上界**和**最小**、③的**只涨不跌**和**不越过**、// ④的**在里面**、⑤⑥的**有界**、⑦的**被困住**、⑧的**近**（也就是差多少）。// **没有第一条性质，这八句话一句也写不出来。**// 而它们断言的是同一件事：**砖缝里掉不下东西**——那就是第二条性质。// **所以：八条定理 ＝ 拿"比大小"这套话，把"没有洞"讲了八遍。**

BOX[remember]: 先看懂⑧为什么最有用 :: 第二篇证过：**有极限 ⇒ 关口以后任意两项都近。**// ⑧说的是**反过来也对**：只要关口以后任意两项都近，这队数就**一定有极限**。// 这句话厉害在哪？// 第一篇说过，极限值要**先猜出来**才能证。// 可⑧让你**不必先猜**——你只要检查这队数自己内部靠不靠拢，就能断定它有极限。// **答案是什么可以以后再说，先确定它存在。**

### 当场反过来办一件：判一队数没有极限

⑧说的是"当且仅当"，所以它**两头都能用**：查出关口以后任意两项都近，就断定有极限；查出**做不到**，就断定没有极限。后一种用法，拿第二篇那个吓一跳的例子当场演一遍：

CENTER: **1，　1+[[1/2]]，　1+[[1/2]]+[[1/3]]，　1+[[1/2]]+[[1/3]]+[[1/4]]，　……**

这一回妹妹不必把 ε 说得很小，她只说一句：**ε ＝ [[1/4]]。**

姐姐不管把关口 N 报在哪儿，妹妹都这么还她一手——**往后再走 N 步，看第 N 项和第 2N 项。**这两项之间夹着的那些块是

CENTER: **[[1|N+1]] ＋ [[1|N+2]] ＋ …… ＋ [[1|2N]]**

一共 **N 块**，而且**每一块都不小于 [[1|2N]]**（分母最大的就是最后那一块）。N 块加起来，**至少是 [[1/2]]**。

[[1/2]] 比 [[1/4]] 大。所以不管关口报在哪儿，后面总找得出两项，**距离超过妹妹要的那个 ε**。柯西条件不成立，由⑧，**这队数没有极限。**

BOX[remember]: 反着用，也是同一条定理 :: ⑧是一句"当且仅当"，**两个方向都是它**：// **正着用**：任意两项都近 ⇒ 有极限（而且不必先猜出答案）。// **反着用**：找得出一个 ε，任凭关口报在哪儿都有两项越过它 ⇒ 没有极限。// 反着用的时候，妹妹**不必**把 ε 说得多小——她只要说一个**堵得住**的就行。

### 最后单看一眼⑧：它就是我们一直在做的那件事

八个都发齐了。临了单看一眼**⑧**——因为它说的，正是**我们从第一篇就一直在做的事**。

第一篇：摆一队数，报关口，让它越挤越拢。第二篇：把**越挤越拢**写成柯西条件。两篇的力气全花在这上头，可当时始终没有人回答一句——**挤到最后，那儿真有一个数吗？**

⑧回答的就是这一句：**一队数只要自己越挤越拢，它就一定挤得到一个数身上。**

CENTER: **我们前面所有的"逼近"，⑧就是给它们的担保。**

而它跟①一样，也能**反过来读**，当造法使。

先把话说在前头，免得会错意：**这不是说非要两条一起才行。**⑧是**另一条路**——走①那条到得了，走⑧这条也到得了。篇首那四件好处，**靠的全是①这一条**，①一种就够用了。

也反过来读：**要说清楚一个数是谁，就摆出一队分数、说清楚它们怎么挤。**还是那个数——1，1.4，1.41，1.414，……这队分数越挤越拢，它挤向的那个东西，就是它。

到这里，那两条本质性质**各干一件事，缺一样都不成**：

- **没有洞**，这队数才保证挤得到一个东西上头——分数街上就挤空了，第三篇第二节那个洞就在那儿；
- **谁大谁小说得清**，你才判得出两队分数**挤向的是不是同一个**。不然同一个数会有一堆说法，谁也不知道它们说的是不是一回事。

BOX[remember]: 一刀，和一队，说的是同一件事 :: 这两种办法**互相造得出来**——// **给你一刀，我摆得出一队**：左堆里往上找、右堆里往下找，两边一步步逼向刀口，那就是一队越挤越拢的数。// **给你一队，我切得出一刀**：把**队伍走到后来就甩在身后的那些数**放左堆，其余的放右堆——刀口正好落在这队数挤向的地方。// 所以它们不是两样东西，是**同一个位置的两种说法**。// // 请特别当心一件事：**这两种造法不是"两条都得成立"的性质，而是两条通往同一个地方的路。**// 挑一条走就行——上面那四件好处，就是只走①那一条走出来的。// **这正是这一篇的主题：同一件事，换一种说法。**

FIG: fig-34-cut-and-squeeze.png | 一刀和一队，落在同一个位置上。上面是切一刀：左右两堆，刀口在中间；下面是挤一队：一队分数从两侧越挤越拢。两样说的是同一个数。

BOX[remember]: 篇首那道加法，到这里不难了 :: 回头看篇首那道 0.333… ＋ 0.777…。// 其三里我们已经用③断定那队截断和**挤得到**一个数；现在换"挤一队"的眼光再看一遍——// 它一点也不为难：// 拿 0.3，0.33，0.333，…… 和 0.7，0.77，0.777，……　**一项一项对着加**——// 每一项都是有限小数，加它们用的就是你三年级的竖式，**一次进位的麻烦都没有**。// 得到 1.0，1.10，1.110，1.1110，……　这队数挤向 **1.111…**。// // 为什么不为难？因为这条路上**从头到尾没有"第几位是几"这回事**。// **进位的麻烦是写法带来的；换掉写法，麻烦就跟着走了。**// // 而第三篇第五节当时说，唯一的办法是"**截到第 n 位相加，再让 n 越来越大**"——// 那时候它像个应急的土办法。现在你看见了：**它就是"挤一队"，是一种造实数的正经办法。**

BOX[grown]: 这两种造法的大名 :: 用**切一刀**造实数，叫**戴德金分割**；用**挤一队**造实数，叫**柯西列**——严格做法还要把"挤向同一个地方的两队"算成同一个数，这一步叫**等价类**。// 第三篇用的那个造法叫**十进制构造**。// **这一节只让你看见两种说法对得上**：真正的造法是**从分数出发**、不许预设那个数已经在那儿，而这里我们是站在已经铺好的街上比划的。// 三条路造出来的是同一样东西——**证明这件事，是长大以后的事。**

## 三、先把第②个证出来


八个里得先站稳一个。我们选②，因为**用第三篇的小数写法，它能一位一位地造出来**。

（这也正好回答第三篇的习题 C4：妹妹问"上界有无穷多个，凭什么保证里面有一个最小的"。）

BOX[key]: 造一个最小的上界 :: 给一堆数（不空，有上界）。我们一位一位把它的上确界写出来。// // **整数位。**把整数一个个看过去：太小的整数肯定不是上界（因为这堆数不空，总有数比它大）；太大的整数肯定是上界。// 所以中间有个分界。**a~0~** 就取**最后一个"还不是上界"的整数**。// // **第一位小数。**在 a~0~ 和 a~0~+1 之间有十个刻度。同样地，前面几个还不是上界，后面几个是。// **a~1~** 就取**最后一个"还不是上界"的刻度上的那个数字**。// // **一直下去。**得到一个无限小数 x ＝ a~0~.a~1~a~2~a~3~……// 记住造法给了我们两件事：截到第 n 位的那个数（叫它 x~n~）**不是上界**；而 x~n~ ＋ [[1|10^n]] **是上界**。

造出来了，还得验它真的是"最小的上界"。**两条都要验**，缺一条都不算。

BOX[key]: 验第一条：x 是上界 :: 反证。假如这堆数里有个 s 比 x 大。// 可是 x~n~ ＋ [[1|10^n]] 是上界，所以 s 不超过 x~n~ ＋ [[1|10^n]]。// 而 x~n~ 又不超过 x。所以 **s 不超过 x ＋ [[1|10^n]]**。// 这对**每一个** n 都成立，而 [[1|10^n]] 想多小有多小。// 所以 s 不可能真的比 x 大。**矛盾。**

BOX[key]: 验第二条：比 x 小的都不是上界 :: 取任意一个比 x 小的数 y。// x~n~ 就是 x 砍掉后面几位，n 越大，x~n~ 越接近 x。所以**总有某个 x~n~ 比 y 大**。// 而按造法，x~n~ **不是上界**——也就是说这堆数里有个数超过 x~n~。// 那个数当然也超过 y。// **所以 y 不是上界。**

两条都验过了。**x 就是最小的上界。②证毕。**

### 当场办一件：拿一堆看得见的数走一遍

上面通篇是"一堆数""某个数"，听着空。换一堆摆得出来的：**所有自己乘自己小于 3 的分数。**照造法一位一位来——

TABLE:
| 报这一位 | 最后一个还不是上界的 | 再往上一格就是上界了 | 于是取这个数字 |
| 整数位 | 1（因为 1.7 就在这堆里，比 1 大） | 2（2 自己乘自己是 4，已经比 3 大了） | 1 |
| 第 1 位 | 1.7（因为 1.73 就在这堆里） | 1.8（1.8 自己乘自己是 3.24） | 7 |
| 第 2 位 | 1.73（因为 1.732 就在这堆里） | 1.74（1.74 自己乘自己是 3.0276） | 3 |

一直报下去，得到 **1.73……**——**这堆分数挡得最紧的那道墙，就这么一位一位造出来了。**

顺便对一眼：第三篇的习题 B1 让你一位一位找过**自己乘自己等于 3**的那个数，找出来的头三位也是 1.73。**同一串数字，造了两回**——那一回造的是**一个数**，这一回造的是**一堆数挡得最紧的那道墙**。造法一模一样，因为要报的本来就是同一个位置。

BOX[key]: 妹妹该挑的一根刺 :: 第三篇立过一条规矩：**不许以无穷多个 9 结尾**。// 可上面这个造法，有时偏偏就会造出一串 9 来。// 你自己试试：拿"所有比 1 小的数"这一堆。// 整数位：0 还不是上界（0.5 比它大），1 是上界，所以 a~0~ ＝ 0。// 第一位：0.9 还不是上界（0.95 比它大），所以 a~1~ ＝ 9。第二位还是 9……// **造出来的是 0.999…，可我们的规矩不许这么写。**// // 这算不算把自己的规矩打破了？// 不算——因为第一篇早就证过 **0.999… ＝ 1**。造法指的位置是对的，只是报名字的方式不合规矩，改写成 1.000… 就行。// **但你能发现这一点，比会背这个证明重要得多。**

BOX[remember]: 这个证明的分量 :: 它不是文字游戏。它说的是：// **"最小的上界一定存在"这件事，是小数写法白送给我们的。**// 换句话说——只要你接受"实数就是无限小数"，就等于接受了"数轴上没有洞"。// 这两件事本来就是一回事。

## 四、把其余七个串起来


站稳了②，剩下的就是接力。每一步都不长。

### ② ⇒ ③（有上确界 ⇒ 单调有界必收敛）

BOX[key]: 证明 :: 设这队数只涨不跌，而且都不超过某条线。// 由②，它们有一个最小的上界 M。姐姐来证这队数奔向 M。// 妹妹给 ε。因为 **M − ε 比 M 小，所以它不是上界**——那就有某一项 a~N~ 超过了 M − ε。// 又因为只涨不跌，N 以后的每一项都不小于 a~N~，也就都超过 M − ε；// 而 M 是上界，它们又都不超过 M。// 所以 N 以后：**M − ε ＜ a~n~ ≤ M**，离 M 不到 ε。**证毕。**// // **那"只跌不涨"的那一半呢？**把每个数都换成它的相反数，整条街左右翻个面：只跌不涨就变成只涨不跌，下界就变成上界，刚才这一段原样套用即可。// **这一招叫"翻个面"——把一件没做过的事，翻成一件已经会做的事。**（自己写一遍是习题 B1。）

### ③ ⇒ ④（单调有界 ⇒ 区间套钉住一个点）

BOX[key]: 证明 :: 一串套着的段子，左端点记作 a~1~，a~2~，……，右端点记作 b~1~，b~2~，……// 因为后一段在前一段里面，所以**左端点只涨不跌**，而且都不超过 b~1~。由③，左端点奔向某个数 p。// 同理**右端点只跌不涨**、都不小于 a~1~，奔向某个数 q。（③本来就把"只跌不涨、有下界"那一半算在内了，证法就是②⇒③末尾那一手"翻个面"。）// 而段子长度想多短有多短，所以 p 和 q 之间的距离比任何正数都小——**p 就是 q**。// 这个点被每一段套着。**证毕。**

### ④ ⇒ ⑦（区间套 ⇒ 致密性）

**这一步你已经做过了。**第二篇第六节那个"不停地砍一半"，用的正是④：砍出来的段子一层套一层、越砍越短，于是钉住一个点，那个点就是聚点。

现在你终于知道那一步凭什么了——**凭的就是④，而④来自③，③来自②，②来自小数写法。**一条链子，从头到尾没有断口。

### ④ ⇒ ⑥（区间套 ⇒ 聚点定理）

一模一样的砍法。有界的地方里挤着无限多个点，砍一半，至少一半里还是无限多个点，一直砍下去，钉住的那个点就是聚点。

### ④ ⇒ ⑤（区间套 ⇒ 有限覆盖）

这一步最漂亮，而且用的还是砍一半。

BOX[key]: 证明（反证法） :: 假设这一段被一堆开集盖住了，但是**怎么挑有限几个都盖不住**。// // **砍一半。**两个半段里，至少有一个也是"挑有限几个盖不住"的——因为要是两半都能用有限几个盖住，把这两批合起来（还是有限几个）就把整段盖住了，和假设矛盾。挑那个坏的半段。// // **一直砍。**得到一串越套越短的坏段子。由④，它们钉住一个点 p。// // **可是 p 也被盖着呀。**盖住 p 的那个开集，按开集的定义，**包含 p 周围的一整个小圈**。// 段子想多短有多短，所以总有某一层的**整段**都躺进了那个小圈里。// 那一层只用**一个**开集就盖住了——一个也是有限个！// 可我们挑的每一层都是"有限几个盖不住"的。**矛盾。**// 所以假设错了：**一定能挑出有限几个。证毕。**

### ⑦ ⇒ ⑧（致密性 ⇒ 柯西准则）

这是最有用的一步：**不用先猜出答案，也能断定极限存在。**

要用到第四篇的两件工具：**三角不等式**（从 A 到 C 不会比"先到 B 再到 C"更远），和**把 ε 掰成两半**。忘了的话翻回去看一眼。

BOX[key]: 证明 :: 设这队数满足柯西条件。// // **第一步：它被困住。**取 ε ＝ 1，有个关口 N；N 以后的项都离 a~N+1~ 不到 1，全挤在一小段里。而 N 以前只有**有限多项**，有限多个数总有最大最小。所以整队被困住。// // **第二步：它有聚点。**由⑦，能挑出一小队奔向某个数 p。// // **第三步：整队都奔向 p。**妹妹给 ε。// 姐姐把 ε **掰成两半**：柯西条件给一个关口 N~1~，使 N~1~ 以后**任意两项**的距离都不到 ε 的一半。// 小队奔向 p，所以小队里总有一项 a~k~（号码 k 比 N~1~ 大）离 p 不到 ε 的一半。// 现在随便取 N~1~ 以后的一项 a~n~。从 a~n~ 到 p，先走到 a~k~ 再走到 p：// 前半段不到 ε 的一半（两项都在 N~1~ 后面），后半段也不到 ε 的一半。// 加起来**不到 ε**。**证毕。**

BOX[remember]: 又是那两个常备动作 :: 这个证明里，第四篇第七节那两个动作**又出现了**：// **取靠后的那个关口**（这次要同时满足柯西条件和子列的要求），// 和**把 ε 掰成两半**（一半留给 a~n~ 到 a~k~，一半留给 a~k~ 到 p）。// 学会这两下，ε–N 证明就没有什么可怕的了。

### ① 和 ② 是一回事

BOX[key]: 两个方向 :: **① ⇒ ②：**要找一堆数的上确界？就在数轴上切一刀：// 左边放"不是上界的数"，右边放"是上界的数"。// **两边都不空**：这堆数不空，所以比它里头随便哪个数还小的数，全在左边；它又有上界，所以右边也站着人。// 由①，切口上正好站着一个数。**它一定属于右边那堆**——// 因为要是它不是上界，这堆数里就有个数比它大，那么它右边紧挨的一小截也都不是上界，切口就不该切在这儿。// 所以它是上界；而比它小的都在左边、都不是上界。**它就是最小的上界。**// // **② ⇒ ①：**切了一刀以后，左边那堆数有上界（右边随便一个数都是），// 由②它有最小的上界——**那个数就站在切口上。**

## 五、"先证存在，再算是多少"

⑧最值钱的地方，是它**不要求你先猜出答案**。这背后是一个贯穿两册书的**方法**，值得单独说一次。

### 顺序反了会出什么事

第二篇第四节我们用过一招：设和是 S，列个方程解出来。当时提醒过"这只是猜"，还欠下一笔账没还——**这一招什么时候会翻车。**现在有了八条定理，可以还了。

BOX[key]: 不先确认存在，会出人命的 :: 那一招用在 1 + [[1/3]] + [[1/9]] + …… 上，解出 **S ＝ [[3/2]]**，漂亮又好用。// 现在把同一招用到 **1 ＋ 2 ＋ 4 ＋ 8 ＋ ……** 上试试。// 设这个和是 S。把括号外提一个 2：// **S ＝ 1 ＋ 2 × (1 ＋ 2 ＋ 4 ＋ ……) ＝ 1 ＋ 2S**// 解这个方程：**S ＝ −1**。// // 一堆正数加起来，得到 **−1**？// // 方程本身一步没算错。错在**最开始那四个字**：// **"设这个和是 S"——它已经假设了 S 存在。**// 可这一串越加越大，根本没有极限。// **对一个不存在的东西列方程，什么荒唐结论都推得出来。**

错的不是方程，是**顺序**——"设它是 S"这四个字，已经偷偷假设了它存在。第二篇那时候我们手上还没有任何工具能判定"它到底存不存在"，所以只能先记一笔账；**八条定理就是用来还这笔账的**。

BOX[remember]: 正确的顺序 :: **第一步：先证明极限存在。**（常用③单调有界、⑦致密性、⑧柯西准则。）// **第二步：**这时候才可以"两边取极限"，把它的性质推出来。// **顺序反了，第二步就是空中楼阁。**

### 一个漂亮的例子：怎么开平方

想算 √2，有一个又快又老的办法：

CENTER: **a~1~ ＝ 1，　　a~n+1~ ＝ [[a_{n} + 2 ÷ a_{n}|2]]**

（白话：拿手上这个数，和"2 除以它"，取平均。）

算几步看看：

TABLE:
| n | a~n~ | a~n~ 的平方 |
| 1 | 1 | 1 |
| 2 | 1.5 | 2.25 |
| 3 | 1.416666… | 2.006944… |
| 4 | 1.4142156… | 2.0000060… |
| 5 | 1.4142135… | 2.0000000… |

四步就准到小数点后六位——**计算器开平方用的就是这个办法**。

现在的问题是：**它奔向的那个数，凭什么正好是 √2？**

BOX[key]: 第一步 —— 先证它有极限 :: **它只跌不涨**（从第 2 项起）：// 只要 a~n~ 的平方不小于 2，就有 2 ÷ a~n~ ≤ a~n~，取平均只会变小。// **它有下界**：每一项的平方都不小于 2。// （这两句的代数验证见下面的加餐。）// // 只跌不涨 ＋ 有下界 ⇒ 由**③单调有界定理**，// **这队数一定有极限。**记它作 L。

BOX[key]: 第二步 —— 这才轮到算它是多少 :: 既然 L 存在，就可以**对递推式两边取极限**了。// 左边 a~n+1~ 奔向 L；右边 [[a_{n} + 2 ÷ a_{n}|2]] 奔向 [[L + 2 ÷ L|2]]。// 两边相等：// **L ＝ [[L + 2 ÷ L|2]]**// 整理：2L ＝ L ＋ 2 ÷ L，也就是 L ＝ 2 ÷ L，于是 **L × L ＝ 2**。// 再加上每一项都是正的，所以 **L ＝ √2**。**证毕。**

BOX[key]: 这一步为什么是合法的 —— 八条定理真正的底气 :: **正因为有这八条，我们才能放心大胆地做极限**：在一个式子两边同时取极限时，用不着提心吊胆"左边是个极限、右边却早已不成立"——完备性事先担保了两边都存在，这一步才站得住。// // 没有这个担保，"两边取极限"就是 1 ＋ 2 ＋ 4 ＋ 8 那个笑话。

BOX[remember]: 请把两步的分工看清楚 :: **第一步（③）只说"它存在"，一个字也没说它是几。**// **第二步才把它是几解出来**——而且用的是最省事的办法：列个方程。

BOX[task]: 加餐：把第一步的两句话验一验 :: **（甲）每一项的平方都不小于 2。**// 提示：对任何两个正数 x、y，都有 (x − y)^2^ ≥ 0，展开就得到 (x ＋ y)^2^ ≥ 4xy。// 取 x ＝ a~n~、y ＝ 2 ÷ a~n~，这时 xy ＝ 2，于是 (x ＋ y)^2^ ≥ 8。// 两边除以 4，正好是 a~n+1~ 的平方不小于 2。// **（乙）从第 2 项起只跌不涨。**// 提示：a~n+1~ ≤ a~n~ 等价于 2 ÷ a~n~ ≤ a~n~，也就是 a~n~ 的平方不小于 2 —— 甲已经给了。

### 这个方法在两册书里出现过多少次

TABLE:
| 在哪 | 先证的"存在" | 然后才推出的"是多少 / 什么性质" |

| 第三篇 二 | 造出小数、ε–N 证收敛 | 它的平方**正好**是 2 |

BOX[key]: 为什么这是高等数学最要紧的习惯之一 :: 小学到中学，"求极限"总是**先算出一个数**。// 可越往上走，越多的东西**根本算不出闭合的式子**——// 圆周率、e、大多数积分、大多数微分方程的解，都是如此。// **数学的办法是：先证明它存在，给它起个名字，再去研究它的性质。**// 八大定理的全部用处就在这里：// **它们从不告诉你答案是多少，只告诉你答案存在。**// 而很多时候，**"存在"就已经够用了。**

BOX[key]: 回头望一眼那块地 :: 上面表里"第二册 八、九篇"那一行，说的正是开篇那块地。// 开篇妹妹猜 [[1/3]] 时，姐姐把话按住："这只是猜。"现在你知道这句话的分量了——不先确认存在就动手算，会捅出本节 1 ＋ 2 ＋ 4 ＋ 8 那样的大娄子。// 那块地会在第二册第八篇拿到"存在"，第九篇结案"是几"。**先证存在，再算是多少——它就是照这个规矩办的。**

## 六、这一圈说明了什么


我们走了这么一条链：

CENTER: **小数写法 ⇒ ② ⇒ ③ ⇒ ④ ⇒ ⑤、⑥、⑦ ⇒ ⑧**，而且 **② 和 ① 互通**

BOX[key]: 要诚实：我们证了什么，没证什么 :: **证了的：**从小数写法出发，②成立；并且②一路推出了其余七个。// **没证的：**要说它们**互相**等价（任意一个都能推回其余），还需要把箭头反过来再走一遍。// 那些反向的证明大多不难，但很啰嗦，这一册不写。// 我们只给了①⇒②这一个反向的例子，让你看见"互相"是什么意思。// **知道自己证到了哪一步，比多背两个定理重要。**

那么，这件事为什么值得大惊小怪？**第二节末尾那四件事，就是这句话的现钱**——省事、一劳永逸、一件工具反复用、不被直觉骗。下面这个盒子，说的是它们背后同一个道理。

BOX[remember]: 因为它把八件事变成了两件事 :: 你不需要分别相信八条道理。// **你只需要相信两条**——**谁大谁小说得清**、**数轴上没有洞**——八条全部白送。// 而这两条，第三篇已经告诉你它们是从哪来的：// **是我们规定"实数就是无限小数"的那一刻，一起买下来的。**// // 还有一件更省心的事：**前面几篇所有的推理，只要用的都是这两条，就跟这八条站在一起。**// 哪天换一种造数的办法（长大以后真会见到别的造法），只要新办法也过得了这两条的入学考，// **前面那些证明一个字都不用改**——这正是篇首说的"全部学分自动承认"。

BOX[remember]: 说清楚一件事：八条一条也没废 :: **两条是地基，八条是工具。**// 说"变成两件事"，说的是**你要相信的东西只有两条**——地基只需要这么多，而且这两条最抽象、也最直接。// 可**干起活来，仙女八姐妹一位都不能少**，各有各最顺手的场合：// 砍一半的时候，你用的是⑦（第二篇第六节）；// 开平方的时候，你用的是③（本篇第五节）；// 想判一队数**没有**极限，你用的是⑧（本篇第二节那件当场办的）；// 想一个小数位都不提就说清一个数，你用的是①（本篇第二节的切一刀）。// **它们不是八条可以扔掉的旧话，是同一句话的八副面孔**——遇上哪种活，就换哪副面孔。


CENTER: 从第一篇到这里，我们其实一直在做同一件事：

CENTER: **把一个做不完的过程，换成一串做得完的承诺。**

CENTER: 极限是这样，无限小数是这样，砍一半也是这样。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 这八条通称**实数完备性的八大定理**（有的书列七条，把⑥⑦合并或不列①）。// 名字：②确界原理（Least Upper Bound Property）· ③单调有界定理 · ④闭区间套定理（Cantor）· ⑤有限覆盖定理（Heine–Borel）· ⑥聚点定理（Weierstrass）· ⑦致密性定理（Bolzano–Weierstrass）· ⑧柯西收敛准则 · ①戴德金分割定理。// ⑤里的性质叫**紧致性**，它是点集拓扑的核心概念之一。// 这八条对**有理数**全部失效——这正是"实数完备而有理数不完备"的准确含义。// 再往前一步就是**度量空间的完备性**和**拓扑空间**，那是大学的事了。

BOX[grown]: 这一手的大名，和一个真实的先例 :: 篇首那个想法——只用最本质的性质推理，不看对象是什么材料造的——大学里叫**公理化**。配套一条唯一性定理：**满足清单的，本质上只有一个**——小数、戴德金分割、柯西列，殊途造出的是同一个实数系。// 人类在数学之外真干过一次这样的换法：**"一千克"曾经是一件东西**——巴黎近郊地窖里那块铂铱合金，全世界的秤都得跟它对表；可东西有怪癖，沾灰、掉屑，一百多年间和它的复制品们漂了约五十微克，逼出一个没法回答的问题："是它变胖了，还是全世界变瘦了？"2019 年起，千克改用**普朗克常数**定义。**千克曾经是一件东西，现在是一条规则——东西会沾灰，规则不会。**// 顺带一提：0.333… 的"循环病"也是写法的毛病——给三分之一换一身三进制（逢三进一）的衣服，它就是干干净净的 0.1。**病随制服走，数从不生病。**// 最后，公理还是妹妹连环炮"凭什么？那这条又凭什么？"的**地板**：追问和计算一样，只能在有限步内完成；答到"这条不证，是桌上的规则"，就到了底——而且**明说了**它是规则，不是含糊过去。// 这一册选小数入学，是为了让你**一位一位亲手造**；亲手造过，你才知道这份清单凭什么可信。
