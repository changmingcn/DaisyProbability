# 给大人的话

学不会高等数学，不是学生不聪明，是教师不聪明。高等数学很多地方本应**一点就破**，那些教师自己没有学明白这一点，所以点不到。

另一个误区（尤其是微积分）是：直觉不能拿来学数学，要用严密的计算和逻辑。**这个想法正好错了。**没有直觉就没有发现；逻辑和计算，只是我们**阐述**直觉的工具。这一册从头到尾都按这个次序走——**直观负责发现，ε–N 负责证明**。

以前缺乏好的学习资料，数学把很多人吓住了，让他们不敢学数学。我知道真正懂数学的人不赞同这个观点，但是他们往往没有时间动手写资料。现在借助 AI，我打算做一件我认为很自然的事情：**教小学生微积分**，而且必须涵盖严整的数学逻辑。

这套笔记分上下两部分。**上部分**就是这一册：从极限的定义出发，把那套因为老师不会教而吓倒了好多学生的误差语言（ε–N，以及它的函数版本 ε–δ）轻松愉快地讲一遍，然后逐步讲到**实数完备性的八大定理**。**下部分**逐渐过渡到微分和积分，最终以**牛顿–莱布尼兹公式**为结尾。

我们将证明，微积分的概念非常轻松简单，小学生都能掌握。当然，为了让小学生听明白，我们做了很大删减。

## 三条取舍

**第一，避开"无理数"这个概念**，把实数定义为有限小数和无限小数。实际上，有理数和无理数本来就是**代数学**中的划分，分析学完全不需要这个分界。小数加上一点点点集拓扑，足以奠定实数完备性的基础——所以这一册不讲拓扑空间、不讲同胚，只留下说清八大定理所必需的几个词：邻域、聚点、开集与闭集、区间套、开覆盖、上下确界。**每一个都必须能指着数轴说清楚。**

**第二，把所研究的函数限定为多项式函数**，包括幂函数，但是不包括指数函数、对数函数和三角函数。说明微积分的基本概念，幂函数足以。（这一条主要约束下部分。）

**第三，有意识地纳入一些对其他领域极其重要的概念。**例如我们将会反复强调"**计算只能在有限步内完成**"，为可计算性理论留一点印象。还有一些东西，我不知道怎么处理，会谨慎地避开，例如"从每一个集合里各挑一个数"。

但是我们不会牺牲数学的严密性。本来这个材料就是为了给孩子打基础，而不是蒙事。即便很多地方我们无法绕过，**也要老实承认，留个口子**。

## 一条暗线："计算只能在有限步内完成"

这句话不是喊一句口号就算数。它在这一册里出现了四次，一次比一次硬——如果只让孩子记住一件事，我希望是这件：

- **第一篇**：极限的整个定义就是为它设计的。妹妹每提一个误差，姐姐只用**一个有限的号码**回答她；**没有任何一步需要做无穷次操作**。
- **第二篇第六节**：砍一半的证明里，真正干活的那句话是"**有限 ＋ 有限还是有限**"。一边说无限、一边说有限，两边一撞，聚点就出来了。
- **第五篇第二节的④**：有限覆盖定理，整条讲的就是"无限多个，能不能换成有限几个"。
- 还有一处是**反着用**的，也最值得说：第二篇砍一半时，我们特意规定"两半都装无限多，就挑左边"。为什么要多此一举立这条规矩？因为不立的话，就得**在无穷多层里每层各挑一个**——那正是上面说的、我们打算谨慎避开的那件事。第二篇习题 C5 专门问了这一点。

为什么我们要向小学生讲述微积分等高等数学的概念？因为小学生学明白了微积分，才会知道自己辛辛苦苦做各种多项式加减乘除、因式分解、变量代换等等**到底是为了什么**。这样，学习这些中小学数学才更有动力，避免陷入无效内卷，尤其不要把时间花在那些无聊的奥数网课上。**远远看一眼天边，才有动力继续走脚下的路。**否则，勤奋地卷各种毫无意义的技巧，盲人骑瞎马、夜半临深池而不自知。

## 两个角色：妹妹出招，姐姐接招

我们设计了两个角色，姐姐和妹妹：**让妹妹来提误差，让姐姐来接招**。

这不是为了可爱。极限定义真正难的地方，从来不是希腊字母，而是那句"**对任意** ε，**存在** N"——先由对方任意提，再由我方针对性地回答。这个"先后顺序"是一切的关键，也是大学一年级最容易翻车的地方。把它写成两个人的一问一答，孩子天然就懂"她先出招、我再接招"，顺序自然就不会倒。所以全书从头到尾，妹妹负责挑剔，姐姐负责证明。凡是"给出一个 N""给出一个 δ""取靠后的那个关口""把 ε 掰成两半"这类**接招的动作**，说话的都是姐姐；正文里的"我们"只做另一件事——**作者带着你一起看**：交代这一册怎么安排、一起观察一个现象、一起承认一件做不到的事。

## 从哪儿开始读

不必从第一页顺读到最后一页。**全书最容易上手的是第二篇第七节那组题**——不要求写证明，只要求摆出一队数、指出聚点在哪，答案具体、能画得出来。孩子如果对 ε–N 发怵，先做那一组会好很多；第五篇第一节末尾那个小练习是同一类。

## 符号怎么处理

TABLE:
| 做的事 | 为什么 |
| 保留 ε、N、δ 和下标 a~n~ | 五年级已经学过"用字母表示数"，字母本身不是障碍。躲开它们，反而让孩子将来读正规教材时要重学一遍 |
| 但每个符号第一次出现，都配一句读法和一张图 | 障碍不在字母，在"这个字母代表谁、是谁说了算" |
| 绝对值和下标各给一个小节，当生字来教 | 这两样确实不在小学课本里，是真的生字，不能默认会 |
| 把"无限次"改写成"对折几次""写几个 3" | [[1|2^n]] 这种写法小学没学过，但"对折 n 次"人人会 |
| 函数极限（ε–δ）降为加餐 | 小学没有函数概念。放在第一篇末尾，想看的再看 |
| 每篇末尾有"长大以后的写法" | 把这一篇的白话，对照成课本上的标准符号 |

## 四种盒子

- 蓝盒子 **必须记住**——这一段是骨头，忘了别的也别忘它。
- 绿盒子 **关键的一步**——证明本身，或者撑起一整节的那句话。**全书用得最多的就是它**，孩子读不动的时候，至少要把绿盒子读完。
- 橙盒子 **留给姐姐 / 留给妹妹 / 习题**——请孩子自己动手的地方，别替她们做。
- 灰盒子 **长大以后的写法**——课本上的标准符号，现在看不懂没关系。

## 一句提醒

这本册子里所有的"证明"，都不要求算得快、算得多。它要求的是另一件事：**把一句"看起来是这样"，换成一句"不管你怎么挑剔，我都能回答"**。如果孩子学会了这一件事，这本册子的任务就完成了，后面所有的数学都会容易很多。
