# 第四篇　ε–N 这套语言，到底有多好用

CENTER: 直观负责发现，ε–N 负责证明

第三篇第二节，我们用 ε–N 证明了 1.4，1.41，1.414…… 收敛到 √2。那不是一次孤零零的表演。

到这里为止，ε–N 已经替我们干了不少活：

- **第一篇**：证明 0.333… 就是 [[1/3]]。
- **第二篇**：证明那队部分和满足柯西条件；还证明了那队混起来的数**没有**极限。
- **第三篇**：证明那队小数收敛到 √2，并且它的平方**确实**是 2。

每一次都是同一个套路：**直观先看出现象，ε–N 负责把它钉死。**

这一篇集中做五个例子。请注意：**每一个的开头都是一句"这还用说吗"的话**——然后我们把它翻译成"不管妹妹怎么挑剔，我都能回答"。

## 一、例一（热身）：[[1|n]] 奔向 0


**直观：**分母越来越大，这个数越来越小，当然奔向 0。

可是"越来越小"并不等于"奔向 0"——第二篇那个吓一跳的例子就是反例：每次加的那一块都越来越小，整队数却涨到比任何数都大。所以**还是得证**。

BOX[key]: ε–N 证明 :: 妹妹给一个 ε。// 关口 **N** 就取**任何一个比 [[1|\varepsilon]] 大的整数**。// 于是只要 n ＞ N，就有 [[1|n]] ＜ [[1|N]] ＜ ε。// **证毕。**// // 试一次：妹妹说 ε ＝ 0.001，[[1|\varepsilon]] 就是 1000，姐姐取 N ＝ 1001。// 第 1001 个往后的每一项，都比 0.001 小。

BOX[remember]: 这里悄悄用了一件事 :: "总能找到一个比 [[1|\varepsilon]] 大的整数"——// 也就是说，**整数要多大有多大，没有上限**。// 这件事看着理所当然，它其实也有个名字，// 但这一册就当它显然，不深究。

## 二、例二：夹逼定理——直观最强，也最该被翻译


**直观：**一队数被两个都奔向 L 的队伍夹在中间，它想跑也跑不掉。

FIG: fig-23-squeeze.png | 上下两队都奔向 L，夹在中间的那队没有别的地方可去。

这句话谁都同意。可"想跑也跑不掉"是**一句感想，不是一个证明**。妹妹完全可以问："跑不掉？你怎么知道？"

翻译过来是这样：

BOX[remember]: 夹逼定理 :: 如果每一项都满足 a~n~ ≤ b~n~ ≤ c~n~，// 而且 a~n~ 奔向 L，c~n~ 也奔向 L，// 那么 **b~n~ 也奔向 L**。

BOX[key]: ε–N 证明 :: 妹妹给一个 ε。// 因为 a~n~ 奔向 L，它给姐姐一个关口 N~1~：n ＞ N~1~ 时，a~n~ ＞ L − ε。// 因为 c~n~ 奔向 L，它给姐姐另一个关口 N~2~：n ＞ N~2~ 时，c~n~ ＜ L + ε。// **取 N ＝ N~1~ 和 N~2~ 里靠后的那一个。**// 这样一来，只要 n ＞ N，两句话就同时成立：// **L − ε ＜ a~n~ ≤ b~n~ ≤ c~n~ ＜ L + ε**// 中间那个 b~n~ 被两头堵死了，离 L 不到 ε。**证毕。**// // 试一次：取 a~n~ ＝ 0（一直是 0），c~n~ ＝ [[1|n]]，中间夹着的 b~n~ ＝ [[1|n\times n]]。// 妹妹说 ε ＝ 0.01。下面那队一直是 0，哪个关口都行；上面那队要等 [[1|n]] 比 0.01 小，得到第 100 项以后。// **姐姐取靠后的那一个：N ＝ 100。**

BOX[remember]: 记住这个动作：取靠后的那个关口 :: 妹妹只提**一次**要求，姐姐却常常要向**好几个人**要关口。// 拿到几个以后，取**最靠后**的那一个，所有条件就能同时成立。// **它是 ε–N 证明里最常见的一步**——第七节有它出现过的全部地方。

马上用一次：第二篇第五节那道题里，每个 a~n~ 夹在 0 和 [[1|2^n]] 之间。0 一直是 0（当然奔向 0），[[1|2^n]] 也奔向 0，所以 **a~n~ 奔向 0**——一句话就完了。

## 三、例三：两队数加起来，极限也加起来


**直观：**两边都稳定了，加起来当然也稳定。

先要一个小工具：

BOX[remember]: 三角不等式 :: 从 A 走到 C，**不会比"先到 B、再到 C"更远**。// 也就是说：从 A 到 C 的距离，不会超过"A 到 B"加上"B 到 C"。// 写成符号就是 **| A − C | ≤ | A − B | ＋ | B − C |**。// 道理就是"两点之间直线最短"。名字叫**三角不等式**。

BOX[key]: ε–N 证明 :: 设 a~n~ 奔向 A，b~n~ 奔向 B。要证 a~n~ + b~n~ 奔向 A + B。// 妹妹给一个 ε。这次姐姐**把 ε 掰成两半**：// 因为 a~n~ 奔向 A，有关口 N~1~：n ＞ N~1~ 时 **| a~n~ − A | ＜ [[\varepsilon|2]]**。// 因为 b~n~ 奔向 B，有关口 N~2~：n ＞ N~2~ 时 **| b~n~ − B | ＜ [[\varepsilon|2]]**。// 取靠后的那个关口。过了它以后，按三角不等式：// **| (a~n~ ＋ b~n~) − (A ＋ B) | ≤ | a~n~ − A | ＋ | b~n~ − B | ＜ [[\varepsilon|2]] ＋ [[\varepsilon|2]] ＝ ε**// **证毕。**// // 试一次：取 a~n~ ＝ [[1|n]]（奔向 0），b~n~ ＝ 2 − [[1|2^n]]（奔向 2）。妹妹说 ε ＝ 0.02。// 姐姐把它掰成两半，两边各要 0.01：a~n~ 那边要等到第 100 项；b~n~ 那边对折 7 次就够了（[[1|128]] 已经比 0.01 小）。// 两个关口差着十几倍——**姐姐取靠后的那一个：N ＝ 100。**// 从第 100 项往后，两个加起来离 2 不到 0.02。

BOX[remember]: 记住这个动作：把 ε 掰成两半 :: 要证一段路不到 ε，就把它拆成两截，每截各证不到 ε 的一半。// 这一招和"取靠后的关口"一样，是 ε–N 证明的常备动作——第七节一起索引。

## 四、例四：直观会骗人的地方


前三个例子里，直观和 ε–N 说的是一回事。现在看一个**它们打架**的例子。

**问：**一队数，每一项都**严格大于 0**。那它的极限，也一定严格大于 0 吗？

**直观说：**当然啦，全都是正数嘛。

**ε–N 说：不。**

反例就是例一那队数：[[1|n]]。每一项都比 0 大，一个都不等于 0。可它的极限**恰恰就是 0**。

BOX[key]: 所以要记住 :: 取极限以后，**"＜" 会退化成 "≤"**。// 每一项都大于 0，只能推出极限大于**或者等于** 0。// 那个"或者等于"是甩不掉的。

BOX[remember]: 这就是这套语言的价值 :: 直观分不清"大于"和"大于等于"这一点点差别，ε–N 分得清。// 凡是直观和严格语言打架，**赢的一定是严格语言**——// 因为直观说的是"我觉得"，// 而 ε–N 说的是"**不管你怎么挑剔，我都能回答**"。

## 五、例五：有极限的队伍，一定被困住

**直观：**一队数既然都奔向同一个地方，当然不会跑得漫无边际。

这句话下一篇要用，所以现在把它证掉。

BOX[key]: ε–N 证明 :: 设这队数奔向 L。// 这一次**姐姐自己挑 ε**——就取 ε ＝ 1。// 于是有一个关口 N：n ＞ N 时，每一项都离 L 不到 1，// 也就是全都挤在 L 左右各 1 的那一小段里。// 关口**以前**呢？只有 a~1~ 到 a~N~ 这**有限多**项，// 有限多个数总有最大的、也总有最小的。// 把这两拨合起来取最大最小，整队数就被夹住了。**证毕。**

BOX[remember]: 注意这里的新动作 :: 前面几个例子都是**妹妹给 ε，姐姐回答**。// 这一次反过来了：**姐姐自己挑了一个 ε**（挑了 1）——**第一篇第五节末尾那次已经这么干过一回。**// 定义说"对任意 ε 都成立"，那当然也包括姐姐随手挑的那个。// **"对任意"意味着姐姐可以任意取用**——这是 ε–N 定义的另一半好处。// 第五篇证柯西准则时，第一步用的就是这一招。

## 六、换个眼光：取极限本身是一种运算

回头看这五个例子，会发现它们其实在回答**同一个问题**。要看出来，先换个说法。

BOX[key]: 取极限，是一台机器 :: 加、减、乘、除都是**运算**：投进去数，吐出来数。// **取极限也是一种运算**——只不过它投进去的不是一个数，是**一整队数**：// // 一队数 a~1~、a~2~、a~3~…… ——**投进取极限这台机器**——→ 一个数 L// // 这台机器有个现成的名字，写作 **lim**（"极限"的英文头三个字母）。// **lim a~n~ ＝ L**，读作"a~n~ 的极限等于 L"。

既然它是一种运算，就得回答**所有运算都要回答的那个问题**：

CENTER: **它和别的运算，能不能换次序？**

FIG: fig-24-commute.png | 左边：先加再取极限，和先取极限再加，走到同一个地方。右边：换成"＞"，这条路就断了。

### 先加再取极限，和先取极限再加，一样吗？

看图的左半边。从左上角出发有两条路：

- **上面走**：先把两队数加起来，再取极限。
- **左边走**：先各自取极限，再把两个数加起来。

**例三证的就是这两条路殊途同归**——所以那个方框里可以打勾。

### 换成"＞"呢？

看图的右半边。**例四证的是：这条路断了。**

每一项都 a~n~ ＞ 0，先比大小是成立的；可**先取极限**再比，就只剩下 **A ≥ 0**。严格不等号**过不了取极限这一关**。

BOX[remember]: 于是五个例子各归其位 :: **例一**：先算一台最简单的机器，热身。// **例二（夹逼）**：**"≤" 能过关**——三队数的夹关系，取完极限还在。// **例三（和）**：**"＋" 能过关**。// **例四**：**"＞" 过不了关**，只能退化成 "≥"。// **例五（有界）**：取极限之前就断定得了的性质。// // 这一篇从头到尾在做的，就是**一条一条地验：哪些运算能穿过 lim，哪些不能。**

BOX[key]: 所以每一条都得单独证 :: 取极限是一台**很温和**的机器：加、减、乘、除、"≤" 都能安然穿过它。// 但它**不是万能通行证**——严格不等号就过不去。// 越往高处走，过不去的东西越多（大学里会遇到"求导"和"取极限"换不了次序的例子）。// **"能不能换次序"，永远得单独问一次、单独证一次。**

### 最要命的一次：连"是分数"都过不了关

前两次"过不了关"，取极限只是**削弱**了性质——"＞"退成了"≥"，好歹还剩点东西。

现在看一次**性质整个没了**的。

回到第三篇第二节那队数：

CENTER: **1，　1.4，　1.41，　1.414，　1.4142，　……**

- **每一项都是分数**——有限小数就是分数，这个没有疑问。
- 可它的极限是 **√2**，而第三篇第二节的加餐**证明过：√2 不是分数。**

FIG: fig-25-not-a-fraction.png | 上面一行成立，下面一行不成立。这一次不是削弱，是整个没了。

BOX[key]: 在只有分数的世界里，这台机器会卡住 :: 假想一个**只有分数**的世界（数轴上只有分数那些点，别的位置都是空的）。// 上面那队数**全都住在这个世界里**，而且第三篇证过**它满足柯西条件**——越挤越紧。// 可它**没有极限**：它挤向的那个位置上，**一个分数也没有**。// // **投得进去，吐不出来。**取极限这台机器，在分数世界里会卡住。

BOX[key]: 所以实数到底是为什么造出来的 :: **就是为了让这个方框打勾。**// 第三篇把实数定义成"无限小数"，看起来只是换了个说法；// 现在能说清它真正买到了什么：// // **取极限这台机器，投进去实数，一定吐得出实数。**// // 这句话就是"**完备**"。第五篇那八条，说的全是这一件事。// 而这一节的那个红叉，就是**不完备**长什么样。// // 先把这队分数**收好**——到了第五篇你会发现，**它是一颗能把八条定理全部打穿的子弹**。// 怎么打，那一篇的习题请你亲手来，这里一个字不剧透。

### 最后一次翻车：网上那个"圆周率等于 4"

前面三次翻车，翻的都是一队**数**。最后这一次，翻的是一队**图形**——而且它在网上骗过很多人。

FIG: fig-30-folding.png | 上排：折多少次，一圈都还是 4。下排：切多少级，一趟都还是 2。可它们都贴得要多近有多近。

先看上面那一排。一个圆，直径是 1，外面套一个正方形——正方形一圈是 4。

现在**折角**：把四个角往里折，折到正好碰着圆；再折，再折。锯齿越来越贴着圆，折到第四次，看上去已经就是一个圆了。

可是**一圈还是 4**。道理很简单：折角只不过把横的那一小段和竖的那一小段**挪了个位置**——横的还是横的，竖的还是竖的，没多一点，也没少一点。

于是有人这样收尾：锯齿最后变成了圆，锯齿一圈是 4，所以圆一圈也是 4。而圆的一圈是 π 乘直径，直径是 1，所以——

CENTER: **π ＝ 4**

第三篇第三节你亲手用圆规量过：π 比 3 大，祖冲之把它挤进了 3.1415926 和 3.1415927 之间。**4 是不可能的。**可上面每一句听着都没毛病。错在哪一句？

BOX[dialog]: 姐姐先认下两件事 :: **妹妹：**"我来挑刺——是不是锯齿其实没贴上去？"// **姐姐：**"贴上去了，这一句是真的。你说要多近，我就折到多近：你要 0.001，我多折几次，锯齿上每一点离圆都不到 0.001。**这正是我们这一册的句式**，它经得起你挑。"// **妹妹：**"那是不是一圈其实不是 4？"// **姐姐：**"也是 4，一次都没变过。所以错**不在**这两句里头。"

两句都拿不下来，毛病就只能藏在第三句里——**锯齿变成了圆，所以长度也跟着变**。

下面就来说清楚这一句到底错在哪儿。不过 π 这个数本身算起来有点麻烦，所以我们**换一个图形**——**同一套推理，一个字都不改**，它照样走得通，而且这一回它算出来的是 **√2 ＝ 2**——一样荒唐。

换过来的好处是：**每一个数都算得清清楚楚**，错在哪一步就赖不掉了。

看图的下面那一排。一个边长 1 的方格，从左下角走到右上角。

**走楼梯**：横一段、竖一段、横一段、竖一段……**一趟有多长，就是把这些段加起来。**不管切成多少级，横的那些段加起来正好是 1（方格的宽），竖的那些段加起来也正好是 1（方格的高）。所以：

CENTER: **楼梯一趟永远是 2**

切得越细，楼梯越贴着对角线。贴到什么程度？**切成 n 级，楼梯上每一点离对角线都不到 [[1|n]]。**

（为什么不到 [[1|n]]？一级台阶横竖各 [[1|n]] 长，整级台阶**整个装在一个边长 [[1|n]] 的小方格里**，而对角线正好从这个方格的一角穿到另一角。方格里任何一点离这条对角线，都不会超过方格的边长。）

这句话经得起妹妹挑吗？按这一篇的规矩走一遍——**这是一次正经的 ε–N**：

BOX[dialog]: 正着用：楼梯真的挤向对角线 :: **妹妹：**"我只允许这么小的距离——ε。"// **姐姐：**"我取一个不小于 [[1|\varepsilon]] 的整数，叫它 N。// 从第 N 级往后再怎么切，楼梯上每一点离对角线都不到 [[1|n]]；// 而 [[1|n]] 不超过 [[1|N]]，[[1|N]] 又不超过 ε。**一个点都跑不出去。**"// **妹妹：**"那我要 0.001。"// **姐姐：**"切一千级。"

所以"**楼梯挤向对角线**"这句话不是看图看出来的印象，是**证出来的**。

那么**对角线本身**有多长？

FIG: fig-32-diagonal.png | 四个方格拼成一个大的。斜着那个正方形是四个半格拼的，面积正好 2。

BOX[key]: 一张图看出对角线有多长 :: 拿四个边长 1 的方格拼成一个大正方形，**面积是 4**。// 再把四条对角线连起来，中间围出一个**斜着的正方形**：// 它的四条边都是方格的对角线，四个角都是两条对角线碰头——// 一条斜上去、一条斜下来，对称地分在格线两边，**正好是直角**。// // 它是**四个半格**拼起来的，所以**面积正好是 2**。// 一个面积 2 的正方形，边长是多少？**第三篇第二节**造过那个数，// 它叫 **√2**，写出来是 1.41421356……// // 所以：**方格的对角线，长 √2。**

现在把开头那套推理**原样搬过来**：楼梯挤向对角线，楼梯一趟永远是 2，所以对角线长 2。而对角线长 √2，于是——

CENTER: **√2 ＝ 2**

跟 **π ＝ 4** 是同一个毛病，一个字都没改。可这一回，错在哪儿一句话就说得清：

CENTER: **长度是各段加起来的，而这个和从头到尾一次都没动过。**

切得再细，只是把段分得更碎——**横的还是横的、竖的还是竖的，一段没少、一段没多。**所以楼梯的长度是这么一队数：

CENTER: **2，　2，　2，　2，　……**

**一个从头到尾没变过的数，不会自己变成另一个数。**楼梯的**位置**一直在挪，它的**长度**一次也没挪过。差得也不是一点点：**2 和 1.41421…，从第一级到第一千级，一直差着这么多。**

这是直觉上的答案。按这一册的规矩，还要把它证严实——这队数当然有极限，**极限就是 2**；可我们要问的是：**它挤向 √2 吗？**

这一问也归 ε–N 管，只不过这一回是**反着用**：

BOX[dialog]: 反着用：楼梯的长度不挤向 √2 :: **妹妹：**"这回我不必把 ε 说得多小。我只说一个：**ε ＝ 0.5**。"// **姐姐：**"那我认输。不管我把关口 N 报在哪儿，第 N 级往后每一趟楼梯还是 2；// 而 2 离 √2 差 0.58 多，**比 0.5 还大**。**一趟都进不了妹妹的圈。**"// // **反着用是这么个用法**：正着用要"任凭 ε 多小，姐姐都给得出 N"；// 要说一队数**不**挤向某个数，只需**找出一个堵得住的 ε**，让任凭哪个 N 都不管用。// 妹妹这一次不必费劲——**0.5 就够堵了。**

两件事这就都证死了：

- **楼梯挤向对角线**——正着用的那次 ε–N；
- **楼梯的长度不挤向对角线的长度**——反着用的这次 ε–N。

一件说的是位置，一件说的是长度。**这就是"量长度过不了关"的精确说法。**两条路走出去，走到了两个地方：

FIG: fig-31-length-commute.png | 先量长度再取极限，得 2；先取极限再量长度，得 √2。这个方框打叉。

BOX[remember]: 又一样过不了关的：量长度 :: **"量长度"过不了取极限这一关。**// 一队图形挤向另一个图形，**它们的长度并不跟着挤过去**。// 前面那个盒子说过，**越往高处走，过不去的东西越多**——// 不用等到大学，这就是一个。

**凭什么会这样？**这一篇第三节那个三角不等式，正好答得上。

BOX[key]: 楼梯的每一级都在绕道 :: 一级台阶是**先横过去、再竖上来**——也就是**先到 B、再到 C**。// 对角线是**从 A 直接到 C**。// 三角不等式说的正是：**绕道不会更近。**// // 要紧的是下面这句：**切得再细，每一级还是在绕道。**// 一级台阶，横的那段长 h，竖的那段也长 h，加起来 **2 × h**；// 对角线上对应的那一小截，只有大约 **1.414 × h**。// **每一级都是这个比，切多少级都是这个比**——// 所以总长永远差同一个倍数，切得再细也追不上。

说到底是这么回事：

CENTER: **挤过去的是位置，长度看的是方向**

楼梯离对角线越来越近，这是**位置**上的事。可楼梯的每一小段，要么横、要么竖，**从头到尾没有一段是斜的**——它的**走法**一步也没靠近过对角线。而长度量的，正是走法。

BOX[remember]: 那第三篇的圆规为什么算得对 :: 第三篇第三节拿**正多边形**去挤圆，六边形、十二边形、二十四边形……那条路是**对的**，祖冲之靠它挤出了七位。// 差别就在这里：正多边形的边是**斜的**，边越多，它的方向越跟着圆转。// 折角锯齿的边**永远只有横竖两个方向**。// // **同样是"越来越贴近"，一个管用，一个不管用。**// 所以第三篇那句**边越多就越准**，靠的从来不是贴得近，// **是方向跟着圆转。**

最后留一个问题给你——它是下一册的入口。

BOX[key]: 那面积呢？这一次它没翻车 :: 同样是这些锯齿，**它们围住的面积，确实挤向圆的面积**：// 折 1 次是 0.914，折 2 次 0.865，折 4 次 0.809，一路掉向圆的 0.785……// **周长翻了车，面积没有。**// // 但**千万别把这当成一条规律**——“面积安全、长度危险”**不是**一条定理。// 第二册第十篇要拿长方形去量一块弯边的地，那一次为什么算得对，**那一篇会给你一个交代**：// 那里造出了**上下两队**，把真面积夹死在中间；// 而楼梯这边**只有上面一队**，下面从来没有人顶上来。// 一队数是钉不死一个答案的——// 这正是**这一篇例二**那条夹逼定理非要三个条件不可的原因。

### 这也解释了"两边取极限"

第五篇会反复用到一个动作：**在一个等式两边同时取极限**。现在它的身份很清楚了：

BOX[remember]: 两边取极限 :: 一个等式的两边，是**同一队数的两种写法**。// 把 **lim 这台机器同时作用在两边**——投进去的既然是同一队数，吐出来当然是同一个数。// **所以两边取极限是合法的。**// // 但**前提是这队数真的有极限**。要是它根本没有极限，机器就吐不出东西来，// 等号两边接的就是两个不存在的东西。// 谁来保证有极限？**第五篇那八条定理**——那一篇还会拿 1 ＋ 2 ＋ 4 ＋ 8 给你看一个不先确认存在就翻车的例子。

## 七、这一篇学到的两个动作

五个例子里，有两个动作反复出现。它们比任何一条具体结论都值钱。前面已经各记过一次，这里把它们出现过的地方一次列全：

TABLE:
| 动作 | 一句话 | 出现在 |
| **取靠后的那个关口** | 要几个条件同时成立，就把几个 N 里最靠后的那个拿来用 | 第二篇证"极限只有一个"；例二夹逼；例三求和；第五篇证柯西准则 |
| **把 ε 掰成两半** | 要证一段路不到 ε，就拆成两截，每截各证不到一半 | 例三求和；第五篇证柯西准则 |

以后你还会见到掰成三半、掰成 n 半的版本。

BOX[key]: 这一篇的一句话 :: 五个例子，一个模式：**先看出现象，再把它翻译成"不管 ε 多小，我都能给出一个有限的 N"**。// **直观负责发现，ε–N 负责证明。**// 这套语言值得学，不是因为它复杂，// 而是因为它能把"我觉得"变成"**我证明了**"。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 例二那条叫**夹逼定理**（也叫迫敛性、两边夹定理）。// 例三属于**极限的四则运算法则**：和、差、积、商四条，证法都是"掰 ε ＋ 三角不等式"。// 例四那句话的正式说法是：**极限保持非严格不等号，不保持严格不等号**。// 例五叫**收敛数列必有界**；反过来不成立（有界不一定收敛，第二篇那队混起来的数就是反例）。// 三角不等式写作 | x + y | ≤ | x | + | y |。// // 折角那件事的正式说法是：**曲线的长度对"逐点靠近"并不连续**。// 楼梯只会把长度**算多**，不会算少——这一半有个名字，叫**下半连续**。// 要让长度也跟着收敛，光管住位置不够，**还得管住方向**（也就是切线，第二册的事）。// 还有更凶的：三维里有个 Schwarz lantern，拿三角形去贴一个圆柱面，// 贴得要多近有多近，**算出来的面积却可以要多大有多大**。// 所以"面积安全"真的不是一条定理。
