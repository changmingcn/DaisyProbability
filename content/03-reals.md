# 第三篇　实数是什么：只用小数说清楚

CENTER: 我们其实早就在用极限了，只是自己没发现

第二篇第六节，我们证"被困住的数列一定有聚点"，砍到最后用了这么一句：

CENTER: **"这些段子越套越小，最后正好钉住一个点。"**

画出来一目了然。可妹妹应该追问：**凭什么？万一钉住的那个位置上根本没有数呢？**

这一篇就来回答它。不过在动手之前，先说清楚一件事：**这句追问，凭什么值得花一整篇去答？**

先说一件你自己已经干过两次的事。

一年级的时候，**3 减 5 是"不能减"的**——老师说不够减，你也就认了。后来你知道了：能减，答案是**负 2**，冬天的温度计上真有那一格。

三年级的时候，**3 除以 2 是"除不尽"的**。后来你也知道了：除得尽，答案是 1.5，半个饼真的在桌上。

两次是同一件事：**手里的一个算法，把我们带到了已有的数的外面；于是"数"这个词管的范围，得往外扩一圈。**

请注意扩的方式：**不是谁心血来潮发明了一个新数**，而是那个东西**本来就在那儿**——温度计上的那一格、桌上的半个饼——我们只是终于承认它也是数，并且给了它一个写法。

现在轮到第三次。这一次把我们带出去的，是**取极限**。

CENTER: **算出来的东西要不是个数，这一步就真的"不算数"了。**

BOX[remember]: 这一篇要办的事：三问 :: 一个数的世界要好用，得经得起三问——// **一、算一算。**加、减、乘、除做完，答案还是这个世界里的数吗？// **二、挤一挤。**一队数越挤越拢，**挤向的那个位置上，真的有数在吗？**// **三、比一比。**拿"谁大谁小"问出来的东西——比如"挡住这堆数、而且挡得最紧的那一个"——是这个世界里的数吗？// // 三问里只要有一问答"不在"，那一步就白算了：**辛辛苦苦算出来的东西不是数，这一步当然不算数。**// 这一篇就照三问走：**第二、三节**看第二问是怎么被捅穿的，**第四节**把新的世界定下来，**第五节**答第一问、也答第三问的前一半，**第六节**把第三问问准，**第七节**结账。

而回答的起点，是一件我们**每天都在做、却从没意识到**的事。

## 一、写下一个循环小数，就是在用极限

第一篇第四节已经把 0.333… 拆开看过了：它不是一道写不完的题，而是 0.3、0.33、0.333、…… 这队有限小数的**极限**，并且我们证明了那个极限就是[[1/3]]。

也就是说——**每次写下一个循环小数，我们都在不声不响地用极限。**只是从来没人这么提醒过我们。

### 再做一个例子

来看 **0.121212…**（12 不停地重复）。它代表的是这一队有限小数：0.12，0.1212，0.121212，……

那它等于多少？用第二篇第四节学过的那一招——**列个方程**：

- 设这个数是 S。
- 把小数点往右挪两位（也就是乘以 100）：100 × S ＝ 12.121212……
- 而 12.121212… 就是 **12 加上 S**。
- 所以 **100 × S ＝ 12 + S**，也就是 99 × S ＝ 12。
- 解得 **S ＝ [[12/99]] ＝ [[4/33]]**。

验算一下：[[4/33]] 用竖式除出来，正好是 0.121212……对上了。

BOX[remember]: 这一招对所有循环小数都管用 :: 循环节有几位，就把小数点往右挪几位，再减掉原来那个数。// 重复的部分正好抵消，剩下的就是一个普通的分数。// **所以：每一个循环小数，都是一个分数。**// （反过来也对：一个分数除出来，**一定是循环小数**——因为竖式除法的余数只有有限种，迟早要重复。**除得尽的那些也算**：除尽以后一直往下落 0，那就是"**以 0 循环**"。）

BOX[key]: 顺便留个心眼 :: 上面那个方程，一上来就写"设这个数是 S"——// **它已经假设了这个数存在。**// 第二篇第四节提醒过同样的事：方程能帮我们**猜出**答案，// 但"它到底存不存在"是另一个问题。这一篇后面就要正面处理它。

## 二、再看一个不循环的

现在换个例子。我们来找**自己乘自己正好等于 2** 的那个数。

这一次，我们把这队数**一句话定死**：

BOX[remember]: 这一队数是怎么来的 :: **a~n~** 就是**自己乘自己小于 2 的、最大的那个 n 位小数**。// a~1~ 是一位小数里最大的，a~2~ 是两位小数里最大的，a~3~ 是三位小数里最大的……// 怎么找？**一位一位试就行**——每一位都取最大的、平方还没超过 2 的数字。

试出来是这样。请特别注意**每一行的两个平方，正好把 2 夹在中间**：

TABLE:
| n | a~n~（平方小于 2 的最大 n 位小数） | a~n~ 的平方 | 再往上一格 | 那一格的平方 |
| 0 | 1 | 1 | 2 | 4 |
| 1 | 1.4 | 1.96 | 1.5 | 2.25 |
| 2 | 1.41 | 1.9881 | 1.42 | 2.0164 |
| 3 | 1.414 | 1.999396 | 1.415 | 2.002225 |
| 4 | 1.4142 | 1.99996164 | 1.4143 | 2.00024449 |

CENTER: **1，　1.4，　1.41，　1.414，　1.4142，　1.41421，　……**

"再往上一格"就是 a~n~ + [[1|10^n]]——n 位小数里紧挨着它的下一个。因为 a~n~ 已经是**最大**的那个了，所以再往上一格，平方就一定超过 2。这句话记牢，等一下要用：

CENTER: **a~n~ × a~n~ ＜ 2 ＜（a~n~ + [[1|10^n]]）×（a~n~ + [[1|10^n]]）**

把这些数字一位一位接下去写成一个无限小数，就得到一个数。**我们给它起个名字，叫 √2**（念作"根号二"）。

BOX[key]: 注意这里的顺序 —— 又是"先猜，后证" :: 我们**先按一条造法把这个数造出来**（每位取最大的、平方不超过 2 的数字），// 然后给它起名叫 √2。// 但光起名字不算数。要让这个名字站得住，得**验两件事**：// 一，**上面那队数真的收敛到它**（下面用 ε–N 证）；// 二，**它自己乘自己真的等于 2**（再下面证）。// 这正是第一篇的规矩：**名字可以先取，身份要靠证明。**

### 用 ε–N 证明：这队数收敛到 √2

先看清楚一件事：**a~n~ 就是 √2 砍到第 n 位**。两个数的前 n 位小数一模一样，从第 n+1 位起才可能不同。

所以它们能差多远？**差不到小数点后第 n 位的一个单位**：

CENTER: **| √2 − a~n~ | ＜ [[1|10^n]]**

比如 a~3~ ＝ 1.414，而 √2 ＝ 1.414213…，两者相差 0.000213…，确实不到 [[1/1000]]。

有了这个，ε–N 就是走个过场了：

BOX[key]: 证明 :: 妹妹给一个 ε，随她多小。// 姐姐这样挑关口 N：**看她的 ε 小数点后第一个不是 0 的数字在第几位，N 就取那一位再加 1。**// 这样一定有 [[1|10^N]] ＜ ε。// 于是只要 n ＞ N：// **| √2 − a~n~ | ＜ [[1|10^n]] ≤ [[1|10^N]] ＜ ε。**// 一个都不会跑出去。**证毕。**

妹妹试几次看看：

TABLE:
| 妹妹的 ε | 姐姐给的关口 N | 因为 | 从第 N 项往后 |
| 0.1 | 2 | [[1/100]] ＜ 0.1 | 1.41、1.414、1.4142…… 都离 √2 不到 0.1 |
| 0.001 | 4 | [[1/10000]] ＜ 0.001 | 1.4142 往后的每一项都够格 |
| 0.000001 | 7 | [[1/10000000]] ＜ 0.000001 | 写到小数点后 7 位往后都够格 |

**她可以一直提下去，姐姐每次的回答都只是一个有限的位数。**这跟第一篇对付 0.333… 的做法，一模一样。

### 再验第二件事：它自己乘自己真的等于 2

这一步才是真正让"√2"这个名字站得住的地方。用的就是刚才那句记牢了的话：

CENTER: **a~n~ × a~n~ ＜ 2 ＜（a~n~ + [[1|10^n]]）×（a~n~ + [[1|10^n]]）**

而 √2 本身也正好夹在 a~n~ 和 a~n~ + [[1|10^n]] 之间（前 n 位一样，所以只可能落在这一格里）。**平方以后，大小顺序不变**（都是正数），所以 **√2 的平方**和 **2** 这两个数，被关进了同一个小区间：从 a~n~ 的平方，到 a~n~ + [[1|10^n]] 的平方。

这个区间有多宽？算一下就知道它不超过 **[[4|10^n]]**（因为 a~n~ 比 1.5 还小）。

BOX[remember]: 这一招叫"夹逼" :: 我们没有直接去算 √2 的平方是多少——**那是算不完的**。// 我们做的是：**把它和 2 一起关进同一个格子，再把格子越缩越小。**// 两个东西被同一个越缩越小的格子夹住，就只能是同一个数。// 这一招叫**夹逼**。记住它，因为它比这道题本身有用得多。

BOX[key]: 收尾的一击 :: 于是对**每一个** n 都有：// **| √2 的平方 − 2 | ＜ [[4|10^n]]**// n ＝ 4 时，这个差不到 0.0004；n ＝ 10 时，不到 0.0000000004……// **想多小有多小。**// 一个不是负数、又比任何正数都小的数，只能是 **0**。// 所以 **√2 的平方就是 2**，一点不差。**证毕。**

BOX[remember]: 记住这个小工具 :: **比任何正数都小的距离，只能是 0。**// 这一招在这本册子里会反复出现——// 第二篇证"极限只有一个"用的是它，// 第五篇证"区间套钉住的点只有一个"用的还是它。

### 请仔细比较这两队数

CENTER: **0.3，　0.33，　0.333，　0.3333，　……**

CENTER: **1，　1.4，　1.41，　1.414，　1.4142，　……**

TABLE:
| 问题 | 上面那队 | 下面那队 |
| 每一项是什么？ | 有限小数 | 有限小数 |
| 越往后越挤吗？ | 是 | 是 |
| 关口以后任意两项都近吗？（柯西） | 是 | 是 |
| 为什么？ | 前 n 位完全一样，相差不到 [[1|10^n]] | 前 n 位完全一样，相差不到 [[1|10^n]] |

| 数字会重复吗？ | **会** | **不会** |

**除了最后一行，两队数没有任何区别。**

BOX[key]: 这一篇最要紧的一句话 :: 循环小数是一个极限；**不循环的小数也是一个极限**。// 两者的造法一模一样，连 ε–N 的证法都一模一样。// **"数字会不会重复"这件事，和"是不是极限"毫无关系。**// 所以我们没有理由只承认前一种、不承认后一种。

BOX[key]: 加餐：妹妹一定会问的一个问题 :: "1.41421… 会不会其实也是个循环小数，只不过循环节特别特别长，我们还没看到？"// 这是个好问题。如果是，那它就还是个分数（第一节证过循环小数都是分数）。// **答案是：不会。**证明如下——// 假设有分数的平方等于 2，写成最简分数 [[p|q]]（p 和 q 不能再约分了）。// 那么 p × p ＝ 2 × q × q。右边是偶数，所以 **p 是偶数**（奇数乘奇数还是奇数）。写 p ＝ 2k。// 代进去：4 × k × k ＝ 2 × q × q，两边除以 2，得 q × q ＝ 2 × k × k。// 同样的道理，**q 也是偶数**。// 可 p 和 q 都是偶数，那就还能再约分——和"最简"矛盾。**所以这样的分数不存在。**// // 注意这个答案**不改变**上面那个结论。它只是告诉我们：// 不循环的那些确实是**新面孔**，不是老朋友换了件衣服。

BOX[key]: 停一下，看看刚才发生了什么 :: 回到篇首的**第二问**。// 我们手上那队数——1，1.4，1.41，1.414，……——**每一项都是有限小数，也就是分数**（第一节说过：有限小数就是"以 0 循环"的循环小数）。// 一队分数，规规矩矩地越挤越拢。// 可它们挤向的那个位置上**没有分数**——加餐刚刚证完。// **这就是第二问被捅穿的现场：出发时明明在分数的世界里，取一次极限，人就到外面去了。**// 而这不是纸面上的毛病——// **画一个面积是 2 的正方形，它的边长就是这个数。**尺子上真真切切有那么一个点；可你只带着分数去找，那个位置是**空的**。// 那是一个洞。

## 三、第二个例子：一个连开方都够不着的数

√2 至少还说得出自己是谁："自己乘自己等于 2 的那个数。"下面这一个，连这句话都说不上。

拿一根线绕你家任何一个圆量一量——杯口、锅盖、车轮。**周长除以直径**，量出来总是 3.14 左右。换个大的圆、换个小的圆，还是 3.14 左右。这个数你已经认识：它叫 **π**（念作"派"）。

它当然是存在的：**你手上那个杯口的周长就是那么长，不多不少，一根线量得出来。**

可你没法把它**算**出来。人们能做的只有一件事：**拿多边形去挤圆**。

### 当场办一件：正六边形，把 π 的整数位挤出来

正六边形最好算，而且你自己拿一把圆规就能验：

- **第一步。**圆规张开多大，画出来的圆半径就有多大。画完圆**别动圆规**，就拿这个开口，从圆周上随便哪一点起，一段一段往下截——**正好截六段，回到原地。**（这就是画正六边形的老办法。）
- **第二步。**六段都是同一个开口截出来的，所以这个六边形的**每条边都正好等于半径**。
- **第三步。**那么它一圈有多长？六条边，每条一个半径，一共**六个半径**。而直径是**两个半径**。六个半径里正好装得下三个直径——**六边形一圈的长度，正好是直径的 3 倍。**
- **第四步。**圆比这个六边形鼓，鼓出去的那一圈还要绕得更远。所以**圆的周长比直径的 3 倍还长**。

头一件事就这么水落石出了：**π 比 3 大**，整数位就是这么定下来的。

接着是正十二边形、正二十四、四十八、九十六……边越多，多边形越贴着圆，算出来的数就越准。一千五百年前，祖冲之靠这条路把 π 挤进了 3.1415926 和 3.1415927 之间——**小数点后七位，一位不差。**

CENTER: **3，　3.1，　3.14，　3.141，　3.1415，　……**

**挤**，就是这一册从头讲到尾的那件事：一队数，一层层把一个点关死（下一节那张图画的正是这件事）。挤得越细，能认下的小数位数就越多。**没有极限，就没有 π**——它不是先有一道式子、算出来才有的；**它一出生就是一个极限。**

而这一队里的每一项，**又都是有限小数，也就是分数**。

BOX[key]: 说句老实话：这里借了两件事 :: 关于 π，这一册**用了、但是没有证**两件事：// **一、所有的圆，周长除以直径都是同一个数**——正因为是同一个数，给它起个名字才有意义。// **二、π 不是分数**——这件事比"√2 不是分数"难证得多，一直到两百多年前才有人做出来，证法离这一册太远。// 两笔都记在**附录 D** 里了。请你先信着——因为这一节的重点不在它们怎么证，而在下面这句话。

BOX[remember]: 两个例子，说的是同一件事 :: **√2 是"算"出界的**：一动开方，人就到分数外面去了。// **π 是"量"出界的**：一根线绕圆一圈，那个长度本身就已经在分数外面。// 出界不是罕见的事故——**它就在你手边，在你的杯子上。**// 而两次出界走的是同一条路：**一队分数，挤向一个不是分数的地方。**// 说到底，**把我们带出分数世界的那个动作，就是取极限。**

## 四、约定：实数就是无限小数

既然两种小数都是极限，那就一视同仁。

BOX[remember]: 实数 :: 一个**实数**，就是一个**无限小数**：// 一个整数部分，一个小数点，然后一位一位排下去，**永远排下去**。// 比如 3.000000…、0.333333…、0.121212…、1.414213…// **有限小数不用另算一类**——它就是"**以 0 循环**"的那种循环小数：0.25 就是 0.250000…，从第三位起一直在循环 0。// 所以"一位一位永远排下去"对**每一个**实数都成立，一个例外也没有。// **它代表的，是把它一位一位截出来的那队有限小数的极限。**// 循环的那些，碰巧也能写成分数；不循环的那些就不循环。// **我们不为这个区别另立一类、另起一个名字。**

FIG: fig-19-decimal-zoom.png | 每多写一位小数，就把这个点关进一个小十倍的格子里。写不完，但每一位都写得出来。

看这张图：说出"第 1 位是 6"，就把这个点关进了 0.6 到 0.7 那一格；再说"第 2 位是 6"，就关进了 0.66 到 0.67；再说一位，关进 0.665 到 0.666……

**格子一次比一次小十倍，想多小有多小。**所以，报出一串永不停止的数字，就等于**一层层地把一个点关死**。这正是第一篇讲的事：我们写不完，但每一位都写得出来，这就够了。

BOX[key]: 你手上拿得到的数，其实全是有限小数 :: 计算器上按出来的 √2 是 1.4142136——**那是一个有限小数，它不是 √2。**// 尺子量出来的桌子长 1.2 米，也是有限小数；量得再细，还是有限小数。// **现实里你能拿到手的，永远只是截断的那一段。**// // 那真正的那个数在哪儿？**在极限里。**// **计算只能在有限步内完成**（这句话这本书里会一次次回来）——// 我们**做不完**无穷多位，可我们**说得清**这队有限小数挤向谁。// **这就是这一整册书的办法。**

BOX[remember]: 一个必要的约定 :: **不许以无穷多个 9 结尾。**// 因为第一篇证过 0.999… ＝ 1。// 要是允许两种写法，同一个点就有两个名字，比大小的时候会打架。// 所以我们规定：1 就写成 1.000…，不写成 0.999…。// 这样每个点**只有一个**名字。

### 顺带一件大事："次方"可以松绑了

实数的范围一旦定死，**很多原来说不通的算法，一下子都说得通了**。挑一个最典型的看：**次方**。

"次方"这个词，原来只管得了很窄的一段——

- **2^3^** 就是三个 2 相乘，等于 8。次数是整数，好懂。
- 2 的 [[1/2]] 次方呢？我们**规定**它是开平方。凭什么可以这么规定？因为要让"**次数相加，结果相乘**"这条老规矩继续成立：两个"2 的 [[1/2]] 次方"乘起来，次数加成 1，就该等于 2——那它自己乘自己等于 2，可不就是 √2。
- 2 的 1.4 次方也一样：1.4 就是 [[14/10]]，所以先给 2 开 10 次方，再自己乘 14 次。**次数只要是分数，总有办法。**

可是 **2 的 √2 次方**呢？√2 ＝ 1.41421…，"自己乘自己 1.41421… 次"——这句话根本没有意思。

办法还是这一册从头用到尾的那一个：**先算一队，再看它们挤向哪儿。**把次数换成 √2 的那队有限小数，每一个都是分数，所以每一个都算得出来：

TABLE:
| 次数 | 2 的这个次方 | 再往上一格 | 那一格的值 | 格子有多宽 |
| 1 | 2 | 2 | 4 | 2 |
| 1.4 | 2.639015… | 1.5 | 2.828427… | 0.189… |
| 1.41 | 2.657371… | 1.42 | 2.675855… | 0.0184… |
| 1.414 | 2.664749… | 1.415 | 2.666597… | 0.00184… |
| 1.4142 | 2.665119… | 1.4143 | 2.665303… | 0.000184… |

**每多写一位小数，格子就窄十倍。**这跟第二节找 √2 的做法一模一样——只不过那一次被夹住的是 √2，这一次被夹住的是一个新数。

BOX[remember]: "2 的 √2 次方"是这样定出来的 :: 把次数换成 √2 的那队有限小数：1，1.4，1.41，1.414，……// 每一个都是**分数次方**，都算得出来；它们一格一格挤拢。// **它们挤向的那个数，就叫做"2 的 √2 次方"。**// 同一个办法，可以定出**任何一个正数的任何一个实数次方**——2 的 π 次方也一样。

BOX[key]: 这正是实数的定义在干活 :: 这个定义立不立得住，全看篇首的**第二问**答不答得出"在"：// 那队数每一项都算得出来，可**挤向的那个位置上必须真有一个数**，"2 的 √2 次方"这个名字才有东西可指。// 数轴上要是有洞，它随时可能扑空。// **把实数的范围定死，这一类原来没意思的算法才有地方落脚。**// **而且这不是纸上谈兵——下面就有一个非算不可的场合。**

### 真会有人要算它吗——会，而且不用等到长大

有些东西会自己慢慢变少。就说一样：**今天有一堆，过一天就只剩一半；再过一天，又只剩一半的一半。**这种东西的**半衰期**是一天。

先算好算的：

TABLE:
| 过了多少天 | 还剩多少 |
| 1 | [[1/2]] |
| 2 | [[1/4]] |
| 3 | [[1/8]] |
| n | 2^n^ 分之一 |

到这里都是整数次方，好懂。可是**时间不会只走整数天**。钟表照样会走到 1 天零 9 个多小时那一刻——那一刻正好是 **√2 天**（√2 ＝ 1.414…，差不多一天半）。

FIG: fig-29-halflife.png | 整数天上的点好算。可钟表照样会走到第 √2 天——那一刻也得有一个"还剩多少"。

CENTER: **过 √2 天，还剩多少？**

BOX[key]: 这个问题必须有答案 :: 钟表**真的会走到**那一刻。走到了，东西就剩那么多，不多不少。// 说"这个问题没有答案"，等于说**那一刻不存在**。// // 所以"2 的 √2 次方"**不是数学家闲着没事造出来的怪东西**，// **是现实逼着我们必须定义的一个数。**

答案就是刚才那个数：**还剩 2 的 √2 次方分之一**，也就是 1 除以 2.665…，大约 **0.375**——三分之一多一点。

**而且这个答案不是我们随口规定的，是被逼出来的。**只要承认一件很朴素的事——

CENTER: **先过 a 天，再过 b 天，和一口气过（a ＋ b）天，剩下的一样多**

——那么"过 a 天剩多少"和"过 b 天剩多少"两个比例**乘起来**，就该等于"过 a＋b 天剩多少"。这正是这一节开头那条老规矩：**次数相加，结果相乘。**它把"过半天剩多少"逼成了"自己乘自己等于 [[1/2]] 的那个数"，把"过 1.4 天剩多少"逼成了分数次方，**一路逼到 √2 天**——那里只剩最后一步：那队分数次方挤向的位置上，**得真有一个数**。

BOX[remember]: 回到篇首那三问 :: 这就是**第二问**在现实里的样子。// "挤向的那个位置上，真的有数在吗？"——// **答"在"，钟表走到 √2 天那一刻才有一个剩余量；**// **答"不在"，那一刻就成了一个没有答案的时刻。**// // 前面几节费那么大劲把实数的范围定死，**回报就在这儿**。

BOX[task]: 自己算一算 :: 半衰期还是一天。// **（1）**过**半天**还剩多少？（提示：这个数自己乘自己应该等于 [[1/2]]。答案是 0.707 左右。）// **（2）**过 **1.5 天**还剩多少？（提示：1.5 ＝ 1 ＋ 0.5，用"次数相加、结果相乘"：先剩一半，再对半天。）// **（3）**过 √2 天剩 0.375，过 1.5 天剩多少？**哪一个剩得多？为什么？**（想想 √2 和 1.5 谁大。）

BOX[key]: 说句老实话：这一小节借了两件事 :: 一、**那队数真的挤得到一个数**——上面那张表只让你看见格子在变窄，**没有证**。// 二、**幂的老规矩（次数相加就把结果相乘；次数相乘就是一层套一层）在这种次数下还成立**——下面那个小论证正要用它。// 这一册**不还这两笔**，附录 D 记着。// **知道自己借了什么，比假装证过了强。**

BOX[key]: 一个漂亮的小论证：不是分数的数，也能次方出分数来 :: **问：底数不是分数、次数也不是分数，结果有没有可能是分数？**// 先给要看的那个数起个名字——想写公式，就得先造符号：// **G ＝ √2^√2^**　（念作"G 等于根号二的根号二次方"）// 它是一个数（上面刚教过这种次方怎么定），所以**要么是分数，要么不是**，只有这两种可能。// // **第一条路：G 是分数。**那当场就成了——底数 √2 不是分数，次数 √2 不是分数，结果是分数。要的例子有了。// // **第二条路：G 不是分数。**那就拿 **G 自己**当底数，再做一次 √2 次方：// **G^√2^ ＝ √2^√2×√2^ ＝ √2^2^ ＝ 2**// 底数 G 不是分数（这条路的前提摆在那儿），次数 √2 不是分数，结果是 **2**——一个整整齐齐的整数。要的例子也有了。// // **两条路必有一条通。所以这样的例子一定存在。**

BOX[remember]: 请注意刚才发生了什么 :: 我们**证明了这样的例子存在**——// 可我们**说不出它到底是哪一个**：是 G 本身，还是绕一圈得到的那个 2？// **先证存在，再算是多少**——这本册子会一次次回到这件事（第五篇第五节整整一节在讲它）。// 这一次更极端：**存在证到了，"是多少"我们连碰都没碰。**// // 还要分清一件事：这**不是**第一节那个"设这个数是 S"的毛病。// 那一次是**假设**它存在，这一次是**证明**它存在。// **差别就是全部。**

## 五、比大小怎么办

有了这个约定，比大小就特别简单：**从左往右一位一位看，第一个不一样的位说了算。**

比如 1.4142… 和 1.4150…：整数位一样，第 1、2 位一样，第 3 位 4 ＜ 5，所以左边那个小。完事。

**这就是第三问的前一半**：随便给两个实数，"谁大谁小"这件事一定问得出答案来，不会卡住。

加减乘除呢？这里有一件事值得停下来看一眼。先问一个听起来很傻的问题：

CENTER: **0.333… ＋ 0.666…，你怎么加？**

竖式加法是**从最右边一位开始**的：先加个位、进位、再加十位……可这两个数**根本没有最右边那一位**。老办法在这里**动不了**。

出路还是第一篇那个：**先截到第 n 位算，再让 n 越来越大。**截得越长，结果越准，准到妹妹要求的任何程度。（第二节验"√2 的平方等于 2"，用的正是这个办法。）这一册不展开细节，你只要知道**它是能做到的**，而且靠的还是极限。

当场截三次看看：

TABLE:
| 截到第几位 | 上面这个 | 下面这个 | 加起来 |
| 1 | 0.3 | 0.6 | 0.9 |
| 2 | 0.33 | 0.66 | 0.99 |
| 3 | 0.333 | 0.666 | 0.999 |

三个答数一个比一个长：0.9、0.99、0.999……**这队数第一篇算过，它的极限是 1。**所以那道加法的答数就是 1。

顺便看一眼答数该**怎么写**：这队数挤向 1，那就把和写成 1.000…，不写成 0.999…——第四节那条**不许以无穷多个 9 结尾**的约定，头一回派上了用场。

BOX[remember]: 你每天做的加法，本身就是一个极限 :: 无限小数没有"最后一位"，从右往左那套竖式**用不上**。// 唯一的办法是：**截到第 n 位相加，再让 n 越来越大**。// 也就是说——**一旦碰上无限小数，"加法"这两个字本身就得靠极限来定义。**// // 请注意这一条和前面几个例子**方向是反的**：// √2、π、2 的 √2 次方，说的是极限让我们**多**会一样新本事；// 这一条说的是：**没有极限，你三年级就会的那样本事，在无限小数上根本立不住。**// **极限不是锦上添花，它是地基。**

**这就是第一问的答案**：加减乘除做完，落点还是一个无限小数——不出界。

第一篇第四节其实说过另一句话：0.333… × 3，乘的是**那个数**，不是写 3 的过程。现在这里又说"先截到第 n 位算，再让 n 越来越大"——**这是两条路。**它们凭什么走到同一个地方？那要看**乘法能不能穿过取极限**。这个问题第四篇第六节专门问。

BOX[remember]: 第一条本质性质：谁大谁小，说得清 :: 上面这条比大小的规矩，看着只是小数写法的一点技术。其实它立住的，是实数的**第一条本质性质**：// **任意两个数，要么根本就是同一个数，要么一个比另一个大——不会有"谁也不比谁大"的两个数。**// // 别小看这一句，它一登场就在干活。第二节最后那一招——**"比任何正数都小的距离，只能是 0"**——靠的就是它：// 那个距离要是不等于 0，它自己就是一个正数；**拿它自己当妹妹要的那个 ε**，它就得比自己还小。荒唐。所以它只能是 0。// // 这条性质**分数也有**——分数之间照样谁大谁小说得清。// 真正把实数和分数分开的是**第二条**，第六节就到。

## 六、说清"最大"不够用：上界与上确界

第七节要问的就是**数轴上有没有洞**，第五篇要用八种说法回答它。在那之前，先把**关于数的次序**的几个词说清楚——篇首的第三问，也要在这一节才问得准。

先看一堆很普通的数：**所有比 1 小的数**。问一句：这堆数里，**最大的是哪一个**？

0.9 不是——0.99 比它大。0.99 也不是——0.999 比它大。随便报一个出来，我们总能再报一个更大的、而且还是比 1 小的。**这堆数根本没有"最大的那一个"。**

可它明明被 1 挡住了，谁也过不去。**"没有最大的"和"被挡住了"，这两件事同时成立**——所以"最大"这个词不够用，它描述不了"被 1 挡住"这件事。

我们需要新的词，而且要两个：一个说**挡得住**，一个说**挡得最紧**。

### 上界、下界、有界

一堆数，如果有某个数**比它们都大（或相等）**，这个数就叫它们的一个**上界**。同样有**下界**。既有上界又有下界，就叫**有界**——说白了就是**被夹在两堵墙中间**。

注意：上界**不止一个**。10 是上界，100 也是，1000 也是。

### 上确界：所有上界里最小的那个

FIG: fig-22-supremum.png | 上界有无穷多个，最靠左的那一个叫上确界。

BOX[remember]: 上确界 :: 一堆数的**上确界**，就是**所有上界里最小的那一个**。// 它有两条性质，缺一不可：// 一，**它是上界**（这堆数没有一个超过它）；// 二，**比它小的都不是上界**（随便往左挪一点，就会有数冒出来超过它）。// **上确界自己不一定属于这堆数。**比如"所有比 1 小的数"，上确界是 1，可 1 不在这堆里。

BOX[key]: 第三问的后一半：比大小也会出界 :: 有了这个词，篇首的第三问就问得准了：// **"所有上界里最小的那一个"，是不是我们世界里的一个数？**// // 在只带着分数的世界里试一次。取这么一堆数：**所有平方小于 2 的分数**。// 有上界吗？**有**——2 是一个，1.5 也是，1.42 也是。// 那**最小的**那个上界是谁？// 你报 1.5，我拿 1.42 挡到你前头；你报 1.42，我拿 1.415；你报 1.415，我拿 1.4143……// 这一队数第二节早就排好了，照着"再往上一格"那一列一位一位往下报就是。**报不到头。**// // 凭什么报不到头？你报的任何一个分数上界 b，都得挡住整队 a~n~，所以 **b 比 √2 大**（相等是不可能的：加餐证过 √2 不是分数）。// 既然 b 比 √2 大，就一定有一格 **a~n~ ＋ [[1|10^n]]** 卡在 √2 和 b 中间——只要 n 取得够大，这一格的宽度就比 b 到 √2 的距离还小。// 而这一格**照样是上界**（它的平方超过 2），又**比 b 小**。你报的每一个，我都能再往里挪一格。// // 上确界是拿"谁大谁小"问出来的一个**新东西**；这个新东西，在分数的世界里问出来是**空的**。// 所以：**不光取极限会出界，比大小也会。**

## 七、"数轴上没有洞"到底在说什么

现在可以正面回答妹妹那句追问了。

FIG: fig-20-dedekind-cut.png | 不管你怎么切，切口上一定正好站着一个数。

**在只有分数的数轴上，这句话是假的。**你可以切在"平方等于 2"的地方——左边放所有平方小于 2 的，右边放其余的。这一刀切下去，切口上**什么都没有**（第二节的加餐证过：那儿没有分数）。那是一个真正的缺口。

**在无限小数组成的数轴上，这句话是真的。**因为切口的位置，可以一位一位地报出来：第一位取几，第二位取几……报出来的那个无限小数，就正好站在切口上。**第二节我们已经完整地做过一次了**——那次报出来的名字叫 √2。

### 当场办一件：同一刀，切两次

把上面两段并排做一遍，看得最清楚。**刀的位置一动不动**：左边那堆放自己乘自己小于 2 的数，右边那堆放其余的。

TABLE:
| 这一刀 | 只带着分数的那把尺子 | 无限小数的那把尺子 |
| 左边那堆有谁 | 1、1.4、1.41、1.414、…… 都在里头 | 一样都在里头 |
| 右边那堆有谁 | 1.5、1.42、1.415、…… 都在里头 | 一样都在里头 |
| 谁被漏掉了 | **第二节造的那个数。**加餐证过它不是分数，所以两堆都收不下它 | 谁也没漏。它是一个无限小数，属于**右边**那堆，而且是右边最靠左的那一个 |
| 切口上站着谁 | **没人。**那是一个真正的缺口 | **√2。**第二节已经一位一位把它报出来了 |

**同一把刀，切在同一个地方，结果两样。**差别不在刀，在尺子。

BOX[remember]: 第二条本质性质：数轴上没有洞 :: "数轴上没有洞"——切在哪儿，哪儿就有一个数——// 这条性质的正式名字叫**完备**。// 所以我们可以说：**分数不完备，实数完备。**// // 到这里，实数最要紧的两条性质就都齐了：// **第一条，谁大谁小说得清**（第四节）——**分数也有**；// **第二条，数轴上没有洞**（这一节）——**分数没有**。// 两条的分工是：**第一条是说话用的语言，第二条是用这门语言说出来的那句关键的话。**// 第五篇的八句话，说的全都是第二件事——**而且八句全是拿第一条的词说出来的。**

TABLE:
| 做这个动作 | 只带着分数 | 有了实数以后 |
| 算：加、减、乘、除 | 不出界 | 不出界（第五节） |
| 算：开方，比如求 √2 | **出界**（第二节） | 不出界（这一册只对 2 做了，见附录 D） |
| 挤：一队数取极限 | **出界**（第二、三节各一次） | **不出界**——这就是"没有洞" |
| 比：挡得最紧的那一个 | **出界**（第六节） | 不出界——**第五篇第三节要证的就是它** |

BOX[key]: 三问结账 :: 这一篇立的那两条本质性质，全部的用处就是让右边那一列**一路都是"不出界"**。// 有了它，后面每一句话才敢直接往下说：// "这队数挤向的那个数……"——**它在。**// "挡得最紧的那一个……"——**它在。**// 要是不敢这么说，往后每一句话都得挂上一条尾巴："**如果那个数存在的话**"。// **数学做不下去，往往不是因为算不动，而是因为每一句话都不敢往下说。**

BOX[key]: 这一篇的一句话 :: 只认分数，等于只认"数字会重复"的那些极限——**这是没道理的挑食**。// 把两种极限都认下来，尺子就没有缺口了。// "没有缺口"这件事，就是第二篇第六节那一步的全部依据。// 它有很多种说法——第五篇会看到，整整八种，而且它们**全都是同一件事**。

BOX[key]: 回头望一眼那块地 :: 开篇担心过**两种漏**。格子的网眼漏掉弯边上的零头——这个好懂；更阴的是第二种：要是**数的世界**也有网眼，两列数挤向的位置可能**什么都没有**，答案从缝里掉下去。// 这一篇把第二种漏堵死了：实数就是全部无限小数，**数轴上没有洞**。挤向的地方，不会扑空。// 把"不会扑空"变成一条条拿得出手的定理，是第五篇的活；至于那儿等着的是不是妹妹猜的 [[1/3]]——那是第二册的事。

BOX[task]: B 组：动动手 :: **B1.** 照第二节的做法，一位一位找出"自己乘自己等于 3"的那个数的前 3 位。**再做一遍**：找出"自己乘自己、再乘一次自己，等于 2"的那个数的前 3 位（它叫 2 的立方根）。// **B1 追问.** 这套一位一位试的办法，对"自己乘自己等于 7"管不管用？对"四个自己相乘等于 5"呢？**先别急着说管用**——回头看一遍你刚才的步骤，指出哪一步用到了"2"或者"平方"这两件事**本身**。（指不出来，那就说明这个办法跟它们没关系。）// **B2.** 接着 B1：妹妹要求误差不超过 0.0001，你给的关口 N 是多少？把第二节那段 ε–N 照抄一遍，把数字换成你自己的。// **B3.** "从 0 到 1 之间的所有有限小数"有没有上确界？是多少？它在这堆数里吗？// **B4.** 照第五节那三行截法，自己做一遍 0.222… ＋ 0.111…：截到第 1、2、3 位各加一遍，写出三个答数，再说出它们挤向谁。// **B5.** 照第七节那张表，把刀改切在**自己乘自己小于 3** 的地方。分数那把尺子上，切口上站着谁？无限小数那把呢？（那个数的头几位，B1 已经让你找过了。）// **B6.** 拿圆规照第三节那四步画一个正六边形，量一量六条边和半径对不对得上。再想一想：**正十二边形**一圈的长度，会比直径的 3 倍长还是短？为什么？

BOX[task]: C 组：想一想 :: **C1.** 第二节证"√2 的平方等于 2"时，最后一步说"比任何正数都小的距离只能是 0"。如果只证到"这个差小于 0.0001"就停，为什么不够？// **C2.** 第二节加餐那个证明里，哪一步用到了"最简"？如果不要求最简，证明会在哪里断掉？// **C3.** 为什么要禁止"以无穷多个 9 结尾"？如果不禁止，比大小的规则会出什么毛病？举一个具体的例子。// **C4.** 妹妹说："上界有无穷多个，凭什么保证里面有一个**最小**的？"——这是个好问题。请你先别急着回答，记住它。**第五篇第三节**就是在回答它。// **C5.** 一年级说"3 减 5 不能减"，这一篇说"一队分数挤向的地方可能没有数"。这两件事**像在哪里**？又**有哪里不一样**？// **C6.** 下面五个动作，哪些会把你带出**分数**的世界？//　①两个分数相加　②两个分数相除（除数不是 0）　③一个分数开平方　④一队分数取极限　⑤给一堆分数找"挡得最紧的那一个"// 有三个的答案是"**有时候会**"——请给这三个各举一个"会"的例子和一个"不会"的例子。// **C7.** 第四节末尾那个小论证，证明了"这样的例子一定存在"，却指不出**到底是哪一个**。而第一节提醒过："设这个数是 S"这四个字**已经假设了它存在**。**这两件事差在哪儿？**为什么小论证不算犯同一个毛病？// **C8.** 第五节说竖式加法要从最右边一位开始，可无限小数根本没有最右边那一位。**那减法呢？乘法呢？**各说一句：为什么**从右往左**那套办法在它们身上也用不上。// **C9.** 第五节末尾那个蓝盒说：**比任何正数都小的距离，只能是 0**。它给的理由是——那个距离要是不等于 0，它自己就是一个正数，拿它自己当妹妹要的那个误差，它就得比自己还小，荒唐。请你把这段道理再讲一遍，并指出它用到了**第一条本质性质**的哪一句。// **C10.** √2 和 π 都不是分数。可这一册对这两件事的态度**不一样**：一个是自己证出来的，一个只是先信着。翻到附录 D 找出这两条，说说书里为什么要把它们分开写。
## 长大以后的写法
BOX[grown]: 课本上会这样写 :: 实数集记作 **R**，有理数集记作 **Q**。**有理数**就是我们说的分数，即循环小数（**有限小数算"以 0 循环"**）；不是有理数的实数叫**无理数**，即不循环的无限小数。// 这一册故意不强调这个区分——因为按小数的讲法，两者的造法完全一样，都是一队有限小数的极限，连收敛的证法都一样。分类是后来才需要的事。// 第二节那个 ε–N 论证，正式写法是：∀ε＞0，∃N，n＞N 时 | a~n~ − √2 | ＜ 10^−n^ ＜ ε。// 第二节验平方那一步用的想法叫**夹逼**（第四篇第二节会把它写成一条定理）。// 上确界记作 sup S，下确界记作 inf S。// 用小数构造实数叫**十进制构造**；另外两条常见路线是**戴德金分割**和**柯西列等价类**，殊途同归。// 加餐那个证明（没有分数的平方等于 2）相传出自毕达哥拉斯学派，是数学史上最著名的证明之一。// 第四节末尾用极限定出来的那种次方，长大以后叫**指数函数**；把次数从分数推广到实数，用的就是那个做法。// 那个小论证留下的悬念——**√2 的 √2 次方到底是不是分数**——1934 年才有答案：**它不是**（盖尔丰德–施奈德定理）。所以真正通的是第二条路。**但请注意：小论证并不需要知道这个答案**，这正是它漂亮的地方。
