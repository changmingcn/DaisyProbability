# 第五篇　导函数拿来干什么

CENTER: 一个数就能告诉你：这台机器（函数）现在是在涨，还是在跌

导函数 f′ 站在一点上吐出的值 f′(a)，是一个数。**一个数能有多大用？**用处大得出奇——它是**正的还是负的**，就把这台机器在这一点的脾气全说清楚了。

## 一、正的在涨，负的在跌

想一想平均变化率的意思：**吐出来的变了多少，除以投进去的挪了多少。**

投进去的往右挪（h 是正的），那么：

- 吐出来的**变多**了 → 平均变化率是**正的** → 机器（函数）在**涨**。
- 吐出来的**变少**了 → 平均变化率是**负的** → 机器在**跌**。

f′(a) 是平均变化率奔向的那个数，所以：

BOX[remember]: 一句话 :: **f′(a) 是正的 ⇒ 在涨。f′(a) 是负的 ⇒ 在跌。**// f′(a) 是 **0** ⇒ 既不涨也不跌——**正在拐弯**。

FIG: fig-05-sign.png | 绿的地方在涨，橙的地方在跌；拐弯的两个点上，f′ 正好是 0。

BOX[key]: 慢着——这句话还没有证 :: 上面那段推理，说的是**平均变化率**：从 a 挪到 a ＋ h，吐出来的确实变多了。// 可 **f′(a) 只站在 a 这一点上**。// // 从**这一点的 f′ 是正的**，到**一整段都在涨**——// **中间还隔着一段路，这一篇没有走过去。**// // 妹妹要是较真，会问：**"你怎么知道中间没有一段偷偷往回跌？"**// 这个问题**本篇答不上来**，它要用到第一册的八大定理。// **第六篇第六节专门去还这张欠条。**// 在那之前，上面那句话请当成**好用的感想**，别当成证过的定理。

## 二、找最高点和最低点

看那张图：**最高点和最低点，都出现在 f′ 等于 0 的地方**。这很合理——如果还在涨，那就还没到顶。

于是我们有了一个**找最值的办法**：

BOX[key]: 找最高点的办法 :: **第一步，**求导，写出 f′。// **第二步，**解方程 f′(a) ＝ 0，找出所有"拐弯的地方"。// **第三步，**看看每个地方两边是涨还是跌，判断它是顶还是谷。

BOX[key]: 这里也赊了账 :: 这个办法里，藏着两件没交代的事：// // **第一件：最高点凭什么存在？**上面是"看那张图"看出来的——**可那是看图。**// 万一这台机器（函数）根本就没有最高点呢？// **第二件：**就算它存在，凭什么**在那儿 f′ 正好是 0**？// // 两件都要请第一册的完备性来还：// **第六篇第二节**证"最高点存在"，**第六篇第三节**证"顶上是平的"。// // 眼下先当工具用——**它给出的答案都对，只是理由还欠着。**

## 三、一道真题：篱笆围最大的地

有 20 米篱笆，要围一块长方形的地，怎么围面积最大？

设一条边是 a 米。四条边一共 20 米，所以另一条边是 **10 − a** 米。面积是：

CENTER: **f(a) ＝ a × (10 − a) ＝ 10a − a^2^**

等式两边求导：**f′(a) ＝ 10 − 2a**。

让它等于 0：**10 − 2a ＝ 0**，解得 **a ＝ 5**。

BOX[remember]: 答案 :: 一条边 5 米，另一条边也是 5 米——**围成正方形，面积最大，25 平方米**。// 检查一下：a ＝ 4 时面积 24，a ＝ 6 时也是 24，都比 25 小。✓// // 这个结论也许你早就"感觉到"了。// **但现在你能证明它**，而且这个办法对**任何**多项式都管用，不只是这一道题。

BOX[task]: 留给姐姐 :: （1）如果篱笆只围三面（有一面靠墙），20 米篱笆最大能围多少？// （2）一个数和"10 减它"的乘积，什么时候最大？这和上面那道题是同一道题吗？// （3）f(a) ＝ a^3^ − 3a。求导，解 f′(a) ＝ 0，找出两个拐弯的地方。哪个是顶，哪个是谷？

## 四、直观翻车：f′ 是 0，不一定是顶也不一定是谷

妹妹该挑刺了：**f′ 是 0**，和**是最高点或最低点**，是一回事吗？

**不是。**这是本篇要抓的那条刺。

BOX[key]: 反例：a^3^ :: f(a) ＝ a^3^，导函数是 3a^2^。// 在 a ＝ 0 处，f′(0) ＝ 0——**f′ 确实是 0**。// 可 0 是最高点吗？不是：投 1 出 1，比 0 大。// 是最低点吗？也不是：投 −1 出 −1，比 0 小。// // 那儿发生了什么？**机器（函数）在那一点"歇了一下"，然后继续往上爬。**// 它只是**喘了口气**，并没有掉头。

BOX[remember]: 所以第三步不能省 :: f′ 等于 0 只说明**可能**是顶或谷，// **必须再看两边**才能定。// 这和第一册那条教训是同一件事：// **"正着成立"不等于"反过来也成立"。**// // 第七篇会给你一个**更快的办法**——看**二阶导函数**，不必再看两边。// 但那个办法也有失灵的时候，**失灵的时候还得回来看两边。**
