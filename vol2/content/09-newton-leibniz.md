# 第九篇　两条路，一个答案

CENTER: 前面两条路一直没打过照面。这一篇它们撞在一起

到现在为止我们做了两件事，**它们看起来毫不相干**：

- **第三、四篇**：量一个函数**走得多快**。靠的是代数——平均变化率约掉 h，代入就行。
- **第八篇**：量一条曲线**底下有多大**。靠的是极限——切条、求和、夹逼。

一件关于**陡不陡**，一件关于**多大块**。一件是算除法，一件是算加法。

**这一篇要说：它们是同一件事。**

## 一、把面积也做成一个函数

第八篇算的是"从 0 到 b"的面积，b 是个定死的数。现在换个眼光：**让右边那头自己动起来。**

BOX[remember]: 面积函数 :: 定义一个新函数 **A**：// **投进去一个 x，吐出来"从 0 到 x，曲线底下那块地的面积"。**// 投 1，吐出从 0 到 1 的面积；投 2，吐出从 0 到 2 的面积。// x 越往右，攒下的面积越多，所以这个函数**只涨不跌**。

FIG: fig-08-area-function.png | A(x) 是已经攒下的面积。x 再往右挪一点点 h，就多出橙色那一小条。

## 二、问一个奇怪的问题：这个面积函数，走得多快？

这个问题奇怪在**它把两条路强行放到了一起**——面积是第八篇的事，"走得多快"是第四篇的事。

按第四篇的办法，算 A 的平均变化率：

CENTER: **[[A(x+h) - A(x)|h]]**

上面那个 **A(x+h) − A(x)** 是什么？就是图上**橙色那一小条的面积**——多走一点点，多攒下的那点地。

那一小条**宽是 h**，**高差不多是 f(x)**。所以它的面积**差不多是 h × f(x)**。除以 h，就**差不多是 f(x)**。

BOX[remember]: 换成微分的说法 :: 那一小条**宽 h、高 f(x)**，面积就是 **f(x) × h**——// 这正是"多走一点点，攒下的面积多多少"，也就是 **A 的微分**。// 而按第四篇第五节，A 的微分又写作 **A′(x) × h**。// 两个写法一对：**A′(x) ＝ f(x)**。// // 这只是**看出**结论，还不是证明——因为那一小条的顶是斜的，"高是 f(x)"只是近似。// 下一节把这点误差算清楚。

BOX[key]: 先看结论，再补严格 :: **A 的导函数，好像就是 f 本身。**// 也就是说：**面积函数求个导，就变回原来那个函数。**// // 但"差不多"三个字必须交代清楚——那一小条**不是**规规矩矩的长方形，// 它的顶是斜的。**差多少？下一节算给你看。**

## 三、"差不多"到底差多少

这一步是全册技术上最要紧的一步。而它用的工具，**第四篇第四节已经备好了**。

那条事实是：对任何多项式，**f(t) − f(x) 一定能提出一个 (t − x)**。

BOX[key]: 算一算误差 :: 在那一小条里，t 跑遍 x 到 x ＋ h，所以 **t − x 最多是 h**。// 而提出 (t − x) 以后剩下的那个多项式，在这一小段上**总有个不超过的数**，叫它 M。// 于是那一小条里**每一点的高，和 f(x) 相差都不超过 M × h**。// // 一小条的宽是 h，高的误差不超过 M × h，// 所以面积的误差不超过 **M × h^2^**（宽 h，乘上高的误差 M × h）。// // 再除以 h：// **平均变化率和 f(x) 的差距，不超过 M × h。**// h 奔向 0，M × h 也奔向 0。// **所以平均变化率奔向 f(x)。**

BOX[remember]: 这一步为什么漂亮 :: 让第四篇**求导变成代数**的那条事实，// 和让这一篇"误差可以忽略"的那条事实，// **是同一条事实。**// 多项式的这个好脾气，两条路上都在替我们干活。

于是我们证明了：

CENTER: **A′(x) ＝ f(x)**

## 四、牛顿–莱布尼兹公式

上面那句话反过来读，就是一件极有用的事。

我们想要 **A**（面积），可 A 很难直接算——第八篇切了半天条才算出一个 x^2^。但现在我们知道：**A 是一个导函数等于 f 的函数**。

**那就反过来找它！**别去切条了，直接问："**哪个函数的导函数是 f？**"

BOX[key]: 牛顿–莱布尼兹公式 :: 要算 f 底下**从 b 到 c** 的面积：// **第一步**，找一个函数 F，让它的导函数正好是 f。// **第二步**，答案就是 **F(c) − F(b)**。// // 就这两步。**一条曲线底下的面积，变成了两个数一减。**

为什么是 F(c) − F(b)？因为 F 和面积函数 A **导函数一样**，所以它们只差一个常数（都在同样地涨，起点可能不同）。一减，那个常数就抵掉了——**又是"一层层抵消"**。

BOX[remember]: 导函数一样就只差一个常数，凭什么 :: 这句话听着像废话，**其实需要证明**——而且不好证。// // 它就是**第六篇第六节的推论三**：// F − A 这个函数的导函数处处是 0，// 由中值定理，**导函数处处是 0 的函数只能是一条平线**，也就是一个常数。// // 请记住这条公式**踩在哪里**：// 没有第六篇那条中值定理，牛顿–莱布尼兹就只是一句好听的话。

### 加餐：第二种读法——总变化，是小变化加出来的

这条公式还有第二种读法。第一种读法是"别切条了，找 F 去"——图它省事。第二种读法更深一层：它把"微"和"积"这两个字的关系挑明了。

BOX[key]: 第二种读法 :: 把从 b 到 c 切成 n 小步，每步长 h。**F 一路的总变化，本来就是每一小步的变化首尾相接加起来**：// **(F(b+h) − F(b)) ＋ (F(b+2h) − F(b+h)) ＋ … ＝ F(c) − F(b)**// ——**又是"一层层抵消"**：中间的全消掉，只剩两头。（这也是 C4 那道题的钥匙。）// 而每一小步的变化，按**第四篇第五节的微分**去估，就是// **F′ × h ＝ f × h**// ——正好是**一小条长方形的面积**。// 两边一对：**左边加出总变化 F(c) − F(b)，右边加出全部小条，也就是面积。**// // 这就是公式的第二张脸：// **求导，把 F 拆成一小步一小步的变化；量面积，把这些小变化拼回去。**// **一拆一拼，互为逆运算**——就像加法配减法、乘法配除法：**求导配量面积**。// "微积分"三个字里的"微"和"积"，说的正是这一拆一拼。

BOX[remember]: 每步都是估的，拼出来凭什么是准的 :: 每一小步用微分去估，都差一个零头。n 步的零头，会不会堆成大错？// **不会，账第三节已经备好了**：每一小步的零头不超过 M × h^2^。// （F 和面积函数 A 每一小步的变化一样大——差的那个常数一步之内就抵掉了，// 所以这笔账和第三节是同一笔；M 取整段从 b 到 c 上那个"总有个不超过的数"。）// n 步加起来：不超过 M × h^2^ × n ＝ M × h × (c − b)。// h 奔向 0，它也奔向 0——**拼回去这一步，站得住。**// 这正是第三节把误差算到 h^2^ 那么细的原因：// **零头比 h 小一档，n 步堆起来才刚好还能被 h 压住。**

## 五、先验个算

第八篇辛辛苦苦切条算出：f(x) ＝ x^2^ 从 0 到 b，面积是 [[b^{3}|3]]。

现在用公式：谁的导函数是 x^2^？第四篇的表告诉我们 x^3^ 的导函数是 3x^2^，所以 **[[x^{3}|3]] 的导函数正好是 x^2^**。于是

CENTER: **F(b) − F(0) ＝ [[b^{3}|3]] − [[0^{3}|3]] ＝ [[b^{3}|3]]**

**一模一样。**可这一次，我们**一个长条都没切**。

BOX[remember]: 两条路的会合 :: 第八篇：切条、求和公式、夹逼——**算了整整两页**。// 这一篇：想一想谁的导函数是 x^2^——**一行**。// 这就是这条公式的价值。// // 还有一层：两条路**必须**会合，不是碰巧。"面积"早被两条规矩钉死——一段一段可以相加；每一小条夹在"最矮的高乘宽"和"最高的高乘宽"之间。// 第二、三节的证明一字不改，就是在证：**守这两条规矩的函数，导函数只能是 f**；再由第六篇推论三，导函数一样只差一个常数，而从起点出发时都是 0——**答案只可能有一个**。// 所以数格子、切条、找 F，只是去同一个地方的三条路。**谁来算都一样，这才叫"算出来了"。**

BOX[key]: 回头望一眼那块地——结案 :: 第一册开篇，妹妹问过："凭什么这么整齐？弯线又不是拿 3 画出来的。"现在可以答她了：// **那个 3，是求导从 x^3^ 上拽下来的。**要让导函数正好是 x^2^，就得先拿 3 除回去——[[1|3]] 就是这么来的。整齐不是巧合，是"一拆一拼互为逆运算"在数字上留下的指纹。// 从数格子，到 ε–N，到数轴没有洞，到存在证书，到速度表，到切条夹逼，再到这一行公式——**开篇的三个问题，到这里全部答完。那块地，结案了。**

## 六、开方的面积：公式到底省了多少事

上面那个例子还不够狠——毕竟切条也能算出来。现在来一个**切条算不出来的**。

CENTER: **√x 底下，从 0 到 1，面积是多少？**

BOX[remember]: 先回顾一下我们已经知道什么 :: 第八篇第七节已经证过：**这块面积存在**。// 用的是第一册的**③单调有界定理**——低估只涨不跌、又有上界。// 可那个证明**一个字也没说它是多少**。// **现在就来算它。**

BOX[key]: 老办法在这里走不通 :: 第八篇第七节已经说过是为什么：切条求和要算下去，// 就得知道 **√1 ＋ √2 ＋ … ＋ √n 等于多少**——**没有这样的公式。**// **这条路是堵死的。**

那就走新路：**找一个导函数是 √x 的函数。**

先得会求 √x 的导函数。平均变化率是 [[\sqrt{x+h} - \sqrt{x}|h]]，展开这条路是堵死的——**但第四篇第四节说过，换一招 h 照样约得掉**。就是这一招：

BOX[key]: 上下同乘，把根号消掉 :: 分子分母**同时乘上** (√(x+h) ＋ √x)。// 分子变成 (x+h) − x ＝ **h**，正好和分母的 h 约掉！// 剩下：// **[[1|\sqrt{x+h} + \sqrt{x}]]**// 现在可以让 h 奔向 0 了，得到 **[[1|2\sqrt{x}]]**。// // **顺带结掉一笔暗账。**"让 h 奔向 0"这一步用到了 √(x+h) 奔向 √x——// 也就是**开方也是连续的**。第三篇只证了多项式连续，开方这一台一直没交代。// 可上面那个式子自己就把它给出来了：// **√(x+h) − √x ＝ [[h|\sqrt{x+h} + \sqrt{x}]]**// 分母不小于 √x，所以这两个数**相差不超过 h 的绝对值除以 √x**。// h 一小，它就跟着小。// // 注意这一招和第四篇是**同一个念头**：// 想办法把那个碍事的 h **弄掉**，再代入。// 多项式靠展开，开方靠上下同乘。

现在反过来猜：**谁的导函数是 √x？**

试试 **F(x) ＝ [[2|3]] × x × √x**。用第四篇的乘积法则验一验：

CENTER: **F′(x) ＝ [[2|3]] × （1 × √x ＋ x × [[1|2\sqrt{x}]]）＝ [[2|3]] × （√x ＋ [[\sqrt{x}|2]]）＝ [[2|3]] × [[3\sqrt{x}|2]] ＝ √x** ✓

BOX[remember]: 答案 :: 从 0 到 1，√x 底下的面积是// **F(1) − F(0) ＝ [[2|3]] × 1 × 1 − 0 ＝ [[2|3]]**。// // **加不出来的那块地，两行就算出来了。**

BOX[key]: 回头看：第一册到底有没有白学 :: 这一册**处处**踩在第一册上。点名如下：// **①–⑧ 里的第③条（单调有界）**——第八篇第七节靠它断定 √x 底下的面积**存在**，而那块面积是加不出来的。// **夹逼定理**（第一册第四篇例二）——第八篇第六节用它把低估高估收口。// **和的极限**（第一册第四篇例三）——第四篇证乘积法则时把式子拆成两块。// **"先证存在，再算是多少"**（第一册第五篇第五节）——**这一篇整篇就是它的一次演出**：先知道面积在，再用公式去够它。// // 第一册那八条**从不告诉你答案是多少，只告诉你答案存在**。// 而这一册证明了：**知道它存在，就已经足够让你把它算出来。**

BOX[key]: 这一册的一句话 :: 牛顿–莱布尼兹公式的价值，不在于它好看。// 在于：**直接加起来做不到的事，它绕过去了。**// 一条路量快慢，一条路量大小，// 走到底才发现**它们是同一条路的两头**——// 而这，就是微积分。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 面积正式写作**定积分**：从 b 到 c 的 f(x) dx，用一个拉长的 S 记号 ∫。那个 S 就是"求和"（Sum）的意思——正是第八篇在做的事；dx 站在被加的每一小条里，报它的宽。// 面积函数 A(x) 叫**变上限积分**；A′(x) ＝ f(x) 叫**微积分基本定理第一部分**。// F(c) − F(b) 那条叫**牛顿–莱布尼兹公式**，也叫**微积分基本定理第二部分**。导数等于 f 的那台 F 叫 f 的**原函数**。// √x 的导数正式写作 [[1|2\sqrt{x}]]；它的原函数 [[2|3]]x√x 通常写成 [[2|3]]x 的 [[3|2]] 次方。// 一般的函数（不只是多项式）也有这条公式，证它要用**连续函数在闭区间上取到最大最小**——那正是第六篇第二节的**最值定理**。这一册在第三节仍旧走了多项式的捷径（那个 M 直接找得出来），但**那条大定理本身，第六篇已经证过了**。
