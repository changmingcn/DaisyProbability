# 第三篇　机器的极限

CENTER: 第一册讲的是"一队数"奔向哪里。可机器（函数）投进去的数不排队——这一篇把桥搭过去

下一篇要问"就在这一点上走得多快"，那里会冒出一句"**让 h 奔向 0**"。**下一篇第一节会先让你看见：汽车速度表指的那个数，就是这么一个极限——这件事你其实早就相信了。**

这句话看着眼熟，其实是**新的**。第一册讲的极限是关于**一队数**的：a~1~、a~2~、a~3~……有第一个、第二个，有号码。可机器投进去的数**不排队**——它可以是 1，可以是 1.4，可以是 1.41421…，中间连成一片，**没有"第几个"**。

没有号码，就没有"第 N 个以后"。**第一册那套关口 N 的说法，在这里直接用不了。**

所以先补这一篇。

## 一、先把第一册那句话摆出来

BOX[remember]: 一队数的极限（第一册） :: 妹妹先说一个误差 ε，随她多小。// 姐姐回答一个**关口 N**：从第 N 个数往后，每一项离 L 都不到 ε。// 一个都不许跑出去。

关键零件有两个：**妹妹的 ε**（误差），和**姐姐的 N**（从第几个起）。

第一个零件可以照搬——**误差还是误差**。麻烦的是第二个：**机器（函数）没有"第几个"。**

## 二、第一条路：让投进去的数排成一队

既然新问题不好办，那就**把它翻译成旧问题**。

想问"投进去的数靠近 c 的时候，吐出来的数怎么样"，我们就**自己给投进去的数排个队**：挑一队数 a~1~、a~2~、a~3~……，让它们**奔向 c**。

这一队投进机器（函数），吐出来的也是一队：f(a~1~)、f(a~2~)、f(a~3~)……**这一队是有号码的**，第一册的办法立刻能用！

FIG: fig-10-sequence-to-function.png | 横着的那队橙点挤向 c，竖着的那队绿点就挤向 L。

BOX[remember]: 第一条路的说法 :: **不管你怎么排队**——只要投进去的那一队奔向 c，// 吐出来的那一队就**总是**奔向同一个数 L，// 我们就说：**a 奔向 c 的时候，f(a) 的极限是 L。**

BOX[key]: "不管你怎么排队"这五个字不能少 :: 妹妹可以从左边排队过去，可以从右边排过来，可以左右横跳。// **每一种排法**吐出来的那队都得奔向**同一个** L，才算数。// 只要有一种排法给出别的答案，**这个极限就不存在**。// 这和第一册"两个聚点就没有极限"是同一个道理。

这条路最大的好处：**一个新概念都不用学**。它把机器的极限，整个化归成了第一册已经嚼烂的数列极限。

## 三、第二条路：不绕道，直接说

排队毕竟麻烦。还有一条路，是**直接照着"误差"的想法重说一遍**——第一册的加餐里露过一面。

回忆一下第一册那两个零件：妹妹给误差，姐姐给"从哪儿起"。机器（函数）这边，"从哪儿起"换成**"离 c 多近"**：

BOX[remember]: 第二条路的说法（ε–δ） :: **妹妹管出口：**"我要求吐出来的数，离 L 不超过 ε。"// **姐姐管入口：**"好。那你投进去的数，只要离 c 不超过 **δ** 就行——δ 我来给。"// // δ 也是个希腊字母，念作"德尔塔"。它和 ε 分工不同：// **ε 管出口的准，δ 管入口的近。**

FIG: fig-11-epsilon-delta.png | 妹妹先画横的那条带，姐姐回答竖的那条带：竖带里的每一个点，出来都落在横带里。

看这张图就明白了：妹妹把横带压得越窄，姐姐就得把竖带也收得越窄。**只要每一次都收得出来，极限就成立。**

BOX[key]: 两条路是一回事 :: 第一条路（排队）和第二条路（ε–δ），**说的是同一件事**。// 这一册不证明它们等价——那是大学的事——// 但你可以这样理解：// 竖带收得住，任何一队奔向 c 的数迟早都会掉进竖带里，出来自然就掉进横带里。

## 四、最要紧的一条：**不管 a 等不等于 c**

现在到了这一篇真正的要害。请特别注意极限定义里的一句话：

CENTER: **我们只管"a 靠近 c 的时候"，从来不管"a 正好等于 c 的时候"。**

为什么要特意排除掉那一点？听起来像是吹毛求疵。**恰恰相反——不排除掉，下一篇就没法做了。**

BOX[key]: 例子就是下一篇要用的东西 :: 取 f(a) ＝ a^2^。第二篇 B1 算过：边长从 3 变到 3.1，面积多了多少。// 现在把这件事写成式子——**平均变化率**：// **[[f(a+h) - f(a)|h]] ＝ [[2ah + h^{2}|h]]**// // **h 正好等于 0 的时候：**上面是 0，下面也是 0。// **0 除以 0 什么都不是**——这台机器（函数）在 h ＝ 0 处**根本没有定义**。// **h 不等于 0 的时候：**约掉 h，等于 **2a ＋ h**。// **h 奔向 0：**它奔向 **2a**。// // 所以：**这个极限存在，尽管那一点上什么都没有。**

BOX[remember]: 记死这一条 :: **极限只问"靠近的时候怎么样"，不问"到了那一点怎么样"。**// 要是极限也要求"在那一点必须有定义"，// **整个微积分都做不成**——因为平均变化率在 h ＝ 0 处永远是 0 除以 0。// // 下一篇整篇都建在这一条上。

## 五、会跳的机器：极限不存在长什么样

不是每台机器（函数）都有极限。看一台会跳的：

BOX[dialog]: 一台会跳的机器 :: 规矩：投进去的数**比 c 小**，就吐出 **0.5**；// **等于 c 或比 c 大**，就吐出 **1.6**。

BOX[remember]: 先说清楚：它是一台正经机器 :: 别被"会跳"两个字骗了——**这台机器守诺言，是好机器（函数）**：// 投进去的每一个数，吐出来的都是**说死了的一个数**，投几次都一样。// 按第一篇第一节那条诺言，**它有资格叫 f**；// 它的画像上，一条竖线也只碰得到一个点。// // 它坏的不是诺言，是**别的东西**——这一节就是要说清坏在哪。// **"守诺言"和"接得上"，是两件事。**

FIG: fig-12-jump.png | 从左边过来一直奔向 0.5，从右边过来一直奔向 1.6。两边不一样。

按第一条路：从左边排队过去，吐出来的一队全是 0.5，奔向 0.5；从右边排队过来，全是 1.6，奔向 1.6。**两种排法给出两个答案**——按第二节那五个字，**这台机器在 c 处没有极限**。

BOX[task]: 留给妹妹 :: 用第二条路（ε–δ）再说一遍它为什么没有极限。// **提示：**你只要**说出一个**足够小的 ε，让姐姐**无论如何也给不出** δ，就赢了。// 试试 ε ＝ 0.5：不管姐姐把 δ 说得多小，// "离 c 不到 δ"的数里面总有比 c 小的（吐 0.5），也有等于 c 的（吐 1.6）。// 这两个结果差 1.1，怎么可能都离同一个数不到 0.5？

## 六、连续：极限正好等于那一点的值

会跳的机器（函数）坏在哪？坏在**"奔向的那个数"和"那一点真正的值"对不上**。

如果对得上，这台机器就有一个好名字：

BOX[remember]: 连续 :: 如果 **a 奔向 c 时 f(a) 的极限，正好等于 f(c)**，// 就说这台机器**在 c 处连续**。// 白话：**画像在这儿不断开**，一笔画得过去。

好消息是：**多项式处处连续**，而且能证。用的还是第二篇那个"只用加法和乘法"的造法——

BOX[key]: 证明：多项式处处连续 :: 对多项式，**f(a) − f(c) 一定能提出一个 (a − c)**（下一篇第四节会细说这件事）：// **f(a) − f(c) ＝ (a − c) × q(a)**// 这里 q 也是一台多项式机器。// 在 c 附近的一小段里，后面那个多项式**总有个不超过的数**，叫它 M。// 于是 **f(a) 和 f(c) 相差不超过 M × (a 到 c 的距离)**。// // 现在妹妹给 ε。姐姐就取 **δ ＝ [[\varepsilon|M]]**。// 只要 a 离 c 不到 δ，f(a) 离 f(c) 就不到 M × δ ＝ ε。**证毕。**

BOX[remember]: 这个证明值得回头看 :: 它是这一册里**第一个真正的 ε–δ 证明**。// 而且它用的那条性质（提得出一个因子），// 下一篇让微分变成代数，第九篇让面积的误差可以忽略——// **三处用的是同一条性质。**

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 函数极限：对任意 ε＞0，存在 δ＞0，使得当 0＜| a − c |＜δ 时，| f(a) − L |＜ε。记作 lim(a→c) f(a) ＝ L。// **那个 0＜ 就是第四节那句"不管 a 等不等于 c"**——它把 a ＝ c 这一点排除在外。// 第二节那条路叫**海涅定理**（归结原则）：函数极限存在 ⟺ 对任意奔向 c 的数列，函数值数列都收敛到同一个数。这一册只用它的直觉，没有证。// 连续的正式定义：lim(a→c) f(a) ＝ f(c)。会跳的那个函数叫**跳跃间断点**。// 第六节证的是**多项式在每一点都连续**；更一般地，多项式还满足**局部利普希茨条件**——那个 M 就是它的利普希茨常数。
