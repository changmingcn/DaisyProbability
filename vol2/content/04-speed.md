# 第四篇　走得多快

CENTER: 这一篇会出现全册第一个惊喜：多项式让"取极限"这一步，变成了"代入"

## 一、先说清楚"多快"是什么意思

车开得多快？**走了多远，除以用了多久。**两个小时开了 120 千米，平均一小时 60 千米。这个算法你早就会。

**可仪表盘上那根针，指的不是它。**它指的是"**此刻**多快"——踩一脚油门，针立刻往上走；松开，针就往下落。**它每一秒都在回答"就是现在，多快"。**

BOX[dialog]: 妹妹的第一问 :: **妹妹：**"'此刻'？一瞬间里，车走了 **0 米**，用了 **0 秒**。// 0 除以 0 什么都不是——那根针到底在指什么？"// **姐姐：**"问得对。可你从来没怀疑过它指着一个数，对不对？// 那我们就把'它指的到底是哪个数'说清楚。"

办法很老实：**一瞬量不了，那就量一小段；再把这一小段缩短。**

一辆车从停着起步，越开越快。行车记录仪记下了它每一刻走了多远。我们盯住**第 3 秒这一刻**，从它往后量一小段，算这一小段的平均速度：

TABLE:
| 量的这一小段 | 走了多远 | 用了多久 | 这一小段的平均速度 |
| 第 3 秒 → 第 4 秒 | 14 米 | 1 秒 | 14 |
| 第 3 秒 → 第 3.1 秒 | 1.22 米 | 0.1 秒 | 12.2 |
| 第 3 秒 → 第 3.01 秒 | 0.1202 米 | 0.01 秒 | 12.02 |
| 第 3 秒 → 第 3.001 秒 | 0.012002 米 | 0.001 秒 | 12.002 |

看最后一列：**14、12.2、12.02、12.002……这一队数，挤向 12。**

而那一刻，仪表盘上的针，正指着**每秒 12 米**（差不多每小时 43 千米）。

FIG: fig-29-speedometer.png | 量的那一小段越短，算出来的平均速度就越挤向 12——针指的就是这一队数挤向的那个数。

BOX[remember]: 速度表是一台"极限表" :: 一瞬间的速度**没法直接量**（那是 0 除以 0）。// 我们**就把它定义成**：那一小段越缩越短时，// **平均速度这一队数奔向的那个数**。// // 请看清楚这句话的分量：// **这一队数——14、12.2、12.02、12.002——正是第一册第一篇那种"一队数"。**// 你从小就相信仪表盘指着一个准数；// **那就等于说，你从小就相信这个极限存在。**// 极限不是新发明的怪东西，**它是你早就在用的东西，今天才给它起了名字。**

BOX[key]: 妹妹出招，姐姐接招——这一回招在车上 :: **妹妹：**"你说是 12。我不信空口白话：我要你说的这个数，**误差不超过 0.01**。"// **姐姐：**"好。你把那一小段**掐在 0.005 秒以内**去量，算出来的平均速度和 12 就差不到 0.01。"// **妹妹：**"我再狠一点，**误差不超过 0.001**。"// **姐姐：**"那就掐在 **0.0005 秒**以内。你要多准，我就掐多短——**你说多小，我都接得住。**"// // 这一来一往，就是第一册那套 ε–N 的语言，// 只不过这一次妹妹要的是**速度的准头**，姐姐给的是**那一小段的短。**// **抽象的那套话，原来一直长在仪表盘上。**

BOX[remember]: 这也正是要有第三篇的原因 :: 妹妹掐的那一小段，可以是 0.1 秒、0.005 秒、0.0007 秒——// **想多短有多短，中间连成一片，没有"第几段"。**// 这就是第三篇说的：**机器（函数）投进去的数不排队**，// 所以第一册那套"从第 N 个起"要换成"离得够近就行"。// **第三篇搭的桥，就是为这一刻搭的。**

好了。现在把这件事**从车搬到机器上**——车不过是一台机器：投进一个时刻，吐出走了多远。

机器也一样。投进去的数从 a 挪到 a ＋ h，吐出来的数就从 f(a) 变成 f(a+h)。于是：

**走得多快**，就是"吐出来的变了多少"除以"投进去的挪了多少"：

CENTER: **[[f(a+h) - f(a)|h]]**

这个式子有个名字，叫**平均变化率**——"变化率"就是"变得多快"，"平均"是说它管的是**一整段**，不是某一点。

FIG: fig-03-difference-quotient.png | 横着挪了 h，竖着变了这么多。两个一比，就是这一段里"平均走得多快"。

BOX[remember]: 它量的是"平均" :: 从 a 到 a ＋ h 这一整段里，机器可能一会儿快一会儿慢。// 平均变化率给的是**这一整段的平均**，就像"全程平均时速"。// 我们真正想知道的是：**就在 a 这一点上，它有多快？**// **也就是：仪表盘那根针，该指着几。**

BOX[key]: 回头望一眼那块地 :: 第一册开篇留过一句谜语：打开那块弯边的地的钥匙，**长得完全不像面积**，是一样你早就认识的东西。// 现在可以揭开了：**就是这只速度表。**// 一根指针，怎么会跟一块地扯上关系？说出来你也未必信——**第八、九篇见分晓**。

## 二、把两个点挪近

在画像上，平均变化率就是**穿过两个点那条直线有多陡**。这条直线叫**割线**。

现在把后一个点往前挪——也就是让 h 越来越小：

FIG: fig-02-secant-to-tangent.png | h 越小，那条橙线就越像"贴着曲线走"。

h 一直小下去，割线就越来越像一条**只碰曲线一下**的直线。那条线叫**切线**，它的陡度就是"**就在 a 这一点上有多快**"。

BOX[key]: 针指的那个数，写下来 :: **在 a 这一点上走得多快，就是平均变化率在 h 趋于 0 时的那个极限。**// 这个数记作 **f′(a)**，念作"**f 撇 a**"。它叫什么名字，先卖个关子——// 下一节算出几个来，你自己就会看出它**不只是一个数**。// 注意"h 趋于 0"是第一册那个意思：**不是让 h 等于 0**（那就成了 0 除以 0），// 而是"不管妹妹把误差定得多小，姐姐都能让 h 小到平均变化率离 f′(a) 不超过它"。

BOX[remember]: 为什么不能直接让 h ＝ 0 :: h ＝ 0 的时候，上面是 0，下面也是 0。// **0 除以 0 什么都不是。**// 所以必须绕道：先算 h 不等于 0 时的平均变化率，再看它奔向哪里。// 这正是第一册整本书在做的事。

## 三、第一个惊喜：约得掉 h

现在动手算。取最简单的 f(a) ＝ a^2^：

CENTER: **f(a+h) − f(a) ＝ (a+h) × (a+h) − a × a ＝ a^2^ ＋ 2ah ＋ h^2^ − a^2^ ＝ 2ah ＋ h^2^**

除以 h：

CENTER: **[[2ah + h^{2}|h]] ＝ 2a ＋ h**

**h 约掉了。**

BOX[key]: 这就是那个惊喜 :: 约掉 h 之后剩下的 **2a ＋ h**，是一个**规规矩矩的多项式**——// 里面再也没有"除以 h"这种危险动作。// 于是"让 h 趋于 0"这一步，**就是把 h 换成 0**：// **f′(a) ＝ 2a。**// // 一般的机器（函数）可没这么好命，得老老实实用 ε–N 一步一步磨。// **多项式把微积分的一半，变成了代数。**

再算 a^3^：

CENTER: **(a+h) × (a+h) × (a+h) − a^3^ ＝ 3a^2^h ＋ 3ah^2^ ＋ h^3^**

除以 h 得 **3a^2^ ＋ 3ah ＋ h^2^**，把 h 换成 0，得 **f′(a) ＝ 3a^2^**。

TABLE:
| 机器 | 平均变化率（约掉 h 以后） | 把 h 换成 0 |
| a | 1 | **1** |
| a^2^ | 2a ＋ h | **2a** |
| a^3^ | 3a^2^ ＋ 3ah ＋ h^2^ | **3a^2^** |
| a^4^ | 4a^3^ ＋ 6a^2^h ＋ 4ah^2^ ＋ h^3^ | **4a^3^** |

BOX[key]: 右边那一列，自己就是一台机器（函数） :: 现在可以揭上一节卖的关子了。看表的右列：**1、2a、3a^2^、4a^3^——它们大多还带着 a**。// 也就是说：**每投进一个 a，就吐出一个"这一点上走得多快"。**// 投进一个数、吐出一个数，守诺言——**这正是一台机器（函数）**。// 它是从 f 造出来的新机器，专管报告 f 在各点的快慢。// 这台新机器叫 **f 的导函数**，记号就是 **f′**；// f′(a) 不是孤零零一个数，**它是导函数在 a 处吐出的值**。// 第一节那根针，指的就是"里程"这台机器的导函数在第 3 秒吐出的数。

BOX[remember]: 看出规律了吗 :: **a^n^ 的导函数是 n × a^n−1^。**// 次数掉下来当系数，指数减一。// 一个常数（比如 5）的导函数是 **0**——它根本不变。

BOX[task]: 留给姐姐 :: 自己把 a^4^ 那一行算一遍，验证表里没写错。// 提示：(a+h) × (a+h) ＝ a^2^ ＋ 2ah ＋ h^2^，再乘两次。// 算完再猜一猜 a^5^ 的导函数，然后**验证你的猜测**。

## 四、为什么"约得掉"不是碰巧

妹妹应该追问一句：**凭什么每次 h 都约得掉？**

因为有一件事对**所有**多项式都成立：

BOX[key]: 一个能扛住整册书的事实 :: 对任何多项式 f，**f(a+h) − f(a) 一定能提出一个 h**：// **f(a+h) − f(a) ＝ h × q(h)**（q 也是一台多项式机器（函数））// 道理很朴素：把 (a+h) 的各次方展开，**不带 h 的那些项**正好凑成 f(a)，被减掉了；// 剩下的每一项都至少带一个 h。// 所以除以 h 之后，**一定**是个多项式，**一定**能直接代 0。// // 记住这句话——**第九篇证牛顿–莱布尼兹时，用的还是它。**

可这就带出下一个问题：**多项式之外的机器呢？**

第二篇特意留着的那台**开方机器 √a**，正好是现成的对照。它不是"只用加和乘"造出来的，所以上面这条路对它是堵死的：**(a+h) 的开方展不开，h 根本写不出来。**

**可 h 照样约得掉。**只要换一招——上下同乘一下，那个碍事的 h 就自己冒出来了。这一招留到**第九篇第六节**当场演给你看，那里正好要用 √a 的导函数。

BOX[remember]: "约得掉"不是多项式的特权 :: 多项式好在**看得见**：把 (a+h) 展开，h 就明明白白摆在那儿，你能把它**写下来**。// 别的机器不一定写得出来，可 h 照样约得掉——// **招数不一样，干的是同一件事：把 h 从变化里提出来。**// // 而且要看清楚我们真正要的是什么：// 说"h 约得掉"，要的是**那个商奔向一个数**——那个数就是 f′(a)。// 所以这句话问的从来不是代数上提不提得出 h，而是：// **这台机器在这一点上，f′(a) 到底存不存在。**// // 那提得出来的时候，**提出来的到底是什么**？// 下一节把"微分"请出来，答案就在那儿。

## 五、微分：把快慢反过来用

f′(a) 回答的是"**在 a 这一点上变化有多快**"。**反过来用**，它就能回答另一个问题：

CENTER: **输入变一点点，输出会跟着变多少？**

回到第二篇的习题 B1：正方形边长从 3 变成 3.01，面积多了多少？

- **真答案**：3.01 × 3.01 − 3 × 3 ＝ 9.0601 − 9 ＝ **0.0601**
- **用 f′ 估**：a^2^ 的导函数是 2a，在 a ＝ 3 处等于 6。输入变了 0.01，所以输出**大约**变 6 × 0.01 ＝ **0.06**

只差 **0.0001** —— 那正是第二篇 B2 里画的**那个小角**（0.01 × 0.01）。

BOX[remember]: 微分 :: 输入从 a 挪动 h，输出**大约**变// **f′(a) × h**// 先看清这样东西的身份：**它不是一个数，是一台小机器（函数）**——// 投进挪动 h，吐出 f′(a) × h；挪 2 倍就兑 2 倍，挪一半就兑一半，**成正比**。// 这台**正比小机器**，就叫 f 在 a 处的**微分**。// // 一句话记住三个词的分工：// **平均变化率**：真正变了多少，除以挪了多少（准，但要 h ≠ 0）。// **导函数 f′**：把各点的快慢记下来的那台机器（f′(a) 是它在 a 处的值）。// **微分**：站定一点，把挪动按 f′(a) 的率兑成变化的那台**正比小机器**（估的，但最好用）。

BOX[key]: 打个比方：站在一点上，微分是一台兑换机 :: 游戏厅里的兑换机：投进 1 个币，吐出固定张数的票——**投多少，按率给多少**。// 机器 f 站在 a 这一点上，也有一个**当场的兑换率**，就是 f′(a)：// 输入端挪 1 小格，输出端就跟着变 f′(a) 格；挪 h，就兑给你 **f′(a) × h**。// **微分就是这台兑换机本身**——率是 f′(a)，投进挪动，兑出变化。// 有两句话要盯紧：// **一、率是"当场"的。**挪到别的地方，f′ 换了数，率就跟着换——// **每一点上支一台自己的兑换机**；报各点兑换率的，正是第三节的导函数。// **二、兑换机是"直"的，机器是"弯"的。**真变化比按率兑出来的多一点零头，// 下面马上把这零头有多小算清楚。// 这个看法往后会一再回来：第十篇把"凭什么按 f′ 这个率兑"说透；// 第九篇更漂亮——**把一小笔一小笔兑出来的变化全部加回去**，那就是牛顿–莱布尼兹。

### 一支飞了两千年的箭

BOX[dialog]: 妹妹替两千年前那个人出招 :: **妹妹：**"我想到一个更狠的。给飞着的箭拍一张照片，就一瞬间那么一张——// 照片里它停在一个位置上，**一点也没往前挪**。// 再拍一张，还是停在一个位置上。每一瞬它都没挪，那它到底什么时候在挪？"// **姐姐：**"这一问不是你想出来的。两千多年前，古希腊人**芝诺**就是这么问的，一问问倒了两千年。// 而且你前半句**完全正确**——照片里确实看不出动：// 飞着的箭和挂在墙上的箭，各拍一张，两张一模一样。// **错的是后半句那两个字：'没挪'。**你把两个不同的意思当成一个了。"

BOX[remember]: 两个"没挪"，说的不是一回事 :: **头一个：这一瞬没有位移**——走了 0 米。// 这句话对**每一支**箭都成立：飞着的、挂着的，一模一样。// **另一个：它是停着的**——速度是 0。// 这句话只对挂在墙上那一支成立。// // 头一个说的是**位置**，另一个说的是**速度**。// **照片拍得到位置，拍不到速度。**// 一支箭动没动，从来不是一张照片里的事——// **是这张照片，和它旁边那些张之间的事。**// 速度表读的，正是这个"之间"。

芝诺这一问真正卡人的地方，是**他只给你两样东西挑**：

TABLE:
| 手里拿着的 | 看得见"此刻"吗 | 算得出走了多远吗 |
| 一瞬——那一小段掐没了 | 看得见 | 算不出：走了 0，什么消息都没留下 |
| 一整段——平均速度 | 看不见 | 算得出，可那是一整段的粗账 |
| **微分 f′(a) × h** | **看得见**：f′(a) 是此刻的率 | **算得出**：h 是一小段真时间 |

BOX[key]: 微分正是他不肯要的第三样 :: 在芝诺那里，箭只有两条路：把那一小段掐成一瞬，或者整段整段地看。// 掐成一瞬，"此刻"有了，路程没了；整段地看，路程有了，"此刻"没了。// **微分是第三条路：左手拿此刻的率，右手拿一小段真时间，两样相乘。**// // f′(a) 来自**一瞬**——它是这一点上的兑换率；// h 是**一小段**——它不是 0，它有长度。// **微分是"此刻"头一回开口说出一段真实的距离。**// // 还有一件事要看清楚：芝诺不是被驳倒的，是被**换掉了问题**。// 他问的是"一瞬间里有没有动"，这个问法本身就找不到答案；// 改问**那一小段缩下去的时候，平均速度挤向哪儿**，答案立刻就有了。// 第一册也是这么干的：不问**能不能做完无穷**，改问**妹妹要多准，姐姐掐多短**。// **换掉问题，是这两册书从头到尾的看家本事。**

回头看第一节妹妹的第一问，你会发现她早就站在芝诺前头了：她说这一瞬走了 **0 米**、用了 **0 秒**。芝诺只念了前半句，**只盯着分子**；妹妹两句都念了，所以她问的是**那根针在指什么**，而不是**针根本不该有数**。

芝诺这一问里还藏着第二个动作：**把每一瞬的 0 攒起来，说全程也是 0**。可**把无穷多份攒到一起**到底是什么意思，第一册第二篇龟兔那里就交代过——**那不是加法，得另外说清楚**。那边的结论是无穷多段不等于无穷多长；这边是同一件事翻个面：**每一份都是 0，不等于攒起来也是 0**。

### 这就回答了第二篇 C3

第二篇 C3 问过一个当时答不上来的问题：**那个小角，边长变化越小就越"可以忽略"——"可以忽略"到底是什么意思？**

现在可以精确回答了。取 f(a) ＝ a^2^：

- 真正的变化是 **2a × h ＋ h^2^**
- 微分是 **2a × h**
- 两者相差 **h^2^**

BOX[key]: "可以忽略"的准确意思 :: 光说"h^2^ 很小"没有用——h 本身也很小。// 关键在于**它们小的程度不一样**：// **把这个误差除以 h**，得到的是 **h**，而 h 奔向 0。// // 所以"可以忽略"的准确说法是：// **误差除以 h 之后，还奔向 0。**// 也就是：它不只是小，它比 h **还要小一档**。// // 这句话是整册书里"可以忽略"四个字**唯一**被允许的意思。

### 回过头看：h 凭什么约得掉

第四节那一问，到这里才算有了真答案。

刚才对 a^2^，我们把真变化拆成了两块：**微分 2ah**，加上**零头 h^2^**。可那是靠展开算出来的。换一台机器（函数）——比如展不开的开方——还拆得出来吗？

拆得出来，而且不用重算一遍。**只要这台机器在这一点上有 f′(a)**，三句话就够：

BOX[key]: 三句话，把零头拆出来 :: **一、**零头就是真变化**减去** f′(a) × h。这是"零头"两个字的意思，没什么好说的。// **二、**把它除以 h。真变化除以 h 是**平均变化率**；f′(a) × h 除以 h 是 **f′(a)**。// 所以**零头除以 h，就等于平均变化率减去 f′(a)**。// **三、**而平均变化率**正奔向 f′(a)**——**f′(a) 存在**说的就是这件事。// 一个奔向 f′(a) 的数，减掉 f′(a)，**当然奔向 0**。// // 于是零头除以 h 奔向 0：**零头比 h 小一档。**// 请注意这三句话里**一个字都没用到多项式**——// **对任何有 f′(a) 的机器（函数）都成立，开方也在内。**

BOX[remember]: "约得掉 h"和"成正比的那一块"，说的是同一件事 :: 拆出来的头一块是 **f′(a) × h**：// 挪 2 倍它就变 2 倍，挪一半它就变一半——// **变多少跟挪多少成正比**，比例正是 f′(a) 这个率。// **成正比的东西除以 h，h 正好被约掉**，只剩下那个率。// 另一块零头除以 h 奔向 0，**进不了答案**。// // 所以"h 约得掉"不是运气，也不是多项式的特权：// **只要 f′(a) 存在，变化里就一定有跟 h 成正比的那一块——那正是微分兑出来的，约掉的也正是它。**// 多项式不过是让这件事**看得见**：h 被你亲手写了出来；// 开方写不出来，那一块照样在那儿。

妹妹一定还想问：**凭什么偏偏是成正比的那一块？**换一个陡度、拿别的直线来配，不行吗？这一问要到**第十篇第四节**才答得干净——那里会证明：能把误差压到比 h 小一档的直线，**只有一条**。

## 六、三条微分法则

从一台机器（函数）造出它的导函数，这个动作就叫**微分**——把 f 微分一遍，得到 f′。（这个动作课本上也叫**求导**，两个说法指同一件事。）有了上面这些，再加三条规矩，任何多项式都微分得动。

BOX[remember]: 三条规矩 :: **一、加起来的：**两台机器（函数）加起来，导函数就是导函数加起来。// **二、乘常数的：**整台机器乘上 5，导函数也跟着乘上 5。// **三、乘起来的：**两台机器乘起来，导函数是——// **前一台的导函数 乘 后一台，加上 前一台 乘 后一台的导函数。**

第三条最不像话，所以先画个图，看看它是从哪来的。把 f 当长、g 当宽，f × g 就是长方形的面积：

FIG: fig-04-product-rule.png | 长变一点、宽变一点，面积多出来两条，外加右上角一小块。

多出来的面积，是这三块拼起来的：**长的微分 × 宽**，加上 **长 × 宽的微分**，再加上**右上角那一小块**。

前两块正是法则里那两项。第三块是"长的微分 × 宽的微分"——按上一节的说法，**它除以 h 之后还奔向 0**，所以它进不了最后的答案。

**但是图只能让人相信，不能当证明。**要证明，就得写成平均变化率，再**取极限**。

BOX[key]: 乘积法则的证明 :: 先写出 f × g 这台机器的平均变化率，然后**加一项、再减掉同一项**（加 f(a+h)g(a)，再减 f(a+h)g(a)，等式不变），拆成两块：// **[[f(a+h)g(a+h) - f(a)g(a)|h]] ＝ [[f(a+h) - f(a)|h]] × g(a+h) ＋ f(a) × [[g(a+h) - g(a)|h]]**// // 这个等式对**每一个不等于 0 的 h** 都成立。现在**考虑等式左右两边在 h 趋于 0 时的极限**。// // **左边**：按定义，正是 f × g 在 a 处的 (f × g)′(a)。// **右边第一块**：[[f(a+h) - f(a)|h]] 奔向 f′(a)；同时 g(a+h) 奔向 g(a)——**这一步用的是第三篇证过的"多项式处处连续"**。// **右边第二块**：f(a) 一直不动，[[g(a+h) - g(a)|h]] 奔向 g′(a)。// // 于是 **(f × g)′ ＝ f′ × g ＋ f × g′**。**证毕。**

BOX[remember]: 图上那个小角，到哪儿去了 :: 它没有被"扔掉"——**它藏在 g(a+h) 这个因子里**。// g(a+h) 比 g(a) 多出来的那一点点，乘上前面那一块，正是右上角那一小块。// 取极限的时候 g(a+h) 奔向 g(a)，**那一点点自己就消失了**。// // 请注意说法的差别：// **不是**"它很小，所以不管它"；// **而是**"取极限以后，它奔向 0"。// **图让人相信，极限才让人证明。**

BOX[remember]: 这里借了一条 :: 上面拆成两块以后，我们用了"**两块相加，极限就是极限相加**"（第一册第四篇例三证过），// 还用了"**两个都有极限的东西相乘，极限就是极限相乘**"——**这一条第一册没有证**，只在例三末尾提过一句。// 它和例三同属"极限的四则运算法则"，证法一样（掰 ε ＋ 三角不等式）。// 这一册**用了它但没证它**，附录 D 里记着这笔账。

## 七、直观翻车：乘起来的导函数，不是导函数乘起来

妹妹一定会想：加起来那条那么简单，乘起来是不是也该是"导函数乘导函数"？

**不是。**这是本篇要抓的那条刺。

BOX[key]: 一个例子就够了 :: 取 f(a) ＝ a，g(a) ＝ a。它们乘起来是 **a^2^**。// **正确答案：**a^2^ 的导函数是 **2a**。// **"导函数乘导函数"给出：**1 × 1 ＝ **1**。// 2a 和 1 显然不是一回事。// // 用规矩三算一遍：1 × a ＋ a × 1 ＝ **2a**。✓ 对上了。

BOX[remember]: 记住这个教训 :: 一条规矩在加法上成立，**不等于**它在乘法上也成立。// 数学里"看起来该这样"的地方，**都要拿一个具体例子试一下**。// **第五篇第四节还会再翻一次车**——那次翻的是**f′ 是 0 就一定是最高点**。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 课本管 **f′(a) 这个数**叫 f 在 a 处的**导数**，管"微分一遍"这个动作叫**求导**；本书正文只说**导函数的值**和**微分**，见到那两个词照直对上就行。// 导数的定义：f′(a) ＝ lim(h→0) [f(a+h) − f(a)] ÷ h。也记作 dy/dx。// 三条规矩分别叫**和法则**、**数乘法则**、**乘积法则**（莱布尼兹法则）。// a^n^ 的导函数是 na^n−1^，叫**幂法则**。// 这一册不需要**商法则**和**链式法则**，因为多项式用不上；但它们是同一套平均变化率推出来的。// 第四节那个事实的正式说法是**因式定理**：多项式 f(t) − f(a) 一定能被 (t − a) 整除。
