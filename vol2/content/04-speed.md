# 第四篇　走得多快

CENTER: 这一篇会出现全册第一个惊喜：多项式让"取极限"这一步，变成了"代入"

## 一、先说清楚"多快"是什么意思

车开得多快？**走了多远，除以用了多久。**两个小时开了 120 千米，平均一小时 60 千米。这个算法你早就会。

**可仪表盘上那根针，指的不是它。**它指的是"**此刻**多快"——踩一脚油门，针立刻往上走；松开，针就往下落。**它每一秒都在回答"就是现在，多快"。**

BOX[dialog]: 妹妹的第一问 :: **妹妹：**"'此刻'？一瞬间里，车走了 **0 米**，用了 **0 秒**。// 0 除以 0 什么都不是——那根针到底在指什么？"// **姐姐：**"问得对。可你从来没怀疑过它指着一个数，对不对？// 那我们就把'它指的到底是哪个数'说清楚。"

办法很老实：**一瞬量不了，那就量一小段；再把这一小段缩短。**

一辆车从停着起步，越开越快。行车记录仪记下了它每一刻走了多远。我们盯住**第 3 秒这一刻**，从它往后量一小段，算这一小段的平均速度：

TABLE:
| 量的这一小段 | 走了多远 | 用了多久 | 这一小段的平均速度 |
| 第 3 秒 → 第 4 秒 | 14 米 | 1 秒 | 14 |
| 第 3 秒 → 第 3.1 秒 | 1.22 米 | 0.1 秒 | 12.2 |
| 第 3 秒 → 第 3.01 秒 | 0.1202 米 | 0.01 秒 | 12.02 |
| 第 3 秒 → 第 3.001 秒 | 0.012002 米 | 0.001 秒 | 12.002 |

看最后一列：**14、12.2、12.02、12.002……这一队数，挤向 12。**

而那一刻，仪表盘上的针，正指着**每秒 12 米**（差不多每小时 43 千米）。

FIG: fig-29-speedometer.png | 量的那一小段越短，算出来的平均速度就越挤向 12——针指的就是这一队数挤向的那个数。

BOX[remember]: 速度表是一台"极限表" :: 一瞬间的速度**没法直接量**（那是 0 除以 0）。// 我们**就把它定义成**：那一小段越缩越短时，// **平均速度这一队数奔向的那个数**。// // 请看清楚这句话的分量：// **这一队数——14、12.2、12.02、12.002——正是第一册第一篇那种"一队数"。**// 你从小就相信仪表盘指着一个准数；// **那就等于说，你从小就相信这个极限存在。**// 极限不是新发明的怪东西，**它是你早就在用的东西，今天才给它起了名字。**

BOX[key]: 妹妹出招，姐姐接招——这一回招在车上 :: **妹妹：**"你说是 12。我不信空口白话：我要你说的这个数，**误差不超过 0.01**。"// **姐姐：**"好。你把那一小段**掐在 0.005 秒以内**去量，算出来的平均速度和 12 就差不到 0.01。"// **妹妹：**"我再狠一点，**误差不超过 0.001**。"// **姐姐：**"那就掐在 **0.0005 秒**以内。你要多准，我就掐多短——**你说多小，我都接得住。**"// // 这一来一往，就是第一册那套 ε–N 的语言，// 只不过这一次妹妹要的是**速度的准头**，姐姐给的是**那一小段的短。**// **抽象的那套话，原来一直长在仪表盘上。**

BOX[remember]: 这也正是要有第三篇的原因 :: 妹妹掐的那一小段，可以是 0.1 秒、0.005 秒、0.0007 秒——// **想多短有多短，中间连成一片，没有"第几段"。**// 这就是第三篇说的：**机器（函数）投进去的数不排队**，// 所以第一册那套"从第 N 个起"要换成"离得够近就行"。// **第三篇搭的桥，就是为这一刻搭的。**

好了。现在把这件事**从车搬到机器上**——车不过是一台机器：投进一个时刻，吐出走了多远。

机器也一样。投进去的数从 x 挪到 x ＋ h，吐出来的数就从 f(x) 变成 f(x+h)。于是：

**走得多快**，就是"吐出来的变了多少"除以"投进去的挪了多少"：

CENTER: **[[f(x+h) - f(x)|h]]**

这个式子有个名字，叫**平均变化率**——"变化率"就是"变得多快"，"平均"是说它管的是**一整段**，不是某一点。

FIG: fig-03-difference-quotient.png | 横着挪了 h，竖着变了这么多。两个一比，就是这一段里"平均走得多快"。

BOX[remember]: 它量的是"平均" :: 从 x 到 x ＋ h 这一整段里，机器可能一会儿快一会儿慢。// 平均变化率给的是**这一整段的平均**，就像"全程平均时速"。// 我们真正想知道的是：**就在 x 这一点上，它有多快？**// **也就是：仪表盘那根针，该指着几。**

BOX[key]: 回头望一眼那块地 :: 第一册开篇留过一句谜语：打开那块弯边的地的钥匙，**长得完全不像面积**，是一样你早就认识的东西。// 现在可以揭开了：**就是这只速度表。**// 一根指针，怎么会跟一块地扯上关系？说出来你也未必信——**第八、九篇见分晓**。

## 二、把两个点挪近

在画像上，平均变化率就是**穿过两个点那条直线有多陡**。这条直线叫**割线**。

现在把后一个点往前挪——也就是让 h 越来越小：

FIG: fig-02-secant-to-tangent.png | h 越小，那条橙线就越像"贴着曲线走"。

h 一直小下去，割线就越来越像一条**只碰曲线一下**的直线。那条线叫**切线**，它的陡度就是"**就在 x 这一点上有多快**"。

BOX[key]: 针指的那个数，写下来 :: **在 x 这一点上走得多快，就是平均变化率在 h 趋于 0 时的那个极限。**// 这个数记作 **f′(x)**，念作"**f 撇 x**"。它叫什么名字，先卖个关子——// 下一节算出几个来，你自己就会看出：**真正的主角不是这一个数，是把各点的数连成的那台机器**。// 注意"h 趋于 0"是第一册那个意思：**不是让 h 等于 0**（那就成了 0 除以 0），// 而是"不管妹妹把误差定得多小，姐姐都能让 h 小到平均变化率离 f′(x) 不超过它"。

BOX[remember]: 为什么不能直接让 h ＝ 0 :: h ＝ 0 的时候，上面是 0，下面也是 0。// **0 除以 0 什么都不是。**// 所以必须绕道：先算 h 不等于 0 时的平均变化率，再看它奔向哪里。// 这正是第一册整本书在做的事。

## 三、第一个惊喜：约得掉 h

现在动手算。取最简单的 f(x) ＝ x^2^：

CENTER: **f(x+h) − f(x) ＝ (x+h) × (x+h) − x × x ＝ x^2^ ＋ 2xh ＋ h^2^ − x^2^ ＝ 2xh ＋ h^2^**

除以 h：

CENTER: **[[2xh + h^{2}|h]] ＝ 2x ＋ h**

**h 约掉了。**

BOX[key]: 这就是那个惊喜 :: 约掉 h 之后剩下的 **2x ＋ h**，是一个**规规矩矩的多项式**——// 里面再也没有"除以 h"这种危险动作。// 于是"让 h 趋于 0"这一步，**就是把 h 换成 0**：// **f′(x) ＝ 2x。**// // 一般的机器（函数）可没这么好命，得老老实实用 ε–N 一步一步磨。// **多项式把微积分的一半，变成了代数。**

再算 x^3^：

CENTER: **(x+h) × (x+h) × (x+h) − x^3^ ＝ 3x^2^h ＋ 3xh^2^ ＋ h^3^**

除以 h 得 **3x^2^ ＋ 3xh ＋ h^2^**，把 h 换成 0，得 **f′(x) ＝ 3x^2^**。

TABLE:
| 机器 | 平均变化率（约掉 h 以后） | 把 h 换成 0 |
| x | 1 | **1** |
| x^2^ | 2x ＋ h | **2x** |
| x^3^ | 3x^2^ ＋ 3xh ＋ h^2^ | **3x^2^** |
| x^4^ | 4x^3^ ＋ 6x^2^h ＋ 4xh^2^ ＋ h^3^ | **4x^3^** |

BOX[key]: 求导是操作，导数是一个点上的值 :: 看表的右列：**1、2x、3x^2^、4x^3^——它们大多还带着 x**。// 也就是说：从原来的函数 f 出发，我们造出了一台新函数，记作 **f′**；// 这个“从 f 造出 f′”的动作叫**求导**，可以写成 **f → f′**。// // 再把一个具体的 x 投进 f′，吐出的 **f′(x)**，// 才叫 **f 在 x 这一点的导数**——它是一个数，只站在这一个点上。// 第一节那根针，指的就是里程函数在第 3 秒的导数。// **求导管整台函数；导数管一个点。**这两个身份往后不再混用。

BOX[remember]: 看出规律了吗 :: 对 **x^n^** 求导，得到 **f′(x) ＝ n × x^n−1^**。// 次数掉下来当系数，指数减一。// 对常数函数（比如 f(x) ＝ 5）求导，得到 **f′(x) ＝ 0**——// 它在每一点的导数都是 0，因为它根本不变。

BOX[task]: 留给姐姐 :: 自己把 x^4^ 那一行算一遍，验证表里没写错。// 提示：(x+h) × (x+h) ＝ x^2^ ＋ 2xh ＋ h^2^，再乘两次。// 算完再猜一猜：对 x^5^ 求导会得到什么，然后**验证你的猜测**。

## 四、为什么"约得掉"不是碰巧

妹妹应该追问一句：**凭什么每次 h 都约得掉？**

因为有一件事对**所有**多项式都成立：

BOX[key]: 一个能扛住整册书的事实 :: 对任何多项式 f，**f(x+h) − f(x) 一定能提出一个 h**：// **f(x+h) − f(x) ＝ h × q(h)**（q 也是一台多项式机器（函数））// 道理很朴素：把 (x+h) 的各次方展开，**不带 h 的那些项**正好凑成 f(x)，被减掉了；// 剩下的每一项都至少带一个 h。// 所以除以 h 之后，**一定**是个多项式，**一定**能直接代 0。// // 记住这句话——**第九篇证牛顿–莱布尼兹时，用的还是它。**

可这就带出下一个问题：**多项式之外的机器呢？**

第二篇特意留着的那台**开方机器 √x**，正好是现成的对照。它不是"只用加和乘"造出来的，所以上面这条路对它是堵死的：**(x+h) 的开方展不开，h 根本写不出来。**

**可 h 照样约得掉。**只要换一招——上下同乘一下，那个碍事的 h 就自己冒出来了。这一招留到**第九篇第六节**当场演给你看，那里正好要求 √x 在每一点的导数。

BOX[remember]: "约得掉"不是多项式的特权 :: 多项式好在**看得见**：把 (x+h) 展开，h 就明明白白摆在那儿，你能把它**写下来**。// 别的机器不一定写得出来，可 h 照样约得掉——// **招数不一样，干的是同一件事：把 h 从变化里提出来。**// // 而且要看清楚我们真正要的是什么：// 说"h 约得掉"，要的是**那个商奔向一个数**——那个数就是 f′(x)。// 所以这句话问的从来不是代数上提不提得出 h，而是：// **这台机器在这一点上，f′(x) 到底存不存在。**// // 那提得出来的时候，**提出来的到底是什么**？// 下一节把"微分"请出来，答案就在那儿。

## 五、微分：把快慢反过来用

f′(x) 回答的是"**在 x 这一点上变化有多快**"。**反过来用**，它就能回答另一个问题：

CENTER: **输入变一点点，输出会跟着变多少？**

回到第二篇的习题 B1：正方形边长从 3 变成 3.01，面积多了多少？

- **真答案**：3.01 × 3.01 − 3 × 3 ＝ 9.0601 − 9 ＝ **0.0601**
- **用导数估**：对 x^2^ 求导得到 f′(x) ＝ 2x，所以在 x ＝ 3 处的导数是 f′(3) ＝ 6。输入变了 0.01，输出就**大约**变 6 × 0.01 ＝ **0.06**

只差 **0.0001** —— 那正是第二篇 B2 里画的**那个小角**（0.01 × 0.01）。

先给输出起个名字：**y ＝ f(x)**。然后站定 x，把输入端的一小段挪动记作 **dx**，把线性替身给出的输出变化记作 **dy**。

BOX[remember]: 微分 :: 站定 x，微分是这样一台小函数：// **投进 dx，吐出 dy ＝ f′(x)dx。**// // 先看清它的身份：**f′(x) 是导数，是一个数；微分是 dx → dy 的整台函数。**// dx 变 2 倍，dy 就变 2 倍；dx 减半，dy 也减半——// 它是一台**线性函数**，用这一点的导数 f′(x) 当倍率。// // 真函数 f 是弯的；微分只管 x 附近这一小块，用直的变化去替代弯的变化。// 它给的是最好的线性近似，不是真变化本身；两者之间还差一个零头。

BOX[key]: 四个词，各管一件事 :: **平均变化率**：真正变了多少，除以挪了多少，管一整段（准，但要 h ≠ 0）。// **导数 f′(x)**：f 在 x 这一点有多快——一个数。// **求导 f → f′**：对整台函数做的操作，得到新函数 f′。// **微分 dx → dy ＝ f′(x)dx**：站定一点，用导数当倍率造出的局部线性函数。

BOX[key]: 打个比方：站在一点上，微分是一台兑换机 :: 游戏厅里的兑换机：投进 1 个币，吐出固定张数的票——**投多少，按率给多少**。// 函数 f 站在 x 这一点上，也有一个**当场的兑换率**，就是导数 f′(x)：// 投进 dx，兑换机就兑出 **dy ＝ f′(x)dx**。// **微分就是这台兑换机本身**——导数只是写在机器上的倍率。// // 有两句话要盯紧：// **一、倍率是“当场”的。**挪到别的点，导数换了数，就得换一台兑换机；// f′ 这台函数负责把每一点该用的倍率列出来。// **二、兑换机是直的，原函数是弯的。**真变化比 dy 多一点零头，// 下面马上把这零头有多小算清楚。// 第十篇会把“为什么这台线性函数替得最好”说透；// 第九篇会把一小笔一小笔 dy 全部加回去——那就是牛顿–莱布尼兹。

### 画出来看：微分是图上的哪一段

兑换机是打比方。微分还有一张**真正的脸**，就画在画像上。

FIG: fig-31-tangent-pieces.png | 左：站在一点上投进 dx，顺切线走升起 dy——这台 dx → dy 的线性函数就是微分；爬曲线得到的真变化还多一个零头。右：整条曲线切成小段，每段用自己的线性替身顶上，切得越细贴得越紧。

先看左图。站在 x 这一点，往右投进一小段 dx。想知道输出真变了多少，就得**爬曲线**，一直爬到曲线上那个新的点。可你也可以换上局部替身：**顺着这一点的切线走**。切线是直的，倍率正是这个点的导数 f′(x)——横着走 dx，竖着就升 **dy ＝ f′(x)dx**。

BOX[remember]: 微分在图上的位置 :: **顺切线走升起 dy，这个 dx → dy 的对应就是微分。**// 它和真变化（爬曲线升的那一整段）差的，是顶上那一条小缝——**零头**。// dx 挪得越短，小缝缩得比 dx 还快（后面会证：零头比 dx 小一档）。// // 所以微分干的事，画出来就是一句话：// **在一小段里，拿线性函数顶替原函数的变化**——// 弯的变化，用**跟挪动成正比**的直线变化顶替，误差比挪动小一档。

再看右图。这件事**在每一点上都做得成**。把整条曲线切成许许多多小段，每一小段都用它自己的切线小段顶替——拼出来的折线和曲线几乎贴在一起，**段切得越细，贴得越紧**。

BOX[key]: f′ 的几何意义，也在这张图里 :: 右图每一小段的倍率是谁定的？**是那一点的导数**：// 走到哪一点，f′ 就报出 f′(x)，也就是那一点切线的陡度。// f′ 自己仍是一台函数，作用是把**各点的导数列成一张名单**；// 真正顶替原函数的，是每一点上按这张名单支起来的微分 **dx → dy**。// // 这张图往后还有两次出场：// **第九篇**会把这些 dy **全部加回去**——那就是牛顿–莱布尼兹；// 而“凭什么顶替原函数的只能是这一台线性函数”，**第十篇第四节**会证个明白。

这张图值得收成一句话——函数整条是**弯**的，那是**全局**；可在每一点的**局部**，都支得起一台**直**的小机器顶替它：

CENTER: **导数是一个数；微分是用这个数造出的局部线性函数**

### 把求导、导数和微分并排看

到这里，三个长得很近的对象可以彻底分开了。

BOX[key]: 三层，别混 :: **第一层，求导：f → f′。**这是对整台函数做操作，产物 f′ 仍是一台函数。// **第二层，导数：f′(x)。**把一个点 x 投进 f′，吐出这一点的倍率——一个数。// **第三层，微分：dx → dy ＝ f′(x)dx。**站定 x，用这个倍率造一台线性函数，// 拿来替代原函数在这一点附近的变化。// // 所以不是“微分等于导数”，也不是“导数是一台替身”：// **导数给倍率，微分才是替身。**

BOX[remember]: h 和 dx 也分开 :: 前四节里的 **h**，是拿来算平均变化率、再让它奔向 0 的试探步；// 它帮我们把导数 f′(x) 造出来。// **dx** 是导数已经造好以后，投进微分这台线性函数的输入；// 微分回答的是：给我一个 dx，我用 **dy ＝ f′(x)dx** 回答你。// 一个负责**造倍率**，一个负责**使用倍率**。

### 一支飞了两千年的箭

BOX[dialog]: 妹妹替两千年前那个人出招 :: **妹妹：**"我想到一个更狠的。给飞着的箭拍一张照片，就一瞬间那么一张——// 照片里它停在一个位置上，**一点也没往前挪**。// 再拍一张，还是停在一个位置上。每一瞬它都没挪，那它到底什么时候在挪？"// **姐姐：**"这一问不是你想出来的。两千多年前，古希腊人**芝诺**就是这么问的，一问问倒了两千年。// 而且你前半句**完全正确**——照片里确实看不出动：// 飞着的箭和挂在墙上的箭，各拍一张，两张一模一样。// **错的是后半句那两个字：'没挪'。**你把两个不同的意思当成一个了。"

BOX[remember]: 两个"没挪"，说的不是一回事 :: **头一个：这一瞬没有位移**——走了 0 米。// 这句话对**每一支**箭都成立：飞着的、挂着的，一模一样。// **另一个：它是停着的**——速度是 0。// 这句话只对挂在墙上那一支成立。// // 头一个说的是**位置**，另一个说的是**速度**。// **照片拍得到位置，拍不到速度。**// 一支箭动没动，从来不是一张照片里的事——// **是这张照片，和它旁边那些张之间的事。**// 速度表读的，正是这个"之间"。

芝诺这一问真正卡人的地方，是**他只给你两样东西挑**：

TABLE:
| 手里拿着的 | 看得见"此刻"吗 | 算得出走了多远吗 |
| 一瞬——那一小段掐没了 | 看得见 | 算不出：走了 0，什么消息都没留下 |
| 一整段——平均速度 | 看不见 | 算得出，可那是一整段的粗账 |
| **微分 dx → dy ＝ f′(x)dx** | **看得见**：f′(x) 是此刻的率 | **算得出**：dx 是一小段真时间 |

BOX[key]: 微分正是他不肯要的第三样 :: 在芝诺那里，箭只有两条路：把那一小段掐成一瞬，或者整段整段地看。// 掐成一瞬，“此刻”有了，路程没了；整段地看，路程有了，“此刻”没了。// **微分是第三条路：左手拿此刻的率，右手把一小段真时间 dx 投进去，得到 dy ＝ f′(x)dx。**// // f′(x) 来自**一瞬**——它是这一点上的兑换率；// dx 是**一小段**——它不是 0，它有长度。// **微分让“此刻”头一回能对一段真时间说出线性的路程近似。**// // 还有一件事要看清楚：芝诺不是被驳倒的，是被**换掉了问题**。// 他问的是“一瞬间里有没有动”，这个问法本身就找不到答案；// 改问**那一小段缩下去的时候，平均速度挤向哪儿**，答案立刻就有了。// 第一册也是这么干的：不问**能不能做完无穷**，改问**妹妹要多准，姐姐掐多短**。// **换掉问题，是这两册书从头到尾的看家本事。**

回头看第一节妹妹的第一问，你会发现她早就站在芝诺前头了：她说这一瞬走了 **0 米**、用了 **0 秒**。芝诺只念了前半句，**只盯着分子**；妹妹两句都念了，所以她问的是**那根针在指什么**，而不是**针根本不该有数**。

芝诺这一问里还藏着第二个动作：**把每一瞬的 0 攒起来，说全程也是 0**。可**把无穷多份攒到一起**到底是什么意思，第一册第二篇龟兔那里就交代过——**那不是加法，得另外说清楚**。那边的结论是无穷多段不等于无穷多长；这边是同一件事翻个面：**每一份都是 0，不等于攒起来也是 0**。

### 这就回答了第二篇 C3

第二篇 C3 问过一个当时答不上来的问题：**那个小角，边长变化越小就越"可以忽略"——"可以忽略"到底是什么意思？**

现在可以精确回答了。取 f(x) ＝ x^2^：

- 真正的变化是 **2x × dx ＋ (dx)^2^**
- 微分是 **dy ＝ 2x × dx**
- 两者相差 **(dx)^2^**

BOX[key]: "可以忽略"的准确意思 :: 光说"(dx)^2^ 很小"没有用——dx 本身也很小。// 关键在于**它们小的程度不一样**：// **把这个误差除以 dx**，得到的是 **dx**，而 dx 奔向 0。// // 所以"可以忽略"的准确说法是：// **误差除以 dx 之后，还奔向 0。**// 也就是：它不只是小，它比 dx **还要小一档**。// // 这句话是整册书里"可以忽略"四个字**唯一**被允许的意思。

### 回过头看：微分凭什么替得像

第四节那一问，到这里才算有了真答案。

刚才对 x^2^，我们把真变化拆成了两块：**微分 dy ＝ 2x dx**，加上**零头 (dx)^2^**。可那是靠展开算出来的。换一台机器（函数）——比如展不开的开方——还拆得出来吗？

拆得出来，而且不用重算一遍。**只要这台机器在这一点上有 f′(x)**，三句话就够：

BOX[key]: 三句话，把零头拆出来 :: **一、**站定 x，把 dx 投进微分，得到 **dy ＝ f′(x)dx**；零头就是真变化**减去 dy**。// **二、**把零头除以 dx。真变化除以 dx 是**平均变化率**；dy 除以 dx，按上面的线性规则正好只剩 **f′(x)**。// 所以**零头除以 dx，就等于平均变化率减去 f′(x)**。// **三、**而平均变化率**正奔向 f′(x)**——**f′(x) 存在**说的就是这件事。// 一个奔向 f′(x) 的数，减掉 f′(x)，**当然奔向 0**。// // 于是零头除以 dx 奔向 0：**零头比 dx 小一档。**// 请注意这三句话里**一个字都没用到多项式**——// **对任何有 f′(x) 的机器（函数）都成立，开方也在内。**

BOX[remember]: "约得掉"和"线性替身"，说的是同一件事 :: 微分给出的头一块是 **dy ＝ f′(x)dx**：// dx 放大 2 倍，dy 就放大 2 倍；dx 变成一半，dy 也变成一半——// **输出跟输入成正比**，比例正是 f′(x) 这个导数。// dy 除以 dx，dx 正好被约掉，只剩下那个倍率；另一块零头除以 dx 奔向 0，**进不了答案**。// // 所以试探步 h 能在差商里约掉，不是运气，也不是多项式的特权：// **只要 f′(x) 存在，变化里就一定有一台以 dx 为输入的线性替身——那正是微分。**// 多项式不过是让这件事**看得见**；开方展不开，线性替身照样在那儿。

## 六、三条求导法则

对整台函数 f 做一次操作，得到另一台函数 f′，这个动作就叫**求导**。把 x 投进 f′，得到的数 f′(x) 才是 f 在 x 点的**导数**。能在一点造出微分 **dx → dy ＝ f′(x)dx**，就说函数在这一点**可微**。有了上面这些，再加三条规矩，就能给任何多项式求导——多项式**处处可微**。

BOX[remember]: 三条规矩 :: **一、加起来的：**(f ＋ g)′ ＝ f′ ＋ g′。// **二、乘常数的：**(5f)′ ＝ 5f′。// **三、乘起来的：**(fg)′ ＝ f′g ＋ fg′。// // 每条等式说的都是**求导前后的函数关系**；再投进一个 x，等式两边才变成这一点的导数值。

第三条最不像话，所以先画个图，看看它是从哪来的。把 f 当长、g 当宽，f × g 就是长方形的面积：

FIG: fig-04-product-rule.png | 长变一点、宽变一点，面积多出来两条，外加右上角一小块。

多出来的面积，是这三块拼起来的：**长的微分输出 × 原宽**，加上 **原长 × 宽的微分输出**，再加上**右上角那一小块**。

前两块正是法则里那两项。**看清每一块乘的是什么：变化的那条边，乘的都是另一条边的原长——函数的值，不是它的变化。**真让“变化乘变化”的，只有右上角那一小块——两台微分各自的输出相乘——按上一节的说法，**它除以 h 之后还奔向 0**，所以它进不了最后的答案。

BOX[remember]: 三条规矩，同一个直觉 :: 拆开看，三条规矩干的是同一件事：// **只留跟挪动成正比的，把不成正比的交给极限。**// 加起来的：两份变化各自留下成正比的一块，照抄相加；// 乘起来的：进答案的两条边带，**变化的一边乘的都是另一边的原长**；// 想让两份**变化**乘在一起？只有右上小角——零头中的零头。// 这也预先说破了下一节那场翻车：**f′g′ 算的是小角的账，不是边带的账。**

**但是图只能让人相信，不能当证明。**要证明，就得写成平均变化率，再**取极限**。

BOX[key]: 乘积法则的证明 :: 先写出 f × g 这台机器的平均变化率，然后**加一项、再减掉同一项**（加 f(x+h)g(x)，再减 f(x+h)g(x)，等式不变），拆成两块：// **[[f(x+h)g(x+h) - f(x)g(x)|h]] ＝ [[f(x+h) - f(x)|h]] × g(x+h) ＋ f(x) × [[g(x+h) - g(x)|h]]**// // 这个等式对**每一个不等于 0 的 h** 都成立。现在**考虑等式左右两边在 h 趋于 0 时的极限**。// // **左边**：按定义，正是 f × g 在 x 处的 (f × g)′(x)。// **右边第一块**：[[f(x+h) - f(x)|h]] 奔向 f′(x)；同时 g(x+h) 奔向 g(x)——**这一步用的是第三篇证过的"多项式处处连续"**。// **右边第二块**：f(x) 一直不动，[[g(x+h) - g(x)|h]] 奔向 g′(x)。// // 于是 **(f × g)′ ＝ f′ × g ＋ f × g′**。**证毕。**

BOX[remember]: 图上那个小角，到哪儿去了 :: 它没有被"扔掉"——**它藏在 g(x+h) 这个因子里**。// g(x+h) 比 g(x) 多出来的那一点点，乘上前面那一块，正是右上角那一小块。// 取极限的时候 g(x+h) 奔向 g(x)，**那一点点自己就消失了**。// // 请注意说法的差别：// **不是**"它很小，所以不管它"；// **而是**"取极限以后，它奔向 0"。// **图让人相信，极限才让人证明。**

BOX[remember]: 这里借了一条 :: 上面拆成两块以后，我们用了"**两块相加，极限就是极限相加**"（第一册第四篇例三证过），// 还用了"**两个都有极限的东西相乘，极限就是极限相乘**"——**这一条第一册没有证**，只在例三末尾提过一句。// 它和例三同属"极限的四则运算法则"，证法一样（掰 ε ＋ 三角不等式）。// 这一册**用了它但没证它**，附录 D 里记着这笔账。

### 可微不可微，画像上一眼看得出

第六节开头说过：在一点上微分造得出来，就叫**可微**。这件事画出来就是第五节那张图——**放大以后，能看成一段直线**，有切线可以顶替。那**不可微**长什么样？

FIG: fig-32-spikes.png | 左：尖角。左右两边各有各的陡度，一条切线定不下来——连着，可是在尖角上不可微。右：一条浑身是毛刺的曲线——处处连着、处处是尖的，没有一处能用直线顶替。

先看最简单的一种：**尖角**。拿这台机器试：投进 x，吐出**它的绝对值**（第一册教过的生字）。在 0 那一点上算平均变化率：从右边挪，一律是 1；从左边挪，一律是 −1。**两边各奔各的，凑不出同一个极限——f′(0) 不存在。**画像上就是左图那个 V 字：左右两边各有各的陡度，**一条切线定不下来**。

注意它**连着**——尖角不断开。反过来倒是真的：**可微的机器在那一点一定连着**——真变化就是平均变化率乘 h，h 奔向 0 时，前一个奔向 f′(x)、后一个奔向 0，乘起来奔向 0，变化奔向 0 就是接得上。（这一步用的又是**极限相乘**，附录 D 记着的那笔账。）

**尖角要是多起来呢？**右图那条曲线，**处处连着、处处是尖的——浑身毛刺，放大多少倍毛刺都不消失**。第十篇第一节会拿放大镜看曲线：可微的曲线越放越直；这一条**放到天边也直不了**，没有一处可微。这样的曲线真的存在，数学家第一次见到它时都吓了一跳——大名在下面灰盒里。

BOX[remember]: 可微性，画像一眼看得出 :: **可微，就是放大以后能看成直线**：弯的变化，能用成正比的顶替。// **不可微，就是放大到最后还是尖的**：左右陡度对不上，切线定不下来。// **连续管接得上，可微管平滑**——可微的都连着；// 连着的不一定可微，它可以浑身是毛刺。// 顺带一句：习题 C7 那台开方机器在 0 那一点，是**另一种**不可微——// 不是尖，是**立得太陡**（平均变化率要多大有多大）。

BOX[grown]: 那条毛刺曲线的大名 :: 处处连续、处处不可微的函数，头一个公开的例子叫**魏尔斯特拉斯函数**（1872 年）：把一层比一层细的波浪无穷层叠起来，每一层都往曲线上添更细的毛刺。右图画的是只叠六层的近亲——真身要无穷层叠上去。// 它刚露面时把当时的数学界吓得不轻：大家原本以为"连续的函数至多几个尖角"，有人把这类例子叫作**病态函数**。今天它是常客——**海岸线、山脊、股价走势图，都长着这种放大不消失的毛刺**，研究它们的学问叫**分形**。

## 七、直观翻车：乘积的导数，不是两个导数相乘

妹妹一定会想：加起来那条那么简单，乘起来以后，某点的导数是不是也该等于两个原函数在这点的导数相乘？

**不是。**这是本篇要抓的那条刺。

BOX[key]: 一个例子就够了 :: 取 f(x) ＝ x，g(x) ＝ x。它们乘起来是 **x^2^**。// **正确答案：**对 x^2^ 求导得到 2x，因此它在 x 点的导数是 **2x**。// **"两个导数相乘"给出：**1 × 1 ＝ **1**。// 2x 和 1 显然不是一回事。// // 用规矩三算一遍：1 × x ＋ x × 1 ＝ **2x**。✓ 对上了。

翻车的原因，第六节那张长方形早就画着：进答案的两条边带，**变化的一边乘的都是另一边的原长**；两个导数相乘所对应的，是**右上小角**——那是零头，除以 h 之后还奔向 0，进不了答案。**拿零头当答案，当然对不上。**

BOX[remember]: 记住这个教训 :: 一条规矩在加法上成立，**不等于**它在乘法上也成立。// 数学里"看起来该这样"的地方，**都要拿一个具体例子试一下**。// **第五篇第四节还会再翻一次车**——那次翻的是**f′ 是 0 就一定是最高点**。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 课本管 **f′(x) 这个数**叫 f 在 x 处的**导数**，本书也照用这个名字。把每一点的导数收在一起，x ↦ f′(x) 当然仍是一台函数；为了不把"一个点的数"和"整台函数"混在一起，本书只写 **f′**，不另造一个名字。// 导数的定义：f′(x) ＝ lim(h→0) [f(x+h) − f(x)] ÷ h。求导是 **f → f′**；微分则是在站定 x 后造出的线性函数 **dx → dy ＝ f′(x)dx**。// 三条规矩分别叫**和法则**、**数乘法则**、**乘积法则**（莱布尼兹法则）。// 对 x^n^ 求导得到 nx^n−1^，叫**幂法则**。// 这一册不需要**商法则**和**链式法则**，因为多项式用不上；但它们是同一套平均变化率推出来的。// 第四节那个事实的正式说法是**因式定理**：多项式 f(t) − f(x) 一定能被 (t − x) 整除。
