# 第一篇　函数：好机器和破机器

CENTER: 什么才算一台机器？先把这件事说死，全书都踩在它上面

第一册的加餐里出现过一台机器：**投进去一个数 x，吐出来一个数**，记作 f(x)。

那时它只是个配角。这一册它是主角。

主角登场之前，得先验明正身：**什么才算一台机器？**这件事看着像废话，其实是全书的地基。

## 一、好机器和破机器

投进去一个数，吐出来一个数——这样的东西满世界都是。可它们**分成两种**，差别要紧得很。

BOX[remember]: 好机器的诺言 :: **同一个数投两次，吐出来的必须一模一样。**// 今天投 3 出 9，明天投 3 还得出 9；后天投 3，仍然是 9。// // **说话算话、稳定发挥的，叫好机器：只要输入一样，每次吐出来的数也一样。**// **时常故障、会变卦的，叫破机器。**

好机器你身边就有。大人答应过你：**期末考进前十，就买那本你想要的书**。要是他信守诺言，那么"考进前十"这个输入一进来，输出就是**那本书**——不会今天说买书、明天改口买支铅笔、后天说等等再看。**一台好机器，就是一个永远信守诺言的大人。**

破机器也不少：

BOX[key]: 老虎机是破机器的头号代表 :: 游戏厅的**老虎机**：投进一个币，这次哗啦啦吐出一百个，// 下一次投同一个币，一个也不吐。// **同样的投入，不一样的产出**——它变卦。// // 所以**老虎机是一台破机器**。抽奖箱、骰子、明天的天气，也都是破机器。// // 破机器故障起来千奇百怪：有的像老虎机这样忽多忽少，// 有的更离谱——投一个数进去，**一次吐出好几个数**，你都不知道该拿哪一个。// （这样的家伙第三节就会撞见：一条竖线碰到两个点的，就是它的画像。）// // 破机器不是没人研究（长大以后你会遇到专门对付它们的一门学问），// **但这两册书只研究好机器。**

BOX[remember]: 一个约定 :: 往后我们说"**机器**"，**一律指好机器**。// 要说破的，会明说"破机器"。// f 这个名字，也只给好机器用。

BOX[key]: 第一册那件苦差事，原来就是在证这个 :: 第一册第二篇花了整整一节，证"**一队数不可能奔向两个不同的数**"（极限唯一）。// 当时你也许会想：这还用证？// **现在你知道它在证什么了——它证的是"取极限"这台机器守诺言。**// 投进去一队数，吐出来的极限**只能有一个**。// 要是同一队数能有两个极限，lim 就是台**破机器**，// 后面所有的话都没法说了。// **那一节不是找茬，是在给全套书办出生证。**

BOX[dialog]: 妹妹追问一句要紧的 :: **妹妹：**"那这台呢——投 2 出 4，投 −2 也出 4。同一个答案给了两个人，它算变卦吗？"// **姐姐：**"不算，它是好机器。**两个不同的人，可以得同一个奖品**——这不叫说话不算话。"// **妹妹：**"那什么才叫？"// **姐姐：**"**同一个人**，这次给这个、下次给那个。诺言管的是**从投进去到吐出来**这个方向：// **一个输入，只许有一个输出。**倒过来那个方向，机器没答应过你什么。"

BOX[remember]: 这条诺言，全书都在用 :: 记住这一条，后面三个地方都要靠它：// **一、**画像上，一条**竖线只能碰到画像一次**（第三节）。// **二、**开方机器**只挑正的那个答案**——不挑就守不住诺言（第二篇第二节）。// **三、**第三篇那台**会跳的机器**：它跳，但它**不变卦**——所以它仍然是**好机器**，// 只是**不连续**。**"守不守诺言"和"连不连得上"，是两件事。**

## 二、给机器起个名字

机器多了，得叫得出名字。数学上给机器起的名字通常就是一个字母，最常用的是 **f**。

BOX[remember]: f(x) 怎么念 :: **f(x)** 念作"**f 括号 x**"，意思是：// **把 x 投进 f 这台机器，吐出来的那个数。**// 它不是"f × x"。f 是机器的名字，不是一个数。

同一页纸上要是有两台机器，第二台常叫 **g**，再多就叫 **h** 或 **F**。名字随便挑，**挑定了就不许改口**——这也是一种说话算话。

## 三、把机器画出来

一台机器有无穷多个"投进去—吐出来"的配对，怎么一眼看全？**画出来。**

规矩很简单：**投进去的数往横里放，吐出来的数往竖里放，每一对画一个点。**

拿一台顶简单的机器试手：投进 x，吐出 **x × x**。这个乘出来的数，就是**边长为 x 的正方形的面积**，写作 **x^2^**，念"x 的平方"。

FIG: fig-01-machine.png | 投 1 出 1，投 2 出 4，投 3 出 9。把所有的点都画上，就连成一条曲线。

这条曲线就是这台机器的**画像**。以后我们说"这台机器在这儿涨得快"，指的就是这条曲线在这儿翘得陡。

BOX[key]: 一条竖线，只能碰到画像一次 :: 画像上，**同一个横位置**上的点，说的是**同一个输入**。// 要是一条竖线碰到画像**两次**，就等于说：// 同一个数投进去，吐出来两个不一样的答案——**变卦了**。// // 所以第一节那条诺言，在图上长这个样子：// **随便画一条竖线，最多只能碰到画像一个点。**// 碰到两个点的那张图，**根本不是任何机器的画像。**

FIG: fig-30-promise.png | 左：一条竖线只碰到一个点——守诺言。右：同一条竖线碰到两个点——同一个数两个答案，这不是机器的画像。

BOX[task]: 留给妹妹 :: 在方格纸上画出"投进 x 吐出 x ＋ 3"这台机器。// 它的画像是什么形状？和 x^2^ 那条比，有什么不一样？// 再画"投进 x 吐出 2x"。（2x 就是 2 × x——**数字挨着字母，乘号可以不写**，简易方程里你见过。）三张图摆在一起看看。

BOX[key]: 回头望一眼那块地 :: 认出来了吗？**第一册开篇那条平方曲线**，就是 f(x) ＝ x^2^ 这台机器的画像——当年只说“每个数的头顶上点一个点”，现在它有了正式身份。// 那块弯边的地，还在曲线底下原地等着。别急：这一册先把家伙备齐，**第十篇才对它动手**。

BOX[remember]: 现在可以告诉你它们的大名了 :: 这一篇讲了两样东西，它们各有一个正式名字。// **好机器，大名叫「函数」。**投进一个数、吐出一个数，而且守诺言——这就是函数，一个字不多、一个字不少。// **画像，大名叫「函数图像」。**每一对“投进去的、吐出来的”画成一个点，连起来的那条线就是它。// // 反过来也说得清：**破机器不是函数**——老虎机、骰子、明天的天气，它们不守诺言，进不了这扇门。// 而刚才那条**竖线检验**，就是**认函数图像的办法**：一条竖线最多碰到它一个点。// // 往后一段路，我们说“机器”的时候，会**在后面把“函数”写进括号里**——// 好让你慢慢把这两个词认成同一样东西。// **等你看见它们本来就是一回事，括号就撤掉：从第十篇起，一律叫函数。**

## 四、习题

BOX[task]: A 组：认一认 :: **A1.** 用一句话说出**好机器的诺言**。老虎机为什么是破机器？// **A2.** f(x) ＝ x^2^ − 2x。算出 f(0)、f(1)、f(2)、f(3)。// **A3.** 上一题的四个答案里，有没有两个是一样的？这**算不算变卦**？为什么？// **A4.** "f(x) 不是 f × x"——为什么这个提醒很要紧？举一个会算错的例子。

BOX[task]: B 组：动动手 :: **B1.** 在方格纸上把 f(x) ＝ x^2^ 从 x ＝ 0 画到 x ＝ 3，每 0.5 取一个点。// **B2.** 同一张纸上画 g(x) ＝ x × x × x。哪一条涨得更凶？从第几个数开始？// **B3.** 画一个圆。用**竖线检验**说明：它**不是**任何机器的画像。// **B4.** 接着 B3：把这个圆**横着切开**，只留上半个。现在它是机器的画像了吗？（这一招第二篇还会再用一次。）

BOX[task]: C 组：想一想 :: **C1.** 下面这些，哪些是好机器，哪些是破机器？说出理由。// （1）投进一个人的名字，吐出他的生日。//（2）投进一个人的生日，吐出他的名字。//（3）投进一个数，吐出"比它大的某个数"。//（4）投进今天的日期，吐出**明天**的天气。//（5）投进今天的日期，吐出**昨天**的天气。// **C2.** 老虎机是破机器，可赌场老板照样能算清楚它长远会吐多少币。这说明：**"每一次说不准"和"长远说得准"是两回事**吗？（不必写答案，能把两句话的区别说清楚就算过关。）// **C3.** 第一节说"第一册证极限唯一，就是在证取极限守诺言"。用你自己的话说一遍：要是一队数能有两个极限，会出什么乱子？

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 第三节末尾已经把**函数**这个大名给你了；那条诺言正式叫**单值性**——课本会说"对定义域内每一个 x，**有且只有一个** y 与之对应"，那个"只有一个"就是第一节的诺言。第三节那条"竖线只碰一次"叫**竖线检验**。// **破机器数学里也管**——投进去同一个东西、出来的结果每次不同，那是**概率**和**随机变量**的地盘（掷骰子、老虎机、明天的天气都归它）。它不是"没法研究"，是**要用另一套工具**；这两册书的工具只对好机器管用。// 投得进去的那些数，合起来叫**定义域**；吐出来的那些数，合起来叫**值域**。// **函数图像**课本上常简称**图像**；投进去的那条线叫 **x 轴**，吐出来的叫 **y 轴**——和这一册的自变量 x 同名同源。
