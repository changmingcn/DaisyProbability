# 第七篇　导数拿来干什么

CENTER: 摊开整张坡度地图：每一点的导数，决定那里那把微分直尺朝上还是朝下

第四篇先借来 f′ 这张坡度地图，第六篇已经用极限把它真造出来。这一篇把地图整个摊开，沿路看 **x → f′(x)** 的正负：正的地方，钉在那里的微分直尺朝上；负的地方，直尺朝下。要研究整条曲线，看的不是孤零零一把直尺，而是**全路每一点的符号怎样排着走**。

## 一、正的在涨，负的在跌

想一想平均变化率的意思：**吐出来的变了多少，除以投进去的挪了多少。**

投进去的往右挪（h 是正的），那么：

- 吐出来的**变多**了 → 平均变化率是**正的** → 机器（函数）在**涨**。
- 吐出来的**变少**了 → 平均变化率是**负的** → 机器在**跌**。

f′(x) 是平均变化率奔向的那个数，所以：

BOX[remember]: 一句话 :: **f′(x) 是正的 ⇒ 在涨。f′(x) 是负的 ⇒ 在跌。**// f′(x) 是 **0** ⇒ 既不涨也不跌——**正在拐弯**。

FIG: fig-05-sign.png | 绿的地方在涨，橙的地方在跌；拐弯的两个点上，f′ 正好是 0。

BOX[key]: 慢着——这句话还没有证 :: 上面那段推理，说的是**平均变化率**：从 x 挪到 x ＋ h，吐出来的确实变多了。// 可 **f′(x) 只站在 x 这一点上**。// // 从**这一点的 f′ 是正的**，到**一整段都在涨**——// **中间还隔着一段路，这一篇没有走过去。**// // 妹妹要是较真，会问：“你怎么知道中间没有一段偷偷往回跌？”// 这个问题**本篇答不上来**，它要用到第一册的八大定理。// **第八篇第六节专门去还这张欠条。**// 在那之前，上面那句话请当成**好用的感想**，别当成证过的定理。

## 二、找最高点和最低点

看那张图：**最高点和最低点，都出现在 f′ 等于 0 的地方**。这很合理——如果还在涨，那就还没到顶。

于是我们有了一个**找最值的办法**：

BOX[key]: 找最高点的办法 :: **第一步，**求导，写出 f′。// **第二步，**解方程 f′(x) ＝ 0，找出所有**可能拐弯的候选点**。// **第三步，**看看每个候选点两边是涨还是跌，判断它是顶、谷，还是并没有掉头。

BOX[key]: 这里也赊了账 :: 这个办法里，藏着两件没交代的事：// // **第一件：最高点凭什么存在？**上面是“看那张图”看出来的——**可那是看图。**// 万一这台机器（函数）根本就没有最高点呢？// **第二件：**就算它存在，凭什么**在那儿 f′ 正好是 0**？// // 两件都要请第一册的完备性来还：// **第八篇第二节**证“最高点存在”，**第八篇第三节**证“顶上是平的”。// // 眼下先当工具用——**它给出的答案都对，只是理由还欠着。**

## 三、一道真题：篱笆围最大的地

有 20 米篱笆，要围一块长方形的地，怎么围面积最大？

设一条边是 x 米。四条边一共 20 米，所以另一条边是 **10 − x** 米。面积是：

CENTER: **f(x) ＝ x × (10 − x) ＝ 10x − x^2^**

等式两边求导：**f′(x) ＝ 10 − 2x**。

让它等于 0：**10 − 2x ＝ 0**，解得 **x ＝ 5**。

BOX[remember]: 答案 :: 一条边 5 米，另一条边也是 5 米——**围成正方形，面积最大，25 平方米**。// 检查一下：x ＝ 4 时面积 24，x ＝ 6 时也是 24，都比 25 小。✓// // 这个结论也许你早就"感觉到"了。// **但现在你能证明它**，而且这个办法对**任何**多项式都管用，不只是这一道题。

BOX[task]: 留给姐姐 :: （1）如果篱笆只围三面（有一面靠墙），20 米篱笆最大能围多少？// （2）一个数和“10 减它”的乘积，什么时候最大？这和上面那道题是同一道题吗？// （3）f(x) ＝ x^3^ − 3x。求导，解 f′(x) ＝ 0，找出两个候选点。哪个是顶，哪个是谷？

## 四、直观翻车：f′ 是 0，不一定是顶也不一定是谷

妹妹该挑刺了：**f′ 是 0**，和**是最高点或最低点**，是一回事吗？

**不是。**这是本篇要抓的那条刺。

BOX[key]: 反例：x^3^ :: f(x) ＝ x^3^，求导得到 f′(x) ＝ 3x^2^。// 在 p ＝ 0 处，f′(0) ＝ 0——**地图在这一点确实标着 0**。// 可 0 是最高点吗？不是：投 1 出 1，比 0 大。// 是最低点吗？也不是：投 −1 出 −1，比 0 小。// // 那儿发生了什么？钉在 p ＝ 0 的微分是 **dx → dy ＝ 0**，线性替身横着躺平；// 可原函数只是**喘了口气**，并没有掉头。

BOX[remember]: 所以第三步不能省 :: 某一点的导数等于 0，只说明这里的**线性替身是水平的**；它可能是顶、可能是谷，也可能两样都不是。// **必须再看两边**才能定。// 这和第一册那条教训是同一件事：// **“正着成立”不等于“反过来也成立”。**// // 第九篇会给你一个**更快的办法**——看**二阶导数**，不必再看两边。// 但那个办法也有失灵的时候，**失灵的时候还得回来看两边。**
