# 第十篇　形状：再求一次导

CENTER: 第一张地图记坡度；再求一次导，第二张地图记坡度怎样变化

## 一、对 f′ 再求一次导

第七篇第一节已经把第一张地图算出来：对 f 求导得到 f′，让 x 沿路走，f′(x) 就逐点报出原曲线的坡度。

既然是机器，**它当然也能再求一次导**。

BOX[remember]: 二阶导数 :: 对 f′ 再求导，得到 **f″**；把 x 投进去，数 **f″(x)** 就叫 f 在 x 点的**二阶导数**，念作“f 两撇 x”。// 求法一点也不新鲜：**把 f 求两次导。**// // 例：f(x) ＝ x^3^ → f′(x) ＝ 3x^2^ → **f″(x) ＝ 6x**。// // f′(x) 是这一点的一阶导数，f″(x) 是这一点的二阶导数；f′、f″ 则分别是求一遍、求两遍导所得的函数。

### 另讲一个故事：两个 dx 真的乘在一起

第五篇算过正方形面积的真变化：

CENTER: **(3＋dx)^2^ − 9 ＝ 6dx ＋ (dx)^2^**

当时我们先抓住直的主干 **6dx**，把 **(dx)^2^** 留作弯曲的小角。现在回头看那块小角。它不是用来记录“做了两次”的暗号；两个 dx 在这里真的乘在一起：

CENTER: **(dx)^2^ ＝ (dx) * (dx)**

一份 dx 是一把直尺，接收一支箭头，读出横向变化。**dx * dx** 有两个位置：第一份 dx 读第一支箭头，第二份 dx 读第二支箭头，再把两份读数相乘。若两个位置放进同一支箭头，得到的就是这份横向读数的平方。箭头放大两倍，一把直尺的读数放大两倍；这把“方尺”的读数便放大四倍。

BOX[key]: 从直尺到方尺 :: **dx** 是线性的直尺，只需要一支箭头。// **(dx)^2^ ＝ dx * dx** 是由两把 dx 直尺搭成的方尺，需要两个箭头位置；交换两支箭头，乘积不变。// 长大以后，这种有两个位置、交换位置也不变的东西叫**对称二形式**。

现在看上面的 **d^2^**。它是一个二阶微分算子；把整台函数 f 交给它，得到 **d^2^f**。这个结果和 **(dx)^2^** 是同一种方尺。在只有 x 这一个方向的直线上，方尺只有这一种基本样子，所以站定 p 后，d^2^f 一定是 (dx)^2^ 的某个倍数。这个倍率就是 f 在 p 点的二阶导数 **f″(p)**：

CENTER: **d^2^f ＝ f″(p)(dx)^2^**

于是，把 d^2^f 里有多少份 (dx)^2^ 单独写出来，正是：

CENTER: **[[d^{2}f|dx^{2}]] ＝ f″(p)**

BOX[key]: 这个分式在问什么 :: 上面的 **d^2^** 是二阶微分算子，**d^2^f** 是它交出的方尺；下面的 **dx^2^** 是真实的乘积 **dx * dx**，是用来作比较的基本方尺。// **[[d^{2}f|dx^{2}]]** 问的就是：“d^2^f 等于多少份 dx^2^？”答案是倍率 **f″(p)**。// 这个倍率怎样算？仍沿最熟悉的路：**f → f′ → f″**。

拿 f(x) ＝ x^2^ 来核对。求两次导得到 f″(p) ＝ 2，所以

CENTER: **d^2^f ＝ 2(dx)^2^**

第五篇那块小正方形 **(dx)^2^**，原来正是二阶世界使用的基本材料。它不是整份 d^2^f；对平方函数，它恰好是 **[[1|2]]d^2^f**。这件事长大以后会在泰勒公式里写得整整齐齐。

## 二、f″ 说的是什么：陡度在涨还是在跌

f′ 说的是"**走得多快**"。那 f″ 说的就是"**走得多快这件事本身，变得多快**"。

**上一篇的推论一，现在换一台机器（函数）再念一遍**——

BOX[key]: 同一条推论，用在 f′ 身上 :: 第九篇第六节的推论一说：**一台机器的 f′ 处处是正的，这台机器就在涨。**// // 现在把“这台机器”换成 **f′**：// **f″ 是正的 ⇒ f′ 在涨 ⇒ 陡度越走越大。**// **f″ 是负的 ⇒ f′ 在跌 ⇒ 陡度越走越小。**// // 一条推论，**换一台机器再念一遍**，就成了一条新结论。// 这一篇整篇都是这一句话的展开。

坐车打个比方：**f′ 是仪表盘上的速度，f″ 就是"正在加速还是正在减速"。**

BOX[remember]: 别把两件事搞混 :: **涨还是跌，看 f′**：机器是往上走还是往下走。// **陡度在变大还是变小，看 f″**。// // 这两件事**互不管辖**。跌着的机器可以越跌越慢（f′ 是负的、f″ 是正的），// 涨着的机器也可以越涨越慢（f′ 是正的、f″ 是负的）。

## 四、拐点：碗和拱换班的地方

BOX[remember]: 拐点 :: 画像从碗形变成拱形（或者反过来）的那一点，叫**拐点**。// // 在那儿 **f″ 要变号**——所以先去解方程 **f″(x) ＝ 0**，找出所有候选。// // 例：f(x) ＝ x^3^，f″(x) ＝ 6x。它在 x ＝ 0 处变号：// 左边 f″ 是负的（拱形），右边是正的（碗形）。**x ＝ 0 就是拐点。**

FIG: fig-19-f-fp-fpp.png | 三张图对齐着看：上面是 f，中间是 f′，下面是 f″。f′ 穿过横轴的地方，正是 f 的顶和谷；f″ 穿过横轴的地方，正是 f 的拐点。

## 五、二阶判别法：是顶还是谷，一算就知道

第八篇找最值的第三步是“**看看两边是涨还是跌**”。那一步有点麻烦。**二阶导数能替它干。**

BOX[key]: 二阶判别法 :: 把候选点叫 p，先有 **f′(p) ＝ 0**——这一点的微分直尺水平。// // **f″(p) 是正的 ⇒ 这是谷**（附近最低）。// **f″(p) 是负的 ⇒ 这是顶**（附近最高）。// **f″(p) 也是 0 ⇒ 说不准**，还得老老实实回去看两边。

为什么只看 p 点的 f″(p) 就敢说“附近”？这一册研究的多项式很规矩：f″ 不会在 p 旁边突然跳号。若 f″(p) 是正的，在离 p 足够近的一小段里它仍是正的，曲线保持碗形；负的情形同理。

BOX[remember]: 为什么“说不准” :: 三台机器（函数），在 x ＝ 0 处 f′ 和 f″ **全都是 0**，形状却各不相同：// // **x^4^**：是谷。（投别的数进去，吐出来的都比 0 大。）// **−x^4^**：是顶。// **x^3^**：**两样都不是**——就是第八篇第四节那台“歇了口气又接着往上爬”的机器。// // 同一套数字，三种答案。**这就是“说不准”三个字的准确意思。**

BOX[remember]: 第八篇 A4 现在能答满了 :: 第八篇 A4 问的是：说出 **f′ 是 0** 的三种可能情况。// 当时只能靠比划，现在你有三台具体的机器：// **x^4^ 是谷、−x^4^ 是顶、x^3^ 两样都不是。**// // 而且你还多知道了一件事：**怎么分辨**——// 先看 f″；只有 f″ 也是 0 的时候，才需要回去看两边。

## 六、直观翻车：f″ 是 0，不一定是拐点

妹妹一定会顺着往下问：**解出 f″(x) ＝ 0，那一点就是拐点吗？**

**不是。**这是本篇要抓的那条刺。

BOX[key]: 反例：x^4^ :: f(x) ＝ x^4^。f′(x) ＝ 4x^3^，**f″(x) ＝ 12x^2^**。// // 在 x ＝ 0 处，f″(0) ＝ 0——**确实是 0**。// 可是 12x^2^ **永远不是负的**：0 的左边、右边，f″ 都是正的。// **碗形一路还是碗形，根本没有换班。**// // 所以：**f″ 是 0 只是候选，必须再看两边有没有真的变号。**

BOX[remember]: 又是同一个教训，这已经第三次了 :: **第七篇**：(fg)′ 不是 f′g′。// **第八篇**：f′ 是 0，不一定是顶也不一定是谷。// **本篇**：f″ 是 0，不一定是拐点。// // **“解出方程”和“得到结论”之间，永远还隔着一步验证。**// 数学里“看起来该这样”的地方，**都要拿一个具体例子试一下**。

## 七、真题：把 x^3^ − 3x 的形状描出来

取 **f(x) ＝ x^3^ − 3x**——**第八篇第三节留给姐姐的第（3）题，问的就是它**。当时只让你找出两个拐弯的地方、判断哪个是顶哪个是谷。现在工具齐了，我们把**整张画像**描出来。

**第一步，求导，找拐弯的地方。**

CENTER: **f′(x) ＝ 3x^2^ − 3 ＝ 3 × (x^2^ − 1)**

让它等于 0，解得 **x ＝ −1** 和 **x ＝ 1**。

**第二步，再求一次导，拿 f″ 判断是顶还是谷。**

CENTER: **f″(x) ＝ 6x**

- **f″(−1) ＝ −6**，是负的 → 拱形 → **x ＝ −1 是顶**，那里的高是 f(−1) ＝ **2**。
- **f″(1) ＝ 6**，是正的 → 碗形 → **x ＝ 1 是谷**，那里的高是 f(1) ＝ **−2**。

**第三步，找拐点。**解 **f″(x) ＝ 0** 得 **x ＝ 0**。它左边 f″ 是负的、右边是正的——**真的变号了**，所以 x ＝ 0 是拐点，高是 f(0) ＝ **0**。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 更正式地说，**dx^2^** 是一形式 dx 的对称乘积 **dx ⊙ dx**，也常写成 **dx ⊗ dx**；它不是楔积。二阶微分算子把 f 变成对称二形式 **d^2^f**。在一维坐标 x 中，**d^2^f ＝ f″(p) dx ⊙ dx**，所以 **[[d^{2}f|dx^{2}]]** 是 d^2^f 相对于基准二形式 dx^2^ 的系数。// 同一件事也可写成：把 x 方向放进 d^2^f 的两个位置，读出 f″(p)。它和“对 f′ 再求一次导”算出的数相同；前一种写法说明这个数乘在什么对象上，后一种写法说明这个数怎样算。// 对一般光滑函数，真变化的开头是 **f(p＋dx)−f(p) ＝ df ＋ [[1|2]]d^2^f ＋ 更小的项**。对平方函数，更小的项正好没有，所以第五篇的 **6dx＋(dx)^2^** 在这里完整对上。// 碗形正式叫**凸函数**（下凸，convex），拱形叫**凹函数**（上凸，concave）——**中文书上“凹”“凸”两个字的用法并不统一**，看到时先确认它的定义再用，这是常见的坑。// 拐点叫 **inflection point**；第五节那条叫**二阶导数判别法**。把更高阶的微分都用上，就得到**泰勒公式**——它能用多项式逼近一般函数。**那正好是这一册的反方向：这一册只做多项式，泰勒公式让别的函数也变成多项式。**
