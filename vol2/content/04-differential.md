# 第四篇　先把微分用起来

CENTER: 先假设导数已经求得；先看微分这台线性函数能替我们做什么

第三篇把函数的极限说清楚了。照通常的次序，下一步该立刻追问：**导数怎样求？**

这一册偏要先忍住。我们先把几份导数答案借来，拿它们造出微分，再看这台线性函数究竟有多好用。等好处全看见了，第六篇再回头，从极限出发把导数一个个造出来。

BOX[key]: 这一篇的读法 :: 这一篇不是把证明省掉，而是把证明**往后放**。// 先凭直觉认识工具、先用几次；第六篇再证明多项式的答案和“零头比 dx 小一档”，第十一篇再算开方的导数。// **先用后证，可以；只用不证，不可以。**附录 D 也记着这两笔账。

## 一、先借一张整路的坡度地图

先看一台机器（函数）f。对整台 f 做一个操作，得到一张新的答案表，记作 **f′**。这个操作叫**求导**，写成：

CENTER: **f → f′**

现在别急着把眼睛停在一个答案上。让 x 沿着整条曲线走：走到哪里，f′ 就报出哪里变化有多快。这样从头到尾读一遍，**x → f′(x)** 就像一张铺满全路的**坡度地图**。走到其中一点 p，地图在这里标出的数 **f′(p)**，就是 f 在 p 点的**导数**。

我们先借下面几份答案：

TABLE:
| 原来的函数 f | 整张坡度地图 x → f′(x) | 地图在一点标出的导数 |
| f(x) ＝ 5 | f′(x) ＝ 0 | 比如 f′(3) ＝ 0 |
| f(x) ＝ x | f′(x) ＝ 1 | 比如 f′(3) ＝ 1 |
| f(x) ＝ x^2^ | f′(x) ＝ 2x | 比如 f′(3) ＝ 6 |
| f(x) ＝ x^3^ | f′(x) ＝ 3x^2^ | 比如 f′(2) ＝ 12 |
| f(x) ＝ √x | f′(x) ＝ [[1|2\sqrt{x}]]（x ＞ 0） | 比如 f′(49) ＝ [[1|14]] |

BOX[remember]: 一张坡度地图 :: 对 f 求导，得到 **f′**。让 x 沿全路走，**x → f′(x)** 就把每一点的导数都标出来。// 比如走到 p ＝ 3，平方函数这张地图标着 f′(3) ＝ 6。// 下一节不再沿路走：我们把 p 钉在 3，只取下这个 6，做一把只管 3 附近的直尺。

BOX[dialog]: 妹妹不肯白借 :: **妹妹：**“你把答案写在表里，我就得信？”// **姐姐：**“不用信。眼下只把它们当作借来的工具。第六篇会从平均变化率和极限出发，算出前四行；开方那一行到第十一篇第六节也会当场算出来。// 现在先问另一件事：**假如这些导数已经求得，它们能替我们做什么？**”

## 二、微分：在一点钉下一把线性直尺

从坡度地图上选定一个站脚点，叫 **p**。f′(p) 回答“**在这里变化有多快**”。现在把 p 固定下来，就能回答另一个问题：

CENTER: **输入挪一点点，输出大约跟着变多少？**

先给原函数的输出起个名字：**y ＝ f(x)**。站定 p，把输入端的一小段挪动记作 **dx**，再把这一点的导数 f′(p) 当成固定倍率：

BOX[remember]: 微分 :: 像用一枚图钉钉住 p：地图不再往别处翻，只把这里的导数 f′(p) 刻在一把小直尺上当固定倍率。// **投进 dx，吐出 dy ＝ f′(p)dx。**// // 这台 **dx → dy ＝ f′(p)dx** 的线性函数就叫微分。// p 固定不动，dx 才是它的输入；dx 变 2 倍，dy 就变 2 倍，dx 减半，dy 也减半。// 它不管别处的坡度，只用这一个倍率替代原函数在 p 附近的变化。

回到第二篇的习题 B1：正方形边长从 3 变成 3.01，面积多了多少？

- **真答案**：3.01 × 3.01 − 3 × 3 ＝ 9.0601 − 9 ＝ **0.0601**
- **微分给的答案**：对 x^2^，借来的表说 f′(3) ＝ 6。投进 dx ＝ 0.01，得到 **dy ＝ 6 × 0.01 ＝ 0.06**

只差 **0.0001**——那正是第二篇 B2 里画的**那个小角**（0.01 × 0.01）。

BOX[key]: 把刚才的正方形顺着读一遍 :: 从 f(x) ＝ x^2^ 出发，求导得到坡度地图 **x → f′(x) ＝ 2x**；走到 p ＝ 3，读出导数 f′(3) ＝ 6；把 p 钉住，再把 dx ＝ 0.01 投进微分，吐出 dy ＝ 0.06。// 同一串动作，从整条曲线的坡度地图，一直走到了一把只管 3 附近的线性直尺。

BOX[key]: 地图和直尺，手里各干一件事 :: 想象一条弯弯的山路。**f′ 是公路局的整张坡度地图**：每个里程碑旁边，都记着那里的坡度。// 真走到 p，修路的人不会拿整张地图去铺路；他只抄下 p 旁边的数字 f′(p)，照这个坡度架起一把直尺。横着量 dx，直尺就报出竖着的 dy。// // **地图让站脚点走遍全路；直尺把站脚点钉住，只让 dx 在附近走。**// 换到下一处，就拔起图钉，查地图上的新数字，再架一把新的直尺。

## 三、画出来看：微分是图上的哪一段

地图和直尺是打比方。微分还有一张真正的脸，就画在机器（函数）的图像上。

FIG: fig-31-tangent-pieces.png | 左：把 p 钉住，投进 dx，顺切线直尺升起 dy——这台 dx → dy 的线性函数就是微分；爬曲线得到的真变化还多一个零头。右：沿坡度地图走，每到一处换一把局部直尺；许多小直线接起来，切得越细贴得越紧。

先看左图。站在 p 这一点，往右投进一小段 dx。要知道输出真变了多少，得沿着曲线爬到新的点。微分给了另一条路：**顺着钉在 p 的切线直尺走。**它的固定倍率是 f′(p)——横着走 dx，竖着就升 **dy ＝ f′(p)dx**。

BOX[remember]: 微分在图上的位置 :: **顺切线走升起 dy，这个 dx → dy 的对应就是微分。**// 它和爬曲线得到的真变化之间，还隔着顶上一条小缝——**零头**。// 图上看起来，dx 越短，这条缝就比 dx 缩得更快。// 所以微分干的事可以先记成一句直觉：// **在一小段里，拿线性函数顶替原函数的变化。**

再看右图。走到每一个点，都按那一点的导数重新支一小段直线；许许多多小直线连起来，就能冒充整条曲线。段切得越细，折线就贴得越紧。

BOX[key]: 走到一点，就换一把直尺 :: 坡度地图 f′ 沿路列着各点的倍率：走到 p，读出 f′(p)，随即按 **dx → dy ＝ f′(p)dx** 支起一小段直线。// 走到下一点，拔起图钉，再读下一个倍率，支下一段。// 原函数一路弯过去；每一把微分都不巡游，只在自己的站脚点附近走直线。

CENTER: **整张地图管全路；每把微分直尺只管一个站脚点附近**

BOX[key]: 这里还欠一句证明 :: 图只让人看见“越切越细，贴得越紧”，还没有证明。// 我们真正要证的是：**真变化减去 dy 后的零头，除以 dx 还奔向 0。**// 第五篇先拿这句话干活；第六篇第五节会从导数的定义出发，用三句话把它证出来。// 到那里，“微分替得像”才从直觉变成定理。

## 四、一支飞了两千年的箭

先拿路程机器（函数）来试这台微分。

BOX[dialog]: 妹妹替两千年前那个人出招 :: **妹妹：**“给飞着的箭拍一张照片，就一瞬间那么一张。照片里它停在一个位置上，一点也没往前挪。// 再拍一张，还是停在一个位置上。每一瞬它都没挪，那它到底什么时候在挪？”// **姐姐：**“两千多年前，古希腊人芝诺就是这么问的。你前半句完全正确：一张照片里确实没有位移。// 错的是把‘这一瞬没有位移’和‘速度是 0’当成同一句话。”

BOX[remember]: 两个“没挪”，说的不是一回事 :: **这一瞬没有位移**——照片只记下一个位置。// **它是停着的**——这一点的速度，也就是导数，是 0。// // 照片拍得到位置，拍不到速度。// 一支箭动没动，不是一张照片里的事，// **是这张照片和旁边那些张之间怎样变化的事。**

芝诺只给了两样东西挑：一瞬，能看见“此刻”却没有一段路；一整段，能算平均速度却丢掉“此刻”。微分给了第三样：

TABLE:
| 手里拿着的 | 看得见“此刻”吗 | 能对一小段说出变化吗 |
| 一瞬 | 看得见 | 不能：一小段被掐没了 |
| 一整段的平均 | 看不见 | 能，但只是粗账 |
| **微分 dx → dy ＝ f′(p)dx** | **看得见：f′(p) 是此刻的率** | **能：dx 是一小段真时间** |

BOX[key]: 微分正是第三样 :: 把这一刻叫 p，从整张速度地图读出 f′(p)，再把 p 钉住，把一小段真时间 dx 投进去，// 微分就给出线性的路程近似 **dy ＝ f′(p)dx**。// 同一个当场倍率，可以接收长短不同的 dx；// **这样，“此刻有多快”和“接下来一小段大约走多远”就接上了。**

芝诺不是被一句话驳倒的，而是被换掉了问题：不再问“一瞬里有没有走出一段路”，改问“邻近小段的平均速度挤向哪个数”。第六篇会把这句话正式写成导数的定义。

## 五、沿着这条路再走一遍

BOX[key]: 从 f 出发 :: 先对整台机器（函数）求导：**f → f′**，得到坡度地图 **x → f′(x)**。// 沿地图走到 p，读出这里的导数 **f′(p)**。// 用图钉把 p 固定，把 dx 投进 **dx → dy ＝ f′(p)dx**，得到线性的局部变化 dy。// 往后每次用微分，都沿着这条路走。

BOX[remember]: h 走在前面，dx 接着上场 :: 第六篇先让 **h** 进入平均变化率，再让它奔向 0，求出 f′。// f′ 已经写好以后，轮到 **dx** 投进微分，换出 dy。// 书里的字母就按这个次序接力。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 有的书会写 **y ＝ f′(x)**。为了看清输入，本书更愿意读成 **x → f′(x)**：x 在定义域里移动，这整台函数收着原曲线每一点的导数。// 选定基点 p 后，p 固定，微分写成线性函数 **dx → dy ＝ f′(p)dx**；这时真正变化的输入是 dx，dy 是它的输出。“线性”就是正文说的成正比。// 所以本篇从整张坡度地图上取下一个倍率，钉成 p 点的局部直尺；第六篇再从极限出发造出整张地图，并证明这把直尺留下的误差比 dx 小一档。长大以后，“只管 p 附近”会说成“只管 p 的邻域”。
