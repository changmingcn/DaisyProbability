## 一、先把几份导数答案借来

先看一台机器（函数）f。对整台 f 做一个操作，得到一张新的答案表，记作 **f′**。这个操作叫**求导**，写成：

CENTER: **f → f′**

把某个 x 投进这张答案表，读出的 **f′(x)** 就是 f 在 x 这一点的**导数**，回答：**f 在这里变化有多快。**

我们先借下面几份答案：

TABLE:
| 原来的函数 f | 求导后记作 f′ | 在一点得到的导数 |
| f(x) ＝ 5 | f′(x) ＝ 0 | 比如 f′(3) ＝ 0 |
| f(x) ＝ x | f′(x) ＝ 1 | 比如 f′(3) ＝ 1 |
| f(x) ＝ x^2^ | f′(x) ＝ 2x | 比如 f′(3) ＝ 6 |
| f(x) ＝ x^3^ | f′(x) ＝ 3x^2^ | 比如 f′(2) ＝ 12 |
| f(x) ＝ √x | f′(x) ＝ [[1|2\sqrt{x}]]（x ＞ 0） | 比如 f′(49) ＝ [[1|14]] |

BOX[remember]: 从一张答案表里读一个点 :: 对 f 求导，得到 **f′**。走到哪一个 x，就从表里读出 **f′(x)**；比如走到 3，平方函数这张表报出 6。// 下一节就把这个 6 当成固定倍率，装进一台只管 3 附近的小函数里。

BOX[dialog]: 妹妹不肯白借 :: **妹妹：**“你把答案写在表里，我就得信？”// **姐姐：**“不用信。眼下只把它们当作借来的工具。第六篇会从平均变化率和极限出发，算出前四行；开方那一行到第十一篇第六节也会当场算出来。// 现在先问另一件事：**假如这些导数已经求得，它们能替我们做什么？**”

## 二、微分：把一个数变成一台线性函数

站在一台机器（函数）f 的某一点上，f′(x) 回答“**在这里变化有多快**”。把它反过来用，就能回答另一个问题：

CENTER: **输入挪一点点，输出大约跟着变多少？**

先给输出起个名字：**y ＝ f(x)**。站定 x，把输入端的一小段挪动记作 **dx**，再把这一点的导数 f′(x) 当成固定倍率：

BOX[remember]: 微分 :: 站定 x，把刚读出的 f′(x) 写在一台小函数上当固定倍率：// **投进 dx，吐出 dy ＝ f′(x)dx。**// // 这台 **dx → dy ＝ f′(x)dx** 的线性函数就叫微分。// dx 变 2 倍，dy 就变 2 倍；dx 减半，dy 也减半。// 往后估算原函数在 x 附近的变化，就先把 dx 投给它。

回到第二篇的习题 B1：正方形边长从 3 变成 3.01，面积多了多少？

- **真答案**：3.01 × 3.01 − 3 × 3 ＝ 9.0601 − 9 ＝ **0.0601**
- **微分给的答案**：对 x^2^，借来的表说 f′(3) ＝ 6。投进 dx ＝ 0.01，得到 **dy ＝ 6 × 0.01 ＝ 0.06**

只差 **0.0001**——那正是第二篇 B2 里画的**那个小角**（0.01 × 0.01）。

BOX[key]: 把刚才的正方形顺着读一遍 :: 从 f(x) ＝ x^2^ 出发，求导得到 f′(x) ＝ 2x；走到 x ＝ 3，读出 f′(3) ＝ 6；再把 dx ＝ 0.01 投进微分，吐出 dy ＝ 0.06。// 同一串动作，从整台 f 一直走到了 3 附近的一小段变化。

BOX[key]: 打个比方：微分是一台兑换机 :: 游戏厅里的兑换机，投进 1 个币，吐出固定张数的票——**投多少，按率给多少**。// 函数 f 站在 x 这一点上，也有一个当场的兑换率 f′(x)。把它写在兑换机上，再投进 dx，就兑出 **dy ＝ f′(x)dx**。// // 换一个站脚点，f′(x) 换了数，兑换机上的倍率也跟着换。// 原函数可以是弯的；这台兑换机永远是直的，只管眼前这一小块。

## 三、画出来看：微分是图上的哪一段

兑换机是打比方。微分还有一张真正的脸，就画在机器（函数）的图像上。

FIG: fig-31-tangent-pieces.png | 左：站在一点上投进 dx，顺切线走升起 dy——这台 dx → dy 的线性函数就是微分；爬曲线得到的真变化还多一个零头。右：整条曲线切成小段，每段用自己的线性替身顶上，切得越细贴得越紧。

先看左图。站在 x 这一点，往右投进一小段 dx。要知道输出真变了多少，得沿着曲线爬到新的点。微分给了另一条路：**顺着这一点的切线走。**切线是直的，倍率正是 f′(x)——横着走 dx，竖着就升 **dy ＝ f′(x)dx**。

BOX[remember]: 微分在图上的位置 :: **顺切线走升起 dy，这个 dx → dy 的对应就是微分。**// 它和爬曲线得到的真变化之间，还隔着顶上一条小缝——**零头**。// 图上看起来，dx 越短，这条缝就比 dx 缩得更快。// 所以微分干的事可以先记成一句直觉：// **在一小段里，拿线性函数顶替原函数的变化。**

再看右图。走到每一个点，都按那一点的导数重新支一小段直线；许许多多小直线连起来，就能冒充整条曲线。段切得越细，折线就贴得越紧。

BOX[key]: 走到一点，就支一小段 :: f′ 沿路列着各点的倍率：走到 x，读出 f′(x)，随即按 **dx → dy ＝ f′(x)dx** 支起一小段直线。// 走到下一点，再读下一个倍率，支下一段。// 原函数一路弯过去；微分在每个站脚点上都只走直线。

CENTER: **走到哪一点，就用那一点的倍率，支起一台线性小函数**

BOX[key]: 这里还欠一句证明 :: 图只让人看见“越切越细，贴得越紧”，还没有证明。// 我们真正要证的是：**真变化减去 dy 后的零头，除以 dx 还奔向 0。**// 第五篇先拿这句话干活；第六篇第五节会从导数的定义出发，用三句话把它证出来。// 到那里，“微分替得像”才从直觉变成定理。

## 四、一支飞了两千年的箭

先拿路程机器（函数）来试这台微分。

BOX[dialog]: 妹妹替两千年前那个人出招 :: **妹妹：**“给飞着的箭拍一张照片，就一瞬间那么一张。照片里它停在一个位置上，一点也没往前挪。// 再拍一张，还是停在一个位置上。每一瞬它都没挪，那它到底什么时候在挪？”// **姐姐：**“两千多年前，古希腊人芝诺就是这么问的。你前半句完全正确：一张照片里确实没有位移。// 错的是把‘这一瞬没有位移’和‘速度是 0’当成同一句话。”

BOX[remember]: 两个“没挪”，说的不是一回事 :: **这一瞬没有位移**——照片只记下一个位置。// **它是停着的**——这一点的速度，也就是导数，是 0。// // 照片拍得到位置，拍不到速度。// 一支箭动没动，不是一张照片里的事，// **是这张照片和旁边那些张之间怎样变化的事。**

芝诺只给了两样东西挑：一瞬，能看见“此刻”却没有一段路；一整段，能算平均速度却丢掉“此刻”。微分给了第三样：

TABLE:
| 手里拿着的 | 看得见“此刻”吗 | 能对一小段说出变化吗 |
| 一瞬 | 看得见 | 不能：一小段被掐没了 |
| 一整段的平均 | 看不见 | 能，但只是粗账 |
| **微分 dx → dy ＝ f′(x)dx** | **看得见：f′(x) 是此刻的率** | **能：dx 是一小段真时间** |

BOX[key]: 微分正是第三样 :: 先在这一刻读出 f′(x)，再把一小段真时间 dx 投进去，// 微分就给出线性的路程近似 **dy ＝ f′(x)dx**。// 同一个当场倍率，可以接收长短不同的 dx；// **这样，“此刻有多快”和“接下来一小段大约走多远”就接上了。**

芝诺不是被一句话驳倒的，而是被换掉了问题：不再问“一瞬里有没有走出一段路”，改问“邻近小段的平均速度挤向哪个数”。第六篇会把这句话正式写成导数的定义。

## 五、沿着这条路再走一遍

BOX[key]: 从 f 出发 :: 先对整台机器（函数）求导：**f → f′**。// 沿着 f′ 走到 x，读出当场的变化率 **f′(x)**。// 在这里站定，把 dx 投进 **dx → dy ＝ f′(x)dx**，得到线性的局部变化 dy。// 往后每次用微分，都沿着这条路走。

BOX[remember]: h 走在前面，dx 接着上场 :: 第六篇先让 **h** 进入平均变化率，再让它奔向 0，求出 f′。// f′ 已经写好以后，轮到 **dx** 投进微分，换出 dy。// 书里的字母就按这个次序接力。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 对 f 求导，记作 **f → f′**；走到 x 处，写出 f′(x)。站定 x 后，微分写成线性函数 **dx → dy ＝ f′(x)dx**。// “线性”在这里就是正文说的成正比：输入加倍，输出也加倍。// 本篇先假设 f′ 已经求得，沿着 **f → f′ → f′(x) → dy** 这条路看它怎样进入局部估算；第六篇再从极限出发求出 f′，并证明余下的误差比 dx 小一档。
