# 附录 D　给大人：这本册子诚实地跳过了什么

BOX[key]: 先说三笔**还上了**的账 :: 这一册早先的版本里，有三处是**先用起来、没有证**的：// **一、**f′ 是正的就在涨（第八篇第一节）；// **二、**最高点出现在 f′ 为 0 的地方（第八篇第二节）——连**最高点凭什么存在**都没交代；// **三、**F 和 A 在每一点的导数一样就只差一个常数（第十二篇第四节）——那是当时**全册最大的一处借用**。// // **这三处现在都证了**，全靠第九篇：最值定理 → 费马引理 → 罗尔 → 中值定理 → 三条推论。// 第八篇仍旧**先用后证**，但它明写自己在赊账，并指向第九篇。// **“先当好用的感想使，回头再证”和“含糊过去”，是两回事。**

BOX[key]: “先用后证”的明线 :: 第四篇已经从极限定义导数，并完整算过平方函数；第五篇并不再借“导数是什么”，只借几份尚未推导的**多项式与开方的导数值**，以及**微分留下的零头比 dx 小一档**。// 第六篇立刻用微分以直代曲；第七篇推导多项式的求导算法，并证明零头性质；第十二篇第六节再求出开方的导数。// 所以顺序是：定义先立稳，工具先用起来，计算与证明随后补齐。

- **只对多项式和开方做了。**“对 x^n^ 求导得到 n × x^n−1^”这条规律，册子里只验到 x^4^ 就归纳了，**没有对一般的 n 给出证明**（要用二项式定理）。这是有意的，但请别让孩子以为验了四个就等于证明了。
- **牛顿–莱布尼兹那一篇仍旧走了多项式的捷径。**一般函数要证这条公式，得用“连续函数在闭区间上取到最大最小”（**最值定理**）。**那条定理第九篇已经真证了**，可第十二篇第三节并没有回头去用它——那个 M 仍旧是从多项式直接找出来的。**这是一条捷径，只对多项式管用**，将来学一般情形时那一步要重来一遍。第四节加餐里“拼回去”的零头账，用的也是同一个 M、同一条捷径。
- **第九篇把“≤ 能穿过取极限”从数列搬到了函数上，没有重写证明。**第一册第四篇例四证的是**一队数**；第九篇第三节（费马引理）用的是**函数的极限**（h 奔向 0）。正文只说了“ε 那一步一个字都不用改”——**这句话是真的，但册子里确实没有把它写出来。**
- **碗形和切线全躺在画像下面——正方向证了，反方向还欠着。****f″ 处处是正的，切线就全在画像下面**，第十篇第三节已经证出（零件来自第九篇的推论一）；**反方向**（切线全在下面，凭什么就是碗形）仍旧只有图和直觉。
- **二阶判别法只在本册的多项式范围内使用。**第十篇第五节已经明说：从 **f″ 在 p 点是正的** 推出 **附近仍是正的**，用到了 f″ 连续。对多项式成立（f″ 还是多项式，而多项式连续，第三篇证过）；对一般函数要另外加条件。
- **"平均变化率"这个叫法。**[[f(x+h) - f(x)|h]] 在数学分析里的标准名字是**差商**；这一册改叫**平均变化率**（中学课本的叫法），因为它自带解释、不像行话。两者是同一个东西。
- **极限的乘法法则用了但没证。**第七篇证乘积法则时，用到“两个都有极限的东西相乘，极限就是极限相乘”；第七篇第四节末那句“可微的都连着”，用的也是它。第一册只在第五篇例三末尾提过这条（和加法法则同属四则运算法则，证法一样），**两册都没有写出来**。
- **面积只做了曲线在横线上方、从左到右的情形；体积只做了横截面为正方形的方尖塔。**没有讲负面积、曲线跑到横线下面怎么办，也没有讲一般立体怎样选切面。
- **没有讲：商法则、链式法则、换元、分部积分、不定积分的记号。**多项式用不上，加进来只会稀释主线。
- **第十一篇的低估比高估正好少最后一条，只在递增的情形成立。**册子里画的都是递增的例子，但没有明说这个前提——第十一篇 C2 就是在提醒这件事。
- **牛顿法只对第一册那个函数证了收敛。**第六篇第四节的**滑下去**，对 x^2^ − 2、从 x~1~ ＝ 1 出发，收敛性是第一册第五篇第五节用③证的；**换一个函数、换一个出发点，册子里没有给任何保证**——第六篇第七节那条平切线的反例，就是**保证不存在**的证据。
- **线盘山是一个可以逐块对账的模型，不是一般的换坐标定理。**第十一篇把方截面软绳盘进台阶方尖塔，让“按层”和“沿绳”数的是同一批小立方块，因此两本账严格相等；再用内外台阶塔夹逼到斜面的真塔。对任意弯曲软管、任意坐标怎样保证体积形式不变，册子没有证明。
