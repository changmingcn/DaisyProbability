# 第十二篇　两条路，一个答案

CENTER: 前面两条路一直没打过照面。这一篇它们撞在一起

到现在为止我们做了两件事，**它们看起来毫不相干**：

- **第四到第十篇**：定义导数，造出微分，再学习求导、判涨跌、看形状。主问题都是一个函数**走得多快**。
- **第十一篇**：量一条曲线**底下有多大**，也用同一套办法量一座方尖塔装了多少。靠的是极限——切条、切片、求和、夹逼。

一件关于**陡不陡**，一件关于**多大块**。一件是算除法，一件是算加法。

**这一篇要说：它们是同一件事。**

## 一、把面积也做成一个函数

第十一篇算的是“从 0 到 b”的面积，b 是个定死的数。现在换个眼光：**让右边那头自己动起来。**

BOX[remember]: 面积函数 :: 定义一个新函数 **A**：// **投进去一个 x，吐出来"从 0 到 x，曲线底下那块地的面积"。**// 投 1，吐出从 0 到 1 的面积；投 2，吐出从 0 到 2 的面积。// x 越往右，攒下的面积越多，所以这个函数**只涨不跌**。

## 二、问一个奇怪的问题：这个面积函数，走得多快？

这个问题奇怪在**它把两条路强行放到了一起**——面积是第十一篇的事，“走得多快”是第四篇的事。

照第四篇造导数的办法，先算 A 的平均变化率：

CENTER: **[[A(x+h) - A(x)|h]]**

上面那个 **A(x+h) − A(x)** 是什么？就是图上**橙色那一小条的面积**——多走一点点，多攒下的那点地。

那一小条**宽是 h**，**高差不多是 f(x)**。所以它的面积**差不多是 h × f(x)**。除以 h，就**差不多是 f(x)**。

BOX[remember]: 换成微分的说法 :: 在面积函数的整张坡度地图上选一点 p，把 p 钉住，再把小宽度 **dx** 投进 A 的微分，输出记作 **dA**。拍平的小条宽 dx、高 f(p)，所以 **dA ＝ f(p)dx**。// 而微分的通式又给出 **dA ＝ A′(p)dx**。两把局部直尺对同一个 dx 给出相同输出，倍率必须相同：**A′(p) ＝ f(p)**。// // p 可以选在每一点，所以把全路的这些等式收起来，就是整张地图的等式 **A′ ＝ f**。// 这只是**看出**结论，还不是证明——因为那一小条的顶是斜的，“高是 f(p)”只是近似。下一节把这点误差算清楚。

BOX[key]: 先看结论，再补严格 :: 对面积函数 A 求导，好像正好得到 **A′ ＝ f**。// 换成点值说：**A 在 x 点的导数 A′(x)，正好是 f(x)。**// // 但“差不多”三个字必须交代清楚——那一小条**不是**规规矩矩的长方形，// 它的顶是斜的。**差多少？下一节算给你看。**

## 三、"差不多"到底差多少

这一步是全册技术上最要紧的一步。而它用的工具，**第七篇第二节已经备好了**。

那条事实是：对任何多项式，**f(t) − f(x) 一定能提出一个 (t − x)**。

BOX[key]: 算一算误差 :: 在那一小条里，t 跑遍 x 到 x ＋ h，所以 **t − x 最多是 h**。// 而提出 (t − x) 以后剩下的那个多项式，在这一小段上**总有个不超过的数**，叫它 M。// 于是那一小条里**每一点的高，和 f(x) 相差都不超过 M × h**。// // 一小条的宽是 h，高的误差不超过 M × h，// 所以面积的误差不超过 **M × h^2^**（宽 h，乘上高的误差 M × h）。// // 再除以 h：// **平均变化率和 f(x) 的差距，不超过 M × h。**// h 奔向 0，M × h 也奔向 0。// **所以平均变化率奔向 f(x)。**

BOX[remember]: 这一步为什么漂亮 :: 让第七篇**求导变成代数**的那条事实，// 和让这一篇“误差可以忽略”的那条事实，// **是同一条事实。**// 多项式的这个好脾气，两条路上都在替我们干活。

于是我们证明了：

CENTER: **A′(x) ＝ f(x)**

### 用第六篇的话再看这条小条

第二节说小条的高“差不多”是 f(x)，第三节已经用误差把这三个字证严。现在再用第六篇的“以直代曲”读一遍，会看见微分在这里到底替了谁。

BOX[key]: 拍平曲顶，就是以直代曲 :: 把 p 旁边那一小条弯着的顶，拍成高度为 f(p) 的横线，小条就变成长方形。// 长方形的宽翻倍，面积恰好翻倍；**面积和宽成正比，比例就是高。**// 曲顶的小条做不到恰好成正比，所以那张长方形只是局部线性替身。// // 把 p 钉住，面积函数 A 的微分是 **dx → dA ＝ A′(p)dx**。// 而上面已经证明 A′(p) ＝ f(p)，所以同一台线性函数也可以写成 **dx → dA ＝ f(p)dx**。// 第六篇的以直代曲，在这里变成了牛顿–莱布尼兹的心脏。

BOX[remember]: 同一个 p，两组局部直尺 :: 从 f 的坡度地图取下 f′(p)，得到 **dy ＝ f′(p)dx**；从面积函数 A 的坡度地图取下 A′(p)，得到 **dA ＝ A′(p)dx ＝ f(p)dx**。// 图里的小长方形跟着 A 走：dx 尺读出宽，dA 尺读出面积；两份读数相差倍率 f(p)。// 若要估 f 自己在 p 附近的变化，则看 dx、dy 那一组。两组都只管 p 附近，别处的值此刻用不上。

FIG: fig-24-strip-flatten.png | 左：曲顶的小条，宽翻倍，面积不恰好翻倍。右：拍成长方形，面积才和宽成正比。

## 四、牛顿–莱布尼兹公式

上面那句话反过来读，就是一件极有用的事。

我们想要 **A**（面积），可 A 很难直接算——第十一篇切了半天条才算出一个 x^2^。但现在我们知道：**对 A 求导会得到 f，也就是 A′ ＝ f**。

**那就反过来找它！**别去切条了，直接问：“**对哪个函数求导会得到 f？**”

BOX[key]: 牛顿–莱布尼兹公式 :: 要算 f 底下**从 b 到 c** 的面积：// **第一步**，找一个函数 F，使 **F′ ＝ f**；也就是 F 在每一点的导数都等于 f 在那一点的值。// **第二步**，答案就是 **F(c) − F(b)**。// // 就这两步。**一条曲线底下的面积，变成了两个数一减。**

为什么是 F(c) − F(b)？因为 F 和面积函数 A **在每一点的导数都一样**，所以它们只差一个常数（都在同样地涨，起点可能不同）。一减，那个常数就抵掉了——**又是“一层层抵消”**。

BOX[remember]: 每一点的导数一样就只差一个常数，凭什么 :: 这句话听着像废话，**其实需要证明**——而且不好证。// // 它就是**第九篇第六节的推论三**：// F − A 这个函数在每一点的导数都是 0，// 由中值定理，**每一点导数都是 0 的函数只能是一条平线**，也就是一个常数。// // 请记住这条公式**踩在哪里**：// 没有第九篇那条中值定理，牛顿–莱布尼兹就只是一句好听的话。

### 加餐：第二种读法——总变化，是小变化加出来的

这条公式还有第二种读法。第一种读法是"别切条了，找 F 去"——图它省事。第二种读法更深一层：它把"微"和"积"这两个字的关系挑明了。

BOX[key]: 第二种读法 :: 把从 b 到 c 切成 n 小步，每步长 h。**F 一路的总变化，本来就是每一小步的变化首尾相接加起来**：// **(F(b+h) − F(b)) ＋ (F(b+2h) − F(b+h)) ＋ … ＝ F(c) − F(b)**// ——**又是“一层层抵消”**：中间的全消掉，只剩两头。（这也是 C4 那道题的钥匙。）// 每走到一步的起点 p，就在那里换一组尺子，让步长的读数满足 **dF ＝ F′(p)dx ＝ f(p)dx**——正好读出一小条长方形的面积。// 下一步换一个 p，也换一个倍率。两边一对：**左边加出总变化 F(c) − F(b)，右边把许许多多局部读数加成全部小条，也就是面积。**// // 这就是公式的第二张脸：// **求导造出 F′ 的整张地图，微分逐点用 dx 尺和 dF 尺读出局部变化，量面积再把这些小变化拼回去。**// **一拆一拼，互为逆运算**——“微积分”三个字里的“微”和“积”，说的正是这一拆一拼。

BOX[remember]: 每步都是估的，拼出来凭什么是准的 :: 每一小步用微分去估，都差一个零头。n 步的零头，会不会堆成大错？// **不会，账第三节已经备好了**：每一小步的零头不超过 M × h^2^。// （F 和面积函数 A 每一小步的变化一样大——差的那个常数一步之内就抵掉了，// 所以这笔账和第三节是同一笔；M 取整段从 b 到 c 上那个"总有个不超过的数"。）// n 步加起来：不超过 M × h^2^ × n ＝ M × h × (c − b)。// h 奔向 0，它也奔向 0——**拼回去这一步，站得住。**// 这正是第三节把误差算到 h^2^ 那么细的原因：// **零头比 h 小一档，n 步堆起来才刚好还能被 h 压住。**

## 五、先验个算

第十一篇辛辛苦苦切条算出：f(x) ＝ x^2^ 从 0 到 b，面积是 [[b^{3}|3]]。

现在用公式：对谁求导会得到 x^2^？第七篇的表告诉我们，对 x^3^ 求导得到 3x^2^，所以对 **[[x^{3}|3]]** 求导正好得到 x^2^。于是

CENTER: **F(b) − F(0) ＝ [[b^{3}|3]] − [[0^{3}|3]] ＝ [[b^{3}|3]]**

**一模一样。**可这一次，我们**一个长条都没切**。

BOX[remember]: 两条路的会合 :: 第十一篇：切条、求和公式、夹逼——**算了整整两页**。// 这一篇：想一想对谁求导会得到 x^2^——**一行**。// 这就是这条公式的价值。// // 还有一层：两条路**必须**会合，不是碰巧。“面积”早被两条规矩钉死——一段一段可以相加；每一小条夹在“最矮的高乘宽”和“最高的高乘宽”之间。// 第二、三节的证明一字不改，就是在证：**守这两条规矩的函数必须满足 A′ ＝ f**；再由第九篇推论三，每一点的导数一样就只差一个常数，而从起点出发时都是 0——**答案只可能有一个**。// 所以数格子、切条、找 F，只是去同一个地方的三条路。**谁来算都一样，这才叫“算出来了”。**

BOX[key]: 回头望一眼那块地——结案 :: 第一册开篇，妹妹问过：“凭什么这么整齐？弯线又不是拿 3 画出来的。”现在可以答她了：// **那个 3，是求导从 x^3^ 上拽下来的。**要让求导结果正好是 x^2^，就得先拿 3 除回去——[[1|3]] 就是这么来的。整齐不是巧合，是“一拆一拼互为逆运算”在数字上留下的指纹。// 从数格子，到 ε–N，到数轴没有洞，到存在证书，到速度表，到切条夹逼，再到这一行公式——**开篇的三个问题，到这里全部答完。那块地，结案了。**

## 六、开方的面积：公式到底省了多少事

上面那个例子还不够狠——毕竟切条也能算出来。现在来一个**切条算不出来的**。

CENTER: **√x 底下，从 0 到 1，面积是多少？**

BOX[remember]: 先回顾一下我们已经知道什么 :: 第十一篇第十节已经证过：**这块面积存在**。// 用的是第一册的**③单调有界定理**——低估只涨不跌、又有上界。// 可那个证明**一个字也没说它是多少**。// **现在就来算它。**

BOX[key]: 老办法在这里走不通 :: 第十一篇第十节已经说过是为什么：切条求和要算下去，// 就得知道 **√1 ＋ √2 ＋ … ＋ √n 等于多少**——**没有这样的公式。**// **这条路是堵死的。**

那就走新路：**找一个求导后得到 √x 的函数。**

先得会对 √x 求导。平均变化率是 [[\sqrt{x+h} - \sqrt{x}|h]]，展开这条路是堵死的——**但第七篇第二节说过，换一招 h 照样约得掉**。就是这一招：

BOX[key]: 上下同乘，把根号消掉 :: 分子分母**同时乘上** (√(x+h) ＋ √x)。// 分子变成 (x+h) − x ＝ **h**，正好和分母的 h 约掉！// 剩下：// **[[1|\sqrt{x+h} + \sqrt{x}]]**// 现在可以让 h 奔向 0 了，得到 **[[1|2\sqrt{x}]]**。// // **顺带结掉一笔暗账。**“让 h 奔向 0”这一步用到了 √(x+h) 奔向 √x——// 也就是**开方也是连续的**。第三篇只证了多项式连续，开方这一台一直没交代。// 可上面那个式子自己就把它给出来了：// **√(x+h) − √x ＝ [[h|\sqrt{x+h} + \sqrt{x}]]**// 分母不小于 √x，所以这两个数**相差不超过 h 的绝对值除以 √x**。// h 一小，它就跟着小。// // 注意这一招和第七篇是**同一个念头**：// 想办法把那个碍事的 h **弄掉**，再代入。// 多项式靠展开，开方靠上下同乘。

现在反过来猜：**对谁求导会得到 √x？**

试试 **F(x) ＝ [[2|3]] × x × √x**。用第七篇的乘积法则验一验：

CENTER: **F′(x) ＝ [[2|3]] × （1 × √x ＋ x × [[1|2\sqrt{x}]]）＝ [[2|3]] × （√x ＋ [[\sqrt{x}|2]]）＝ [[2|3]] × [[3\sqrt{x}|2]] ＝ √x** ✓

BOX[remember]: 答案 :: 从 0 到 1，√x 底下的面积是// **F(1) − F(0) ＝ [[2|3]] × 1 × 1 − 0 ＝ [[2|3]]**。// // **加不出来的那块地，两行就算出来了。**

BOX[key]: 回头看：第一册到底有没有白学 :: 这一册**处处**踩在第一册上。点名如下：// **①–⑧ 里的第③条（单调有界）**——第十一篇第十节靠它断定 √x 底下的面积**存在**，而那块面积是加不出来的。// **夹逼定理**（第一册第四篇例二）——第十一篇第九节用它把面积与体积的低估高估一起收口。// **和的极限**（第一册第四篇例三）——第七篇证乘积法则时把式子拆成两块。// **“先证存在，再算是多少”**（第一册第五篇第五节）——**这一篇整篇就是它的一次演出**：先知道面积在，再用公式去够它。// // 第一册那八条**从不告诉你答案是多少，只告诉你答案存在**。// 而这一册证明了：**知道它存在，就已经足够让你把它算出来。**

BOX[key]: 这一册的一句话 :: 牛顿–莱布尼兹公式的价值，不在于它好看。// 在于：**直接加起来做不到的事，它绕过去了。**// 一条路量快慢，一条路量大小，// 走到底才发现**它们是同一条路的两头**——// 而这，就是微积分。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 面积正式写作**定积分**：从 b 到 c 的 f(x) dx，用一个拉长的 S 记号 ∫。那个 S 就是“求和”（Sum）的意思——正是第十一篇在做的事；dx 站在被加的每一小条里，报它的宽。// 面积函数 A(x) 叫**变上限积分**；A′(x) ＝ f(x) 叫**微积分基本定理第一部分**。// F(c) − F(b) 那条叫**牛顿–莱布尼兹公式**，也叫**微积分基本定理第二部分**。满足 **F′ ＝ f** 的函数 F 叫 f 的**原函数**。// √x 在 x 点的导数是 [[1|2\sqrt{x}]]；它的原函数 [[2|3]]x√x 通常写成 [[2|3]]x 的 [[3|2]] 次方。// 一般的函数（不只是多项式）也有这条公式，证它要用**连续函数在闭区间上取到最大最小**——那正是第九篇第二节的**最值定理**。这一册在第三节仍旧走了多项式的捷径（那个 M 直接找得出来），但**那条大定理本身，第九篇已经证过了**。
