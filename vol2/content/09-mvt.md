# 第九篇　凭什么：导数说了算

CENTER: 一把局部直尺只管一点；中值定理把整张坡度地图和一整段路接起来

## 一、上一篇欠下的两张欠条

第八篇把整张坡度地图摊开来用。可它有两句话，是**先用起来、还没有证**的：地图上一个点的记号，怎样管到一整段路？现在把账翻出来。

### 第一张欠条：f′ 是正的，凭什么"在涨"

第八篇第一节先沿着坡度地图，读每一点上的微分直尺：坡度是正的，直尺就朝上。于是我们先把“整段路上的直尺都朝上”当作“一路在涨”的判断法用起来。

**可你仔细看，每一把直尺都只管自己附近的一小块；一整段路会怎样，还差一句把这些小块接起来的话。**

BOX[key]: 差在哪 :: **f′(p)** 是一个数，它只站在 **p 这一点**上；钉在 p 的微分 **dy ＝ f′(p)dx**，也只用两把局部线性尺冒充 p 附近的变化。// // 从**每一点附近都朝上**，到**从这儿到那儿一整段都在涨**——// **中间还隔着一段路，第八篇没有走过去。**

妹妹要是较真，会这样问：**"你怎么知道中间没有一段偷偷往回跌？"**

这个问题不是抬杠。看一台真机器：

BOX[remember]: 所以那句话缺的是什么 :: 缺的是一句**管住一整段**的话。// 第八篇只知道**一个点**上的事，就下了**一整段**的结论。// 要把这一步补上，得请第一册的八大定理出场。

### 第二张欠条：最高点凭什么存在

第八篇第二节把路中间那些 **f′ 等于 0** 的点圈起来，当作顶和谷的候选。

这句话里藏着**两件**没交代的事：

BOX[remember]: 藏起来的两件事 :: **第一件：**最高点**凭什么存在**？// 第八篇借着图把最高点找了出来；可要是没有图，万一这台机器（函数）根本没有最高点呢？// **第二件：**就算它存在，凭什么**在那儿 f′ 是 0**？

## 二、先还最难的一件：最高点真的存在

这是第一册**八大定理**在这一册最要紧的一次出场。

BOX[remember]: 要证的是什么 :: **一台连续的机器（函数），在一段路上（两头都要），一定取得到最大的那个值。**// // 注意"**取得到**"三个字：不是"有个数比它吐出来的都大"，// 而是**路上真有那么一个点**，机器在那儿吐出来的数最大。// // 这条定理有名字，叫**最值定理**。

它凭什么成立？**凭数轴上没有洞。**而办法还是那一招——

BOX[key]: 又是砍一半 :: 这已经是**第三次**了：// 第一册第二篇第六节，砍一半找聚点；// 第一册第五篇里 ④ 推出 ⑤，砍一半证有限覆盖；// **这一次，砍一半找最高点。**// // 每一次都是同一个念头：// **把一件做不完的事，换成一串越套越紧的段子。**

FIG: fig-14-halving-max.png | 每砍一次都挑"坏的那一半"留下。段子越套越短，最后钉住一个点。

### 第一步：机器跑不到天上去

先证一件小事：**它有上界**——吐出来的数不会要多大有多大。

BOX[key]: 证明（反证 ＋ 砍一半） :: 假如它**没有**上界，也就是吐出来的数要多大有多大。// // **砍一半。**把这段路对半砍开。两半里**至少有一半**上头还是没有上界——// 因为要是两半都有上界，取大的那个就成了整段的上界了。**挑那个坏的半段。**// // **一直砍。**得到一串越套越短的坏段子。// 由第一册的**④区间套定理**，它们钉住一个点 p。// // **可是机器（函数）在 p 处是连续的。**姐姐自己挑一个误差——就挑 1。// 连续就给出一个 δ：只要离 p 不到 δ，吐出来的数就离 f(p) 不到 1。// 也就是说，**p 周围那一小圈上，机器是有上界的**（不超过 f(p) ＋ 1）。// // 可段子想多短有多短，**总有某一层整个躺进那一小圈里**。// 那一层就有上界了——**和"每一层都没有上界"矛盾。**// // 所以假设错了：**它有上界。**

### 第二步：那个最大的值，真的被取到

BOX[key]: 证明（还是砍一半） :: 上一步说明"吐出来的所有数"这一堆**有上界**，而且**不空**。// 由第一册的**②确界原理**，它有一个**最小的上界**，记作 M。// 要证的是：**路上真有一个点 p，使得 f(p) 正好是 M。**// // **砍一半。**两半里**至少有一半**，机器（函数）在它上头的最小上界还是 M——// 因为要是两半的最小上界都比 M 小，取大的那个就压住了整段，// 那 M 就不是**最小**的上界了。**挑那一半。**// // **一直砍**，由④钉住一个点 p。// // 现在证 f(p) 正好是 M。妹妹给 ε。// 姐姐用连续找到一个 δ：离 p 不到 δ 的地方，吐出来的数离 f(p) 不到 ε。// 段子想多短有多短，**总有某一层整个躺进这个圈里**；// 而那一层上最小的上界还是 M，所以那一层上**有一点**吐出来的数超过 M − ε。// 那一点离 p 不到 δ，所以 **f(p) ＞ M − 2ε**。// // 这对**每一个** ε 都成立，所以 f(p) 不可能比 M 小；// 而 M 是上界，f(p) 也不可能比 M 大。// **两头一夹，f(p) 就是 M。证毕。**

BOX[remember]: 最小的那个值也一样 :: 把上面每一句里的"上"换成"下"、"大"换成"小"，// 一个字都不用多想，**最小值也取得到**。（自己写一遍，是 B3。）

BOX[remember]: 这条定理的分量 :: 它**一个字也没说最大值是多少，只说它存在**。// 又是第一册第五篇第五节那句话——// **八条定理从不告诉你答案是多少，只告诉你答案存在。**// // 而下一节马上就会看到：**光知道"存在"，就已经够用了。**

## 三、顶上为什么是平的

现在最高点有了。**它那儿凭什么 f′ 是 0？**

有一个条件必须说清楚：**这个最高点得在路的中间，不能在两头。**（为什么，第七节会翻一次车。）

BOX[key]: 证明：路中间的顶上，f′ 一定是 0 :: 设 p 是**路中间**的一个最高点，机器（函数）在那儿**可微**——有 f′(p)。// // **从右边看。**取一个正的 h。因为 p 是最高点，f(p+h) 不会超过 f(p)，// 所以平均变化率 [[f(p+h) - f(p)|h]] 的**分子不是正的、分母是正的**，// 整个平均变化率**不是正的**。// 让 h 奔向 0，按第一册第四篇例四——**"＜"取极限会退化成"≤"**——得到 **f′(p) ≤ 0**。// // **从左边看。**取一个负的 h。分子还是不是正的，可**分母变成负的**了，// 整个平均变化率**不是负的**。// 让 h 奔向 0，同样得到 **f′(p) ≥ 0**。// // 又不大于 0、又不小于 0，**只能是 0**。**证毕。**

FIG: fig-15-fermat.png | 顶上：左边爬上来，右边掉下去。两边的平均变化率一个不小于 0、一个不大于 0，把 f′(p) 夹成了 0。

BOX[remember]: 这里用上了那条"翻车" :: 第一册第四篇例四那条**当时觉得很扫兴**的结论——// 每一项都是正的，取完极限却只能说"大于**或者等于** 0"——// 在这里第一次真正派上用场：// **正是那个甩不掉的"或者等于"，把 f′ 夹成了 0。**// // 当初它像块绊脚石，现在它是主角。

BOX[remember]: 谷底也一样，它有名字 :: 最低点那儿把符号全反过来，结论还是 **f′ 是 0**。// 这一条叫**费马引理**。// // 顺带说一句：上面那两步用的是**机器的极限**（h 奔向 0），// 而第一册第四篇例四讲的是**一队数的极限**。// 这两者第三篇已经搭好桥了，ε 那一步一个字都不用改。

BOX[remember]: 用微分的话再念一遍 :: 顶点叫 p，坡度地图在这里标着 f′(p) ＝ 0，所以钉在 p 的微分是零线性函数 **dy ＝ f′(p)dx ＝ 0**：无论小箭头怎样，dy 尺都读出 0。// 原函数的真变化并不一定为 0；只是其中**跟 dx 成正比的那一份没有了**。// 这就是“顶上是平的”在微分话里的样子。

## 四、两头一样高，中间必有平的地方

BOX[remember]: 罗尔定理 :: 一台连续、又处处可微的机器（函数），在一段路上（两头都要），// **如果两头一样高**，// 那么**中间一定有一个地方，f′ 是 0**。

BOX[key]: 证明（把前两节拼起来） :: 由**第二节**，这段路上最大值和最小值都取得到。// // **情形一：最大值和最小值都出现在两头。**// 两头一样高，所以最大的那个值和最小的那个值一样大——// 这台机器**一路上就是一条平线**，中间随便哪一点 f′ 都是 0。// // **情形二：最大值或者最小值出现在路的中间。**// 由**第三节**（费马引理），那一点的 f′ 就是 0。// // 两种情形都找到了平的地方。**证毕。**

BOX[remember]: 请看清楚这个证明的形状 :: 它自己一点新东西也没做。// 它只是把**第二节的"存在"**和**第三节的"平"**接了起来：// **先有最高点，才谈得上"顶上是平的"。**// // 这正是"**先证存在，再算是多少**"——只不过这一次，// 第二步要的不是"是多少"，而是"它有什么性质"。

## 五、把画像斜着看：中值定理

罗尔要求两头一样高，太苛刻了。**可这个要求能凑出来。**

念头很朴素：**两头不一样高，那就把整张画像斜着按下去，直到两头一样高。**

BOX[key]: 怎么“按下去” :: 从 b 到 c 这一段，两头的高分别是 f(b) 和 f(c)。// 穿过这两头的那条直线，就是第四篇见过的**割线**，它的陡度是// **k ＝ [[f(c) - f(b)|c - b]]**// // 现在造一台新机器（函数），**把那条割线减掉**：// **g(x) ＝ f(x) − k × (x − b)**// // 算一算它两头有多高：// **g(b) ＝ f(b)**// **g(c) ＝ f(c) − k × (c − b) ＝ f(c) − (f(c) − f(b)) ＝ f(b)**// // **两头一样高了。**

看清这一减减掉的是什么：割线的陡度 k，是这一整段**平均的率**。减掉那条直线，就是**把两头之间跟挪动成正比的那份涨落先扣走**——剩下的 g 只剩弯的部分，两头自然一样高。**还是那个直觉：变化拆成两块——成正比的一块，加上弯的零头**；第五篇是留下成正比的一块用，这里反过来，**扣掉它，专看剩下的弯**。

FIG: fig-16-rolle-mvt.png | 左：两头一样高，中间必有一处是平的。右：两头不一样高，把割线减掉——整张图斜着按平，就回到左边那种情形。

BOX[key]: 中值定理 :: 对 g 用罗尔：中间有一点 p，使 **g′(p) ＝ 0**。// 而 g 就是 f 减掉一条直线，那条直线在每一点的导数都是 k，所以 **g′(x) ＝ f′(x) − k**。// 于是 **f′(p) ＝ k**，也就是：// // **[[f(c) - f(b)|c - b]] ＝ f′(p)**// // 白话：**一整段的平均变化率，路上一定有某一点的导数正好等于它。**

BOX[remember]: 它到底在说什么 :: 全程平均时速六十，**路上一定有某个时刻，仪表盘正好指着六十。**// 这就是中值定理。// // 请注意它**没有**说那个时刻在哪儿，也没打算告诉你。// 又是"**先证存在**"——而且这一次连"再算是多少"都不必：// **光知道"有这么一点"，下一节就够用了。**

## 六、三条推论：欠条全部还清

把中值定理换个写法，用起来更顺手：

CENTER: **f(c) − f(b) ＝ f′(p) × (c − b)**

BOX[key]: 推论一：f′ 处处是正的，它真的一路在涨 :: 设这一整段上 **f′ 处处是正的**。在段里随便取两点，前一点叫 b，后一点叫 c。// 由中值定理，**f(c) − f(b) ＝ f′(p) × (c − b)**。// 看右边：f′(p) 是正的，(c − b) 也是正的，**乘起来是正的**。// 所以 **f(c) ＞ f(b)**。// // 这对段里**任意**两点都成立——**它真的一路在涨。第一张欠条还清。**

BOX[remember]: 妹妹那个问题的答案 :: 第一节妹妹问：“你怎么知道中间没有一段偷偷往回跌？”// // 答案是：**要是真有一段往回跌，在那一段上取两点，**// **中值定理立刻会交出一个 f′ 不是正的点来。**// 可我们说好了整张坡度地图在这段路上处处标着正数。**跌不了。**// // 一点上朝上的直尺只管一点；整段都在涨，需要地图在**整段每一点**都标着正数。第一节那张图，正是少了“整段”两个字会发生的事。

BOX[key]: 推论二：f′ 处处是 0，它就是一条平线 :: 同一个式子，这回右边的 f′(p) 是 0：// **f(c) − f(b) ＝ 0 × (c − b) ＝ 0**// 所以段里**任意**两点吐出来的数都一样——**这台机器（函数）是个常数。**

BOX[key]: 推论三：每一点的导数一样，就只差一个常数 :: 两台机器 F 和 A，满足 **F′(x) ＝ A′(x)**。// 看 **F − A** 这台机器：它在每一点的导数都是 F′(x) − A′(x)，也就是 **0**。// 由推论二，**F − A 是一个常数**。// 也就是说：**F 比 A 只多一个不变的数。**

BOX[remember]: 推论三是第十二篇的地基 :: 第十二篇会说：**F 和面积函数 A 的 f′ 一样，所以它们只差一个常数，一减就抵掉了**。// **那句话本来是赊的，现在还上了。**// // 没有推论三，牛顿–莱布尼兹公式就只是一句好听的话。

## 七、直观翻车：把"两头都要"去掉，最高点就不存在了

妹妹该挑刺了：**第二节那句"两头都要"，是随口加的吗？**

**不是。去掉它，整条定理当场就塌。**这是本篇要抓的那条刺。

BOX[key]: 一个例子就够了 :: 取最简单的机器（函数） **f(x) ＝ x**，路取"**比 0 大、比 1 小**"——**两头都不要**。// // 吐出来的数**要多接近 1 有多接近**：投 0.9 出 0.9，投 0.99 出 0.99，投 0.999 出 0.999……// 可它**永远到不了 1**——因为 1 那一点根本不在路上。// **最小的上界是 1，但这个值取不到。**// // 把两头补上，路变成"从 0 到 1，两头都要"，// 最高点立刻就出现了：**它就站在 1 那一点上。**

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 第二节那条叫**最值定理**（魏尔斯特拉斯极值定理）；第三节叫**费马引理**；第四节叫**罗尔定理**；第五节叫**拉格朗日中值定理**，也叫**微分中值定理**，通常写成 f(c) − f(b) ＝ f′(ξ)(c − b)，那个 ξ 念"克西"，只是"中间某一点"的意思。// 第五节造出来的那台 g 叫**辅助函数**——**造一个新函数去凑条件**是往后很常用的一招。// 第二节的证明走的是④区间套；课本上更常见的是用⑦致密性（取一列吐出来的数奔向 M，再抽出一小队）。**两条路证的是同一件事。**// 再往前还有柯西中值定理、洛必达法则、带余项的泰勒公式——都是从这一条往下推的。
