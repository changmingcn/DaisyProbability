# 第五篇　以直代曲

CENTER: 微分的另一样用处：拿许许多多分段直线连接起来冒充曲线，从而在必要的时候，用直线来估算曲线的局部变化

第四篇刚把微分交到手里：走到 x，读出 f′(x)，再按这个倍率支起线性函数 **dx → dy ＝ f′(x)dx**，去估算眼前的一小段变化。

这一篇先不追问这些导数怎样求。我们把借来的答案用到底：曲线不好算，直线好算；要是能拿许许多多小直线连接起来冒充曲线，就能估数，还能解方程。问题只有一个：**冒充得像不像？**

BOX[key]: 这一篇仍在用第四篇的欠条 :: 我们暂时借用两件事：导数表里的答案，以及“微分留下的零头比 dx 小一档”。// 本篇会在这两件事之上证明：**把陡度换成别的数，就做不到这么像**；// 第六篇回头证明多项式的导数和零头性质，开方的导数到第十一篇第六节再还。// 先看工具有多值钱，再学它怎样造出来——顺序倒过来，账一笔不少。

## 一、放大镜下的曲线

先拿一台机器（函数）做实验。把 f(x) ＝ x^2^ 的画像在 x ＝ 1 附近放大——一次，再一次：

FIG: fig-21-zoom.png | 同一段曲线，越放越大。放得越大，看着越直——可"看不出弯"不等于"没有弯"。

放得越大，弯就越看不出来。

妹妹会问：**"那放大到最后，它就真的变成直线了吗？"**

不是。除了一次函数，多项式的画像**永远是弯的**——再怎么放大，弯还在，只是**小到看不出来**。"看不出来"和"没有"是两回事。

这一篇要做的，就是把"看不出来"从一句感想，变成一句能证明的话——这是第一册的老规矩：**先把话说准，再谈对错。**

## 二、把切线写成一个函数

第四篇的图里已经画过：站定 x，微分沿着一条陡度为 f′(x) 的直线走。现在给这条切线立个户口——它自己也是一台机器（函数）：

BOX[remember]: 切线函数 :: 在 x 这一点的切线，是这样一个函数（记作 **T**，念它的字母名）：// **T(t) ＝ f(x) ＋ f′(x) × (t − x)**// 白话：从 f(x) 出发，每往右挪一格，按陡度 f′(x) 涨一格。// t 是投进去的数——第十一篇第三节就是这么用 t 的。

验一验它配不配叫"切线"。取 f(x) ＝ x^2^，在 x ＝ 3 处：f(3) ＝ 9，f′(3) ＝ 6，于是

CENTER: **T(t) ＝ 9 ＋ 6 × (t − 3)**

- 投 3 进去：T(3) ＝ 9，和 f(3) 一样。**在这一点，替身和真身重合。**
- 它的陡度处处是 6——一条规规矩矩的直线，陡度不多不少，正是 f 在 3 处的陡度。

## 三、成正比：直线的本性

直线到底好在哪？好在一件事：

BOX[remember]: 直线的本性 :: 站定 x，把挪动 dx 投进切线的变化规则，输出**恰好**是 **dy ＝ f′(x)dx**。// dx 放大 2 倍，dy 就放大 2 倍；dx 变成一半，dy 也变成一半——// **输出和输入成正比**，比例就是这一点的导数 f′(x)。// 这不是近似，是一台真正的线性函数。

（"成正比"这三个字，六年级课本里叫**正比例**：一个量变成几倍，另一个量跟着变成同样的几倍。）

真身 f 呢？它是一台机器（函数），画像可以是弯的，做不到"恰好"：

CENTER: **f(x+dx) − f(x) ＝ dy ＋ 零头，其中 dy ＝ f′(x)dx**

第四篇已经把这句话明写成一张欠条：对 x^2^，零头是 (dx)^2^；一般情形下，只要 f′(x) 存在，**零头除以 dx 就奔向 0**——它比 dx 小一档。第六篇第五节会证明它。

BOX[key]: 微分，再读一次 :: 第四篇已经说过：站定 x，微分是线性函数 **dx → dy ＝ f′(x)dx**；它从真变化里取出**跟 dx 成正比**的那一块。// 这一篇多给了一句：**成正比正是直线的本性**。// 两句一合，微分就有了新读法——// **拿一台线性函数去冒充原函数在这里的变化规律，冒充出来的变化 dy，就是微分的输出。**// 以直代曲，就是只留成正比的部分，把零头交给极限。// 这份工作是**局部**的：一小段里作数，换了站脚点就得换下一台。// **函数全局可以是弯的；微分是它在每一点局部的线性替身。**切线函数则是在 f(x) 上加回 dy 得到的仿射替身。

## 四、只有切线做得到

妹妹该挑刺了。

BOX[dialog]: 凭什么是切线 :: **妹妹：**"你说切线冒充得最像。可我随手画一条别的直线，也穿过同一个点，看着也挺贴。你凭什么说它不行？"// **姐姐：**"好，那就比一比。你那条直线穿过同一个点，陡度是 m，m 不等于 f′(x)。拿它冒充，误差是// f(x+h) − f(x) − m × h ＝ (f′(x) − m) × h ＋ 零头。// 现在把误差除以 h：前一块是 f′(x) − m，一个**不是 0 的定数**；后一块奔向 0。// 所以你的误差除以 h，奔向 f′(x) − m，**不奔向 0**——// 你的误差跟 h 一样大，压不到小一档。"

BOX[key]: 这一篇的小定理 :: 穿过这一点的直线有无穷多条，// **能把误差压到比 h 小一档的，只有一条**——// 它的陡度必须正好是 f′(x)。也就是：**只有切线做得到。**// **冒充得最像**从此有了准话：**误差除以 h，还奔向 0。**// 顺便说一句：这个证明没占多项式一点便宜，// **对任何可微的机器（函数）都成立**——开方也在内。// // 这把第四篇留下的问题往前推进了一步：**凭什么偏偏是成正比的那一块**——// 因为换上任何别的陡度，误差就压不到比 h 小一档。// 至于**正确陡度为什么真能把误差压小**，第六篇第五节还清。

BOX[remember]: 回头看，这一步和第一册长得一样 :: 第一册第一篇：把"到达"这句感想，变成 ε–N 那句"保证"。// 这一篇：把"冒充得像"这句感想，变成"误差比 h 小一档"这句准话。// **先把感想变成准话——数学每次都是这么长大的。**

## 五、拿替身干活：估数

√50 是多少？没有计算器，硬开方很苦。以直代曲两步就出数。

√x 这台机器（函数）的导数，第四篇先借给我们：f′(x) ＝ [[1|2\sqrt{x}]]。挑一个离 50 很近、又开得出方的数——49。在 x ＝ 49 处，导数 f′(49) ＝ [[1|14]]，于是微分是 **dx → dy ＝ [[1|14]]dx**；再加回 f(49) ＝ 7，就得到切线

（这份导数答案不是白来的：第十一篇第六节会用平均变化率把它求出来。）

CENTER: **T(t) ＝ 7 ＋ [[1|14]] × (t − 49)**

投 50 进去：

CENTER: **T(50) ＝ 7 ＋ [[1|14]] ≈ 7.0714**

BOX[dialog]: 验收 :: **妹妹：**"口说无凭。7.0714 自己乘自己是多少？"// **姐姐：**"约是 50.0047。差不到万分之一。"// **妹妹：**"你不是说还有零头吗？零头呢？"// **姐姐：**"在的。√50 其实是 7.0710…，替身报 7.0714——差别在第四位上。// 这里挪动 h 是 1；小定理保证零头比 h 小一档，h 越小它缩得越快。// 要是估 √49.1，替身就准到小数点后六位了。"

BOX[remember]: 其实你早用过一次 :: 第四篇第二节估 3.01 的平方，就是这一招：// 在 3 处搭切线，投 3.01 进去。// 那时只说“用微分估一估”，现在你知道这个动作的全名——**以直代曲**。

## 六、牛顿法：顺着切线滑下去

第二件活更漂亮。拿机器（函数）f(x) ＝ x^2^ − 2 来说，想算 √2，就是想找它的画像**穿过横轴的地方**。

曲线穿过横轴的点不好找。**直线穿过横轴的点，一解方程就出来。**那就以直代曲：

BOX[key]: 顺着切线滑下去 :: **第一步：**站上曲线的一个点（横坐标叫 x~1~）。// **第二步：**在那儿画切线。切线是直的，它穿横轴的点一眼能算——落到那儿，叫 x~2~。// **第三步：**从 x~2~ 竖直回到曲线上，再画切线，再落下来，得到 x~3~……// 一步一滑，越滑越贴近曲线自己穿轴的地方。

FIG: fig-22-newton-slide.png | 画切线，滑到横轴；回到曲线，再画再滑。两步就已经贴得很近。

姐姐来把"滑一步"算成公式。站在 x~n~ 处，f(x~n~) ＝ x~n~^2^ − 2，f′(x~n~) ＝ 2x~n~，切线函数是

CENTER: **T(t) ＝ (x~n~^2^ − 2) ＋ 2x~n~ × (t − x~n~)**

让 T(t) 等于 0，解出 t，整理一下（B 组会让你自己整理一遍）：

CENTER: **t ＝ [[x_{n} + 2 ÷ x_{n}|2]]**

BOX[remember]: 请翻到第一册第五篇第五节 :: 那儿有一条“又快又老的办法”：// **拿手上这个数，和“2 除以它”，取平均。**// 四步准到小数点后六位，当时像一句咒语——**它就是上面这条公式。**// 原来每一步都是：**画切线，滑下去。**// 它凭什么收敛？第一册当场就证了：只跌不涨、有下界，由③单调有界定理，**必有极限**。// 直观（滑下去）、代数（取平均）、证明（第一册的③）——// 三块拼图早就各就各位，今天合上了。

## 七、直观翻车：切线也会把你带沟里

牛顿法这么灵，是不是随便站哪儿都行？

**不是。**这是本篇要抓的那条刺。

BOX[key]: 反例：站在平切线处起步 :: 换一台机器（函数）：f(x) ＝ x^3^ − 3x。// 想找它穿横轴的点，从 x ＝ 1 出发。借用第四篇那张导数表的规律，f′(1) ＝ 3 × 1^2^ − 3 ＝ 0。// **这里的切线是平的。**可 f(1) ＝ −2，这条水平线又不在横轴上，永远碰不到横轴。// **第一步就滑不动了。**// 第九篇会把这台函数的整幅画像描出来，到时你会看见 x ＝ 1 正好是谷底。

FIG: fig-23-flat-tangent.png | 站在谷底：切线平躺，够不到横轴。牛顿法第一步就卡死。

BOX[remember]: 教训 :: 以直代曲，只在"这一点附近"作数；// 替身是好替身，也得**挑对地方搭**。// 站在 f′ 为 0 的点上，切线平躺，牛顿法当场卡死；// 站得太偏，滑一步反而可能飞得更远。// **好工具也有说明书。**

## 长大以后的写法

FIG: fig-33-crossing-lines.png | 给下面灰盒配的一张图：在同一点投进同样大小的 dx，微分按不同的导数倍率吐出不同大小的 dy；坡越陡，输出 dy 越大。

BOX[grown]: 课本上会这样写 :: 切线方程：站在 p 那一点，课本写 y ＝ f(p) ＋ f′(p)(x − p)——正是第二节的切线函数 T。“以直代曲”的正式名字叫**线性近似**，也叫**线性化**。// 这里要把两个替身分清：**微分**是从 0 出发的线性函数 **dx → dy ＝ f′(p)dx**；**切线函数**是在原高度上加回这份输出，得到 **dx → f(p) ＋ dy**。前者替代局部的**变化规律**，后者替代原函数在附近的**函数值**。// “微分是一个线性映射”里的“线性”就是第三节的“成正比”，“映射”就是函数。点 p 一换，导数 f′(p) 这个倍率随之更换，于是支起另一台微分。// 第四节那条小定理，其实是导数的另一种定义：现代课本正是用“误差比 dx 小一档”来定义**可微**的；对这一册的世界（一个自变量），**可微和“可导”是同一回事**。// 第六节叫**牛顿法**（也叫牛顿–拉弗森法）。计算器和电脑开方、解方程，今天用的仍是它和它的亲戚。// 想知道零头到底差多少，要等**泰勒公式**——它连零头都写成公式给你。// 上面那张方格纸图画的就是微分这台机器：投进同样大小的 dx，导数倍率越大，吐出的 dy 越大。到了高维，输入和输出会变成多方向的箭头；“在一点用线性函数替代局部变化”这句话仍然不变。
