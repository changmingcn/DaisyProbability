# 第八篇　面积有多大

CENTER: 换一条完全不相干的路。这一条上，第一册学的东西才真正派上用场

前两篇讲的是"走得多快"。这一篇讲一件**看起来毫不相干**的事：

CENTER: **一条曲线底下，那块地有多大？**

请先忘掉导数。这一篇一次都不会用到它。

## 一、老办法：数格子

在方格纸上画出函数的画像，数一数底下有多少个小格子——这就是最朴素的量面积。**第一册开篇你亲手干过**：那块弯边的地，少算法和多算法把它夹在 0.24 和 0.43 之间；格子缩小一半，夹紧成 0.2925 和 0.3875。

毛病你也早就见过：**边上那一圈格子，被曲线切成了半个半个的，数不清。**

格子画小一点会不会好些？会。**那就一直画小下去。**——第一册开篇就是在这句话跟前停住的：谁也画不完。整整一册书之后，我们回来了——**这一次，带着家伙。**

## 二、切成竖条

与其数格子，不如**切成竖条**：把从 0 到 b 这一段横着切成 n 段，每段上立一根长条。

可长条要立多高？曲线在那一小段上是变化的呀。**两个办法**：

- 每条都取**左边那头**的高 → 每条都矮了一点 → **总和比真面积小**。
- 每条都取**右边那头**的高 → 每条都高了一点 → **总和比真面积大**。

FIG: fig-06-strips.png | 左边一套全都矮了，右边一套全都高了。真面积被夹在中间。

BOX[remember]: 先给这三个量起名字 :: 想把话写成一行公式，就得先让每样东西**有个符号**。// 用 n 条算出来的**矮的那一套**总和，记作 **L~n~**；**高的那一套**记作 **U~n~**；// 我们要求的**真面积**记作 **A**。// 于是"真面积被夹在中间"写成一行就是：// **L~n~ ≤ A ≤ U~n~**

BOX[key]: 注意这个句型 :: **L~n~ ≤ A ≤ U~n~**// 如果两套都奔向同一个数，真面积就只能是那个数。// **这正是第一册第四篇的夹逼定理。**// 第一册说过它有用——**这里就是它兑现的地方。**

## 三、要先会加：1 ＋ 2 ＋ … ＋ n

要把长条加起来，先得会算 **1 ＋ 2 ＋ … ＋ n**。

FIG: fig-07-triangle-number.png | 两个一模一样的三角摆在一起，正好拼成一个长方形。

实心点摆成一个三角：第一行 1 个、第二行 2 个……第 n 行 n 个，一共就是 1 ＋ 2 ＋ … ＋ n 个。空心点也摆一个同样的三角，倒过来一扣——**正好拼成 n 行 n＋1 列的长方形**。

CENTER: **1 ＋ 2 ＋ … ＋ n ＝ [[n(n+1)|2]]**

## 四、第一块面积：直线底下

先拿最简单的函数 f(a) ＝ a 试手：从 0 到 b，它底下是个三角形，面积**应该**是 [[b^{2}|2]]（底乘高除以二）。看看切条法给不给同一个答案。

切成 n 条，每条宽 [[b|n]]。取右边那头当高，第 k 条的高就是 [[kb|n]]。所以：

CENTER: **U~n~ ＝ [[b|n]] × （[[b|n]] ＋ [[2b|n]] ＋ … ＋ [[nb|n]]）＝ [[b^{2}|n^{2}]] × （1 ＋ 2 ＋ … ＋ n）**

把第三节的公式代进去：

CENTER: **＝ [[b^{2}|n^{2}]] × [[n(n+1)|2]] ＝ [[b^{2}|2]] × （1 ＋ [[1|n]]）**

n 越大，[[1|n]] 越小（第一册第四篇例一）。所以总和奔向 **[[b^{2}|2]]**。**和三角形面积对上了。**✓

## 五、第二块面积：抛物线底下

现在来真的：f(a) ＝ a^2^ 底下，从 0 到 b。这一块**没有现成的公式可以对答案**。

同样切 n 条，第 k 条的高是 [[kb|n]] 的平方：

CENTER: **U~n~ ＝ [[b^{3}|n^{3}]] × （1^2^ ＋ 2^2^ ＋ … ＋ n^2^）**

于是我们需要**平方的和**。它也有公式：

CENTER: **1^2^ ＋ 2^2^ ＋ … ＋ n^2^ ＝ [[n(n+1)(2n+1)|6]]**

BOX[key]: 加餐：这个公式怎么来的（一层层抵消） :: 先注意一件事：**(k+1)^3^ − k^3^ ＝ 3k^2^ ＋ 3k ＋ 1**（把左边展开就看见了）。// 现在把 k ＝ 1、2、…、n 这 n 个式子**全部加起来**。// **左边**：(2^3^−1^3^) ＋ (3^3^−2^3^) ＋ … ＋ ((n+1)^3^−n^3^)// ——中间的 2^3^、3^3^…… **前一个减、后一个加，一层层全抵消了**，只剩 **(n+1)^3^ − 1**。// **右边**：3 × （平方和）＋ 3 × （1+2+…+n）＋ n。// 两边一对，再把第三节的公式代进去，解出来就是上面那条。// // **"一层层抵消"这一招记住它**——第九篇还会再见到一次。

代进去算：

CENTER: **U~n~ ＝ [[b^{3}|n^{3}]] × [[n(n+1)(2n+1)|6]] ＝ [[b^{3}|6]] × （2 ＋ [[3|n]] ＋ [[1|n^{2}]]）**

n 越来越大时，[[3|n]] 和 [[1|n^{2}]] 都奔向 0，括号里奔向 2。所以：

BOX[remember]: 抛物线底下的面积 :: 从 0 到 b，f(a) ＝ a^2^ 底下的面积是 **[[b^{3}|3]]**。// 比如从 0 到 3，面积是 9。// **请记住这个答案**——第九篇会用另一条完全不同的路，再算它一次。

BOX[key]: 回头望一眼那块地——妹妹赢了一半 :: 把 b ＝ 1 代进去：从 0 到 1，平方曲线底下的面积，**正好 [[1/3]]**。// 第一册开篇妹妹猜的那个数——**猜对了**。0.24 和 0.43 夹住的、0.2925 和 0.3875 夹住的，就是它。// 你要是在开篇的橙盒里写下过自己数的两个数，现在可以翻出来对账了。// 可妹妹还有第二问："凭什么这么整齐？"这一层，**第九篇揭底**。

### 加餐：同一个公式，另一个世界——金字塔为什么是三分之一

六年级课本里有一条规矩：**圆锥的体积，是同底同高圆柱的三分之一。**那个三分之一是哪来的？课本没说。其实它和本节是**同一笔账**。

BOX[key]: 切片算一座方尖塔 :: 一座方底的"金字塔"：底是边长 b 的正方形，尖顶正好在高 b 处。// 从尖往下量，深到 t 的地方**水平切一刀**，切面是边长 t 的正方形，面积 t^2^——越往下，切面越大。// 把塔横着切成 n 层薄板，每层厚 [[b|n]]，第 k 层的切面边长约是 [[kb|n]]。// 把 n 层薄板的体积全加起来，记作 V~n~：// **V~n~ ＝ [[b|n]] × [[b^{2}|n^{2}]] × （1^2^ ＋ 2^2^ ＋ … ＋ n^2^）**// 又是**平方的和**！代进本节那条公式，跟抛物线一模一样地算下去，// n 越来越大时，它奔向 **[[b^{3}|3]]**——// **正好是同底同高的方柱（体积 b^3^）的三分之一。**

FIG: fig-28-pyramid.png | 把方尖塔横切成薄板：每层切面是正方形，边长跟深度走、面积跟深度的平方走——和抛物线底下切条是同一笔账。

BOX[remember]: 三分之一的出处 :: 抛物线底下的面积是 [[b^{3}|3]]，方尖塔的体积也是 [[b^{3}|3]]——// **因为都踩着 1^2^ ＋ 2^2^ ＋ … ＋ n^2^ 这同一条公式**：// 一个是"高跟位置的平方走"，一个是"切面跟深度的平方走"。// 课本里圆锥的三分之一，道理相同（圆的那份要再等 π 出场）。// 交代一句：薄板是平顶的，真塔面是斜的——要说严实，// 得照第六节那样搭高低两套、再夹逼收口。架子完全一样，这里只搭了一半，// 剩下那一半，留给你。

## 六、把"越切越细"说严格

上面我们一直用**右边那头**当高，得到的是**高估**。左边那头给的是**低估**。

- **U~n~ ＝ [[b^{3}|6]] × （2 ＋ [[3|n]] ＋ [[1|n^{2}]]）**，奔向 [[b^{3}|3]]
- 低估比它少了多少？**正好少了最后那一条的面积**（画个图就看出来了），也就是 [[b|n]] × b^2^，**这个量奔向 0**。

所以低估也奔向 [[b^{3}|3]]。两头都奔向同一个数——

BOX[key]: 夹逼收口 :: **L~n~ ≤ A ≤ U~n~**，而两头都奔向 [[b^{3}|3]]。// 按第一册第四篇的夹逼定理，**真面积只能是 [[b^{3}|3]]**。// // 请注意这一步和第四篇的区别：// 第四篇里 h 被**约掉**了，代入就行；// **这里约不掉**，n 在分母上赖着不走，**只能靠极限**。// **第一册那套语言，是为这一刻准备的。**

BOX[remember]: 还第一册那笔账：楼梯为什么骗得了长度，骗不了这里 :: 第一册第四篇第六节留过一个问题。那里的楼梯**越切越细、贴着对角线**，// 长度却**永远是 2**，一步也没挤向对角线的 √2。// 我们这一篇拿长方形去切一块弯边的地，**用的正是同一只手**——// 凭什么这一次算得对？// // **差别就写在上面那个盒子里：这里有两队。**// 低估 L~n~ 从下面顶上来，高估 U~n~ 从上面压下去，两队奔向同一个数，// 真面积**被夹死在中间**，跑不掉。// 楼梯那边只有一队：2，2，2，……// **上面压着，下面没有人顶**——一队数钉不死一个答案。// // 所以靠得住的从来不是**切得细**，而是：// **上下两队，奔向同一个数。**

## 七、√a 底下的面积，存不存在？

前面两块面积都算出来了。可它们算得出来，靠的是**碰巧有求和公式**：一次的用 1＋2＋…＋n，二次的用 1^2^＋2^2^＋…＋n^2^。

现在换一个函数：**√a**。照样切条、照样求和，要算下去就得知道

CENTER: **√1 ＋ √2 ＋ … ＋ √n 等于多少**

**没有这样的公式。**这条路堵死了。

于是冒出一个比"是多少"更靠前的问题：

CENTER: **√a 底下那块地的面积，到底存不存在？**

BOX[key]: 存在。而且不必知道它是多少 :: 把条数**每次加倍**（n → 2n）。// **矮的那一套只会更高**：一根粗条换成两根细条，细条各自贴得更紧，盖住的面积只增不减。// 所以 L~1~、L~2~、L~4~、L~8~…… **只涨不跌**。// 又：它们每一个都被**任何一个高估**压着，所以**有上界**。// // 只涨不跌 ＋ 有上界 ⇒ 由**第一册的③单调有界定理**，// **它一定有极限。**// 同样的话对高的那一套也成立；而两套之差奔向 0，// 所以它们奔向**同一个数**——那就是这块地的面积。**证毕。**

BOX[key]: 第一册那八条，在这里第一次真正派上用场 :: 这里用的是**第③条：单调有界定理**。请体会它的用法：// **它没有告诉我们答案是多少，只告诉我们答案存在。**// 第一册第五篇第五节说过这句话——**很多时候，"存在"就已经够用了。**// // 这不是偷懒，这是数学里极常用的一步：// **先把东西钉在那儿，给它一个名字，再另找办法去算。**// 知道面积存在，第九篇才有资格去问"它的导数是什么"；// 到那时会用另一条完全不同的路把它算出来——**答案是 [[2|3]]**。
