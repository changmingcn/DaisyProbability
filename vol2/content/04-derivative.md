# 第四篇　导数：一点上有多快

CENTER: 先用极限钉住一点上的数；至于怎样快算，留到第七篇

第三篇把函数的极限说清楚了。现在终于可以回答一个一直悬着的问题：一台机器（函数）走到某一点，**就在这里，它变化得有多快？**

答案不是拿尺子在一点上硬量出来的。我们先量一小段里的平均变化，再把这一小段缩短，看答案奔向哪里。奔到的那个数，就叫这一点的**导数**。

## 一、速度表到底指着什么

车开得多快？走了多远，除以用了多久。两个小时开了 120 千米，平均一小时 60 千米。这个算法你早就会。

可仪表盘上那根针指的不是全程平均。踩一脚油门，针立刻往上走；松开，针就往下落。它回答的是：**就是现在，多快？**

BOX[dialog]: 妹妹的第一问 :: **妹妹：**“‘此刻’？一瞬间里，车走了 0 米，用了 0 秒。0 除以 0 什么都不是——那根针到底在指什么？”// **姐姐：**“问得对。一瞬量不了，那就先量一小段，再把这一小段缩短。”

一辆车从停着起步，越开越快。行车记录仪记下它每一刻走了多远。我们盯住**第 3 秒这一刻**，从这里往后量一小段：

TABLE:
| 量的这一小段 | 走了多远 | 用了多久 | 这一小段的平均速度 |
| 第 3 秒 → 第 4 秒 | 14 米 | 1 秒 | 14 |
| 第 3 秒 → 第 3.1 秒 | 1.22 米 | 0.1 秒 | 12.2 |
| 第 3 秒 → 第 3.01 秒 | 0.1202 米 | 0.01 秒 | 12.02 |
| 第 3 秒 → 第 3.001 秒 | 0.012002 米 | 0.001 秒 | 12.002 |

看最后一列：**14、12.2、12.02、12.002……这一队数，挤向 12。**那一刻，速度表的针就指着每秒 12 米。

FIG: fig-29-speedometer.png | 量的那一小段越短，平均速度就越挤向 12——针指的正是这一队数奔向的那个数。

BOX[remember]: 速度表是一台“极限表” :: 一瞬间的速度没法拿“0 米除以 0 秒”来算。// 我们把它定义成：那一小段越缩越短时，**平均速度奔向的那个数**。// 你从小就相信速度表在每一刻指着一个准数；那也就是说，你早就在相信这样的极限。

## 二、把车搬进函数

把眼前站定的地方叫 **p**。机器投进去的数从 p 挪到 p ＋ h，吐出来的数就从 f(p) 变成 f(p+h)。这一小段里，输入挪了 h，输出变了 f(p+h) − f(p)，所以平均变化率是：

CENTER: **[[f(p+h) - f(p)|h]]**

这里的 **p 被钉住**，h 是用来试探旁边的那一小步。h 可以从右边来，也可以从左边来；可以是 0.1、0.001，也可以更短，只是不能等于 0。

FIG: fig-03-difference-quotient.png | 横着挪 h，竖着变 f(p+h) − f(p)；两个一比，是这一整小段的平均变化率。

BOX[remember]: 它量的还是“平均” :: 从 p 到 p ＋ h 这一小段里，机器可能一会儿快、一会儿慢。平均变化率只给整段的平均。// 我们真正要找的是：**就在 p 这一点上，它有多快？**

画像上，这个平均变化率就是穿过两个点的直线有多陡。这条线叫**割线**。现在让 h 越来越小，第二个点向 p 靠近：

FIG: fig-02-secant-to-tangent.png | h 越小，割线越像贴着曲线走；它的陡度若奔向一个数，这个数就属于 p 这一点。

## 三、导数：钉在一点上的数

BOX[key]: 导数的定义 :: 把 p 钉住，让 h 趋于 0。平均变化率 **[[f(p+h) - f(p)|h]]** 若奔向一个确定的数，这个数就叫 f 在 p 点的**导数**，记作 **f′(p)**。// 它回答的只是：**原函数走到 p，这一点上变化得有多快。**

“h 趋于 0”不是把 h 直接写成 0。h ＝ 0 时，分子和分母都成了 0，式子没有意义。正确的动作是：h 始终不等于 0，只让它离 0 要多近有多近，再看平均变化率离哪个数要多近有多近。

BOX[key]: 导数像里程碑旁的一块坡度牌 :: 一条弯弯的山路上，每个里程碑旁都可以立一块小牌，只写**这里**的坡度。f′(p) 就是 p 旁边那块牌上的数。// 牌子不替山路走，也不管别处怎样弯；它只把 p 点的变化快慢钉成一个数。// 下一篇会把这个数刻在一把小直尺上，让直尺代替曲线在 p 附近的变化。

## 四、先完整算出一个

取 f(x) ＝ x^2^。把 p 钉住，从 p 向旁边挪 h：

CENTER: **[[f(p+h) - f(p)|h]] ＝ [[(p+h)^2-p^2|h]] ＝ [[2ph+h^2|h]] ＝ 2p+h**

h 趋近 0，2p ＋ h 就奔向 2p。因此：

CENTER: **f′(p) ＝ 2p**

比如 p ＝ 3，这一点的导数就是 f′(3) ＝ 6。这个 **6 是一点上的值**：它说平方函数走到 3 时，输入每挪一小点，输出大约按 6 倍那么快地变。

BOX[remember]: 一个 p，一个数 :: p ＝ 2 时，导数是 4；p ＝ 3 时，导数是 6；p ＝ 5 时，导数是 10。// 每次先钉住一点，再从邻近平均变化率的极限读出这一点的数。

## 五、让站脚点走遍全路

刚才 p 取 2、3、5，会得到不同的导数值。让站脚点沿整条曲线走，把每一点的导数都收起来，便得到一张新的对应表：

CENTER: **x → f′(x)**

对平方函数，这张表是 **x → 2x**。它像一张铺满全路的坡度地图：走到 x，就报出原函数在那一点的导数 f′(x)。

从原来的机器 f 出发，造出这张新地图 f′，这个操作叫**求导**，写成：

CENTER: **f → f′**

这一篇已经说清求导要找什么。至于怎样不必每次都从头磨极限，快速算出 x^2^、x^3^ 和一般多项式的坡度地图，要到第七篇集中学习。

BOX[key]: 从一点到整张地图 :: **f′(p)** 是钉在 p 点的一个导数值；让 p 沿着整条路走，才收成整张地图 **x → f′(x)**。// 下一篇会反过来做：从地图上走到 p，只取下 f′(p) 这个倍率，造一台只管 p 附近的线性函数。

## 六、定义也会说“不存在”

取 f(x) ＝ |x|，把 p 钉在 0。从右边挪 h，平均变化率总是 1；从左边挪 h，平均变化率总是 −1。左右两边各奔各的，合不成同一个数。

所以 **f′(0) 不存在**。V 字尖角在 0 点没有一个确定的导数；也没有一块既贴合左边、又贴合右边的坡度牌。

不过，这台函数在 0 点是**连续**的：x 只要离 0 足够近，|x| 就会离 0 足够近；画像在这里没有断开。散开的不是函数值，而是两边的**平均变化率**。无论把 h 限在多小的一圈里，右边仍是 1，左边仍是 −1，怎么也挤不进同一个数附近。

FIG: fig-34-absolute-value-derivative.png | 左：f(x) ＝ |x| 的画像在 0 点接得上，却留下一个尖角。右：坡度地图在 0 左边一直是 −1，右边一直是 1，0 点本身只能空着。这里不只是“还没猜出该填什么数”：填任何数，两边也不会奔向它，所以 f′(0) 根本不存在。

BOX[key]: 连续，却不可微 :: 课本会说：**f(x) ＝ |x| 在 0 点连续，却不可导。**在只有一个输入的情形，“可导”和“可微”说的是同一件事：导数 f′(p) 存在，才能在 p 点定下微分 **dy ＝ f′(p)dx**。// 这里求导所需的极限没有收拢，所以 0 点不可微；同一支小箭头交给 dx、dy 两把尺子时，也找不到一个倍率能同时冒充左右两边。// 从画像上看，就是 V 字顶端长着一个尖刺；无论放大多少倍，尖角还在，始终磨不成一小段直线。

BOX[remember]: 一个好定义不只会给答案 :: 极限存在时，它把导数钉成唯一的数；左右凑不到一起时，它也明确告诉我们：这一点没有导数。// “曲线画得出来”不保证“每一点都有导数”。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: f 在 p 点的导数定义为 **f′(p) ＝ lim(h→0) [[f(p+h) - f(p)|h]]**，前提是这个极限存在。这里的结果 f′(p) 是一个数。// 让 p 走遍各点，就得到 **x ↦ f′(x)**；从 f 造出 f′ 的操作叫求导。// 下一篇会把局部线性替身写成 **dy ＝ f′(p)dx**：dx、dy 是量同一支切向箭头的两把直尺；直尺不随曲线弯，它们的读数是线性的，f′(p) 是两份读数之间的倍率。
