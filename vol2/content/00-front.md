# 给大人的话

第一册《给小学生讲微积分（上）》把 ε–N 这套语言立了起来，最后落在实数完备性的八大定理。这一册用它做两件事：**量变化有多快**，和**量面积有多大**。理论的顶点是**牛顿–莱布尼兹公式**——那两件看起来毫不相干的事，原来是一件事。

本册有意把通常的顺序倒过来一次：第三篇铺好极限后，**第四篇先假设导数可以求得，立刻把微分作为局部线性函数交到孩子手里；第五篇先看它能怎样以直代曲、估数、解方程；第六篇才回头讲导数怎样由极限造出来。**先看工具为什么值得学，再学怎样制造它。最后第十二篇带着全部工具出门——瞬时速度、落体、刹车距离，让孩子亲眼看看这套课程在真实世界里值多少钱。

沿用第一册的一切：妹妹出招、姐姐接招；四种盒子（蓝色**必须记住**、绿色**关键的一步**、橙色**留给姐姐妹妹和习题**、灰色**长大以后的写法**）；分数上下排；每篇末尾有「长大以后的写法」。

## 这一册为什么只用多项式和开方

不是为了迁就，是因为**这个限制正好让整册书自洽**：

BOX[key]: 全书的技术底牌 :: **对多项式，求导是纯代数；求面积才真正需要极限。**// 平均变化率 (f(x+h) − f(x)) ÷ h 展开、约掉 h 之后**仍然是一个多项式**——// 于是“让 h 趋于 0”这一步，**就是代入 0**，不需要任何一般极限定理。// 而面积必须“切成小条、加起来、越切越细”，// **那里第一册的夹逼才真正兑现。**// 两条线各自发展，到第十一篇突然合流。

**开方（√）也在**，而且它是本册最有力的收尾：x² 底下的面积**能**用 1²+2²+…+n² 硬加出来；√x 底下的面积**加不出来**（没有 √1+√2+… 的简单公式）。可牛顿–莱布尼兹一来，只要找一个函数 F，使 **F′(x) ＝ √x** 就行。**这条公式的价值不是漂亮，是"直接加做不到的事，它绕过去了"。**

不讲三角函数、指数、对数——它们都会打断上面那条底牌。

## 记号

TABLE:
| 做的事 | 为什么 |
| **先叫机器，再改口叫函数** | 第一册加餐已埋下“机器”这个比喻。**第一篇**用它把概念讲清楚，并在第三节末尾给出两个正式名字：**函数**和**函数图像**。**第二到第九篇**写成“**机器（函数）**”，让孩子把两个词认成同一样东西。**第十篇起一律叫函数**，“机器”退场。老虎机那样时常故障、会变卦的叫**破机器（不是函数）**，本书不研究 |
| x × x 写作 x^2^，读作"x 的平方" | 就是正方形面积；x^3^ 就是正方体体积 |
| 分数一律**上下排** | 分子在上、横线居中、分母在下 |
| 不用 ∫ 和 Σ | 正文一律说"把它们全加起来"；这两个记号只在「长大以后的写法」里露面 |
| **求导：f → f′；导数：f′(x)** | 求导是对整台函数做的操作，得到的新函数记作 f′；投进一个 x，吐出的 **f′(x)** 才是 f 在这一点的**导数**——一个数 |
| **微分：dx → dy ＝ f′(x)dx** | 先写 y ＝ f(x)，再站定 x：投进一小段挪动 dx，线性小函数吐出 dy。正文用这个输入—输出式，不用分数式 |
| **数字挨着 x，乘号省略**：2x^2^ 就是 2 × x^2^ | 课本与简易方程的写法；纯数字相乘（3.01 × 3.01）和字母乘字母（x × x）仍写 × |
| 四个词分工：平均变化率／导数／求导／微分 | 平均变化率管一整段；**导数 f′(x) 是一点上的数**；求导把 f 变成 f′；**微分是 dx → dy 的局部线性函数**。第四篇会把四件事一次说清。标准书上管"平均变化率"叫**差商** |
| ε 管出口、δ 管入口 | 第三篇会把这两个字母的分工说死 |
