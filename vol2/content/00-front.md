# 给大人的话

第一册《给小学生讲微积分（上）》把 ε–N 这套语言立了起来，最后落在实数完备性的八大定理。这一册用它做两件事：**量变化有多快**，以及**量面积和体积有多大**。理论的顶点是**牛顿–莱布尼兹公式**——变化与面积这两件看起来毫不相干的事，原来是一件事；体积则让同一种切片求和多走一维。

第三篇铺好函数极限后，第四篇立刻用它定义导数：先钉住一点 p，从邻近小段的平均变化率读出这一点的数 f′(p)，再让站脚点沿全路走，收成坡度地图 **x → f′(x)**。第五、六篇暂借几份尚未推导的导数值，把它们做成微分这台局部线性函数，用来以直代曲、估数、解方程；第七篇再集中研究怎样求导，并还清误差的证明。这样既不让微分跑到导数定义前面，又让孩子在学习一整套算法之前先看见工具为什么值得学。最后第十三篇带着全部工具出门——瞬时速度、落体、刹车距离。

沿用第一册的一切：妹妹出招、姐姐接招；四种盒子（蓝色**必须记住**、绿色**关键的一步**、橙色**留给姐姐妹妹和习题**、灰色**长大以后的写法**）；分数上下排；每篇末尾有「长大以后的写法」。

## 这一册为什么只用多项式和开方

不是为了迁就，是因为**这个限制正好让整册书自洽**：

BOX[key]: 全书的技术底牌 :: **对多项式，求导是纯代数；求面积才真正需要极限。**// 平均变化率 [[f(x+h) - f(x)|h]] 展开、约掉 h 之后**仍然是一个多项式**——// 于是“让 h 趋于 0”这一步，**就是代入 0**，不需要任何一般极限定理。// 而面积必须“切成小条、加起来、越切越细”，// **那里第一册的夹逼才真正兑现。**// 两条线各自发展，到第十二篇突然合流。

**开方（√）也在**，而且它是本册最有力的收尾：x² 底下的面积**能**用 1²+2²+…+n² 硬加出来；√x 底下的面积**加不出来**（没有 √1+√2+… 的简单公式）。可牛顿–莱布尼兹一来，只要找一个函数 F，使 **F′(x) ＝ √x** 就行。**这条公式的价值不是漂亮，是"直接加做不到的事，它绕过去了"。**

不讲三角函数、指数、对数——它们都会打断上面那条底牌。

## 记号

TABLE:
| 做的事 | 为什么 |
| **先叫机器，再改口叫函数** | 第一册加餐已埋下“机器”这个比喻。**第一篇**用它把概念讲清楚，并在第三节末尾给出两个正式名字：**函数**和**函数图像**。**第二到第十篇**写成“**机器（函数）**”，让孩子把两个词认成同一样东西。**第十一篇起一律叫函数**，“机器”退场。老虎机那样时常故障、会变卦的叫**破机器（不是函数）**，本书不研究 |
| x × x 写作 x^2^，读作"x 的平方" | 就是正方形面积；x^3^ 就是正方体体积 |
| 分数一律**上下排** | 分子在上、横线居中、分母在下 |
| 不用 ∫ 和 Σ | 正文一律说"把它们全加起来"；这两个记号只在「长大以后的写法」里露面 |
| **整张坡度地图：x → f′(x)** | 对 f 求导数，记作 **f → f′**；让 x 沿整条曲线走，f′ 就逐点报出导数。走到一点 p，地图在这里标的数是 f′(p) |
| **钉在 p 点的微分：dy ＝ f′(p)dx** | p 已经站定；同一支切向小箭头交给 dx、dy 两把直尺。直尺不随曲线弯，读数按固定倍率 f′(p) 变化——数学上说，它们是线性的。第五篇以这个式子为主；分数式只在说明课本常见记号时短暂出现 |
| **数字挨着 x，乘号省略**：2x^2^ 就是 2 × x^2^ | 课本与简易方程的写法；纯数字相乘（3.01 × 3.01）和字母乘字母（x × x）仍写 × |
| 从平均变化率走到微分 | 对 f 求导数，得到整张坡度地图 f′；走到 p 读出 f′(p)；把 p 钉住以后，给函数做一次“直尺改造”，就在这里得到一把线性的局部直尺，记作 dy；同一支箭头上的读数满足 **dy ＝ f′(p)dx**。第五篇会沿着这条路走一遍。标准书上管“平均变化率”叫**差商** |
| 从一把直尺走到两个入口 | p 沿路移动时，微分直尺 df~p~ 会换刻度；给整排直尺再做一次这样的改造，得到 d^2^f。它有“搬直尺”和“量箭头”两个入口；**(dx)^2^** 表示两份 dx 各读一个入口，再把读数相乘。第十篇先见传统记号，第十一篇再拆开它 |
| ε 管出口、δ 管入口 | 第三篇会把这两个字母的分工说死 |
