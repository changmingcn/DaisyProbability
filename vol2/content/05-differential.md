# 第五篇　微分：先把线性函数用起来

CENTER: 先在弯曲的变化里看见那块成正比的，再把它做成一台只管附近的线性函数

第四篇已经用极限钉住导数：f′(p) 是原函数走到 p 点时，变化有多快的那个数。可一个数怎样拿来替代一段弯曲的变化？先别急着背定义。我们回到一块看得见、算得清的正方形。

## 一、先看见那块成正比的

正方形边长是 3。现在让边长挪一小段，暂时把这段挪动叫作 **dx**。新边长就是 3 ＋ dx，面积真正增加了：

CENTER: **(3＋dx)^2^ − 3^2^ ＝ 6dx ＋ (dx)^2^**

右边明明白白分成两块：**6dx**，再加上一个小角 **(dx)^2^**。

FIG: fig-35-square-differential.png | 边长从 3 增加 dx，新增面积正好分成两条绿色窄边和一个橙色小角。两条窄边合起来是 6dx，跟 dx 成正比；右上角是 (dx)^2^，dx 越短，它缩得越快。

TABLE:
| 边长挪动 dx | 面积真变化 | 第一块 6dx | 小角 (dx)^2^ |
| 0.1 | 0.61 | 0.6 | 0.01 |
| 0.01 | 0.0601 | 0.06 | 0.0001 |
| 0.001 | 0.006001 | 0.006 | 0.000001 |

第一块有一种特别老实的脾气：dx 变成 2 倍，它也正好变成 2 倍；dx 缩成十分之一，它也正好缩成十分之一。**它和 dx 成正比。**小角却缩得更快：dx 缩成十分之一，它缩成百分之一。

那个倍率 6 不是碰巧冒出来的。第四篇已经算过，平方函数在 p ＝ 3 点的导数正是 **f′(3) ＝ 6**。所以第一块也可以写成：

CENTER: **f′(3)dx**

BOX[key]: 先抓住这个画面 :: 原函数的变化是弯的，不会处处老老实实成正比。// 可在 p 附近，它的变化里有一块最显眼的主干：**f′(p)dx**。// 这一块跟 dx 成正比；剩下的是弯曲留下的零头。// 对正方形，这不是猜想：精确的变化已经展开成 **6dx ＋ (dx)^2^**。

## 二、把第一块做成一台机器

现在换回一般的函数 f。选定一个站脚点 p，第四篇已经给出这里的导数 f′(p)。把 p 固定下来，把 f′(p) 当作一个固定倍率：

BOX[remember]: 微分 :: **投进 dx，吐出 dy ＝ f′(p)dx。**// // 这台 **dx → dy ＝ f′(p)dx** 的线性函数就叫微分。// p 固定不动，dx 才是它的输入；dx 变几倍，dy 就跟着变几倍。// 它不去模仿整条曲线，只拿成正比的变化，替代原函数在 p 附近的变化规律。

这里有一句很要紧：**微分本身不是“差不多”。**对这台线性函数来说，投进 dx，吐出 f′(p)dx，是一笔精确的账。说“差不多”的地方，是我们拿它的输出 dy 去估原函数的真变化。

刚才的正方形正好演示了一次。站在 p ＝ 3，投进 dx ＝ 0.01：

- **微分的输出**：dy ＝ 6 × 0.01 ＝ **0.06**
- **原函数的真变化**：0.0601
- **两者之间的零头**：0.0001

微分不是把小角说成不存在；它先抓住那块和 dx 成正比的主干，把弯曲的小角留作零头。

## 三、倍率从哪里来

微分手里的固定倍率 f′(p)，是从整张坡度地图上取下来的。对原函数求导，得到：

CENTER: **f → f′**

让 x 沿全路走，**x → f′(x)** 把每一点的导数都记下来。真走到 p，就像用图钉把站脚点钉住，只抄下这里的 f′(p)，架起微分直尺 **dx → dy ＝ f′(p)dx**。

我们先借几张还没有推导的地图：

TABLE:
| 原来的函数 f | 整张坡度地图 x → f′(x) | 走到一点读出的导数 |
| f(x) ＝ 5 | f′(x) ＝ 0 | 比如 f′(3) ＝ 0 |
| f(x) ＝ x | f′(x) ＝ 1 | 比如 f′(3) ＝ 1 |
| f(x) ＝ x^2^ | f′(x) ＝ 2x | 比如 f′(3) ＝ 6 |
| f(x) ＝ x^3^ | f′(x) ＝ 3x^2^ | 比如 f′(2) ＝ 12 |
| f(x) ＝ √x | f′(x) ＝ [[1|2\sqrt{x}]]（x ＞ 0） | 比如 f′(49) ＝ [[1|14]] |

BOX[key]: 地图和直尺，手里各干一件事 :: **x → f′(x)** 是铺满全路的坡度地图：x 走到哪里，地图就报出那里的导数。// **dx → dy ＝ f′(p)dx** 是钉在 p 点的局部直尺：p 不再走，只有 dx 在附近挪动。// 换到下一处，就拔起图钉，回地图读出新倍率，再架一把新的直尺。

BOX[dialog]: 妹妹不肯白借 :: **妹妹：**“导数的定义我懂了，可这些地图还没算给我看。”// **姐姐：**“不用白信。第七篇会从第四篇的定义出发，算出前四行；开方那一行到第十二篇第六节也会当场算出来。// 眼下我们只借答案，先看看这把直尺值不值得造。”

## 四、画出来看：微分是图上的哪一段

FIG: fig-31-tangent-pieces.png | 左：把 p 钉住，投进 dx，顺切线直尺升起 dy——这台 dx → dy 的线性函数就是微分；爬曲线得到的真变化还多一个零头。右：沿坡度地图走，每到一处换一把局部直尺；许多小直线接起来，切得越细贴得越紧。

先看左图。站在 p 这一点，往右投进一小段 dx。要知道输出真变了多少，得沿曲线爬到新的点。微分走的是直路：**顺着钉在 p 的切线直尺走。**横着走 dx，竖着就升 **dy ＝ f′(p)dx**。曲线的真变化和 dy 之间，还隔着一条弯曲留下的小缝。

再看右图。走到每一个点，都按那一点的导数重新支一小段直线；许许多多小直线连起来，就能冒充整条曲线。段切得越细，折线就贴得越紧。

BOX[key]: 走到一点，就换一把直尺 :: 原函数一路弯过去；每一把微分都只在自己的站脚点附近走直线。// 走到 p，读出 f′(p)，按 **dx → dy ＝ f′(p)dx** 支起一小段；走到下一点，拔起图钉，换一个倍率，再支下一段。// **整张地图管全路；每把微分直尺只管一个站脚点附近。**

## 五、先拿来用，再把话说严

正方形的例子已经把直觉交到了手里：**真变化可以拆成成正比的主干和弯曲的零头。**图也让人看见，dx 越短，切线直尺越贴近曲线。接下来按数学里很自然的次序走：

BOX[key]: 接下来三步 :: **先看直觉：**本篇的正方形和图，先让微分露出样子。// **再看用处：**第六篇先拿这把直尺估开方、解方程，让它证明自己值得学。// **最后说严：**第六篇会证明别的陡度都不够像；第七篇第三节再从导数定义出发，证明正确的微分确实把零头压得比 dx 小一档。

BOX[remember]: 现在借着的那句话 :: 对平方函数，零头是 (dx)^2^，已经亲手算清。对一般函数，我们暂时借用一句：**只要 f′(p) 存在，真变化减去 dy 的零头，除以 dx 会奔向 0。**// 下一篇先靠它做事；第七篇第三节正式还账。// 所以这里不是把图当证明，而是先让直觉和用途走在证明前面。

BOX[remember]: h 走在前面，dx 接着上场 :: 第四篇让 **h** 进入平均变化率，再让它奔向 0，钉住一点上的导数 f′(p)。// f′(p) 已经知道以后，轮到 **dx** 投进微分，换出 dy。// h 是用来造导数的试探步；dx 是微分真正接收的输入。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 让 x 沿全路移动，各点导数组成坡度地图 **x ↦ f′(x)**；选定基点 p 后，p 固定，微分是线性函数 **dx → dy ＝ f′(p)dx**。// 微分 dy 是局部线性替身给出的变化，不必等于原函数的真变化 f(p＋dx)−f(p)；可微真正保证的是：两者之差除以 dx 奔向 0。// 本篇先从平方函数的精确拆分看见这件事，第六篇看用途与唯一性，第七篇再给一般证明。长大以后，“只管 p 附近”会说成“只管 p 的邻域”。
