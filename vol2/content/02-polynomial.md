# 第二篇　这一册用哪种机器

CENTER: 好机器（函数）有的是。这一册只挑两种：多项式，和开方

上一篇说清了什么才算机器。可**好机器（函数）多得数不过来**，一本书装不下。

这一篇把这一册要用的机器**挑出来、说准**：一种是**多项式**，另一种是它的反面——**开方**。挑得这么窄不是偷懒，恰恰相反：**正因为窄，后面才占得到便宜。**

## 一、多项式：只用加法和乘法造出来的好机器

先看几台：

- 投进 x，吐出 **x ＋ 3**。
- 投进 x，吐出 **x × x**，也就是上一篇见过的 **x^2^**。
- 投进 x，吐出 **x × x × x**，写作 **x^3^**，念"x 的立方"，就是棱长为 x 的正方体的体积。
- 投进 x，吐出 **2x^2^ ＋ 5x − 1**。

它们有个共同点：**造的时候，只动了加法和乘法**。

这样造出来的好机器（函数），有个名字叫**多项式**。**名字不重要，造法很重要**——这一册后面占的所有便宜，都是这个造法给的。所以得把造法说准：

BOX[remember]: 多项式：把造法说准 :: 手里只有两样**原料**：// **投进来的那个 x**，和**一些数**（3、5、−1、[[1/2]] 都行）。// 只准动两种**手**：**加**和**乘**。// 而且只能动**有限次**——做完就得停手。// // 这样造出来的好机器（函数），就叫**多项式**。

BOX[key]: 三个容易含糊的地方 :: **一、减法算不算？**算。**减 3 就是加 −3**——减法不是新的手。// **二、除法呢？除以一个数**算（除以 2 就是乘 [[1/2]]）；// **除以 x 不算**——那是第三种手，多项式不准动。// **三、为什么非要说"有限次"？**因为第一册整本书都在讲这件事：// **没完没了地加下去，是做不完的。**做不完，机器就造不出来。

拿几台机器对着定义验一验：

TABLE:
| 这台机器 | 是多项式吗 | 为什么 |
| x ＋ 3 | 是 | 一次加法 |
| 2x^2^ ＋ 5x − 1 | 是 | 减 1 就是加 −1 |
| 5（投什么都吐 5） | 是 | 光用原料，一次手也不用动 |
| x × (x ＋ 2) | 是 | 一次加法、一次乘法 |
| √x | 不是 | 开方不是加、也不是乘——准动的两种手里没有它 |
| 1 ÷ x | 不是 | 除以 x 也不是——上面盒子里刚点过它的名 |
| 1 ＋ x ＋ x^2^ ＋ x^3^ ＋ …… | 不是 | 动手没完没了，停不下来 |

BOX[remember]: 这一册为什么死盯着多项式 :: 因为**"只用加和乘"这件事，后面会一次次替我们干活**：// 第四篇：求导变成纯代数，一约一代就完事；// 第三篇：证"多项式处处连续"，靠的也是它；// 第九篇：把面积的误差压住，靠的还是它。// **三处用的是同一条好脾气。**// 换成别的机器，每一处都要另想办法。

## 二、反过来的机器：开方

正方形的边长是 x，面积就是 x^2^。**反过来问呢**——已经知道面积是多少，边长是多少？

这台"反过来的机器"（它也是一个函数）也有名字：**开方**，写作 **√x**，念"根号 x"。

- 投进 9，吐出 **3**（因为 3 × 3 等于 9）。
- 投进 2，吐出 **√2** ——第一册第三篇一位一位算过它，1.41421…

FIG: fig-09-square-and-root.png | 两条曲线沿着那条斜线互为镜像：平方投 1.5 出 2.25，开方投 2.25 出 1.5。

可**反过来这件事，差点就办不成**：

BOX[key]: 反过来的时候，诺言差点守不住 :: 面积 9 的正方形，边长是 3。可**(−3) × (−3) 也等于 9**。// 那"投进 9"该吐 3 还是 −3？// **两个都吐，就变卦了**——它就不是好机器（函数）了。// // 数学家的办法很干脆：**说好只吐正的那个。**// **√9 就是 3，不是 −3。**这不是算漏了，是**为了守住诺言，特意挑了一个**。// （边长本来也不能是负数，挑正的正合适。）// // 上一篇 B4 让你把圆横着切一半，也是这个动作：// **反过来的机器，常常得先挑一半，才当得成机器。**

BOX[remember]: 开方不是多项式 :: 造 √x 用不了"只加和乘"这一招——**它是反过来才得到的**。// 所以这一册里它是**唯一的例外**，我们特意留着它。// 为什么留？因为到第九篇你会看到：// **它是牛顿–莱布尼兹公式最有说服力的一个例子**——// 那块地**加不出来**，可公式两行就算出来了。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 只用加法和乘法造出来的函数叫**多项式函数**，一般写作 f(x) ＝ c~n~x^n^ ＋ … ＋ c~1~x ＋ c~0~，那些 c 叫**系数**，最高的那个次数叫**次数**。第一节说的"有限次"，正式的说法就是"**只有有限多项**"——真让它没完没了地加下去，得到的东西叫**幂级数**，那是大学的内容。// √x 正式写作 x 的二分之一次方；这一册不用这种写法，因为它需要分数指数。// √x 只对 x ≥ 0 有定义——负数开不出平方根，要等到学复数才有说法。// 第二节**只挑正的那个**，正式名字叫**算术平方根**；方程 x^2^ ＝ 9 有两个解（3 和 −3），可**函数 √ 只吐一个**。**"方程有两个解"和"函数只能给一个答案"，这两件事不矛盾**——很多人一辈子没把它们分清楚。
