# 第七篇　形状：再求一次导

CENTER: 上一篇那条推论，这一回用在 **f′** 自己身上

## 一、对 f′ 再求一次导

第四篇第三节给 f′ 报过户口：对 f 求导得到 f′，而 f′ 本身仍是一台函数——投进 x，吐出 f 在 x 点的**导数 f′(x)**。

既然是机器，**它当然也能再求一次导**。

BOX[remember]: 二阶导数 :: 对 f′ 再求导，得到 **f″**；把 x 投进去，数 **f″(x)** 就叫 f 在 x 点的**二阶导数**，念作“f 两撇 x”。// 求法一点也不新鲜：**把 f 求两次导。**// // 例：f(x) ＝ x^3^ → f′(x) ＝ 3x^2^ → **f″(x) ＝ 6x**。// // f′(x) 是这一点的一阶导数，f″(x) 是这一点的二阶导数；f′、f″ 则分别是求一遍、求两遍导所得的函数。

BOX[task]: 留给姐姐 :: 求两次导，写出 f″：// （1）x^4^　（2）x^2^ − 4x　（3）2x^3^ ＋ 5x　（4）7（一个常数）// （5）猜一猜：x^5^ 的二阶导数 f″(x) 是什么？

## 二、f″ 说的是什么：陡度在涨还是在跌

f′ 说的是"**走得多快**"。那 f″ 说的就是"**走得多快这件事本身，变得多快**"。

**上一篇的推论一，现在换一台机器（函数）再念一遍**——

BOX[key]: 同一条推论，用在 f′ 身上 :: 第六篇第六节的推论一说：**一台机器的 f′ 处处是正的，这台机器就在涨。**// // 现在把"这台机器"换成 **f′**：// **f″ 是正的 ⇒ f′ 在涨 ⇒ 陡度越走越大。**// **f″ 是负的 ⇒ f′ 在跌 ⇒ 陡度越走越小。**// // 一条推论，**换一台机器再念一遍**，就成了一条新结论。// 这一篇整篇都是这一句话的展开。

坐车打个比方：**f′ 是仪表盘上的速度，f″ 就是"正在加速还是正在减速"。**

BOX[remember]: 别把两件事搞混 :: **涨还是跌，看 f′**：机器是往上走还是往下走。// **陡度在变大还是变小，看 f″**。// // 这两件事**互不管辖**。跌着的机器可以越跌越慢（f′ 是负的、f″ 是正的），// 涨着的机器也可以越涨越慢（f′ 是正的、f″ 是负的）。

## 四、拐点：碗和拱换班的地方

BOX[remember]: 拐点 :: 画像从碗形变成拱形（或者反过来）的那一点，叫**拐点**。// // 在那儿 **f″ 要变号**——所以先去解方程 **f″(x) ＝ 0**，找出所有候选。// // 例：f(x) ＝ x^3^，f″(x) ＝ 6x。它在 x ＝ 0 处变号：// 左边 f″ 是负的（拱形），右边是正的（碗形）。**x ＝ 0 就是拐点。**

FIG: fig-19-f-fp-fpp.png | 三张图对齐着看：上面是 f，中间是 f′，下面是 f″。f′ 穿过横轴的地方，正是 f 的顶和谷；f″ 穿过横轴的地方，正是 f 的拐点。

## 五、二阶判别法：是顶还是谷，一算就知道

第五篇找最值的第三步是“**看看两边是涨还是跌**”。那一步有点麻烦。**二阶导数能替它干。**

BOX[key]: 二阶判别法 :: 设 **f′(x) ＝ 0**——也就是找到了一个"拐弯的地方"。// // **f″(x) 是正的 ⇒ 碗形 ⇒ 这是谷**（附近最低）。// **f″(x) 是负的 ⇒ 拱形 ⇒ 这是顶**（附近最高）。// **f″(x) 也是 0 ⇒ 说不准**，还得老老实实回去看两边。

BOX[remember]: 为什么"说不准" :: 三台机器（函数），在 x ＝ 0 处 f′ 和 f″ **全都是 0**，形状却各不相同：// // **x^4^**：是谷。（投别的数进去，吐出来的都比 0 大。）// **−x^4^**：是顶。// **x^3^**：**两样都不是**——就是第五篇第四节那台"歇了口气又接着往上爬"的机器。// // 同一套数字，三种答案。**这就是"说不准"三个字的准确意思。**

BOX[remember]: 第五篇 A4 现在能答满了 :: 第五篇 A4 问的是：说出 **f′ 是 0** 的三种可能情况。// 当时只能靠比划，现在你有三台具体的机器：// **x^4^ 是谷、−x^4^ 是顶、x^3^ 两样都不是。**// // 而且你还多知道了一件事：**怎么分辨**——// 先看 f″；只有 f″ 也是 0 的时候，才需要回去看两边。

## 六、直观翻车：f″ 是 0，不一定是拐点

妹妹一定会顺着往下问：**解出 f″(x) ＝ 0，那一点就是拐点吗？**

**不是。**这是本篇要抓的那条刺。

BOX[key]: 反例：x^4^ :: f(x) ＝ x^4^。f′(x) ＝ 4x^3^，**f″(x) ＝ 12x^2^**。// // 在 x ＝ 0 处，f″(0) ＝ 0——**确实是 0**。// 可是 12x^2^ **永远不是负的**：0 的左边、右边，f″ 都是正的。// **碗形一路还是碗形，根本没有换班。**// // 所以：**f″ 是 0 只是候选，必须再看两边有没有真的变号。**

BOX[remember]: 又是同一个教训，这已经第三次了 :: **第四篇**：(fg)′ 不是 f′g′。// **第五篇**：f′ 是 0，不一定是顶也不一定是谷。// **本篇**：f″ 是 0，不一定是拐点。// // **"解出方程"和"得到结论"之间，永远还隔着一步验证。**// 数学里"看起来该这样"的地方，**都要拿一个具体例子试一下**。

## 七、真题：把 x^3^ − 3x 的形状描出来

取 **f(x) ＝ x^3^ − 3x**——**第五篇第三节留给姐姐的第（3）题，问的就是它**。当时只让你找出两个拐弯的地方、判断哪个是顶哪个是谷。现在工具齐了，我们把**整张画像**描出来。

**第一步，求导，找拐弯的地方。**

CENTER: **f′(x) ＝ 3x^2^ − 3 ＝ 3 × (x^2^ − 1)**

让它等于 0，解得 **x ＝ −1** 和 **x ＝ 1**。

**第二步，再求一次导，拿 f″ 判断是顶还是谷。**

CENTER: **f″(x) ＝ 6x**

- **f″(−1) ＝ −6**，是负的 → 拱形 → **x ＝ −1 是顶**，那里的高是 f(−1) ＝ **2**。
- **f″(1) ＝ 6**，是正的 → 碗形 → **x ＝ 1 是谷**，那里的高是 f(1) ＝ **−2**。

**第三步，找拐点。**解 **f″(x) ＝ 0** 得 **x ＝ 0**。它左边 f″ 是负的、右边是正的——**真的变号了**，所以 x ＝ 0 是拐点，高是 f(0) ＝ **0**。

**第四步，摆一张表，把每一段的脾气写清楚。**

TABLE:
| 这一段 | f′ 的符号 | f″ 的符号 | 画像长什么样 |
| x 比 −1 小 | 正 | 负 | 涨着的拱（涨得越来越慢） |
| x 正好是 −1 | 0 | 负 | **顶**，高是 2 |
| −1 到 0 之间 | 负 | 负 | 跌着的拱（越跌越猛） |
| x 正好是 0 | 负 | 0 | **拐点**，高是 0 |
| 0 到 1 之间 | 负 | 正 | 跌着的碗（跌得越来越慢） |
| x 正好是 1 | 0 | 正 | **谷**，高是 −2 |
| x 比 1 大 | 正 | 正 | 涨着的碗（越涨越猛） |

BOX[remember]: 两张名单就够了 :: 一台机器的画像长什么样，// **f′ 的正负管涨跌，f″ 的正负管碗拱**——// 两个符号一配，形状就定下来了。// // 说到底是同一个直觉用了两层：// **f′ 是各点切线的陡度名单，f″ 是这张名单自己的名单。**// 看的从来不是哪一个数，**是整条名单的正负。**

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 二阶导数记作 **f″(x)**；再往上还有 f‴(x)、f 在 x 点的 n 阶导数。最稳当的读法仍然分两步：**先对整台 f 求两次导，得到函数 f″；再把 x 投进去，得到这个点的数 f″(x)。**// 如果把 f′ 当作一台新函数 z ＝ f′(x)，那么它在 x 点的微分是 **dx → dz ＝ f″(x)dx**。这仍是一台线性函数：输入 dx，输出陡度的线性变化 dz；二阶导数 f″(x) 只是它的倍率。// 碗形正式叫**凸函数**（下凸，convex），拱形叫**凹函数**（上凸，concave）——**中文书上“凹”“凸”两个字的用法并不统一**，看到时先确认它的定义再用，这是常见的坑。// 拐点叫 **inflection point**；第五节那条叫**二阶导数判别法**。// 用二阶导数判断形状只是开头：把更高阶的导数都用上，就得到**泰勒公式**——它能用多项式去逼近一个一般的函数。**那正好是这一册的反方向：这一册只做多项式，泰勒公式让别的函数也变成多项式。**
