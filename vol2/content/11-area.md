# 第十一篇　面积和体积有多大

CENTER: 换一条完全不相干的路：切开、加起来，再用第一册的夹逼收口

第四到第十篇沿着“走得多快”那条路，定义导数、造微分、求导、判涨跌、看形状。这一篇忽然换路，讲两件**看起来毫不相干**的事：

CENTER: **一条曲线底下，那块地有多大？**

CENTER: **一座斜面围成的山，里面装了多少？**

前五节先把微分放到一旁，只用切条、求和与极限量面积。走到体积时，**第五篇那套微分直尺**会换一种样子回来：一把直尺量薄片的厚度，一张小小的“面积尺”量切面，两者合起来量体积。

## 一、老办法：数格子

在方格纸上画出函数的画像，数一数底下有多少个小格子——这就是最朴素的量面积。**第一册开篇你亲手干过**：那块弯边的地，少算法和多算法把它夹在 0.24 和 0.43 之间；格子缩小一半，夹紧成 0.2925 和 0.3875。

毛病你也早就见过：**边上那一圈格子，被曲线切成了半个半个的，数不清。**

格子画小一点会不会好些？会。**那就一直画小下去。**——第一册开篇就是在这句话跟前停住的：谁也画不完。整整一册书之后，我们回来了——**这一次，带着家伙。**

## 二、切成竖条

与其数格子，不如**切成竖条**：把从 0 到 b 这一段横着切成 n 段，每段上立一根长条。

可长条要立多高？曲线在那一小段上是变化的呀。**两个办法**：

- 每条都取**左边那头**的高 → 每条都矮了一点 → **总和比真面积小**。
- 每条都取**右边那头**的高 → 每条都高了一点 → **总和比真面积大**。

FIG: fig-06-strips.png | 左边一套全都矮了，右边一套全都高了。真面积被夹在中间。

BOX[remember]: 先给这三个量起名字 :: 想把话写成一行公式，就得先让每样东西**有个符号**。// 用 n 条算出来的**矮的那一套**总和，记作 **L~n~**；**高的那一套**记作 **U~n~**；// 我们要求的**真面积**记作 **A**。// 于是"真面积被夹在中间"写成一行就是：// **L~n~ ≤ A ≤ U~n~**

BOX[key]: 注意这个句型 :: **L~n~ ≤ A ≤ U~n~**// 如果两套都奔向同一个数，真面积就只能是那个数。// **这正是第一册第四篇的夹逼定理。**// 第一册说过它有用——**这里就是它兑现的地方。**

## 三、要先会加：1 ＋ 2 ＋ … ＋ n

要把长条加起来，先得会算 **1 ＋ 2 ＋ … ＋ n**。

FIG: fig-07-triangle-number.png | 两个一模一样的三角摆在一起，正好拼成一个长方形。

实心点摆成一个三角：第一行 1 个、第二行 2 个……第 n 行 n 个，一共就是 1 ＋ 2 ＋ … ＋ n 个。空心点也摆一个同样的三角，倒过来一扣——**正好拼成 n 行 n＋1 列的长方形**。

CENTER: **1 ＋ 2 ＋ … ＋ n ＝ [[n(n+1)|2]]**

## 四、第一块面积：直线底下

先拿最简单的函数 f(x) ＝ x 试手：从 0 到 b，它底下是个三角形，面积**应该**是 [[b^{2}|2]]（底乘高除以二）。看看切条法给不给同一个答案。

切成 n 条，每条宽 [[b|n]]。取右边那头当高，第 k 条的高就是 [[kb|n]]。所以：

CENTER: **U~n~ ＝ [[b|n]] × （[[b|n]] ＋ [[2b|n]] ＋ … ＋ [[nb|n]]）＝ [[b^{2}|n^{2}]] × （1 ＋ 2 ＋ … ＋ n）**

把第三节的公式代进去：

CENTER: **＝ [[b^{2}|n^{2}]] × [[n(n+1)|2]] ＝ [[b^{2}|2]] × （1 ＋ [[1|n]]）**

n 越大，[[1|n]] 越小（第一册第四篇例一）。所以总和奔向 **[[b^{2}|2]]**。**和三角形面积对上了。**✓

## 五、第二块面积：抛物线底下

现在来真的：f(x) ＝ x^2^ 底下，从 0 到 b。这一块**没有现成的公式可以对答案**。

同样切 n 条，第 k 条的高是 [[kb|n]] 的平方：

CENTER: **U~n~ ＝ [[b^{3}|n^{3}]] × （1^2^ ＋ 2^2^ ＋ … ＋ n^2^）**

于是我们需要**平方的和**。它也有公式：

CENTER: **1^2^ ＋ 2^2^ ＋ … ＋ n^2^ ＝ [[n(n+1)(2n+1)|6]]**

BOX[key]: 加餐：这个公式怎么来的（一层层抵消） :: 先注意一件事：**(k+1)^3^ − k^3^ ＝ 3k^2^ ＋ 3k ＋ 1**（把左边展开就看见了）。// 现在把 k ＝ 1、2、…、n 这 n 个式子**全部加起来**。// **左边**：(2^3^−1^3^) ＋ (3^3^−2^3^) ＋ … ＋ ((n+1)^3^−n^3^)// ——中间的 2^3^、3^3^…… **前一个减、后一个加，一层层全抵消了**，只剩 **(n+1)^3^ − 1**。// **右边**：3 × （平方和）＋ 3 × （1+2+…+n）＋ n。// 两边一对，再把第三节的公式代进去，解出来就是上面那条。// // **“一层层抵消”这一招记住它**——第十二篇还会再见到一次。

代进去算：

CENTER: **U~n~ ＝ [[b^{3}|n^{3}]] × [[n(n+1)(2n+1)|6]] ＝ [[b^{3}|6]] × （2 ＋ [[3|n]] ＋ [[1|n^{2}]]）**

n 越来越大时，[[3|n]] 和 [[1|n^{2}]] 都奔向 0，括号里奔向 2。所以：

BOX[remember]: 抛物线底下的面积 :: 从 0 到 b，f(x) ＝ x^2^ 底下的面积是 **[[b^{3}|3]]**。// 比如从 0 到 3，面积是 9。// **请记住这个答案**——第十二篇会用另一条完全不同的路，再算它一次。

BOX[key]: 回头望一眼那块地——妹妹赢了一半 :: 把 b ＝ 1 代进去：从 0 到 1，平方曲线底下的面积，**正好 [[1/3]]**。// 第一册开篇妹妹猜的那个数——**猜对了**。0.24 和 0.43 夹住的、0.2925 和 0.3875 夹住的，就是它。// 你要是在开篇的橙盒里写下过自己数的两个数，现在可以翻出来对账了。// 可妹妹还有第二问：“凭什么这么整齐？”这一层，**第十二篇揭底**。

## 六、从面积走到体积：切面乘厚度

长方体的体积为什么是“底面积乘高”？因为从底到顶，**每一处的水平切面都一样大**。把它横切成许多薄板，每块都是“切面面积乘一点厚度”；全部叠回去，还是原来的长方体。

斜面的山不一样：越往上切，切面越小。可是办法没有变。

给立在地面上的轴标一个位置 z。在 z 处水平切一刀，切面面积记作 Q(z)。第五篇里，dx 量横着迈出的一小步；现在沿着这根轴走，量薄层厚度的直尺便叫 dz。这一小层的体积写成：

CENTER: **dV ＝ Q(z)dz**

BOX[remember]: 面积怎样长成体积 :: 曲线下面切竖条：**一点宽度乘一段高度**，得到一小块面积。// 立体里面切薄板：**一点厚度乘一整片面积**，得到一小块体积。// 长方体的 Q(z) 不变；斜面的山里，Q(z) 会随高度改变。// **切面会变，就把每一层各算各的，再全部加起来。**

## 七、方尖塔为什么是三分之一

六年级课本里有一条规矩：**圆锥的体积，是同底同高圆柱的三分之一。**那个三分之一是哪来的？先拿不用 π 的方尖塔看清楚。

一座方底的尖塔，底是边长 b 的正方形，塔高也是 b。从尖顶往下量，深到 t 的地方水平切一刀，切面是边长 t 的正方形，面积 t^2^——越往下，切面越大。

把塔横着切成 n 层，每层厚 [[b|n]]。先用平顶薄板搭一座**包在真塔外面的台阶塔**：第 k 层的切面边长取 [[kb|n]]。把这些薄板的体积全加起来，记作 U~n~：

CENTER: **U~n~ ＝ [[b|n]] × [[b^{2}|n^{2}]] × （1^2^ ＋ 2^2^ ＋ … ＋ n^2^）**

又是平方的和。把第五节的公式代进去：

CENTER: **U~n~ ＝ [[b^{3}|6]] × （2 ＋ [[3|n]] ＋ [[1|n^{2}]]）**

n 越来越大时，它奔向 [[b^{3}|3]]。这已经强烈地告诉我们：真塔的体积应该是 [[b^{3}|3]]。可是台阶塔的面是平的，真塔的面是斜的；要把“应该”变成“一定”，还得等第九节从里面再搭一座，夹逼收口。

FIG: fig-28-pyramid.png | 把方尖塔横切成薄板：每层切面是正方形，边长跟深度走、面积跟深度的平方走——和抛物线底下切条是同一笔账。

BOX[remember]: 同一个平方和，管住地也管住山 :: 抛物线底下：第 k 条的**高度**跟 k^2^ 走。// 方尖塔里面：第 k 层的**切面面积**跟 k^2^ 走。// 所以一块弯边的地和一座斜面的山，最后都踩在 **1^2^ ＋ 2^2^ ＋ … ＋ n^2^** 上。// 不是答案碰巧一样，是切开以后，两本账的骨架本来就一样。

## 八、同一座线盘山，两种算法

现在把方尖塔换一种造法。拿一根**有粗细的软绳**，绕着一根立在地面上的轴，从山脚一圈圈盘到山顶；每一圈都紧贴着邻圈，既不留缝，也不互相压住。远看，它已经不是一根绳，而是一整座“线盘山”。

为了让每一笔都能数得一格不差，先把软绳压成**方方的横截面**，边长是 [[b|n]]；再把山搭成第七节那座 n 层台阶塔。每一层都由边长 [[b|n]] 的小立方块铺满：从尖顶往下数，第一层有 1^2^ 块，第二层有 2^2^ 块……第 n 层有 n^2^ 块。让软绳像盘线一样穿过每一小块，再接到相邻一层。

现在拿两本账簿来算这座台阶线盘山的体积。

**第一本账，顺着轴一层层数。**每个小立方块的体积是 [[b^{3}|n^{3}]]，小立方块总数是平方的和，所以：

CENTER: **V~n~ ＝ [[b^{3}|n^{3}]] × （1^2^ ＋ 2^2^ ＋ … ＋ n^2^）**

**第二本账，顺着绳一段段数。**软绳在每个小立方块里走过的一小段都长 [[b|n]]。把整根绳拉直，它的总长度记作 R~n~：

CENTER: **R~n~ ＝ [[b|n]] × （1^2^ ＋ 2^2^ ＋ … ＋ n^2^）**

软绳的横截面积是 [[b^{2}|n^{2}]]。于是“横截面积乘总长度”给出：

CENTER: **V~n~ ＝ [[b^{2}|n^{2}]] × R~n~ ＝ [[b^{3}|n^{3}]] × （1^2^ ＋ 2^2^ ＋ … ＋ n^2^）**

**两本账逐项对上了。**第一本先把同一层的小段归在一起；第二本不管它们在哪一层，只照着软绳的先后次序加。山没有换，换的只是分组。

FIG: fig-36-line-mountain.png | 同一座台阶线盘山：左边沿竖轴按层归组，右边沿一根软绳的次序归组。每个小立方块只数一次，所以两本账必然相同。

BOX[key]: 同一座山，两种真正算得出的账 :: **按层数**：一层的面积乘一层的厚度，再把各层叠起来。// **沿绳数**：软绳的横截面积乘整根绳的长度。// 两边都得到 **[[b^{3}|n^{3}]] × （1^2^ ＋ 2^2^ ＋ … ＋ n^2^）**。// 这次不只知道“最后应该一样”：同一批小立方块在两本账里一个不少、一个不重，式子也真的一样。

把格子取得越来越细，台阶山就越来越贴近斜面的真塔，V~n~ 奔向 [[b^{3}|3]]。所以线盘山不是绕开了第七节的计算；它把**同一个体积**换了一种分组来计算。

回到没有格子的局部写法。顺竖轴数薄层，写 **dV ＝ Q(z)dz**；顺软绳数小段，若绳在 s 处的横截面积是 B(s)，就写：

CENTER: **dV ＝ B(s)ds**

一定要说“有粗细的软绳”：一根只有路线、没有横截面的数学曲线，再长也装不出体积。

### 回头还第十篇那笔账：先在体积里看懂两个 2

刚才算线盘山，一层体积就是“截面积乘一小段轴长”。现在换一块更简单的楔形体，让这句话自己解释高次微分。

想象一块三角形木楔：向里的厚度固定是 2；沿地面的 x 轴从尖端往右走，走到 x 的地方，木楔的高度也正好是 x。从尖端到这里，侧面的三角形底和高都是 x，面积是 x^2^ 的一半；再乘向里的厚度 2，体积正好是：

CENTER: **V(x) ＝ x^2^**

站在 p 处横切一刀，切面是“向里长 2、向上高 p”的长方形，面积是 **S(p)＝2p**。现在沿 x 轴再切出一片厚度为 u 的薄片。它的局部体积直尺读出：

CENTER: **dV~p~(u) ＝ S(p)u ＝ 2pu**

把这把薄片直尺从 p 搬到 p＋b，仍旧切同样厚度 u。新切面高了 b，面积从 2p 增加到 **2p＋2b**；新薄片因此比旧薄片多出一个“向里长 2、向上高 b、横着厚 u”的小长方体：

CENTER: **dV~p＋b~(u) − dV~p~(u) ＝ 2bu**

FIG: fig-37-second-differential.png | 固定厚度为 2 的楔形体：把薄片从 p 搬到 p＋b，仍切同样的厚度 u；右边薄片比左边多出的那块小长方体，三条边正是 2、b、u，所以体积差是 2bu。

这里终于能看见两份 dx 各在做什么：

- 一份 dx 读 b：**把截面沿 x 轴搬了多远。**
- 另一份 dx 读 u：**正在切的薄片有多厚。**

b 和 u 不是因为“单位都是长度”才可以合在一起；它们是两支都沿 x 轴的箭头，交给的是**同一把 dx 直尺**。所以两份读数真的相乘：

CENTER: **(dx)^2^(b,u) ＝ dx(b) × dx(u) ＝ bu**

再把刚才的体积差读一遍：

CENTER: **d^2^V~p~(b,u) ＝ 2bu ＝ 2(dx)^2^(b,u)**

若把同一支箭头同时交给两个位置，两份 dx 的读数就自己乘自己，于是写成：

CENTER: **d^2^V ＝ 2(dx)^2^**

现在回头看**求微分这种处理**。第一次对体积 V 求微分，得到薄片直尺 **dV＝Sdx**；注意这里乘的是截面积 S 本身。再求一次微分，比较这把薄片直尺搬到旁边后怎样变化，这时才出现面积的微分 **dS**。这块楔子的 **S(x)＝2x**，所以：

CENTER: **dS ＝ 2dx**

x 轴的刻度均匀，dx 这把直尺本身不换刻度；变的是前面的截面积。因此：

CENTER: **d^2^V ＝ dS · dx ＝ 2dx · dx ＝ 2(dx)^2^**

BOX[key]: 两个 2，各说各的事 :: **d^2^V 上面的 2**：先对 V 求微分，得到薄片直尺；再对这把直尺随位置的变化求微分——微分这种处理做了两回。// **(dx)^2^ 上面的 2**：一份 dx 读搬动距离，一份 dx 读薄片厚度——两份读数真的相乘。// // 这里的 d 只是微分处理所用的记号。不是因为两边都叫“长度”，而是因为两个位置用的确实是同一把 x 直尺。

把木楔的外衣脱掉，就回到一般函数。**第五篇提过：微分是用一系列不同的直尺替换原来的曲线。**在 p 点有 **df~p~＝f′(p)dx**；把它搬到 p＋b，再量横向读数为 u 的同一支箭头，两把直尺的读数差是：

CENTER: **〔f′(p＋b) − f′(p)〕u**

一般函数的 f′ 还会弯，这笔差要让 b 越来越小，才会稳定成 **f″(p)bu**；这是第四篇那套取极限的办法。稳定以后，两份 dx 的位置仍然没有变，于是：

CENTER: **d^2^f ＝ f″(p)(dx)^2^**

把倍率单独写出来，就是第十篇留下的记号：

CENTER: **[[d^{2}f|(dx)^{2}]] ＝ f″(p)**

BOX[remember]: 这条分数线在读倍率 :: 它问的是：**二阶微分 d^2^f，含有多少份最基本的 (dx)^2^？**// 在只有 x 这一个方向的数轴上，答案就是 f″(p)。// 真正计算时仍走最熟悉的路：**f → f′ → f″**。

第五篇还留着一块小角。对 f(x) ＝ x^2^，同一步的横向读数若是 dx，第一微分读出 **2pdx**，第二微分把这一步同时放进两个入口，读出 **2(dx)^2^**。可是曲线的真变化是 **2pdx ＋ (dx)^2^**。所以那块小角不是整份第二微分，而是它在这一步读数的一半：

CENTER: **(dx)^2^ ＝ [[1|2]]d^2^f**

BOX[key]: 为什么要有一半 :: 从 p 走出这一步时，平方函数比起点那把直尺多出来的坡度，并不会一开始就跳到 **2dx**；它从 0 均匀长到 **2dx**，平均是 dx。// **平均多出的坡度 dx × 整步 dx ＝ (dx)^2^**，恰好是第二微分读数 **2(dx)^2^** 的一半。// 所以真变化的账是 **2pdx ＋ [[1|2]] × 2(dx)^2^ ＝ 2pdx ＋ (dx)^2^**。// 一般函数也有同样的开头，长大以后叫**泰勒公式**；这一册只把平方函数这笔账核清。

第十三篇还会让这个记号长出身体感觉。里程若是 s(t) ＝ 5t^2^，速度直尺沿路换刻度；再看这排速度直尺怎样换，得到 **d^2^s ＝ 10(dt)^2^**。于是 [[d^{2}s|(dt)^{2}]] ＝ 10——这就是加速度。

## 九、把面积和体积一起夹住

抛物线底下，右端取高得到高估，左端取高得到低估。方尖塔里面也有同样两队：用每层较大的切面搭成**外台阶塔**，用较小的切面搭成**内台阶塔**。真塔被夹在中间。

在这两个例子里，高估与低估的差都正好是：

CENTER: **U~n~ − L~n~ ＝ [[b^{3}|n]]**

n 越来越大时，这个差奔向 0；而 U~n~ 已经奔向 [[b^{3}|3]]，所以 L~n~ 也奔向同一个数。

BOX[key]: 两次夹逼，一起收口 :: 对抛物线底下的真面积 A：// **L~n~ ≤ A ≤ U~n~**// 对方尖塔的真体积 V：// **L~n~ ≤ V ≤ U~n~**// 两边都奔向 [[b^{3}|3]]，所以：// **A ＝ [[b^{3}|3]]，V ＝ [[b^{3}|3]]。**// // 方尖塔的体积正好是同底同高方柱的三分之一。圆锥的三分之一，道理相同；圆的那份要再等 π 出场。

请注意这一步和第七篇的区别：第七篇里 h 被**约掉**了，代入就行；这里 n 在分母上赖着不走，**只能靠极限**。第一册那套语言，是为这一刻准备的。

BOX[remember]: 还第一册那笔账：楼梯为什么骗得了长度，骗不了这里 :: 第一册第四篇第六节留过一个问题。那里的楼梯**越切越细、贴着对角线**，// 长度却**永远是 2**，一步也没挤向对角线的 √2。// 这一篇的长条和台阶塔，看上去也只是越来越贴，凭什么算得对？// // **差别就在这里有两队。**低估 L~n~ 从里面顶上来，高估 U~n~ 从外面压下去，两队奔向同一个数，真面积或真体积被夹死在中间，跑不掉。// 楼梯那边只有一队：2，2，2，……上面压着，下面没有人顶，一队数钉不死答案。// // 所以靠得住的从来不是**切得细**，而是：// **上下两队，奔向同一个数。**

## 十、√x 底下的面积，存不存在？

前面两块面积都算出来了。可它们算得出来，靠的是**碰巧有求和公式**：一次的用 1＋2＋…＋n，二次的用 1^2^＋2^2^＋…＋n^2^。

现在换一个函数：**√x**。照样切条、照样求和，要算下去就得知道

CENTER: **√1 ＋ √2 ＋ … ＋ √n 等于多少**

**没有这样的公式。**这条路堵死了。

于是冒出一个比"是多少"更靠前的问题：

CENTER: **√x 底下那块地的面积，到底存不存在？**

BOX[key]: 存在。而且不必知道它是多少 :: 把条数**每次加倍**（n → 2n）。// **矮的那一套只会更高**：一根粗条换成两根细条，细条各自贴得更紧，盖住的面积只增不减。// 所以 L~1~、L~2~、L~4~、L~8~…… **只涨不跌**。// 又：它们每一个都被**任何一个高估**压着，所以**有上界**。// // 只涨不跌 ＋ 有上界 ⇒ 由**第一册的③单调有界定理**，// **它一定有极限。**// 同样的话对高的那一套也成立；而两套之差奔向 0，// 所以它们奔向**同一个数**——那就是这块地的面积。**证毕。**

BOX[key]: 第一册那八条，在这里第一次真正派上用场 :: 这里用的是**第③条：单调有界定理**。请体会它的用法：// **它没有告诉我们答案是多少，只告诉我们答案存在。**// 第一册第五篇第五节说过这句话——**很多时候，“存在”就已经够用了。**// // 这不是偷懒，这是数学里极常用的一步：// **先把东西钉在那儿，给它一个名字，再另找办法去算。**// 知道面积存在，第十二篇才有资格去问：**对面积函数求导，会得到什么？**// 到那时会用另一条完全不同的路把它算出来——**答案是 [[2|3]]**。
