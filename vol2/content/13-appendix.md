# 附录 D　给大人：这本册子诚实地跳过了什么

BOX[key]: 先说三笔**还上了**的账 :: 这一册早先的版本里，有三处是**先用起来、没有证**的：// **一、**f′ 是正的就在涨（第七篇第一节）；// **二、**最高点出现在 f′ 为 0 的地方（第七篇第二节）——连**最高点凭什么存在**都没交代；// **三、**F 和 A 在每一点的导数一样就只差一个常数（第十一篇第四节）——那是当时**全册最大的一处借用**。// // **这三处现在都证了**，全靠第八篇：最值定理 → 费马引理 → 罗尔 → 中值定理 → 三条推论。// 第七篇仍旧**先用后证**，但它明写自己在赊账，并指向第八篇。// **“先当好用的感想使，回头再证”和“含糊过去”，是两回事。**

BOX[key]: 本版又新立了一条“先用后证”的明线 :: 第四篇先假设导数答案可得，造出微分；第五篇立刻用它以直代曲。这里借了两件事：// **多项式与开方的导数答案**，以及**微分留下的零头比 dx 小一档**。// 第六篇从极限造出多项式的导数，并证明零头性质；第十一篇第六节再求出开方的导数。// 所以这不是省略证明，而是把“有什么用”放在“怎样求”前面。两头都明写，账已经还清。

- **只对多项式和开方做了。**“对 x^n^ 求导得到 n × x^n−1^”这条规律，册子里只验到 x^4^ 就归纳了，**没有对一般的 n 给出证明**（要用二项式定理）。这是有意的，但请别让孩子以为验了四个就等于证明了。
- **牛顿–莱布尼兹那一篇仍旧走了多项式的捷径。**一般函数要证这条公式，得用“连续函数在闭区间上取到最大最小”（**最值定理**）。**那条定理第八篇已经真证了**，可第十一篇第三节并没有回头去用它——那个 M 仍旧是从多项式直接找出来的。**这是一条捷径，只对多项式管用**，将来学一般情形时那一步要重来一遍。第四节加餐里“拼回去”的零头账，用的也是同一个 M、同一条捷径。
- **第八篇把“≤ 能穿过取极限”从数列搬到了函数上，没有重写证明。**第一册第四篇例四证的是**一队数**；第八篇第三节（费马引理）用的是**函数的极限**（h 奔向 0）。正文只说了“ε 那一步一个字都不用改”——**这句话是真的，但册子里确实没有把它写出来。**
- **碗形和切线全躺在画像下面——正方向证了，反方向还欠着。****f″ 处处是正的，切线就全在画像下面**，第九篇第三节已经证出（零件来自第八篇的推论一）；**反方向**（切线全在下面，凭什么就是碗形）仍旧只有图和直觉。
- **二阶判别法那一步，偷偷用掉了 f″ 连续。**第九篇第五节从 **f″ 在这一点是正的** 推出 **这一带是碗形**，中间需要 f″ 在附近也是正的。对多项式成立（f″ 还是多项式，而多项式连续，第三篇证过），**对一般的函数要另外加条件**——这一步和第七篇当初那个洞是同一种毛病，只是这一次它只差一句话。
- **"平均变化率"这个叫法。**（f(x+h) − f(x)）÷ h 在数学分析里的标准名字是**差商**；这一册改叫**平均变化率**（中学课本的叫法），因为它自带解释、不像行话。两者是同一个东西。
- **极限的乘法法则用了但没证。**第六篇证乘积法则时，用到“两个都有极限的东西相乘，极限就是极限相乘”；第六篇第六节末那句“可微的都连着”，用的也是它。第一册只在第四篇例三末尾提过这条（和加法法则同属四则运算法则，证法一样），**两册都没有写出来**。
- **面积只做了曲线在横线上方、从左到右的情形。**没有讲负面积、没有讲曲线跑到横线下面怎么办。
- **没有讲：商法则、链式法则、换元、分部积分、不定积分的记号。**多项式用不上，加进来只会稀释主线。
- **第十篇的低估比高估正好少最后一条，只在递增的情形成立。**册子里画的都是递增的例子，但没有明说这个前提——第十篇 C2 就是在提醒这件事。
- **牛顿法只对第一册那个函数证了收敛。**第五篇第六节的**滑下去**，对 x^2^ − 2、从 x~1~ ＝ 1 出发，收敛性是第一册第五篇第五节用③证的；**换一个函数、换一个出发点，册子里没有给任何保证**——第五篇第七节那条平切线的反例，就是**保证不存在**的证据。
- **金字塔加餐只搭了半个架子。**第十篇第五节的加餐把方尖塔切成平顶薄板、算出三分之一，可**斜面夹在高低两套薄板之间**的那一半（低估那一套、以及夹逼收口）只交代了一句话，没有算。
- **第十二篇的每个函数都是“给定的”。**落体的 5、抛球的 10、刹车的“每秒慢 10”，全是量出来或设出来的**输入**；数学证的只是“如果函数是它，结论必然如此”。正文第六节已经明说，这里再记一笔。
