# 第七篇　怎样求导：把坡度地图算出来

CENTER: 第四篇已经定义导数；这一篇把定义变成可反复使用的算法

第四篇用平均变化率的极限钉住了 f′(p)，第五、六篇又把几份借来的导数值做成微分、切线和估算工具。现在来还计算上的账：怎样从 f 出发，把整张坡度地图 **x → f′(x)** 真正算出来？

仍从第四篇的定义出发。只是这一次不把站脚点固定成某个具体的 p，而让 x 留在式子里，沿全路移动。这样一次运算，就能把每一点的导数一起收进答案。

## 一、第一个惊喜：约得掉 h

现在动手算。取最简单的 f(x) ＝ x^2^：

CENTER: **f(x+h) − f(x) ＝ (x+h) × (x+h) − x × x ＝ x^2^ ＋ 2xh ＋ h^2^ − x^2^ ＝ 2xh ＋ h^2^**

除以 h：

CENTER: **[[2xh + h^{2}|h]] ＝ 2x ＋ h**

**h 约掉了。**

BOX[key]: 这就是那个惊喜 :: 约掉 h 之后剩下的 **2x ＋ h**，是一个**规规矩矩的多项式**——// 里面再也没有“除以 h”这种危险动作。// 于是“让 h 趋于 0”这一步，**就是把 h 换成 0**：// **f′(x) ＝ 2x。**// // 一般的机器（函数）可没这么好命，得老老实实按极限定义处理。// **多项式把微积分的一半，变成了代数。**

再算 x^3^：

CENTER: **(x+h) × (x+h) × (x+h) − x^3^ ＝ 3x^2^h ＋ 3xh^2^ ＋ h^3^**

除以 h 得 **3x^2^ ＋ 3xh ＋ h^2^**，把 h 换成 0，得 **f′(x) ＝ 3x^2^**。

TABLE:
| 机器 | 平均变化率（约掉 h 以后） | 把 h 换成 0 |
| x | 1 | **1** |
| x^2^ | 2x ＋ h | **2x** |
| x^3^ | 3x^2^ ＋ 3xh ＋ h^2^ | **3x^2^** |
| x^4^ | 4x^3^ ＋ 6x^2^h ＋ 4xh^2^ ＋ h^3^ | **4x^3^** |

BOX[key]: 这一次，整张坡度地图真算出来了 :: 看表的右列：**1、2x、3x^2^、4x^3^——它们大多还带着 x**，因为 x 要沿全路走。// 从原来的函数 f 出发，算出这张新表 f′，就是求导 **f → f′**。// 走到一个具体的点 p，把 p 投进 f′，才读出 f 在这里的导数值 **f′(p)**。比如第四篇那辆车走到第 3 秒，速度表就在整张速度地图上读出 12。// 第五、六篇用的是借来的地图；这一节把它逐点算了出来。

BOX[remember]: 看出规律了吗 :: 对 **x^n^** 求导，得到 **f′(x) ＝ n × x^n−1^**。// 次数掉下来当系数，指数减一。// 对常数函数（比如 f(x) ＝ 5）求导，得到 **f′(x) ＝ 0**——// 它在每一点的导数都是 0，因为它根本不变。

BOX[task]: 留给姐姐 :: 自己把 x^4^ 那一行算一遍，验证表里没写错。// 提示：(x+h) × (x+h) ＝ x^2^ ＋ 2xh ＋ h^2^，再乘两次。// 算完再猜一猜：对 x^5^ 求导会得到什么，然后**验证你的猜测**。

## 二、为什么“约得掉”不是碰巧

妹妹应该追问一句：**凭什么每次 h 都约得掉？**

因为有一件事对**所有**多项式都成立：

BOX[key]: 一个能扛住整册书的事实 :: 对任何多项式 f，**f(x+h) − f(x) 一定能提出一个 h**：// **f(x+h) − f(x) ＝ h × q(h)**（q 也是一台多项式机器（函数））// 道理很朴素：把 (x+h) 的各次方展开，**不带 h 的那些项**正好凑成 f(x)，被减掉了；// 剩下的每一项都至少带一个 h。// 所以除以 h 之后，**一定**是个多项式，**一定**能直接代 0。// // 记住这句话——**第十二篇证牛顿–莱布尼兹时，用的还是它。**

可这就带出下一个问题：**多项式之外的机器呢？**

第二篇特意留着的那台**开方机器 √x**，正好是现成的对照。它不是"只用加和乘"造出来的，所以上面这条路对它是堵死的：**(x+h) 的开方展不开，h 根本写不出来。**

**可 h 照样约得掉。**只要换一招——上下同乘一下，那个碍事的 h 就自己冒出来了。这一招留到**第十二篇第六节**当场演给你看，那里会还第五、六篇借用开方导数的那笔账。

BOX[remember]: “约得掉”不是多项式的特权 :: 多项式好在**看得见**：把 (x+h) 展开，h 就明明白白摆在那儿，你能把它**写下来**。// 别的机器不一定写得出来，可 h 照样约得掉——// **招数不一样，干的是同一件事：把 h 从变化里提出来。**// // 真正要问的不是代数上提不提得出 h，而是：// **走到 p，这台机器的平均变化率是否奔向一个数 f′(p)。**// 一旦这个数存在，第五篇就把 p 钉住，用它作固定倍率造出微分。// 下一节要证明：那把局部直尺留下的零头，确实比 dx 小一档。

## 三、还清微分的欠条

### 先把第二篇 C3 的小角算清楚

第二篇 C3 问过一个当时答不上来的问题：**那个小角，边长变化越小就越"可以忽略"——"可以忽略"到底是什么意思？**

现在可以精确回答了。取 f(x) ＝ x^2^，把站脚点叫 p：

- 真正的变化是 **2p × dx ＋ (dx)^2^**
- 微分是 **dy ＝ 2p × dx**
- 两者相差 **(dx)^2^**

BOX[key]: "可以忽略"的准确意思 :: 光说"(dx)^2^ 很小"没有用——dx 本身也很小。// 关键在于**它们小的程度不一样**：// **把这个误差除以 dx**，得到的是 **dx**，而 dx 奔向 0。// // 所以"可以忽略"的准确说法是：// **误差除以 dx 之后，还奔向 0。**// 也就是：它不只是小，它比 dx **还要小一档**。// // 这句话是整册书里"可以忽略"四个字**唯一**被允许的意思。

### 回过头看：微分凭什么替得像

第五篇、第六篇借用的那句话，到这里才算有了真证明。

刚才对 x^2^，我们把 p 附近的真变化拆成了两块：**微分 dy ＝ 2p dx**，加上**零头 (dx)^2^**。可那是靠展开算出来的。换一台机器（函数）——比如展不开的开方——还拆得出来吗？

拆得出来，而且不用重算一遍。**只要这台机器在 p 点有 f′(p)**，三句话就够：

BOX[key]: 三句话，把零头拆出来 :: **一、**把 p 钉住，把 dx 投进微分，得到 **dy ＝ f′(p)dx**；零头就是真变化 **f(p+dx) − f(p)** 减去 dy。// **二、**把零头除以 dx。真变化除以 dx 是从 p 出发的**平均变化率**；dy 除以 dx，按直尺的线性规则正好只剩固定倍率 **f′(p)**。// 所以**零头除以 dx，就等于平均变化率减去 f′(p)**。// **三、**而平均变化率**正奔向 f′(p)**——p 点的导数存在说的就是这件事。// 一个奔向 f′(p) 的数，减掉 f′(p)，**当然奔向 0**。// // 于是零头除以 dx 奔向 0：**零头比 dx 小一档。**// 请注意这三句话里**一个字都没用到多项式**——// **对任何在 p 点有导数的机器（函数）都成立，开方也在内。**

BOX[remember]: "约得掉"和"线性替身"，说的是同一件事 :: 钉在 p 点的微分给出头一块 **dy ＝ f′(p)dx**：// 同一支箭头放大 2 倍，dx、dy 两把尺子的读数都放大 2 倍；箭头缩成一半，两份读数也都缩成一半——// **dy 跟 dx 成正比**，比例正是 f′(p) 这个导数。// 两份读数相除，dx 正好被约掉，只剩下那个固定倍率；另一块零头除以 dx 奔向 0，**进不了答案**。// // 所以试探步 h 能在平均变化率里约掉，不是运气，也不是多项式的特权：// **只要 f′(p) 存在，p 附近就有线性替身 dy ＝ f′(p)dx——那正是微分。**// 它不用知道别处的导数；多项式不过是让这件事**看得见**，开方展不开，局部直尺照样在那儿。

第六篇第六节已经从另一面回答过：换一个陡度、拿别的直线来配，误差就压不到比 h 小一档。两边合起来，账终于完整：**这一节证明正确陡度做得到；第六篇证明别的陡度都做不到。**所以微分不是随手挑的一台直线函数，而是唯一合格的局部线性替身。

## 四、三条求导法则

对整台函数 f 求导，得到坡度地图 **x → f′(x)**；走到 p，读出 f′(p)，再把 p 钉住，写下这一点的微分 **dy ＝ f′(p)dx**。同一支局部箭头能由两把直尺这样稳定地读数，而且读数是线性的，就说 f 在这一点**可微**。有了上面这些，再加三条规矩，就能给任何多项式求导——多项式**处处可微**。

BOX[remember]: 三条规矩 :: **一、加起来的：**(f ＋ g)′ ＝ f′ ＋ g′。// **二、乘常数的：**(5f)′ ＝ 5f′。// **三、乘起来的：**(fg)′ ＝ f′g ＋ fg′。// // 每条等式说的都是**求导前后的函数关系**；再投进一个 x，等式两边才变成这一点的导数值。

第三条最不像话，所以先画个图，看看它是从哪来的。把 f 当长、g 当宽，f × g 就是长方形的面积：

FIG: fig-04-product-rule.png | 长变一点、宽变一点，面积多出来两条，外加右上角一小块。

多出来的面积，是这三块拼起来的：**长的微分输出 × 原宽**，加上 **原长 × 宽的微分输出**，再加上**右上角那一小块**。

前两块正是法则里那两项。**看清每一块乘的是什么：变化的那条边，乘的都是另一条边的原长——函数的值，不是它的变化。**真让“变化乘变化”的，只有右上角那一小块——两台微分各自的输出相乘——按上一节的说法，**它除以 h 之后还奔向 0**，所以它进不了最后的答案。

BOX[remember]: 三条规矩，同一个直觉 :: 拆开看，三条规矩干的是同一件事：// **只留跟挪动成正比的，把不成正比的交给极限。**// 加起来的：两份变化各自留下成正比的一块，照抄相加；// 乘起来的：进答案的两条边带，**变化的一边乘的都是另一边的原长**；// 想让两份**变化**乘在一起？只有右上小角——零头中的零头。// 这也预先说破了下一节那场翻车：**f′g′ 算的是小角的账，不是边带的账。**

**但是图只能让人相信，不能当证明。**要证明，就得写成平均变化率，再**取极限**。

BOX[key]: 乘积法则的证明 :: 先写出 f × g 这台机器的平均变化率，然后**加一项、再减掉同一项**（加 f(x+h)g(x)，再减 f(x+h)g(x)，等式不变），拆成两块：// **[[f(x+h)g(x+h) - f(x)g(x)|h]] ＝ [[f(x+h) - f(x)|h]] × g(x+h) ＋ f(x) × [[g(x+h) - g(x)|h]]**// // 这个等式对**每一个不等于 0 的 h** 都成立。现在**考虑等式左右两边在 h 趋于 0 时的极限**。// // **左边**：按定义，正是 f × g 在 x 处的 (f × g)′(x)。// **右边第一块**：[[f(x+h) - f(x)|h]] 奔向 f′(x)；同时 g(x+h) 奔向 g(x)——**这一步用的是第三篇证过的"多项式处处连续"**。// **右边第二块**：f(x) 一直不动，[[g(x+h) - g(x)|h]] 奔向 g′(x)。// // 于是 **(f × g)′ ＝ f′ × g ＋ f × g′**。**证毕。**

BOX[remember]: 图上那个小角，到哪儿去了 :: 它没有被"扔掉"——**它藏在 g(x+h) 这个因子里**。// g(x+h) 比 g(x) 多出来的那一点点，乘上前面那一块，正是右上角那一小块。// 取极限的时候 g(x+h) 奔向 g(x)，**那一点点自己就消失了**。// // 请注意说法的差别：// **不是**"它很小，所以不管它"；// **而是**"取极限以后，它奔向 0"。// **图让人相信，极限才让人证明。**

BOX[remember]: 这里借了一条 :: 上面拆成两块以后，我们用了"**两块相加，极限就是极限相加**"（第一册第四篇例三证过），// 还用了"**两个都有极限的东西相乘，极限就是极限相乘**"——**这一条第一册没有证**，只在例三末尾提过一句。// 它和例三同属"极限的四则运算法则"，证法一样（掰 ε ＋ 三角不等式）。// 这一册**用了它但没证它**，附录 D 里记着这笔账。

### 可微不可微，画像上一眼看得出

本节开头说过：在一点上微分造得出来，就叫**可微**。第六篇第一节已经把它画了出来——**放大以后，能看成一段直线**，有切线可以顶替。那**不可微**长什么样？

FIG: fig-32-spikes.png | 左：尖角。左右两边各有各的陡度，一条切线定不下来——连着，可是在尖角上不可微。右：一条浑身是毛刺的曲线——处处连着、处处是尖的，没有一处能用直线顶替。

先看最简单的一种：**尖角**。拿这台机器试：投进 x，吐出**它的绝对值**（第一册教过的生字）。在 0 那一点上算平均变化率：从右边挪，一律是 1；从左边挪，一律是 −1。**两边各奔各的，凑不出同一个极限——f′(0) 不存在。**画像上就是左图那个 V 字：左右两边各有各的陡度，**一条切线定不下来**。

注意它**连着**——尖角不断开。反过来倒是真的：**可微的机器在那一点一定连着**——真变化就是平均变化率乘 h，h 奔向 0 时，前一个奔向 f′(x)、后一个奔向 0，乘起来奔向 0，变化奔向 0 就是接得上。（这一步用的又是**极限相乘**，附录 D 记着的那笔账。）

**尖角要是多起来呢？**右图那条曲线，**处处连着、处处是尖的——浑身毛刺，放大多少倍毛刺都不消失**。第六篇第一节拿放大镜看过曲线：可微的曲线越放越直；这一条**放到天边也直不了**，没有一处可微。这样的曲线真的存在，数学家第一次见到它时都吓了一跳——大名在下面灰盒里。

BOX[remember]: 可微性，画像一眼看得出 :: **可微，就是放大以后能看成直线**：弯的变化，能用成正比的顶替。// **不可微，就是放大到最后还是尖的**：左右陡度对不上，切线定不下来。// **连续管接得上，可微管平滑**——可微的都连着；// 连着的不一定可微，它可以浑身是毛刺。// 顺带一句：习题 C7 那台开方机器在 0 那一点，是**另一种**不可微——// 不是尖，是**立得太陡**（平均变化率要多大有多大）。

BOX[grown]: 那条毛刺曲线的大名 :: 处处连续、处处不可微的函数，头一个公开的例子叫**魏尔斯特拉斯函数**（1872 年）：把一层比一层细的波浪无穷层叠起来，每一层都往曲线上添更细的毛刺。右图画的是只叠六层的近亲——真身要无穷层叠上去。// 它刚露面时把当时的数学界吓得不轻：大家原本以为"连续的函数至多几个尖角"，有人把这类例子叫作**病态函数**。今天它是常客——**海岸线、山脊、股价走势图，都长着这种放大不消失的毛刺**，研究它们的学问叫**分形**。

## 五、直观翻车：乘积的导数，不是两个导数相乘

妹妹一定会想：加起来那条那么简单，乘起来以后，某点的导数是不是也该等于两个原函数在这点的导数相乘？

**不是。**这是本篇要抓的那条刺。

BOX[key]: 一个例子就够了 :: 取 f(x) ＝ x，g(x) ＝ x。它们乘起来是 **x^2^**。// **正确答案：**对 x^2^ 求导得到 2x，因此它在 x 点的导数是 **2x**。// **"两个导数相乘"给出：**1 × 1 ＝ **1**。// 2x 和 1 显然不是一回事。// // 用规矩三算一遍：1 × x ＋ x × 1 ＝ **2x**。✓ 对上了。

翻车的原因，第四节那张长方形早就画着：进答案的两条边带，**变化的一边乘的都是另一边的原长**；两个导数相乘所对应的，是**右上小角**——那是零头，除以 h 之后还奔向 0，进不了答案。**拿零头当答案，当然对不上。**

BOX[remember]: 记住这个教训 :: 一条规矩在加法上成立，**不等于**它在乘法上也成立。// 数学里“看起来该这样”的地方，**都要拿一个具体例子试一下**。// **第八篇第四节还会再翻一次车**——那次翻的是**f′ 是 0 就一定是最高点**。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 课本管 **f′(p) 这个数**叫 f 在 p 处的**导数**，本书也照用这个名字。把每一点的导数收在一起，**x ↦ f′(x)** 便是整张坡度地图；本书只写 **f′**，不另造一个名字。// p 点导数的定义是 f′(p) ＝ lim(h→0) [f(p+h) − f(p)] ÷ h。让 p 换遍各点，求导 **f → f′** 就造出整张地图；固定一个 p，微分才写成局部线性关系 **dy ＝ f′(p)dx**。// 三条规矩分别叫**和法则**、**数乘法则**、**乘积法则**（莱布尼兹法则）。// 对 x^n^ 求导得到 nx^n−1^，叫**幂法则**。// 这一册不需要**商法则**和**链式法则**，因为多项式用不上；但它们是同一套平均变化率推出来的。// 第二节那个事实的正式说法是**因式定理**：多项式 f(t) − f(x) 一定能被 (t − x) 整除。
