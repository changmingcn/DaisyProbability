# 第十二篇　倒着走：从结果回头猜机器

CENTER: 前面十一篇都是先说清机器、再算事件；这一篇反过来——先看见结果，回头给"到底是哪台机器"记一本账

## 一、第九篇那枚硬币，一直没算完

第九篇留下过一句话：桌上一枚**来历不明**的硬币，连着抛出好些正面，你**可以回头怀疑它公不公平**。

话是这么说，可**怎么算**？当时没教。

不是忘了教，是**算不了**。把抛三次的结果单摆出来看看：正正正、正正反、正反正、正反反、反正正、反正反、反反正、反反反——八条路，一条不多，一条不少。

CENTER: **这张单子上，从头到尾没有哪一行写着这枚硬币是什么货色。**

BOX[key]: 账内的怀疑，是没地方落脚的 :: 第七篇教过：消息一来，划掉不符合的，剩下的重新分。// 可**这枚硬币不公平**这句怀疑，**一条路也划不掉**——正正正在公平硬币下完全可能，只是少见罢了。// 它根本**不是这张单子上的一件事**：你圈不出它，也就分不出它占几份。// // 想让怀疑变成能算的东西，只有一条路：**换一张更大的单子。**

## 二、把机器也写进结果单

妹妹在桌上放了两枚硬币：

- 一枚**公平币**：正面反面各占一半。
- 一枚**双面正**：两面都印着正，怎么抛都是正。

规矩说清楚：**姐姐闭着眼睛摸一枚**（摸到哪一枚，就算各占一半），摸定了**抛三次**。

现在这台机器有**两步**：先摸币，再抛。结果单也跟着长了一层——它记的不只是抛出什么，还有**摸到的是哪一枚**。

FIG: fig-p18-two-coins.png | 左：抛以前一共十六份，两枚各一半；摸到双面正那八份份份都是三次全正，摸到公平币那八份只有正正正对得上。右：划掉对不上的，只剩九份。

把那个 1 分成 **16 份**最省事：

TABLE:
| 摸到哪一枚 | 占几份 | 这几份里，三次全是正的有几份 |
| 双面正 | 8 份 | **8 份**——它次次都出正 |
| 公平币 | 8 份 | **1 份**——八条路里只有正正正那一条 |

CENTER: **"这枚是双面正"，现在是一件圈得出来的事了。**

BOX[remember]: 把机器写进单子 :: 第三篇的结果单只记**抛出什么**；这一篇的结果单多记一层：**用的是哪一台机器**。// 机器一旦也在单子上，**它是哪一台**就和**抛出正面**一样，成了单子上的一块——第四篇教过怎么圈它，第七篇教过消息来了怎么重分。// **没有新招式，新的只是那张单子。**

## 三、消息来了，还是划掉、重分

姐姐抛了三次：**正、正、正。**

老动作，一步不多。**划掉**对不上这条消息的份：

- 双面正那 8 份，一份不掉（它次次全正）。
- 公平币那 8 份，只剩 1 份。

还剩 **9 份**。在这 9 份里**重新分**那个 1：

CENTER: **是双面正，九份里占八份；是公平币，九份里占一份。**

摸的时候两枚各占一半；**看过三次全正以后，姐姐手上这枚是双面正的可能性变成了 [[8/9]]。**

BOX[dialog]: 妹妹不服 :: **妹妹：**"三次全正而已，公平币也抛得出来啊，凭什么就说八成九？"// **姐姐：**"公平币当然抛得出来——**八条路里有一条**。可双面正那边，**八条路全对得上**。// 同样是三次全正，一边只有一份接得住，另一边八份都接得住。// **这条消息没有排除公平币，它只是把账往双面正那边推了八倍。**"// **妹妹：**"要是抛四次全正呢？"// **姐姐：**"公平币那边就只剩十六份里的一份接得住，双面正那边还是份份接得住。**推得更狠。**"

## 四、它有名字，也有一个价钱

**从看见的结果回头改机器那本账**，这个做法叫**贝叶斯估计**（贝叶斯是两百多年前一位英国牧师的姓，英文写作 Bayes）。

不过估计不该停在"哪一枚更像"。妹妹马上问了一个更要紧的：

BOX[dialog]: 那下一次呢 :: **妹妹：**"别管它是哪一枚了。你就说——**第四次还是正面**的可能性有多大？"// **姐姐：**"问得好，这才是真要用的东西。就拿刚才那本新账来算：// 是双面正（九份里占八份），下一次一定是正；// 是公平币（九份里占一份），下一次正面占一半。// 两条按份合起来——"

CENTER: **[[8/9]] × 1 ＋ [[1/9]] × [[1/2]] ＝ [[17|18]]**

**下一次正面的可能性是 [[17|18]]**，比一开始的一半高出许多——三次全正把账推过去了。

姐姐这一步做的，正是第八篇那个动作：把每种情形上的数乘它占的份，再全部加起来，压成一个数。也正是第十篇那个动作：**消息到来以后重新算的公平价。**

BOX[remember]: 估出来的那个数，就是新账下的公平价 :: 把"这枚币出正面的可能性"看成一台翻译机：投进**双面正**，吐出 1；投进**公平币**，吐出 [[1/2]]。// 消息来以前，两枚各一半，它的公平价是 [[3/4]]。// 消息来以后，按九份那本新账算，它的公平价是 [[17|18]]。// // **贝叶斯估计不是另起炉灶的新本事。**结果单加一层、消息一来划掉重分、再按新账算一次公平价——三个动作，前面全教过。

BOX[key]: 换一条路走，得同一个数 :: 上面是先估机器、再问下一次。**也可以一口气数格子**：把四次抛全摆开，两枚各占 16 份，一共 32 份。// **前三次全正**的份：双面正那边 16 份全对上，公平币那边只有 2 份（第四次正或反）——一共 **18 份**。// 这 18 份里**第四次也是正**的：双面正 16 份，公平币 1 份——**17 份**。// 于是还是 [[17|18]]。// // 两条路线**必须**走到同一个数，账才叫不打架。这一册开头那句话，说的就是这件事。

## 五、翻车：只比"谁更像"，忘了本来有几枚

第七篇那辆洒水车，现在该回来了。

妹妹换一个袋子：**99 枚公平币，1 枚双面正**——家里翻出来的一整盒零钱，混进去一枚玩具币。姐姐照旧摸一枚、抛三次，**还是全正**。

**这回是双面正吗？**

照样数格子。每枚占 8 份，一百枚一共 800 份：

TABLE:
| 摸到哪一种 | 占几份 | 三次全是正的有几份 |
| 双面正（1 枚） | 8 份 | 8 份 |
| 公平币（99 枚） | 792 份 | 99 份 |

三次全正一共 **107 份**，双面正只占其中 **8 份**——**[[8|107]]，连一成都不到。**

CENTER: **同一串正面，推的力气一模一样；起点不同，落点差得很远。**

BOX[remember]: 光问"有多像"是不够的 :: 双面正**更像**这串结果，这一点在两个袋子里完全一样：**八比一**。// 变的是起点——第一个袋子里两种各一枚，第二个袋子里公平币是双面正的九十九倍。// // **最后的账，是"本来有多少"和"有多像"两样合出来的。**// 只盯着有多像、忘了本来有多少，就会一看见三次全正就喊双面正。// 这正是第七篇那句话：**操场湿了，也可能是洒水车天天来。**

## 六、单子上没有的那一行，你永远猜不出来

最后一件老实事，必须说在前头。

姐姐这一整套算法，**从头到尾只在她自己写下的那张单子上转**。单子上写了两种硬币，她就在两种之间分账；写了一百枚，就在一百枚之间分账。

**万一妹妹还偷偷做了第三枚呢？**——比方一枚"十次里有九次出正"的偏心币，而姐姐的单子上根本没有它。那么无论姐姐算得多严密，那本账**永远不会指向它**：它不在单子上，就分不到一份，也就永远抬不起头。

CENTER: **算得对，只保证在你写下的那些可能之中是对的。**

BOX[remember]: 这一册最后一条老实话 :: 第一道门问：**机器是什么？**第二道门问：**你圈的是哪件事？**// 这一篇添了第三个动作：**机器不知道的时候，把它也写进单子，再拿看见的结果回头给它记账。**// 可它同时递来一个新责任——**那张单子得由你来写**。写漏了的可能，账上不会替你叫屈。// // **概率论能把怀疑变成计算，前提是你肯先把怀疑写下来。**

BOX[key]: 机器没指定，和机器不知道 :: 第二篇那个圆是**机器没指定**：题目一个字也没交代弦怎么来，三台机器都不违规，于是三本账并排立着，谁也压不倒谁。// 这一篇是**机器不知道**：机器只有一台，妹妹手里那枚要么公平、要么双面正，**只是姐姐不知道是哪一台**。// **不知道，可以用消息去缩；没指定，消息再多也缩不动**——因为那时候连该缩哪一本都还没定。// 别把这两件事弄混：一个要你补规矩，一个要你收消息。

## 七、习题

BOX[task]: A 组：认一认 :: **A1.** 还是那两枚（公平、双面正）。摸一枚只抛**一次**，是正。它是双面正的可能性是多少？（把 1 分成 4 份数一数。）// **A2.** 同样两枚，抛**四次**全是正。是双面正的可能性是多少？（每枚 16 份。）// **A3.** 消息来以前，"这枚币出正面的可能性"这台翻译机，公平价是多少？// **A4.** 第五节那个袋子（99 枚公平、1 枚双面正），三次全正以后是双面正的可能性是多少？比两枚那一次大还是小？

BOX[task]: B 组：动动手 :: **B1.** 两枚那题，抛三次得到的是**正正反**。现在它是双面正的可能性是多少？——为什么一眼就看得出来？// **B2.** 袋里 1 枚双面正、3 枚公平。摸一枚抛两次，全是正。是双面正的可能性是多少？（每枚 4 份。）// **B3.** 接上题：**下一次是正面**的可能性是多少？用第四节那个办法算。// **B4.** 妹妹说她袋里公平币和双面正**一样多**，可她不肯说一共几枚。姐姐抛三次全正。答案会因为"一共几枚"而变吗？——拿 2 枚（1 加 1）和 20 枚（10 加 10）各算一遍，比一比。

BOX[task]: C 组：想一想 :: **C1.** 为什么说"这枚硬币不公平"不是抛三次那张结果单上的一件事？// **C2.** 第五节两个袋子，"有多像"完全一样，答案却差得很远。用一句话说清楚差在哪儿。// **C3.** **机器没指定**和**机器不知道**有什么不同？各举一个例子。// **C4.** 姐姐的单子上要是漏了一种可能，那本账会怎么样？——这一册有没有办法替你把单子写全？
