# 第八篇　知道消息以后的公平价

CENTER: 分两步问，和一步问，答案一样——这一册全部的路，通到这一句

## 一、先看见一半

红蓝两个骰子，掷出来把点数**加起来**给你钱。第六篇算过：公平价 **7 块**。

现在改一改规矩：**红骰子先掷，掷完让你看一眼**，然后你再决定交多少钱玩下去。

红骰子掷出 **5**。这时候你愿意交多少？

姐姐算：红那一半已经定死是 5，蓝那一半还没掷，它的公平价是 3.5。所以

CENTER: **5 ＋ 3.5 ＝ 8.5**

**看见 5 以后，这个游戏值 8.5 块。**比原来的 7 块贵——因为你看到了一个好消息。

## 二、消息不同，价钱就不同

红骰子当然不一定是 5。六种情形各算一遍：

TABLE:
| 红骰子是 | 1 | 2 | 3 | 4 | 5 | 6 |
| 看见以后的公平价 | 4.5 | 5.5 | 6.5 | 7.5 | 8.5 | 9.5 |

BOX[remember]: 知道消息以后的公平价 :: **先按消息把结果单缩小**（第五篇那一手：划掉不符合的），// **再在剩下的那一小块里算公平价**（第六篇那一手：乘起来、加起来）。// 两篇的本事**接在一起**，就是这一篇。// 长大以后，它叫**条件期望**。

## 三、要紧的一步：它本身还是个未知数

上面那张表有**六个数**，不是一个数。到底哪个算数，**要等红骰子掷出来才知道**。

**红骰子还没掷之前，"看见以后我愿意出多少"这句话本身，还是个说不准的数。**

BOX[remember]: 信封还没拆 :: 桌上有一个信封，里面写着红骰子的点数。// **信封还没拆，所以"拆开以后你愿意出多少钱"——现在也还是一个未知数。**// // 换句话说：**知道消息以后的公平价不是一个数，它是一台翻译机**（第六篇那种 X）：// **投进去"红骰子是几"，吐出来"这时候该出多少钱"。**// // **这是这一册最难的一句话，也是大人最常栽的地方。**// 请你在这里停一下：普通的公平价是**一个数**（7 块）；// 知道消息以后的公平价是**一张表**（六个数），要等消息来了才塌成一个数。

## 四、把六个价钱再平均一次

既然它是一台翻译机，那就可以问它自己的公平价——**这台机器值多少？**

红骰子六个面一样可能，所以把六个数平均：

CENTER: **(4.5 ＋ 5.5 ＋ 6.5 ＋ 7.5 ＋ 8.5 ＋ 9.5) ÷ 6 ＝ 7**

**7。**正是一开始那个公平价。

BOX[remember]: 这一册的顶点 :: **先按消息分开算公平价，再按消息出现的可能性把这些价平均——**// **和一开始一口价算出来的，是同一个数。**// // 一句话记住它：**分两步问，和一步问，答案一样。**// 长大以后这条叫**塔性质**。

## 五、为什么这不是巧合

FIG: fig-p12-tower.png | 36 格按红骰子分成六堆。每堆先算平均，六个平均再平均——和把 36 个数一口气平均，是同一件事。

看那张 36 格的表（第三篇画过）。每一格写着"红点加蓝点"，每一格分到 [[1|36]]。

**一口气算**：把 36 个数加起来，除以 36。

**分两步算**：先按红骰子把 36 格**分成六堆**，每堆 6 格；每堆先加起来除以 6，得到六个数；再把这六个数加起来除以 6。

这两条路凭什么走到一起？

BOX[key]: 就是把同一批数换个顺序加 :: 36 个数加起来，你可以**一个一个加**，也可以**先按堆加、再把六个堆的和加起来**——// **加法本来就允许这么分组**，总和一个字都不会变。// 至于除：分两步是"每堆除以 6，六个数再除以 6"，合起来正好除了 36；一口气是直接除以 36。**一样。**// // **所以这不是巧合，是加法自己的性质。**这一段没有借任何东西。

**上面那个说法有一处偷懒，得补上**：六堆**恰好一样大**（各 6 格），所以最后"平均"是直接除以 6。要是分出来的堆**不一样大**呢？——那就不能直接平均，得**按堆的大小配份**：大堆算数多一点，小堆少一点。

CENTER: **这正是"按消息出现的可能性平均"那句话的意思。**

BOX[remember]: 完整的说法 :: 把每条消息下的公平价，**乘上这条消息出现的可能性**，然后加起来——// 得到的就是原来那个公平价。// 六堆一样大是特殊情形（每条消息各 [[1/6]]），所以看起来像"直接平均"。

## 六、它有什么用：分两步比一步好算

BOX[task]: 一道一步算会算哭的题 :: **先掷一个骰子，掷出几，就抛几次硬币。**问：**正面出现次数的公平价是多少？**// // 一步算：掷出 1 抛 1 次、掷出 2 抛 2 次……每种情形正面数还有好几种可能，摊开来一大片。**能算，但很烦。**// // 分两步算：// **第一步**——假设已经知道骰子掷出的是 N。那就是抛 N 次硬币，每次正面的公平价是 [[1/2]]，// 用第六篇那条——**两台机器加起来，公平价就是两个公平价加起来**——N 次的公平价就是 **N 的一半**。// **第二步**——N 本身的公平价是 3.5（骰子），所以答案是 **3.5 的一半，也就是 1.75**。// // **两行算完。**这就是塔性质的用处：**把一个难问题，切成"先问一半"和"再问另一半"。**

## 七、翻车：把它当成一个数

BOX[key]: 最常见的错 :: "知道消息以后的公平价是 8.5 块"——**这句话只在'红骰子是 5'的前提下成立**。// 把它当成这个游戏的公平价（7 块）去用，就错了。// // 更隐蔽的一种：**忘了它是一台机器，于是忘了它还能再被平均一次**。// 一旦忘了这一点，第四节那个**再平均得回 7** 的漂亮结果就无从谈起——// **它之所以能被平均，正因为它本身是个未知数。**

## 八、回头望一眼那个圆

BOX[key]: 回头望一眼那个圆 :: 开篇的第三问是："**要是拿它打赌，公平价是多少？**"// 第六篇答了前一半：三种做法，三个价（[[1/3]]、[[1/2]]、[[1/4]] 块）。// 这一篇答了后一半：**要是你已经知道了一点消息**——比如"这条弦的中点落在上半个圆"——// **价钱就要重算**：把结果单缩小到上半个圆，再在里头算一次。// // 而且不管你怎么切消息，**塔性质保证**：把各种消息下的价按可能性平均回去，**一定回到原来那个价**。// **切法可以随便挑，总账赖不掉。**

## 九、习题

BOX[task]: A 组：认一认 :: **A1.** 红蓝两个骰子求和。看见红骰子是 2，公平价是多少？看见是 6 呢？// **A2.** 上一题六个答案的平均是多少？它应该等于什么？// **A3.** "知道消息以后的公平价"是一个数，还是一台翻译机？为什么？// **A4.** 用一句话说出塔性质。

BOX[task]: B 组：动动手 :: **B1.** 红蓝两个骰子，钱数是**两个点数之和**。这回看见的是**蓝**骰子。六种情形各算一遍，再平均。得几？// **B2.** 红蓝两个骰子，钱数改成"**红点数乘 2 再加蓝点数**"。先算总公平价；再按红骰子分六堆算，平均回去核对。// **B3.** 先抛一枚硬币：正面就掷 1 个骰子，反面就掷 2 个骰子；掷出的点数之和就是你拿的钱。用分两步的办法算公平价。// **B4.** 一个袋子里 3 红 2 蓝。摸一个球：红球给你 10 块，蓝球给你 0 块。现在有人告诉你"摸到的不是蓝球"。新的公平价是多少？
