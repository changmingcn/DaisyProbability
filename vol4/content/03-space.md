# 第三篇　先说清楚怎么随机

CENTER: 一台随机机器，要交出两样东西：所有可能的结果，以及那个 1 怎样分给它们

## 一、这一册真正的第一步

第二篇给了个教训：**要比大小，得先说清楚"所有可能的结果"是什么。**

第一篇那四样东西，都替你说了：整个盘面、整个靶子、整块地板、整根绳子——**"整个地方"是现成的**，你只管去比那一块占多少。开篇那 64 块钱也替你说了：**四条路**，一条一份。

**圆上的弦不替你说。**于是三个人各说各的，三个答案。

所以从这一篇起，每算一件事，都先过两步：**机器怎样产生结果；这台机器把那个 1 怎样分下去。**写成账，就是：

CENTER: **把所有可能的结果摆出来，再把那个 1 分下去。**

这一篇就把这句话拆开，看看它到底要交代些什么。

## 二、两条家规

既然是把 1 分下去，那就有两条谁也不能破的规矩：

BOX[remember]: 有限结果单的两条家规 :: **家规一：每个结果分到的，不能是负的。**// 可以分到 0，表示这本模型没有给它份；但没有"负的可能性"这种东西。到了没有底的结果单里，分到 0 也不等于从单子上删掉——尾声会专门处理。// // **家规二：把整张有限结果单上的份加起来，正好是 1。**// 为什么正好是 1？因为**总得发生点什么**：掷一个骰子，1 到 6 里必有一个出现，不多不少。// 加起来超过 1，说明你把某件事数了两遍；不到 1，说明你漏了一种可能。

这两条看着简单，却是有限账本最底下的规矩。往后圈一件事、合两件事、给赌局定价，翻到底都不能破坏它们。

BOX[dialog]: 妹妹要试试家规 :: **妹妹：**"我说掷骰子出 6 的可能性是 [[1/2]]，出别的每个都是 [[1/10]]，行不行？"// **姐姐：**"你加加看。[[1/2]] 加上五个 [[1/10]]，是 1。**家规二过了。**没有负数，**家规一也过了。**"// **妹妹：**"那我说得对？"// **姐姐：**"你说得**合法**，不等于说得**对**。家规只管你这张分法自己站不站得住，它管不着这个骰子到底是不是这样。// 要知道真骰子是不是这样，得**掷很多次去看**——那是第九篇的事。"

姐姐这句话要紧：**两条家规是"能不能这么说"的门槛，不是"说得对不对"的判据。**

BOX[key]: 概率预测交出来的是整本账 :: 姐姐刚才不是各猜了六次：猜一次出 1、再猜一次出 2……她交出来的是**同一个未来骰子的六个数**，六个数必须一起过家规。// 真掷的时候，只会有一个结果落地；可在掷以前，"出 6"、"出偶数"、"大于 4"这些不同问法，都要能从同一张分法里查到彼此相容的答案。// // **预测的是一整家可能发生的事各占多少；不是预先点名最后落地的那一个结果。**

BOX[grown]: 长大以后的写法 :: **结果单加上那个 1 怎样分**，合起来叫一个**概率分布**。它不是六个各说各话的预言，而是一份同时约束许多事件的预测。// 到了第四篇，每一种问法都会变成结果单上的一块；那时你会看见，为什么一份分布可以一次回答整整一族问题。

## 三、结果单：一个不漏，一个不重

要把 1 分下去，得先知道**分给谁**。所以第一步永远是同一件事：

CENTER: **把所有可能的结果，一个不漏、一个不重地摆出来。**

这张单子，我们就叫它**结果单**。

掷一个骰子的结果单：1、2、3、4、5、6，六项。飞镖靶的结果单：靶面上的每一个点（这一张单子长得没边，但道理一样）。

**"一个不漏、一个不重"这八个字，是这一篇最容易翻车的地方。**

BOX[task]: 一道会翻车的题 :: 掷**两枚**硬币（一枚一角，一枚五角），问：**两枚都是正面的可能性有多大？**// // 有人这么想：结果无非三种——**两正、两反、一正一反**。所以两正是 [[1/3]]。// **这是错的。**错在结果单。// 真正的结果单有**四项**，因为两枚硬币是分得清的：// 一角正五角正、一角正五角反、一角反五角正、一角反五角反。// **"一正一反"其实是两项，不是一项**——它被数少了。// 所以两正是 **[[1/4]]**。

FIG: fig-p05-two-coins.png | 两枚硬币的结果单是四格，不是三项："一正一反"占了两格。

**为什么"两正、两反、一正一反"这张单子不能用？**它并不违反"一个不漏"——三种情况确实把所有可能都盖住了。它坏在另一头：**你以为这三项该平分那个 1，可它们不该。**一正一反该分到两份。

BOX[remember]: 结果单的两道关 :: **第一道：漏没漏？**所有可能的结果都在单子上吗？// **第二道：该不该平分？**——**这两道关是分开的。**// 单子摆得没错，不等于每项分到的一样多。// 想平分，得先能说清楚**凭什么它们一样**（第五篇的活）。// **最省事的办法是：把单子拆到你敢说"这些确实一样"为止。**两枚硬币拆成四格，就敢说了。

## 四、回头望一眼那个圆

现在可以回答第二篇那三种做法**到底差在哪儿**了。差别不在算错，在**三张结果单根本不是同一张**：

TABLE:
| 第二篇的做法 | 它的结果单是什么 | 把 1 分给谁 |
| 一、两个骰子挑两个端点 | 圆周上**两个点**的每一种搭配 | 36 个点两两搭配，每一种一份 |
| 二、半径上抽一个签 | 一条半径，加上**这条半径上的一个位置** | 十个格子，每格一份 |
| 三、往圆里撒一粒米 | 圆面上的**一个点** | 按**面积**分 |

BOX[key]: 回头望一眼那个圆 :: 三张结果单，摆出来的东西根本不一样：一张摆**成对的端点**，一张摆**半径上的位置**，一张摆**圆面上的点**。// 三台机器先造出三张单子，再各自把那个 1 分下去，于是得到三份完整的概率分布。// **后面算出的 [[1/3]]、[[1/2]]、[[1/4]] 不是三个数在吵架，是三本账各自在回答。**// 那到底该用哪一本？第十一篇会告诉你：先回去问弦究竟怎样产生。

## 五、习题

BOX[task]: A 组：认一认 :: **A1.** 下面每一件事，摆出它的结果单，数一数有几项：// （1）掷一枚硬币；（2）掷一个骰子；（3）从一副只有红、黄、蓝三张牌里抽一张；（4）掷一枚硬币再掷一个骰子。// **A2.** 一个转盘分成八个一样大的格子，三个涂红、五个涂蓝。指针停在红色上的可能性是多少？你用的是哪一种分法（面积、长度，还是份数）？// **A3.** 下面这张分法，家规过不过关？// 结果只有三种，分到的分别是 [[1/2]]、[[1/3]]、[[1/6]]。// **A4.** 再看这一张：[[1/2]]、[[1/2]]、[[1/6]]。哪一条家规破了？

BOX[task]: B 组：动动手 :: **B1.** 掷两枚硬币，用四格结果单算：（1）至少有一个正面；（2）恰好一个正面。// **B2.** 开篇那场比赛，要是妈妈在 **1 比 1** 的时候喊停（还是先到 3 分），把没打完的局补完，结果单有几条路？64 块该怎么分？// **B3.** 还是开篇那场比赛，这次停在 **2 比 0**。补完要几局？结果单几条路？怎么分？// **B4.** 掷两个骰子，有人把结果单写成"两个点数之和"，一共十一项。这张单子漏了吗？**你敢说这十一项一样可能吗？**（先记着你的答案，第五篇见。）

BOX[task]: C 组：想一想 :: **C1.** 开篇分金那题里，我们把"根本不会打的第二局"也补上了。请你用这一篇的话解释：**为什么非补不可？**不补的话，哪一道关过不去？// **C2.** 妹妹说："结果单只要不漏就行了。"请你用两枚硬币那道题说明她错在哪儿。// **C3.** 掷一个骰子，有人把结果单写成"出 6"和"不出 6"两项。这张单子漏了吗？两项该不该平分？// **C4.** 家规二说"加起来正好是 1"。要是一件事**可能永远不结束**（比如一直掷硬币，掷到出正面为止），结果单会有无穷多项。这时候"加起来是 1"还说得通吗？**这个问题正文十一篇不回答**——不是忘了，是它要用第一册的本事（把无穷多项加起来）。**尾声推开门，把这一笔补上了**；来龙去脉附录 D 里说清楚了。
