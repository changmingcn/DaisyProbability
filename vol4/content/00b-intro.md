# 开篇　64 块钱，怎么分

CENTER: 概率论是从一场分钱的争吵开始的——而它的第一个念头，是去看那些还没发生的事

## 一、一场没打完的比赛

姐姐和妹妹掷硬币赌钱。

**每人先拿出 32 块**放在桌上，一共 **64 块**。规矩说好了：**掷出正面姐姐得一分，反面妹妹得一分；先拿到 3 分的人，把 64 块全部拿走。**

打到姐姐 **2 分**、妹妹 **1 分** 的时候，妈妈喊停：睡觉。

CENTER: **这 64 块钱，该怎么分？**

BOX[task]: 先自己判一判 :: 别往下看。**先给个数**：姐姐拿多少，妹妹拿多少？// 写在纸边上，一会儿对答案。

## 二、三种听着都有理的分法

**第一种：全给姐姐。**她领先啊。
——可她**还没赢**。妹妹要是连赢两局，钱就是妹妹的。凭什么现在就判死？

**第二种：一人一半。**比赛没打完，那就当没比过。
——可这对姐姐不公平。她已经占了大便宜：只差一分，而妹妹差两分。

**第三种：按 2 比 1 分。**姐姐得 [[2/3]]，也就是 42 块 6 毛多，妹妹得 21 块 3 毛多。
——这一种听着最像回事，**几百年里也真有人把它当标准答案**。

**可这三个答案，没有一个对。**

## 三、帕斯卡的念头：别看打完的，看没打完的

1654 年，一个赌徒拿一道差不多的题去问法国数学家**帕斯卡**。帕斯卡和另一位数学家**费马**为它通了几封信。**那几封信，后来被当成整个概率论的开端。**

帕斯卡的想法，说穿了只有一句话：

CENTER: **已经打完的那三局，一分钱也不值。值钱的是还没打的那几局。**

为什么已经打完的不值钱？因为**钱是按"接下来谁会赢"分的**，而接下来会发生什么，只跟"现在各差几分"有关。已经打完的局只干了一件事：**把比分带到今天这个样子。**至于它是怎么打成 2 比 1 的，一点关系也没有。

现在的局面，一句话就说完了：

CENTER: **姐姐还差 1 分，妹妹还差 2 分。**

## 四、把没打完的局补完

妹妹要赢，必须**连赢两局**。所以**最多再打两局，胜负一定分出来**。

那就**把这两局补完**，看看会出现什么：

TABLE:
| 第一局 | 第二局 | 谁拿到 3 分 |
| 正（姐姐） | 正（姐姐） | **姐姐** |
| 正（姐姐） | 反（妹妹） | **姐姐**（她第一局就够 3 分了） |
| 反（妹妹） | 正（姐姐） | **姐姐** |
| 反（妹妹） | 反（妹妹） | **妹妹** |

FIG: fig-p00-split.png | 把没打完的两局补完：四条路，姐姐赢三条，妹妹赢一条。

BOX[key]: 这里有一个奇怪、但极其要紧的动作 :: 你有没有注意到——**上面有些局根本不会真的打**。// 第一局姐姐要是赢了，她当场就够 3 分，比赛结束，**第二局压根不会发生**。// **可我们还是把它补上了。**// // 为什么要补一局不会打的？// **因为只有两局都补满，这四条路才一样可能。**每一局正反各半，两局的四种搭配就一样多，一条路一份。// 要是照实写成"姐姐第一局就赢了""妹妹赢了第一局再打第二局"这种长短不齐的结局，**它们就不一样可能了，没法数**。// // **把不会发生的也补上，好让所有结局一样可能**——这个动作，你在这本书里会一次次用到。

四条路里，姐姐赢 **3 条**，妹妹赢 **1 条**。所以：

CENTER: **64 块按 3 比 1 分：姐姐 48 块，妹妹 16 块。**

和"按 2 比 1 分"那个流行答案（42 块多）比一比：**姐姐其实该多拿 5 块多。**领先一分的价值，比比分看上去的要大。

## 五、这一步到底干了什么

BOX[remember]: 概率论的第一个念头 :: **去看那些还没有发生、甚至永远不会发生的事。**// // 你手上的事实只有一条：**2 比 1**。// 可你算钱的时候，靠的全是**没发生的事**——四条根本还没走过的路。// **把它们一条条摆出来，数一数**，答案就出来了。// // 这本书从头到尾就在做这一件事。往后变的只有一样：// **那张"所有结局"的单子，会越来越难摆。**

## 六、不信？那就真的重打

道理归道理。**要不要动手验一验？**

姐姐和妹妹拿了一枚硬币，**从 2 比 1 开始，把剩下的局打完**，记一次是谁赢；然后重新摆回 2 比 1，再打一次……一共重打了 **40 遍**。

**姐姐赢了 31 遍**，妹妹 9 遍。31 除以 40 是 **0.775**。

算出来的是 3 除以 4，**0.75**。

CENTER: **接近，但不一样。**

BOX[task]: 你自己也做一次 :: 找一枚硬币，从 2 比 1 开始打，打完记一次是谁赢，重复 **20 遍**。// 你的数字**不会**和 31 一样，也很难正好是 15。// **那么"算出来的 0.75"到底是什么意思？**// 别急，这本书第九篇专门回答它。

## 七、三个问题，就是这一册的路

从这 64 块钱里，掉出来三个问题。这十一篇书，就是回答它们的路。

BOX[task]: 第一问：凭什么"一样可能"？ :: 分金那题的关键一步是"**四条路一样可能**"，我们说得理直气壮。// 可**这四个字是我们自己放进去的**，不是算出来的。// —— **第五篇**会让你看见它当场翻车：两个骰子的点数加起来，看着十一种结果，其实一点也不一样可能。// // 还有更麻烦的：**不是什么事都能摆成几条路来数。**// 在一个圆里"随便画一条弦"，路在哪儿？格子在哪儿？// —— **第一篇**先说你已经会的办法（比面积、比长度），**第二篇**就让你看见这办法能栽多大的跟头。

BOX[task]: 第二问：数出来的次数，凭什么就是可能性？ :: 我们算出 0.75，重打 40 遍数出 0.775。// 差一点点。**多打几遍会不会越来越近？近到什么程度？谁保证？**// （"越来越近"这句话，你在第一册见过。）// —— **第九篇**回答它。

BOX[task]: 第三问："值多少钱"该怎么算？ :: 分金问题问的其实不是"谁会赢"，而是"**姐姐现在这个局面值多少钱**"。// 我们用四条路凑出了 48 块——**可那是这道题特别简单**。要是每条路赢的钱不一样多呢？要是路有一百条呢？// —— **第八篇**给出正式的办法，并且**回头把这 48 块重算一遍**。// 更狠的在后面：**要是你已经知道了一点消息**（比如"下一局姐姐赢了"），这个价该改成多少？——**第十篇**。

BOX[key]: 回头望一眼那 64 块钱 :: 这三个问题都是从这场没打完的比赛里长出来的，所以这一册会**一路回头看它**：// **第三篇**说清楚它那张"四条路"的单子到底是什么东西；// **第八篇**用正式办法把 48 块重算一遍；// **第十一篇**收官时再回来一次——那时候你会看见：// **开篇那个"把不会打的局也补上"的动作，既是这门学问最漂亮的一手，也是它最容易出岔子的地方。**
