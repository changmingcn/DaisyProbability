# 第九篇　掷一万次

CENTER: 下一次仍然不肯报答案，为什么许多次合起来却会显出稳定的规律

## 一、那 30 次，其实没数准

翻回第二篇。姐姐用两个骰子挑端点，做了 30 次，中了 13 次。**13 除以 30 是 0.43**。

开篇那场比赛也一样：算出来 0.75，重打 40 遍数出 0.775。

可让电脑做一万次，比例稳在 **0.31** 附近。

**0.43 和 0.31，差得不算小。**姐姐没做错任何一步——**她只是做得太少了。**

这一篇要回答开篇留下的第二个问题：

CENTER: **数出来的次数，凭什么就是"可能性"？**

## 二、抛十万次硬币

拿最简单的赌局来看：抛一枚硬币，数正面。我们让电脑真的抛了十万次，中途记了五次账：

TABLE:
| 抛了多少次 | 正面出了几次 | 正面的比例 |
| 10 | 7 | 0.7000 |
| 100 | 54 | 0.5400 |
| 1000 | 537 | 0.5370 |
| 10000 | 5030 | 0.5030 |
| 100000 | 50039 | 0.5004 |

FIG: fig-p11-frequency.png | 正面的比例随着抛的次数越来越多，慢慢挤向一半。前面晃得厉害，后面越来越贴。

看这张图：**前面几十次晃得像心电图**（抛 10 次出了 7 个正面，比例 0.7，离一半远得很），越往后越贴着那条线。可先别急着把"次数多"当成魔法。

BOX[dialog]: 一万行，还是一次随机 :: **妹妹：**"我也做一万行：先抛一枚硬币，后面九千九百九十九行全照抄第一行。每一行单独看，不也都是正反各半吗？"// **姐姐：**"是。可你的正面比例最后只会是 1 或 0：第一行是正面，整张表就全正；第一行是反面，整张表就全反。它永远不会挤向一半。"// **妹妹：**"所以行数多还不够？"// **姐姐：**"对。你把**一次随机抄了很多遍**。要长出下面的规律，得让新的随机一次一次进来，而不是让第一行指挥后面所有行。"

BOX[remember]: 频率挤向可能性 :: 本册只讲最干净的一种情形：**同一套规矩，一次一次重新做，各次互不影响。**这时，"发生的次数 ÷ 做的次数"——这个数叫**频率**，上面那张表的第三列数的就是它——会挤向账上写的可能性；做得越多，通常挤得越紧。// 长大以后这条叫**大数定律**。更宽的一般条件和正式证明，这一册都不讲，附录 D 会把欠账写明。// // **不是"多"自动造出规律，是许多份没有互相照抄的新随机叠在一起，才显出规律。**

这里正好看见概率预测怎样管**一整家事件**。抛十万次，实际落地的是一整串正反；概率论仍不点名那一串。它预测的是"正面比例落在 0.49 到 0.51 之间"这类由许多串拼成的大事件，并且能说：次数够多时，这一大块分到的份会非常接近 1。

**这条一站住，前面几篇就都落地了。**第五篇说要拿许多次的记录回来查假设；第八篇说期望可以看作许多次得失的平均。它们靠的都不只是重复，还靠每次按同一套账重新来。

## 三、"挤向"就是第一册那个词——但这一次它变了样

"挤向"两个字你在第一册见过。那里的说法是：**妹妹说一个误差，姐姐给一个关口，过了关口的项一个都不许跑出去。**

这里能不能照搬？

BOX[dialog]: 妹妹要姐姐打包票 :: **妹妹：**"我要比例离一半不超过 0.01。你给我一个关口，过了它就一定合格。"// **姐姐：**"给不了。"// **妹妹：**"为什么给不了？你不是说做得越多越准吗？"// **姐姐：**"是越准，可**再多也保不了票**。// 抛一万次，**全是正面**这件事**并没有被禁止**——它只是**可能性小得吓人**。// 我能给你的是另一句话：**你要多准，我告诉你掷多少次；掷到那么多次以后，不合格的可能性小到你自己都不在乎。**"// **妹妹：**"那就是说，你把'一个都不许跑'换成了'跑出去的机会要多小有多小'？"// **姐姐：**"对。**这就是这一册和第一册最大的不同。**"

BOX[key]: 两种"越来越准"，差在哪儿 :: **第一册**：过了关口，**一个都不许跑出去**——这是**保票**。// **这一册**：过了关口，**跑出去的可能性要多小有多小**——这是**几乎保票**。// // 别小看这一字之差。**它是必须的**：抛一万次全是正面，谁也禁止不了这件事发生。// 数学能做的不是把它禁掉，而是**说清楚它有多不可能**。// // 这句"要多小有多小"该怎么写成算式、又怎么证——**这一册不做**，附录 D 记着。// 你只要看清楚**它是一句什么形状的话**就够了：**还是妹妹先出招（要多准），姐姐再接招（掷多少次）**，只是接招的时候多了一句"不敢打包票，但差不多"。

## 四、翻车一：99 次正面也没有欠下一次反面

BOX[task]: 先想清楚再往下看 :: 一枚题目已经说明**公平、每次独立重抛**的硬币，连续 **99 次都是正面**。第一百次呢？// 很多人会说："该出反面了吧，总不能一直正面。"// **错。第一百次正面仍是 [[1/2]]，反面仍是 [[1/2]]。**

为什么会觉得"该反了"？因为记住了上一节那句"比例会挤向一半"，于是以为**硬币欠了债，要还**。

**硬币不欠任何人的债。**独立的意思正是：前 99 次的结果全告诉你，第一百次那本正反各半的小账仍然一个字不改。

BOX[remember]: 比例靠近一半，靠的不是"补回来" :: 前 99 次正面**永远不会被抵消**，它们已经写进记录。比例后来可能靠近一半，靠的是后面越来越多的新结果把这段开头稀释：固定的 99 个，在一万次、百万次的总数里占得越来越小。// 后面的反面不需要故意多出来还债；每一次仍各半，许多次合起来的账自己会显出规律。// **不是还债，是稀释。**把硬币想成会补账，长大以后叫**赌徒谬误**。

BOX[key]: 账内计算和账外查验，是两个问题 :: **如果"公平而且各次独立"是题目已经给定的规矩**，第一百次就是 [[1/2]]；99 次正面不改答案。// **如果这是桌上一枚来历不明的真硬币**，99 次正面会让姐姐回头检查：硬币是否做过手脚、抛法是否真的相同。那是在怀疑第五篇放进去的模型，不是在宣布反面该来还债。// // 看到怪记录，可以查机器；只要机器的规矩没改，不能拿历史替下一次改账。

## 五、翻车二：比例靠拢了，"多出几个"反而越来越大

这一条更深，也更容易被上一节的说法带偏。

既然比例挤向一半，是不是**正面和反面的次数也越来越接近**？

**恰恰相反。**我们把"抛 n 次"这件事**重做 200 遍**，每遍记下"正面比反面多出几个"（不管正负，只看差多少），取平均：

TABLE:
| 抛了多少次 | 正反次数差（200 遍的平均） | 比例离一半差多少（200 遍的平均） |
| 10 | 2.6 | 0.1305 |
| 100 | 8.3 | 0.0413 |
| 1000 | 26.5 | 0.0132 |
| 10000 | 72.1 | 0.0036 |

**两列往相反的方向跑。**次数差从 2.6 长到 72.1，一路变大；可比例的偏差从 0.13 缩到 0.0036，一路变小。

BOX[key]: 为什么不矛盾 :: 因为**比例就是"次数差"除以"抛的次数"**。// 次数差是在变大，**可分母变得更快**：次数差长了不到 30 倍，分母长了 1000 倍。// // 所以"大数定律"保证的是**比例**靠拢，// **它从来没保证过"正面和反面的个数会扯平"。**// 想着"抛得够多，正反就该一样多了"——**那是又一次赌徒谬误，只是穿了件更聪明的衣服。**

## 六、回头望一眼那个圆

现在可以给第二篇那 30 次一个交代了。

**姐姐做的那 30 次没有白做**：它让你亲眼看见三种做法给出三个不一样的数。这一点，30 次就够了——**因为三个真值 [[1/3]]、[[1/2]]、[[1/4]] 离得够远**。

**但 30 次不足以说出每个数具体是多少**：13 除以 30 是 0.43，真值却是 0.31。

BOX[key]: 回头望一眼那个圆 :: 第二篇你做的那 30 次，就是这一篇的现场。// **它足够看出三种机器不一样**（三个数差得很明显）；它不足以把每本账量准（那要更多次，或者第十一篇直接计算）。// // 顺带回答开篇的第二问：数出来的频率凭什么能拿来查可能性？// **因为在同一套机制反复、各次没有互相照抄时，不合格的整块记录会分到越来越少的份。**这句话后面永远带着"几乎"，也永远带着对重复办法的要求。
