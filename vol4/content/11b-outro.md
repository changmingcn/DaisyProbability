# 尾声　抛不完的硬币

CENTER: 这一册一直守着有限的世界——最后这几页，把门推开一条缝

第十一篇已经结案了。可这一整册，其实一直在用一样东西，却从来没给它起过名字——**那本账**。

这个尾声不开新案子，只把这本账拿出来翻给你看：它**能记多少**、有什么**规矩**、撑不撑得住**没有底的东西**、拿它到底能**干什么**。门外那三样一直等着的——**无穷**（第一篇 C3、第三篇 C4 各欠了一笔账）、**一个号称必胜的赌法**、还有一句怪话**知道了现在，过去就多余**——说到底都是这本账的事。**看清楚这本账，你就知道长大以后的概率论住在哪儿。**

## 一、有限世界里，这本账已经在手上

BOX[dialog]: 妹妹最后追问一次 :: **妹妹：**"讲了整整一本书，你还是不能告诉我下一把掷出几。"// **姐姐：**"对。概率分布不是替某个点作保；它一次给许多事件分账。真正掷下去，只落一格；掷以前，整本账都得先站得住。"// **妹妹：**"所以你预测的不是那一格？"// **姐姐：**"我预测的是每一块各占多少——包括只圈一格的事，也包括许多格拼成的事。"

把两个骰子的 36 格表再摆一次：同一张表可以圈**加起来小于 5**、**至少一个 6**、**红的比蓝的大**。实际结果只落一格，三个圈却在掷以前就各有一个数。

FIG: fig-p17-three-blocks.png | 同一张 36 格的单子，圈出三件不同的事：加起来小于 5 是 6 格、至少有一个 6 是 11 格、红的比蓝的大是 15 格。实际只落一格，预测却同时管住所有圈法。

每一格都可以圈进、也可以不圈进，36 格一共有六百八十七亿多种圈法。有限世界里，第三篇那张分布因此一次回答了一整族事件；第八篇再把每格翻译成数，复杂的随机变量就有了期望，拿来打赌时就是公平价。

BOX[key]: 这一册已经做完的事 :: **机器**说明结果怎样来；**概率分布**给结果单分那个 1；**事件**把结果拼成可问的块；**组合与条件**说明两台机器和消息怎样改账；**期望**把整本账压成价格。// 概率论不承诺点名最后落地的结果，它承诺这些数彼此相容：互斥的块能相加，反面补到 1，分步定价合回总价。// **有限时，每一块都记得了账；账全，组合和赌局才站得住。**

BOX[grown]: 长大以后的分界 :: 给块记大小的函数叫**测度**（measure）；总数正好是 1 的叫**概率测度**。长度、面积和本册的概率，都是这种账。// 杜雷特（Durrett）的原话是：**Measure theory ends and probability begins with the definition of independence.**这是一句划分工作重心的名言，不是说独立性跑到了测度论外面。独立本身仍用概率测度定义，乘积测度也能造出独立的合账。// 更准确地读：**测度论守住哪些块能记、怎样叠、无穷叠时账怎样不断；概率论再给随机机器接线，研究独立与依赖、消息与重复。**第六篇是这道门，不是因为依赖的东西不能组合，而是因为独立让两本小账直接乘出合账。

在有限的 36 格里，怎么圈、怎么合、怎么取共有、怎么走反面，出来的仍是原来的几格，当然记得了账。这条封闭性几乎白送。

可接下来有两样没有底的东西：一张永远写不完的结果单，一根绳子上无穷多个位置。到了那里，**哪些块能记、叠个没完还能不能记**，不再白送。

CENTER: **有限时白送的账本家规，到了无穷还撑得住吗？**

## 二、一张没有底的结果单

BOX[dialog]: 妹妹出新招 :: **妹妹：**"新赌局。一直抛硬币，**抛到第一次出正面就停**。我赌**第三次或者更晚**才停。// 这个你还能摆结果单吗？它没有个头啊。"// **姐姐：**"能摆。就是这张单子自己也**没有个头**——你看。"

姐姐把单子摆了出来：

TABLE:
| 结果 | 说的是什么 | 分到的份 |
| 正 | 第一次就停 | [[1/2]] |
| 反 正 | 第二次停 | [[1/4]] |
| 反 反 正 | 第三次停 | [[1/8]] |
| 反 反 反 正 | 第四次停 | [[1|16]] |
| …… | 一直写下去，写不完 | 每行是上一行的一半 |

**这是这本书里第一张无穷长的结果单。**两条家规还管不管用？

家规一好查：每行的份都不是负的，过。家规二要加起来正好是 1——**可这里有无穷多行，怎么加？**

**这正是第一册练过的本事。**一行一行往下加：加到第二行是 [[3/4]]，加到第三行是 [[7/8]]，加到第 n 行，**差 [[1|2^n]] 就到 1**。这一册第九篇借过第一册的"挤向"，这里再借一次：**这列越加越长的和挤向 1，而且除了 1 哪儿也去不了。**所以家规二也过关：

CENTER: **那个 1 分得完——虽然要分给无穷多行。**

（妹妹的赌局顺手就算掉了：第三次或更晚才停，就是前两次都是反面，[[1/4]]。）

第三篇 C4 问过**一直掷到出正面为止，"加起来是 1"还说得通吗**，当时明说正文不回答。**现在回答了：说得通**——用的是第一册的部分和。这笔账怎么记，附录 D 里更新了。

### 有一行还没写上去

单子上其实漏了一行：**"永远不出正面"**。

它必须在单子上。**没有任何规矩禁止它**——第九篇姐姐说过，**抛一万次全是正面，并没有被禁止**；一直反面抛下去，同样没有被禁止。

可它分到多少？它要发生，前 10 次就得全是反面，所以它的份**不能超过** [[1|1024]]；前 100 次也得全是反面，所以**不能超过** [[1|2^{100}]]；前一千次、一万次……**它的份比 [[1/2]]、[[1/4]]、[[1/8]] 这道梯子上的每一级都小**，又不能是负的（家规一）。这样的数只有一个：

CENTER: **0。**

BOX[remember]: 份是 0，不等于被删掉 :: "永远不出正面"**在结果单上有座位**：没有哪一条有限的抛法规则把它删掉。可它在账上分到 0。// 这正是第九篇那个"几乎"走到无穷以后的样子：有限次数里，全正或全反始终有一小份；让次数没有尽头，那份沿着 [[1/2]]、[[1/4]]、[[1/8]]……一直压到 0。// 长大以后，一件事的反面只剩份是 0 的结果，就说这件事**几乎必然**发生。**几乎必然不是逐个结果打包票，而是把所有例外合起来量，量到 0。**

**第一关，账本过了。**这张单子写不完，那个 1 仍然分得下去；"永远不出正面"也有账，是 0。只是家规二从有限相加变成无穷相加，借用了第一册的极限本事。

下一关就没这么客气了。

## 三、"随便点一个点"，到底怎么点

第一篇 C3 问过：一根绳子上有无穷多个位置，**剪在正好第 30 厘米那一个点上**，可能性是多少？你多半答了 0，心里发虚：**0？那到底还剪不剪得到？**

这一节把这件事做实。先过全册的第一道门："在绳子上随便点一个点"，**随机机器到底是什么？**绳子上的点无穷多，不像骰子六个面数得清；可取法仍然可以说清。

你玩过猜数字：一个人心里想一个数，另一个人猜，答"大了""小了"，**每答一次，范围就掐掉一半**。现在，让硬币来替你答。

BOX[remember]: 一台造点的机器 :: 拿一根 1 米的绳子抛硬币：**正面留左半，反面留右半**；对留下的半段再抛、再留一半，一直做下去。// 段长从 1 米变半米、[[1/4]] 米……要多短有多短。每个位置要么迟早被掐掉，要么一直留下；最后只指向一个点。// 机器永远停不下来，取法却说清了：**一串抛不完的硬币，指定绳子上的一个点。**

FIG: fig-p14-rope-halving.png | 正面留左半，反面留右半：每抛一次，剩下的段短一半。抛不完的硬币，指向绳子上的一个点。

现在先查左半段：点落在**左半段**，正好等于第一次抛出正面，份是 [[1/2]]；左半段也正好占全长的一半。继续掐下去，每一段都由前几次正反指定，份与它占全长的比例相同。

CENTER: **落在哪一段的份，就是那一段占的长度。**

第一篇剪绳子，你按长度比算得理直气壮；**现在你知道它背后真有一台机器在转——零件全是互不影响的硬币。**

落在**正好某一个点**上呢？每一次掐半都得选对边，份依次不超过 [[1/2]]、[[1/4]]、[[1/8]]……最后是 0。第二节的永远不出正面也是同一形状：一个具体的无穷结果可以留在单子上，却分到 0。

BOX[key]: 这一节真正的翻车 :: 每一个点的份都是 0；可左半段的份是 [[1/2]]。// **半段是由点组成的——0 加 0 加 0……怎么加得出 [[1/2]]？**// 加不出。有限表格里逐项收份的办法，到这里真的断了——不是我们不会加，是这条路根本不通。// 出路你其实已经看见了：**别从点的份往上加，直接给段记长度。**// 第一篇、第二篇拿长度比和面积比算得理直气壮，靠的正是这种**以可问的块为对象**的账。

新账本还有一道关要过——有限时白送的**怎么叠**。第四篇用合起来、取共有、走反面拼事件；到了绳子上，每拼一步，出来的块仍得记得了账。比如**左半段或最右边四分之一**是两段合起来，份是 [[1/2]] 加 [[1/4]]，也就是 [[3/4]]；换成共有或反面，账也不能断。

CENTER: **你怎么叠，账本就得跟到哪儿——叠出来的每一块，都得记得了账。**

BOX[key]: 账本要跟得上 :: 一件事是圈一块，复杂的事由简单的块合、共有、反面而来。第四篇在有限单子上这么拼，这里在绳子上仍这么拼。// 新账本不能只答应**一段记长度**；它还得答应：**一步一步叠个没完，叠出来的块仍在账上，份数也跟着极限不断线。**// 有限时白送的封闭与可加，到了无穷必须写成严密家规。**这正是概率工具最终落到测度论地基上的地方。**

BOX[grown]: 长大以后的写法 :: 能记账的块叫**可测集**；哪些块准进账、可数次并交补以后仍准进账，这套家规叫 **σ-代数**。绳子和圆上的标准名单叫 **Borel 集**。概率事件正式说就是可测集，概率测度守可数可加性。// Durrett 那句话标出的是重心变化：独立仍可由乘积测度严密构造；测度守账，独立与依赖说明机器怎样接，条件化说明消息怎样改账。

## 四、妹妹的必胜妙计

前两节拿没有底的东西去撞账本，账本撑住了。**这一节换个方向：账既然是全的，能拿它干什么。**

妹妹马上送来一个最好的例子——**一套花哨到看不出破绽的赌法**。

BOX[dialog]: 这回必胜 :: **妹妹：**"抛硬币押正面：先押 1 块，输了押 2 块，再输押 4 块……只要后来出一次正面，前面的全捞回，还净赚 1 块。总会出正面吧？"// **姐姐：**"算术全对。我只问一句：**你口袋里有多少钱？**"

妹妹一愣："7 块。"

姐姐说：那你最多押三把——1 块、2 块、4 块。第三把再输，你一分不剩，**想翻倍也翻不动了**。姐姐把这套赌法的结果单摆出来（这张单子四行长短不齐、份也不一样多，可第八篇的期望照算不误）：

TABLE:
| 怎么走 | 口袋里的变化 | 份 |
| 正 | 赚 1 块 | [[1/2]] |
| 反 正 | 赔 1 赚 2：净赚 1 块 | [[1/4]] |
| 反 反 正 | 赔 3 赚 4：净赚 1 块 | [[1/8]] |
| 反 反 反 | 1、2、4 全赔进去：**赔 7 块** | [[1/8]] |

赚钱的三行合起来：1×[[1/2]] ＋ 1×[[1/4]] ＋ 1×[[1/8]] ＝ [[7/8]] 块。
赔钱的那一行：7×[[1/8]] ＝ [[7/8]] 块。

CENTER: **赚的和赔的一样重。期望（公平价）：0。**

电脑拿 7 块口袋玩 200 回合：赢 1 块的回合 171 次，赔 7 块的回合 29 次，总账净赔 32 块。多数时候的小赢挡不住少数时候的悬崖。

FIG: fig-p15-double-bet.png | "必胜妙计"玩 200 回合的总账：缓坡是一块一块地赚，悬崖是一把赔光。这条路一度赚到 40 块——最后停在赔 32 块。

BOX[key]: 妙计的藏身处 :: 口袋越深，翻车越少，**可翻一次赔得越狠，两头正好打平**。口袋只要有底，期望就是 0。// 永远不出正面的份虽然是 0，"总会赢"要变成"稳赚 1 块"，你还得真有钱撑到那一把。所谓必胜，偷偷借了一个**没有底的口袋**。

换个押法也绕不过去：赌注可以看历史再定，可下一枚独立硬币仍各半，所以这一把无论押多少，条件期望都是 0。第十篇塔性质把每条历史下的 0 合回去，整套有限赌法的期望仍是 0。

CENTER: **消息能改变你怎么押，改变不了下一枚硬币。**

最后回头看一眼开篇。**分金那条价钱的路，走的正是这种不涨不跌的步子：**

FIG: fig-p16-split-fair.png | 从 0 比 0 到妈妈喊停：每个局面的价，都是下一局两种明天的平均——56 和 32 平均是 44，48 和 16 平均是 32，64 和 32 平均是 48。

开打前局面值 32；1 比 0 的两种明天值 56 和 32，平均是 44；2 比 1 的两种明天值 64 和 32，平均是 48。**每一个价，都是下一局两种明天的平均。**

BOX[key]: 妈妈在哪儿喊停都公平 :: 价钱这条路每走一步，平均下来不涨不跌。妈妈在哪一步喊停，按当时的价分钱，对两人都不占不亏：2 比 1 分 48，1 比 1 分 32，没开打就各拿回 32。// 开篇的不猜下一局、给整场局定价，到这里有了完整理由：**每个今天的价，都是所有明天按份合回来的价。**

BOX[grown]: 长大以后的写法 :: 随消息前进、条件期望一步不涨不跌的过程叫**鞅**（martingale）；这个词本来就与翻倍下注法有关。消息怎样逐步放出叫**信息流**。何时停下仍保持公平的一般条件属于**可选停时定理**；本册只算了口袋有底的简单情形。

## 五、妹妹的伞

账本还有最后一件事没看：**消息来了，账要重记。**第七篇教过怎么重记（划掉不符合的，剩下的重新分），第十篇教过重记以后的条件期望。这一节看的是重记带来的一个古怪后果。

BOX[dialog]: 出门之前 :: **妹妹：**"只要我书包上挂伞，你书包上十有八九也挂着。我的伞管着你的伞？"// **姐姐：**"不是伞管伞，是天气同时管着两把伞。你的伞能报信，只因为它捎带了天气的消息。"

两把伞确实互相报信，却没有谁指挥谁。按姐姐刚才说的这台简单机器，机关仍是第七篇的**消息来路**：一旦已经知道今天下雨，再看妹妹的伞就没有新消息，姐姐那本账不会再变。

BOX[remember]: 知道了中间人，报信有时会断 :: 两件事互相报信，有时因为背后站着同一个**中间人**。如果中间人的消息到手以后，再知道一件事也不改变另一件的账，就说它们在这条消息下**条件独立**。// 在姐姐给出的简单天气模型里，不知道天气，两把伞互相报信；知道天气，再看一把伞就不改另一把的账。// **不是随便找个第三样东西就行；要实际检查，消息到手以后，两本账还会不会互改。**

走格子的棋再往前一步：下一步只看现在站哪格，不再看怎样走到这里。长大以后，这类**知道现在，过去不再添消息**的过程叫**马尔可夫链**。它与鞅都研究消息逐步到来：一个管下一步怎样接线，一个管条件平均怎样变化。**你知道了什么、又是怎么知道的**，始终是第一问。

## 六、门缝里看见的

BOX[key]: 这本账，翻完了 :: 正文先在有限世界里完成了四层工作：**定机器，给事件记账，给随机来源接线，让账随消息更新。**期望把整本账压成价格，大数定律说明独立重来许多次会显出整体规律。// 尾声只补地基：结果单写不完，那个 1 仍能分；单点的份可以是 0，事件却仍能有正的大小；合、共有、反面一直叠下去，账也必须不断线。把这些家规写严密，就是测度论。// // 测度不是概率论结束的地方，而是它站稳的地面；独立也不是唯一的组合，而是最简单的接线。再往前走，鞅、马尔可夫链和更多现代概率工具，都在研究同一件事：**消息一步一步来时，整本账怎样变，而新的随机怎样接上旧的历史。**

BOX[task]: 留给姐姐和妹妹 :: **一、**第二节那张无穷结果单：**第五次或更晚**才停的份是多少？（提示：前四次得怎么样？）// **二、**口袋 15 块，翻倍下注能押几把？摆出结果单，验一验公平价还是 0。// **三、**用第七篇**划掉、重分**的办法说一遍：为什么**知道了下雨**以后，妹妹的伞就报不了信了？// **四、**那台造点的机器怎样改，才能在圆周上均匀造一个点？它造出的正是第二篇端点法要的那种端点。

CENTER: **第一册的副题问：不能做完无穷，怎么谈论无穷。**

CENTER: **这一册走到门口，递回去一句话：下一次仍然不肯报答案；把机器说清、把事件摆齐，连抛不完的硬币也能记成一本账。**
