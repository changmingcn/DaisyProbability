# 尾声　抛不完的硬币

CENTER: 这一册一直守着有限的世界——最后这几页，把门推开一条缝

第十一篇已经结案了。可是有三样东西，一直在门外等着：**无穷**（第一篇 C3、第三篇 C4 各欠了一笔账）、**一个号称必胜的赌法**、还有一句怪话——**知道了现在，过去就多余**。这个尾声不开新案子，只把门推开一条缝，让你看它们一眼——**看清楚了，你就知道长大以后的概率论住在哪儿。**

## 一、一张没有底的结果单

BOX[dialog]: 妹妹出新招 :: **妹妹：**"新赌局。一直抛硬币，**抛到第一次出正面就停**。我赌**第三次或者更晚**才停。// 这个你还能摆结果单吗？它没有个头啊。"// **姐姐：**"能摆。就是这张单子自己也**没有个头**——你看。"

姐姐把单子摆了出来：

TABLE:
| 结果 | 说的是什么 | 分到的份 |
| 正 | 第一次就停 | [[1/2]] |
| 反 正 | 第二次停 | [[1/4]] |
| 反 反 正 | 第三次停 | [[1/8]] |
| 反 反 反 正 | 第四次停 | [[1|16]] |
| …… | 一直写下去，写不完 | 每行是上一行的一半 |

**这是这本书里第一张无穷长的结果单。**两条家规还管不管用？

家规一好查：每行的份都不是负的，过。家规二要加起来正好是 1——**可这里有无穷多行，怎么加？**

**这正是第一册练过的本事。**一行一行往下加：加到第二行是 [[3/4]]，加到第三行是 [[7/8]]，加到第 n 行，**差 [[1|2^n]] 就到 1**。这一册第九篇借过第一册的"挤向"，这里再借一次：**这列越加越长的和挤向 1，而且除了 1 哪儿也去不了。**所以家规二也过关：

CENTER: **那个 1 分得完——虽然要分给无穷多行。**

（妹妹的赌局顺手就算掉了：第三次或更晚才停，就是前两次都是反面，[[1/4]]。）

第三篇 C4 问过**一直掷到出正面为止，"加起来是 1"还说得通吗**，当时明说正文不回答。**现在回答了：说得通**——用的是第一册的部分和。这笔账怎么记，附录 D 里更新了。

### 有一行还没写上去

单子上其实漏了一行：**"永远不出正面"**。

它必须在单子上。**没有任何规矩禁止它**——第九篇姐姐说过，**抛一万次全是正面，并没有被禁止**；一直反面抛下去，同样没有被禁止。

可它分到多少？它要发生，前 10 次就得全是反面，所以它的份**不能超过** [[1|1024]]；前 100 次也得全是反面，所以**不能超过** [[1|2^{100}]]；前一千次、一万次……**它的份比 [[1/2]]、[[1/4]]、[[1/8]] 这道梯子上的每一级都小**，又不能是负的（家规一）。这样的数只有一个：

CENTER: **0。**

BOX[remember]: 份是 0，不等于"不可能" :: 开篇就说过，这门学问要**去看那些永远不会发生的事**——现在你见到最极端的一种了。// "永远不出正面"**在单子上有座位**：谁也禁止不了它。// 可它**在账本上没有钱**：分到的份是 0。// // 第九篇姐姐不肯打保票，因为"全是正面"没有被禁止。到了**抛不完**的世界里，这句话有了新说法：// **这种事座位还在，份已经是 0。**长大以后，人们管"对手只剩份是 0 的行"叫**几乎必然**——// 第九篇那个"几乎保票"，用的正是同一个"几乎"。

## 二、"随便点一个点"，到底怎么点

第一篇 C3 问过：一根绳子上有无穷多个位置，**剪在正好第 30 厘米那一个点上**，可能性是多少？你多半答了 0，心里发虚：**0？那到底还剪不剪得到？**

这一节把这件事做实。先问一个更根本的问题。这一册的中心句是**说不清怎么取，就没有答案**——那么"在绳子上随便点一个点"，**这个"随便"的取法，到底说得清说不清？**绳子上的点无穷多，又不像骰子那样六个面数得清，看着没法下手。

你玩过猜数字：一个人心里想一个数，另一个人猜，答"大了""小了"，**每答一次，范围就掐掉一半**。现在，让硬币来替你答。

BOX[remember]: 一台造点的机器 :: 拿一根 1 米的绳子，抛一枚硬币：// **正面——留左半段；反面——留右半段。**// 对留下的半段再抛、再留一半；**一直抛下去，不许停。**// 留下的段：1 米、半米、[[1/4]] 米……**要多短有多短**（第一册的老话）。// 无穷多次是抛不完的；可**每个位置要么迟早被掐掉、要么一直留着**，而一直留着的位置只有一个——// **做不完，可谈得清：第一册整本书教的正是这件事。**// 这台机器停不下来，可它指向的那**一个点**是确定的：**这就是"随便点一个点"的操作说明书。**

FIG: fig-p14-rope-halving.png | 正面留左半，反面留右半：每抛一次，剩下的段短一半。抛不完的硬币，指向绳子上的一个点。

现在**查账**。这台机器点出来的点：

- 落在**左半段**？只要第一次是正面：份 [[1/2]]。左半段占全长——**正好一半。对上了。**
- 落在**最左边四分之一**？头两次都是正面：份 [[1/4]]。占全长——**[[1/4]]。又对上了。**
- 落在随便哪一段"掐半掐出来"的段上：**份，永远等于这段占全长的比。**

CENTER: **落在哪一段的份，就是那一段占的长度。**

第一篇剪绳子，你按长度比算得理直气壮；**现在你知道它背后真有一台机器在转——零件全是互不影响的硬币。**

那，落在**正好某一个点**上呢？机器要点中它，**每一次掐半都得掐对边**：第一次就得对，份不超过 [[1/2]]；头两次都得对，不超过 [[1/4]]……又是那道下不完的梯子——**份是 0**。这和上一节"永远不出正面"是**同一笔账**：把"正"念成"左"，那一行就是"每一次都往左"的点，绳子的最左端。第一篇 C3 的答案就这么做实了：**是 0，而且不奇怪。**

BOX[key]: 这一节真正的翻车 :: 每一个点的份都是 0；可左半段的份是 [[1/2]]。// **半段是由点组成的——0 加 0 加 0……怎么加得出 [[1/2]]？**// 加不出。**"把每一格的份加起来"这套办法，到这里是真的断了**——不是我们不会加，是这条路根本不通。// 出路你其实已经看见了：**别给点记账，给段记账。**段的账是现成的——**长度**。// 这一册第一篇、第二篇拿长度比、面积比算得理直气壮，**靠的正是这本"只记段、不记点"的账。**

新账本还有一道关要过。第四篇教过你怎么把简单的事**叠**成复杂的事：圈一块是一件事；"**或**"，是把两个圈**合起来**；"**而且**"，是只要两个圈**共有**的部分；"至少"，走**反面**。到了绳子上，这些动作一个都不能少——而且每叠一步，**叠出来的那一块都得还能记账**：

- "落在**左半段，或者最右边四分之一**"——两段**合起来**。两块不重叠，账就是两笔相加（第四篇的老规矩）：[[1/2]] ＋ [[1/4]] ＝ [[3/4]]。
- "**不落在**中间那一段"——走**反面**：1 减去那一段的长。
- "落在**右半段，而且**落在**前 75 厘米**里"——取两段**共有**的部分：从 50 厘米到 75 厘米那一段，长 [[1/4]]。

CENTER: **你怎么叠，账本就得跟到哪儿——叠出来的每一块，都得记得了账。**

而且这个尾声，其实已经两次**把叠加偷偷做到了无穷步**：第一节那行**永远不出正面**，是无穷多件事**一件套一件**地同时成立（前 10 次全反、前 100 次全反、前一千次全反……）；这一节**点中一个点**，是无穷多段**一层套一层**地套下去（左半段、它的右半段、再它的左半段……），最后只剩那一个点。**两个"份是 0"，都是账本跟着无穷步叠加、一路没断线才记下来的。**

BOX[key]: 概率的事，全在"叠"里 :: 一件事，是圈一块；复杂的事，是简单的块**叠**出来的——合起来、取共有、走反面。**第四篇在有限的单子上这么干，这里在绳子上还是这么干。**// 所以那本新账本真正要做到的，不只是"段记长度"这一条，而是：// **不管你怎么叠——合、共有、反面，哪怕一步接一步叠个没完——叠出来的块，全都还得在账本上。**// **测度论和概率论，就在这句话上会师。**

BOX[grown]: 长大以后的写法 :: 这本"只记段（或块、或片）、不记点"的账法，长大了叫**测度论**：法国数学家**勒贝格**在 1902 年前后把它记严实了。能记账的块叫**可测集**；账本的头一条规矩，正是上面那句——**可测集"或"起来（叫作两块的"并"）、"而且"起来（叫"交"）、翻个反面（叫"补"），出来的还得是可测集**，一步接一步排成队叠个没完也一样；这套规矩叫 **σ-代数**（念"西格玛代数"）。// 在绳子和圆上，**从段出发、用并交补叠得出来的所有块**，有个专门的名字：**博雷尔集**（Borel set）——纪念法国数学家**博雷尔**（Borel）。他是勒贝格的老师，也是最早把"抛不完的硬币"当真研究的人之一。概率论给**一件事**下的正式定义，就是**一个可测集**；把事叠起来的三个动作，账本里全有对应——**合起来是并、取共有是交、走反面是补**。第四篇在结果单上圈块的那套功夫，原封不动搬进了测度论的账本。// // 大学的概率教科书里有一句名言（杜雷特，Durrett）：**测度论到"独立"的定义为止，概率论从这里开始。**// 意思是：结果单、家规、事件怎么叠、翻译机、公平价，这些**记账的功夫**，测度论全包了；// 可**"两枚硬币互不影响"这句话，账本里没有**——它是概率论自己的第一句话。// 你刚才亲眼看过它的分量：账本只管到"段记长度"；**真正把点造出来的，是"每一次抛硬币互不影响"。**

## 三、妹妹的必胜妙计

BOX[dialog]: 这回必胜 :: **妹妹：**"我想出一个**必胜**的赌法。抛硬币，我押正面：先押 1 块，赢了就收手，净赚 1 块。// 输了？下一把押 2 块。再输，押 4 块，再输押 8 块……**总有一把会出正面吧！**// 那一把把前面输的全捞回来，还多赚 1 块。你算：第二把才赢，先赔 1 再赚 2，**净赚 1**；// 第三把才赢，赔了 1 加 2 是 3，赚回 4，**还是净赚 1**。稳赚不赔！"// **姐姐：**"算术全对。我只问一句——**你口袋里有多少钱？**"

妹妹一愣："7 块。"

姐姐说：那你最多押三把——1 块、2 块、4 块。第三把再输，你一分不剩，**想翻倍也翻不动了**。姐姐把这套赌法的结果单摆出来（这张单子四行长短不齐、份也不一样多，可第八篇的公平价照算不误）：

TABLE:
| 怎么走 | 口袋里的变化 | 份 |
| 正 | 赚 1 块 | [[1/2]] |
| 反 正 | 赔 1 赚 2：净赚 1 块 | [[1/4]] |
| 反 反 正 | 赔 3 赚 4：净赚 1 块 | [[1/8]] |
| 反 反 反 | 1、2、4 全赔进去：**赔 7 块** | [[1/8]] |

赚钱的三行合起来：1×[[1/2]] ＋ 1×[[1/4]] ＋ 1×[[1/8]] ＝ [[7/8]] 块。
赔钱的那一行：7×[[1/8]] ＝ [[7/8]] 块。

CENTER: **赚的和赔的一样重。公平价：0。**

口袋深一些呢？63 块，能押六把（1＋2＋4＋8＋16＋32＝63）：赢 1 块的机会涨到 [[63|64]]——**可剩下那 [[1|64]]，一把赔光 63 块**。63×[[1|64]] ＝ [[63|64]]，和赚的那头**又打平了**。

不信账本，就看现场。我们让电脑拿着 7 块的口袋，把这套妙计玩了 **200 回合**（每回合从押 1 块开始，赢了收手，或者三连输赔光）：**赢 1 块的回合 171 次，赔 7 块的回合 29 次**——赔光的份是 [[1/8]]，200 回合摊 25 次上下，跑出 29 次，正是第九篇说的**晃**。总账：**净赔 32 块**。

FIG: fig-p15-double-bet.png | "必胜妙计"玩 200 回合的总账：缓坡是一块一块地赚，悬崖是一把赔光。这条路一度赚到 40 块——最后停在赔 32 块。

BOX[key]: 妙计的藏身处 :: 口袋越深，翻车越稀罕，**可翻一次赔得越狠——两头永远正好打平**。口袋无论多深，**只要有底**，公平价就是 0。// 妹妹那句"**总有一把会出正面吧**"，单看没有错——上一节刚算过，"永远不出正面"的份是 0。// 可"总会赢"要兑现成"稳赚 1 块"，你得**撑得到那一把**。撑到无论哪一把都不倒，要的是一个**没有底的口袋**。// **无穷在这个尾声出场三次：前两次它进了结果单；这一次，它是必胜妙计的全部本钱。**

妹妹还会不服：那我换个赌法呢？不翻倍，翻三倍？看情况再定？——**随便什么赌法，只要口袋有底，公平价都是 0。**这不用一套一套去算，第十篇的塔性质一句话管完。

消息是一把一把来的，每来一把，世界缩小一圈（第七篇）。你尽可以按**已经看到的**输赢决定下一把押多少——可**下一枚硬币不认识你的历史**：第六篇的互不影响，第九篇的**硬币没有记性**。所以无论这一把你押多少（叫它 a 块），**这一把本身的公平价都是 0**——赚 a 和赔 a，各占一半。整套赌法的公平价，按塔性质**分两步问**：先在每条消息下问这一把（条条是 0），再按消息的份平均回去——**0 平均来平均去，还是 0**。

CENTER: **消息能改变你怎么押，改变不了下一枚硬币。**

最后回头看一眼开篇。**分金那条价钱的路，走的正是这种不涨不跌的步子：**

FIG: fig-p16-split-fair.png | 从 0 比 0 到妈妈喊停：每个局面的价，都是下一局两种明天的平均——56 和 32 平均是 44，48 和 16 平均是 32，64 和 32 平均是 48。

开打前 0 比 0，两人对等，局面值 **32**。第一局姐姐赢了，1 比 0 值多少？再打一局：赢了到 2 比 0（那个局面值 56），输了回 1 比 1（值 32）——两种明天平均，**44**。接着 1 比 1 值 32，2 比 1 值 48：**每一个价，都是下一局两种明天的平均**（塔性质，第十篇）。

BOX[key]: 妈妈在哪儿喊停都公平 :: 这才是帕斯卡那个分法**真正公平**的地方：// 价钱这条路，**每走一步，平均下来不涨不跌**。// 所以妈妈**随便哪一步喊停**，按当时的价分钱，对两人**都不占不亏**：// 停在 2 比 1 分 48，停在 1 比 1 分 32，压根没开打就散伙，各拿回 32。**每一种停法都公平。**// 开篇那句**别看打完的，看没打完的**，现在有了第二层意思：// **在这条价钱的路上，往回看没有用，往前看不吃亏。**

BOX[grown]: 长大以后的写法 :: "不管消息怎么来、赌注怎么调，价一步也不涨不跌"的赌局，长大了叫**鞅**（法文 martingale）——这个词本来就是"翻倍下注法"的名字：**数学家把赌徒的妙计没收了，改造成自己的中心概念。**// 现代概率论大半部书写的就是它：**消息一步一步放出来**（术语叫"信息流"），**每一步的新账，在旧账看来都不占便宜**。// 至于"口袋有底就赢不了"的一般说法，长大了叫**可选停时定理**——这一册只算了最简单的情形，账记在附录 D。

## 四、妹妹的伞

BOX[dialog]: 出门之前 :: **妹妹：**"我发现一件怪事。**只要我书包上挂了伞，你书包上十有八九也挂着伞。**// 我的伞管着你的伞？咱们俩明明没商量过！"// **姐姐：**"不是你的伞管我的伞，**是天管着咱们俩的伞**。// 早上要下雨，你带伞，我也带伞；天晴，咱们都不带。// 你看见我的伞，确实能猜到你的伞——**可那不是伞在影响伞，是它们背后站着同一个天。**"

这件事值得慢慢想。两把伞**确实互相报信**：看见一把，另一把八九不离十——按第六篇的说法，它们**不是**互不影响。可它们之间**并没有谁指挥谁**。

机关在**消息的来路**（第七篇整篇讲的就是这个）：妹妹的伞能报姐姐的伞的信，是因为它**捎带着天气的消息**。那要是天气**已经知道了**呢——窗帘拉开看过了，今天下雨。这时候再看见妹妹的伞，**它还能多报什么信？什么也报不了了**：下雨天姐姐带不带伞，是下雨天的事，妹妹的伞插不上嘴。

BOX[remember]: 知道了中间人，报信就断了 :: **两件事互相报信，常常只是因为背后站着同一个"中间人"。**// 中间人的消息一旦到手，两件事就**恢复互不影响**——长大以后这叫**条件独立**：// 不知道天气时，两把伞不是互不影响；**知道了天气，它们就互不影响了。**// // 反过来的错，天天有人犯：**卖出去的冰淇淋越多的日子，游泳呛水的人也越多。**// 冰淇淋害人呛水？——**中间人是天热。**// 看见两件事一起动，先别断定谁管着谁，**先找找有没有第三样东西同时管着它们俩。**

再走一步，就看见现代概率论的另一根大梁。走格子的棋（飞行棋就算）：**你下一步会走到哪儿，只看你现在站在哪一格**——骰子还没掷，可规矩已经把"下一步"和"你是怎么走到这一格的"**隔开了**。这里的"现在"，就是那个中间人：**知道了现在，过去就成了废话。**

BOX[grown]: 长大以后的写法 :: "知道了现在，过去帮不上忙"的随机过程，叫**马尔可夫链**（俄国数学家马尔可夫，1906 年前后）——天气预报、网页排序、会下棋的电脑，里面都有它。// 它和上一节的鞅是亲戚，**都是"消息一步一步来"的学问**：一个说**知道了现在，过去多余**（条件独立），一个说**知道了现在，将来平均不涨不跌**（塔性质）。// 哈佛有位概率老师（布利茨斯坦，Blitzstein）有句口头禅：**条件化，是统计学的灵魂。****你知道了什么、又是怎么知道的**——永远是第一个要问清楚的事；第七篇的两个孩子、三扇门，问的全是它。
