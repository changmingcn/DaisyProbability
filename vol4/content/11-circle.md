# 第十一篇　回到那个圆

CENTER: 三台造弦机器，三份概率分布；同一句赌法，必须先说清楚究竟查哪一本账

## 一、三张结果单，摆在一起

第二篇那三种做法，第三篇已经把它们的结果单摆出来过。现在再看一遍，你的眼光应该不一样了：

TABLE:
| 做法 | 结果单上摆的是 | 假定什么一样可能 | 拿什么量 |
| 一、两个骰子挑两个端点 | 圆周上的**两个点** | 圆周上处处一样 | **弧长** |
| 二、半径上抽一个签 | 一条半径 ＋ 半径上的**一个位置** | 一条半径上处处一样 | **长度** |
| 三、往圆里撒一粒米 | 圆面上的**一个点** | 整个圆面上处处一样 | **面积** |

**三台机器，三张单子，三个假设，三把尺子。**它们各自写出一份完整分布，能回答自己账里的许多事件；可三本账之间没有理由数字相同。现在它们并排放着——答案不同，一点也不奇怪了。

## 二、一把量弦长的尺子

要真把三个答案算出来（不是数出来），还缺一件工具：**怎么一眼看出一条弦比三角形的边长还是短？**

BOX[task]: 请你亲手量一次 :: 画一个圆，画出它的内接正三角形（三条边一样长、三个角顶在圆上）。// **量一量：从圆心到三角形任意一条边的距离，是多少？**// 你会量到：**正好是半径的一半。**// // 再画几条弦，量一量每条弦的中点到圆心有多远：// **中点离圆心越近，弦越长；离得越远，弦越短。**（想想极端情形：中点就在圆心时，那条弦是直径，最长。）

把这两件事合起来，就得到一把尺子：

BOX[remember]: 判断一条弦长不长，只看它的中点 :: **中点到圆心的距离，比半径的一半近 → 这条弦比三角形的边长。**// **远 → 短。正好等于一半 → 一样长。**// // **这一册不证明它**，请你画出来、量出来、信下来。为什么不证，附录 D 里说了。// 但请你看清楚这把尺子有多好用：**它把"弦长不长"这个问题，变成了"中点落在哪儿"。**

FIG: fig-p13-three-answers.png | 同一把尺子，三种做法各自要问的问题不一样：落在哪段弧上、落在半径的哪一半、落在哪个小圆里。

## 三、三个答案，自己算出来

有了这把尺子，三个答案都能**算**出来了——而且用的正是第一篇那三种老办法：比弧长、比长度、比面积。

### 撒米法：比面积

中点是圆面上随便一点。要弦比三角形边长，中点得**落在"离圆心不到半径一半"的地方**——也就是**一个半径只有一半的小圆里**。

小圆和大圆的面积比是多少？半径变成一半，面积变成 **[[1/4]]**（圆面积按半径的平方走，一半的平方是四分之一）。

CENTER: **答案：[[1/4]]。**

### 半径法：比长度

中点在**一条半径上**随便取。这条半径长 1 个半径；要中点离圆心不到一半，它得落在**靠内的那半段**上。

长度比：**[[1/2]]**。

CENTER: **答案：[[1/2]]。**

### 端点法：比弧长

这一种要换个角度看。**先把一个端点钉住**（钉在哪儿都一样，圆是转得动的），就叫它 A 点。另一个端点在圆周上随便落。

从 A 出发画那个内接正三角形，另外两个顶点把圆周**分成三段一样长的弧**（三角形三个顶点均匀分布，所以三段各占 [[1/3]]）。

**另一个端点落在最远那一段弧上时，弦才比三角形的边长**——落在挨着 A 的那两段上，弦都比边短。

弧长比：三段里的一段，**[[1/3]]**。

CENTER: **答案：[[1/3]]。**

BOX[key]: 请你回头看一眼你用的工具 :: 三个答案，**一个都没有靠数数数出来**——全是算出来的。// 而算的时候，你用的是**第一篇第二节那几样**：比面积、比长度、比弧长。// **这些本事，你在第一篇就已经有了。**// 你当时缺的不是本事，是**没人告诉你：得先说清楚在比哪一样东西的大小。**

## 四、所以，三个都对

现在可以下结论了。

CENTER: **三个答案都对，因为它们忠实回答了三台不同机器里的同一类事件。**

BOX[remember]: 结案 :: 这不是数学出了矛盾，也不是概率不可靠；是那句问话少交了一台机器。// **"随便"两个字是一个空着的机器说明书。**// 填上**两个端点各自均匀来**，端点账给 [[1/3]]；填上**中点在一条半径上均匀来**，半径账给 [[1/2]]；填上**中点在圆面上均匀来**，面积账给 [[1/4]]。// 每一本内部都算得严密；先选哪一本，得由弦现实中怎样产生来决定。

## 五、那到底该填哪一个

数学到这里就交卷了：**它能算出每一种填法的答案，但它不替你选填法。**

选填法要看**这条弦到底是怎么来的**——那是现实里的事，不是算式里的事：

TABLE:
| 现实里的弦是怎么来的 | 该用哪张结果单 | 答案 |
| 两个人各在圆周上随便站一处，之间拉一根绳 | 端点法 | [[1/3]] |
| 一根长直棍随便扔在纸上，取它穿过圆的那一段 | 半径法 | [[1/2]] |
| 先在圆里随手戳一个点，再过这个点横切一刀 | 撒米法 | [[1/4]] |

BOX[key]: 说句老实话 :: 上面这张表也是**有商量余地的**——"一根棍子随便扔"这句话，本身还得再说清楚（棍子离圆心多远算随便？朝哪边算随便？）。// **说清楚一层，下面还有一层。**// // 历史上真有数学家为这件事吵过很久。有人提出：**挪一挪、放大缩小一下，答案都不该变**——照这条要求挑，该选 [[1/2]] 那一种。// **这套论证这一册不讲**（附录 D 记着），你只要收下一个念头：// **"哪种随便才自然"是可以讲道理的，但那已经是另一门功课了。**

## 六、结账：这一册变了什么，什么没变

TABLE:
| 你学到的 | 一句话 |
| 随机机器与结果单 | 先说明结果怎样来，再把所有可能摆齐——**一个不漏，一个不重** |
| 概率分布 | 把那个 1 分下去；一次预测一整家事件，不点名最后落地的结果 |
| 一件事 | 结果单上圈一块；圈里的份加起来，合、共有、反面都得守账 |
| 一样可能 | **是假设，不是定理**；先写账，再拿观察回来查账 |
| 独立 | 两台机器总能合；互不报信时，两本小账能直接乘出合账 |
| 条件概率 | 会报信也能合账，只是消息来了要在剩下的块里重新分 |
| 公平价 | 把分布和得失压成一个数；赌局相加**不要求独立** |
| 大数定律 | 同一机制独立重来，下一次仍未知，许多次的比例却几乎稳定 |
| 条件期望 | 消息对应许多小账；先分后合与一步算总账相同 |

BOX[key]: 回头望一眼那 64 块钱——它和这个圆是一对 :: 分金题也补了一局根本不会打的比赛，看着像自己挑拆法；圆题也有三种拆法。为什么一次只有一个价，一次却有三个？// **分金的机器由比赛规矩定死了**：每局公平独立地抛硬币、先到 3 分。补上的第二局只是把这台机器允许的未来摆完整；你没有另造随机。// **圆题没有给造弦机器**：端点、半径、圆面三种办法都能补完那句随便，却会写出不同的账。// // 所以旧主线仍是第一道门：**事情怎样发生说不清，账就没有唯一写法。**过门以后，概率论真正忙的才开始：圈事件、接机器、收消息、定价格，把许多问法放在同一本账里算。

BOX[key]: 回头望一眼那个圆——最后一眼 :: 第二篇留下的是：**真正要改的不是答案，是问题。**现在这句话有了两道门：// **第一道，机器是什么？**所有可能的结果怎样来，那个 1 怎样分？// **第二道，事件是什么？**你在这张结果单上究竟圈哪一块，要怎样同别的块组合？// // 往后碰到随便挑一个人、平均来说、正常情况下，都值得先过这两道门。// **概率论不替你点名下一次；它要求你先把机器和问题说清，再给整家事件记一套不打架的账。**
