# 第七篇　知道了一点消息

CENTER: 消息把世界变小了——在剩下的那一小块里，重新分一次那个 1

## 一、世界变小了

掷一个骰子，出 6 的可能性是 [[1/6]]。

现在有人偷看了一眼，告诉你：**"是偶数。"**

这一句话什么也没改变——骰子已经掷完了，点数早就定了。可**你手上的结果单变了**：1、3、5 已经不可能了，划掉。剩下 2、4、6 三项。

在剩下的三项里，6 占多少？——**[[1/3]]。**

CENTER: **同一件事，从 [[1/6]] 变成了 [[1/3]]。**

变的不是骰子，是**你知道的东西**。

BOX[remember]: 知道消息以后的可能性 :: **一、把不符合消息的结果，从单子上划掉。**// **二、在剩下的结果里，重新把那个 1 分一次。**// 原来各占多少份，现在还按原来的比例，只不过**总份数变小了**。// 这就是"知道了消息以后"的可能性。长大以后这个词叫**条件概率**。

**为什么可以"按原来的比例"？**因为消息只告诉你"不是 1、3、5"，它没说 2、4、6 之间谁更受宠。原来这三项一样多，现在还是一样多——**只是它们要分的那个 1，从六项那儿全接过来了。**

## 二、上一篇那个 [[2|9]]，就是这么来的

回想第六篇抽牌那题：10 张牌 3 红，不放回连抽两张。第二张抽到红的可能性，我们写的是 **[[2|9]]**。

那不是凭空写的，正是这一篇的算法：**在"第一张已经是红的"这个消息下**，袋里还剩 9 张、红的还剩 2 张。世界变小了，重新分。

BOX[key]: 于是那条乘法有了正身 :: 第六篇说"互不影响才能乘"，那**互相影响的时候怎么办**？// **照样乘，只是第二个数要用"知道第一件事以后"的那个。**// **[[3|10]] × [[2|9]]** ——前一个是第一张红的可能性，后一个是**在第一张红了的前提下**第二张红的可能性。// 互不影响只是一种特殊情形：**知道了也白知道，那个数根本没变**，于是看起来像是两个原来的数在相乘。

## 三、翻车：一家有两个孩子

BOX[task]: 想清楚再往下看 :: 一家有两个孩子。你听说：**"这家至少有一个女孩。"**// 问：**两个都是女孩**的可能性是多少？// 先猜一个。

多数人脱口而出 [[1/2]]："另一个不是男就是女嘛。"

**照这一篇的办法走一遍**（假定男女各半，两个孩子互不影响）：

结果单四项，一样可能——**老大老二是分得清的**（第五篇那个教训）：

TABLE:
| | 老二是男 | 老二是女 |
| **老大是男** | 男男 | 男女 |
| **老大是女** | 女男 | 女女 |

消息说"至少有一个女孩"，**划掉男男**。剩下三项：男女、女男、女女。

两个都是女孩，只占其中 **一项**。答案是 **[[1/3]]**，不是 [[1/2]]。

BOX[key]: 说句老实话：这道题的答案，取决于消息是怎么来的 :: 上面那个 [[1/3]] ，算的是这样一件事：**你查了这家的两个孩子，确认"不是两个都是男孩"**。// 可要是消息是这么来的呢——**你在门口碰见这家一个孩子，是个女孩**？// 那你划掉的就不只是男男：你碰见的那个孩子是**随便一个**，于是"男女"和"女男"这两项里，你碰见女孩的机会只有一半。重新算下来是 **[[1/2]]**。// // **同一句"至少有一个女孩"，两种来路，两个答案。**// 你有没有觉得这很眼熟？——**这就是开篇那个圆。**// "随便"要说清楚，"我怎么知道的"也要说清楚。**这一册讲的从来是同一件事。**

## 四、三扇门

现在是这一篇的主菜。

台上三扇关着的门。**一扇门后面是汽车，另外两扇后面是羊。**你先挑一扇——就说你挑了 1 号门。

主持人**知道车在哪儿**。他从剩下两扇里，**打开一扇后面是羊的**（他永远开得出来，因为剩下两扇里至少有一扇是羊）。假设他打开了 3 号门，羊。

现在他问你：**换到 2 号门吗？**

FIG: fig-p09-three-doors.png | 三种情形各占三分之一。你不换只在第一种赢；你换，在另外两种都赢。

**大多数人说"换不换都一样，各一半"。错。**

把结果单摆出来。你已经选了 1 号门，车在哪儿有三种可能，**各占 [[1/3]]**：

TABLE:
| 车在哪 | 主持人只能开 | 你不换 | 你换 |
| 1 号（你选中了） | 2 号或 3 号 | **赢** | 输 |
| 2 号 | 只能开 3 号 | 输 | **赢** |
| 3 号 | 只能开 2 号 | 输 | **赢** |

三行各 [[1/3]]。**不换只在第一行赢，换在第二、三行赢。**

CENTER: **不换赢的可能性 [[1/3]]，换赢的可能性 [[2/3]]。换。**

BOX[dialog]: 妹妹不服 :: **妹妹：**"可是最后就剩两扇门啊，一辆车，不是一半一半吗？"// **姐姐：**"剩两扇门，不等于两扇门一样可能。// 你一开始挑中车的可能性是 [[1/3]]，这个数**主持人开门以后一点没变**——他开的门本来就不可能有车，他没告诉你任何关于**你那扇门**的事。// 所以你那扇门还是 [[1/3]]，**剩下的那 [[2/3]] 全压在没被开的那一扇上了。**"// **妹妹：**"凭什么全压过去？"// **姐姐：**"因为总共是 1。你那扇 [[1/3]] 不动，开掉的那扇是 0——**剩下的只能都归它。**"

## 五、把三扇门换成一百扇

要是还不服，把题目放大：

**一百扇门，一辆车。**你随便挑一扇（挑中的可能性 [[1|100]]）。主持人知道车在哪，然后**当着你的面打开 98 扇，全是羊**，只留下你选的那扇和另外一扇。

**换不换？**

这一回谁都会换。因为你一眼就看出来：**你一开始挑中的可能性只有百分之一**，那 [[99|100]] 现在全挤在剩下那一扇上了。

BOX[remember]: 三扇门为什么反直觉 :: 因为**主持人不是随便开的**——**他知道车在哪，他在躲着车开。**// 他每开一扇门，都在**替你把可能性往那扇没开的门上推**。// 三扇门时他只推了一次，你感觉不出来；一百扇门时他推了 98 次，你就看见了。// **门数不是关键，"他知道"才是关键。**

## 六、要是主持人也不知道呢

把上一段那句话反过来用，就能看见这道题真正的机关。

假设换一个主持人：**他也不知道车在哪**，随手开了一扇（不是你选的那扇），**碰巧**是羊。

这一回，**换和不换真的各占一半。**

为什么？因为这一次他有可能开出车来。**"他开出的是羊"这件事本身，成了一条新消息**——它排除掉了"车在他开的那扇"的可能，而这条消息**对你那扇门和另一扇门是一样公平的**。

BOX[key]: 这一篇最要紧的一句 :: 台上看到的画面**一模一样**：你选了 1 号，3 号开着，里面一只羊。// 可**换该不该，取决于那扇门是怎么被打开的**：// 主持人**知道**且**躲着车开** → 换，[[2/3]]。// 主持人**不知道**、碰巧开出羊 → 换不换都一样，各 [[1/2]]。// // **同一幅画面，两个答案。**// 光看结果不够，**你得知道这个结果是怎么产生的**。

## 七、习题

BOX[task]: A 组：认一认 :: **A1.** 掷一个骰子，已知"点数大于 3"。求：（1）是 6 的可能性；（2）是偶数的可能性。// **A2.** 掷两枚硬币，已知"至少有一个正面"。两个都是正面的可能性是多少？（照两个孩子那题的办法做。）// **A3.** 袋里 5 红 5 蓝，不放回摸两个。已知第一个是红的，第二个是红的可能性是多少？// **A4.** 三扇门那题：不换赢的可能性是多少？换赢的呢？两个加起来应该是几？

BOX[task]: B 组：动动手 :: **B1.** 找个人陪你玩三扇门，用三张扑克牌（一张 A 当车）。**玩 20 次，每次都换**，记下赢了几次。再**玩 20 次都不换**。两组数字对比一下。（第九篇会告诉你，20 次还是太少。）// **B2.** 掷两个骰子，已知"和是偶数"。求"两个都是偶数"的可能性。（回 36 格上数。）// **B3.** 一个班 20 人，12 个女生。已知随便叫起来一个人是女生，她戴眼镜的可能性——**这道题缺条件，缺哪一个？**把它补上再算。// **B4.** 把三扇门改成**四扇门**（一车三羊），主持人知情、开一扇羊门。你换到剩下两扇之一，赢的可能性是多少？

BOX[task]: C 组：想一想 :: **C1.** "消息把世界变小了"——请你解释：为什么划掉一些结果以后，剩下的要**重新分**那个 1，而不是各自保留原来的份？// **C2.** 两个孩子那题，两种"消息来路"给出两个答案。请你各用一句话说清楚这两种来路的区别。// **C3.** 三扇门那题里，主持人开门以后，**你那扇门的可能性变了吗**？为什么？// **C4.** 有人说："三扇门这题的答案是 [[2/3]]，说明数学违反直觉。"这话对不对？——想一想：真正违反直觉的，是数学，还是**我们没看清那扇门是怎么开的**？
