# 第八篇　期望：赌局的公平价

CENTER: 概率分布是一整本账；期望把这本账连同每条路的得失，压成一个可比较的数

## 一、妹妹开了一个赌局

BOX[dialog]: 值多少钱 :: **妹妹：**"我这儿有个游戏。掷一个骰子，**掷出几，我就给你几块钱**。// 玩一次，你先交多少钱给我？"// **姐姐：**"交多了我亏，交少了你亏。**你是问我这个游戏值多少。**"// **妹妹：**"对。你说个数。"

姐姐要算的这个数，就是这一篇的主角。概率论把它叫作**期望**；在这场赌局里，它就是**公平价**——**交这么多钱去玩，谁也不占谁便宜。**这两个名字说的是同一个数，一个是数学名字，一个说明它在赌局里有什么用。

**先猜。**你会交多少？3 块？3 块半？

## 二、先把"能拿多少钱"写成一台机器

结果单是 1 到 6 六项。**每一项对应一笔钱**：出 1 拿 1 块，出 2 拿 2 块……

把这个"翻译"看成一台机器：**投进去一个结果，吐出来一个数。**这台机器我们给它起个名字，叫 **X**（念作"大写 X"）。

BOX[remember]: X 是一台翻译机 :: **X 把结果单上的每一项，翻译成一个数。**// 掷骰子给钱那个游戏里，X 就是"出几拿几"：X 把结果"出 3"翻译成 3。// 换个游戏，X 就换一台：比如"出 6 给你 10 块，别的都不给"，那台 X 把"出 6"翻译成 10，把别的都翻译成 0。// **长大以后，这样一台机器叫随机变量。**// 注意：这里的大写 X 是一台机器，**和第一册里刻意避开的小写字母不是一回事**（见附录 A）。

## 三、期望怎么算

回到"出几拿几"。

想象你把这个游戏玩上一大堆次。六种点数各占 [[1/6]]——**按份算**，每六次里各出现一次。这六次一共拿到

CENTER: **1 ＋ 2 ＋ 3 ＋ 4 ＋ 5 ＋ 6 ＝ 21**

块钱，摊到每一次是 **21 ÷ 6 ＝ 3.5** 块。

FIG: fig-p10-fair-price.png | 六根柱子高矮不一，削平以后的高度就是期望；在赌局里，它也是公平价。

BOX[remember]: 期望的算法 :: **每个结果上的数 × 这个结果的可能性，然后全部加起来。**// 掷骰子那个游戏：// 1×[[1/6]] ＋ 2×[[1/6]] ＋ 3×[[1/6]] ＋ 4×[[1/6]] ＋ 5×[[1/6]] ＋ 6×[[1/6]] ＝ **3.5**// **各结果不一样可能也照办**——可能性大的那一项，在总和里占的分量就大。// 这个数就是 X 的**期望**；在这场赌局里，它也是公平价。

**不一样可能的例子。**一个转盘：红占一半，蓝、黄、绿各占 [[1/6]]。红给 0 块，蓝给 3 块，黄给 6 块，绿给 12 块。期望是

CENTER: **0×[[1/2]] ＋ 3×[[1/6]] ＋ 6×[[1/6]] ＋ 12×[[1/6]] ＝ 3.5**

也是 3.5 块——**两个完全不同的游戏，期望一样。**期望只把整本账压成一个数，不会把两本不同的账变成同一本。

BOX[key]: 说句老实话：这里赊了一笔 :: 上面那句"**玩一大堆次，平均每次拿这么多**"，是期望这个算法的**理由**，可我们并没有证明它。// 凭什么"六种点数各占 [[1/6]]"就等于"每六次各出现一次"？——**真掷六次，很可能一个 6 都没有。**// 这一笔账要到**第九篇**才还：那一篇会说清楚**玩得越多，平均越靠近期望**是什么意思。// 在那之前，请你先把期望**当成一个规定的算法**收下：**乘起来，加起来。**它自己站得住（两条家规保证加起来的份正好是 1），只是"为什么这么规定合理"要等一等。

## 四、翻车：期望 3.5，实际一次也拿不到

姐姐算出 3.5 块。可掷骰子只能出 1 到 6 的整数，**你永远不会拿到 3 块 5 毛。**

BOX[remember]: 期望不是"最可能出现的数" :: 它甚至**不一定是能出现的数**。// 掷骰子给钱，期望是 3.5，可 3.5 一次也不会出现。// 再狠一点：一个游戏"出 1 给你 100 块，别的都不给"，期望是 100×[[1/6]] ＝ 16 块多一点。可你玩一次，要么拿 100，要么拿 0。// // **实际结果、各事件的可能性、期望，是三样东西。**结果最后落一项；分布给许多事件一起记账；期望再把整本账按得失摊平，拿来比较和定价。谁也没有冒充下一次会拿到的钱。

## 五、期望可以拆开算——而且不用管两件事影不影响

这一节是这一篇最有用的一条。

**掷两个骰子，把点数加起来给你钱。期望是多少？**

老实做法：第五篇那张表，十一种和各算一遍，乘起来加起来。能做，但麻烦。

聪明做法：**红骰子的期望是 3.5，蓝骰子的期望也是 3.5，加起来 7。**完了。

BOX[remember]: 拆开算 :: **两台翻译机加起来，期望就是两个期望加起来。**三台、十台都一样。// 而且——**这一条不要求两件事互不影响。**红蓝两个骰子互不报信，可以这么算；就算把蓝骰子换成"红骰子的点数再加 1"，两者绑得死死的，期望照样是 3.5 加 4.5 ＝ 8。// **独立管两本小账怎样接成合账；期望相加，是在已经有的同一本合账上逐格相加。**

**为什么不用管影不影响？**看一眼算式就明白了。

想写公式，先给要说的东西起名字。**盯住结果单上的某一项**：这一项分到的份记作 p；X 在这一项上翻出的数记作 a，Y 翻出的数记作 b。算 X 加 Y 的期望，就是**在每一项上把两个数先加起来、再乘这一项的份，然后全部加总**。而每一项上都有

CENTER: **(a ＋ b) × p ＝ a × p ＋ b × p**

**这就是乘法分配律。**把所有项这么拆开，再把 X 那一半和 Y 那一半各自收拢，就是 X 的期望加 Y 的期望。

BOX[key]: 这是一次真正的证明，而且很短 :: 上面那三行**没有借任何东西**——只用了分配律和"加法可以换顺序"。它从头到尾没提互不影响，所以当然不需要它。// **第六篇的乘法是在两本小账之间接线**，要知道两边怎样配对；// **这里的加法是在同一本合账的每一格里把钱相加**，不必再问线怎样接。// // 这条短证明把"组合"拆成了两种不同动作。以后看到相加或相乘，先问清楚自己到底在合什么。

## 六、赌注翻倍，期望也翻倍

还有一条更简单的：**把每一笔钱都乘 3，期望也乘 3。**（每一项都乘 3，加起来自然乘 3。）

**再加一条：白送你 10 块，期望就加 10。**

BOX[key]: 跨册回响：期望是一台老实机器 :: 第三册讲过**老实机器**：能"拼"（两个东西合起来，机器的结果也合起来），能"乘倍数"（东西放大几倍，结果也放大几倍）。// 这一篇的两条，正是那两条家规：// **把两台翻译机拼起来 → 期望也拼起来；把赌注放大几倍 → 期望也放大几倍。**// **"算期望"这件事，本身就是一台老实机器。**// 第三册说过老实机器有多好用——现在你在一个全新的地方又碰上它了。

## 七、回头望一眼那 64 块钱

开篇那道分金题，现在可以用正式办法重做一遍。

姐姐手上那个局面（她还差 1 分，妹妹差 2 分）**值多少钱**？——这正是问一台翻译机的期望；放在赌局里，也就是问公平价。

那台翻译机 X 是这样的：**投进"补完两局以后的结局"，吐出"姐姐拿到多少钱"**。结果单四条路，各占 [[1/4]]：

TABLE:
| 补完的两局 | 谁拿到 3 分 | 姐姐拿到 |
| 正 正 | 姐姐 | 64 |
| 正 反 | 姐姐 | 64 |
| 反 正 | 姐姐 | 64 |
| 反 反 | 妹妹 | 0 |

期望（公平价）：**64×[[1/4]] ＋ 64×[[1/4]] ＋ 64×[[1/4]] ＋ 0×[[1/4]] ＝ 48**。

**和开篇数出来的一模一样。**

BOX[key]: 那开篇那个"数条数"算什么 :: 开篇我们是**数条数**：四条路姐姐占三条，所以拿 [[3/4]]。// 这一篇是**乘起来加起来**。两条路答案一样，不是巧合——// **数条数只是"每条路给的钱一样多"时的省事写法。**// // 什么时候省不了？**每条路给的钱不一样的时候。**// 比如规矩改成："赢的人拿 64，输的人还能领回 16 块安慰奖。"// 这时候数条数就不够用了，可公平价照算：// **64×[[3/4]] ＋ 16×[[1/4]] ＝ 52**。姐姐这个局面值 52 块。// // 请注意**结果单一个字都没变**，变的只是那台翻译机。**这就是把"可能性"和"值多少钱"分成两件事的好处。**

## 八、回头望一眼那个圆

期望这个词，让我们能把第二篇那个圆**换一种问法**。

设一个最简单的赌局：**弦比三角形的边长，给你 1 块；不长，给你 0 块。**

这台翻译机只吐两个数：1 和 0。它的期望是

CENTER: **1 × （比边长的可能性）＋ 0 × （其余的可能性）**

**后面那一项是 0，所以期望就是前面那个可能性本身。**

BOX[key]: 回头望一眼那个圆 :: 于是第二篇那三个答案，现在有了第二个身份——**它们是三本账压出来的三个期望**：// 端点法 [[1/3]] 块，半径法 [[1/2]] 块，撒米法 [[1/4]] 块。// 口头上都是"弦比三角形边长就赢 1 块"，背后却由三台不同机器造弦。// **要是真拿钱赌，你得先把机器写进规则；否则连期望、连公平价都没有唯一答案。**第十一篇回来收这笔账。

## 九、习题

BOX[task]: A 组：认一认 :: **A1.** 掷一枚硬币，正面给 10 块，反面给 0 块。期望（公平价）是多少？// **A2.** 掷一个骰子，出 6 给 12 块，别的给 0 块。期望是多少？// **A3.** 一个游戏的期望是 5 块。庄家收你 7 块，你吃亏还是占便宜？收 3 块呢？// **A4.** "期望是 3.5 块"能不能推出"你最可能拿到 3 块或 4 块"？为什么？

BOX[task]: B 组：动动手 :: **B1.** 掷一个骰子：出偶数给你点数那么多钱，出奇数你一分不拿。算期望。// **B2.** 转盘八格：三格写 5 块，五格写 1 块。算期望。// **B3.** 掷两个骰子，钱数等于**两个点数之和**。用**两种办法**各算一遍：（甲）第五篇那张十一种和的表；（乙）本篇第五节的拆开算。两个答案应该一样。// **B4.** 掷两个骰子，钱数等于**两个点数之差的绝对值**（大的减小的）。这一回**不能拆开算**——为什么不能？回 36 格上老实算一遍。

BOX[task]: C 组：想一想 :: **C1.** 第五节说**加法不用问影不影响，乘法要问**。用一句话说清楚这两件事的区别。// **C2.** 有人说："期望 3.5 块，说明我玩一次大概能拿 3 块半。"他错在哪儿？// **C3.** 一个游戏：抛硬币，正面给你 2 块，反面你倒赔 2 块。期望是多少？**这个数说明什么？**// **C4.** 第三节赊了一笔账：**"玩一大堆次，平均每次拿这么多"没有证。**请你把这句话说得更精确一点——"一大堆"是多少？"平均"靠近到什么程度？**你会发现你需要第一册的那套说法。**
