# 第四篇　一件事，就是结果单上圈一块

CENTER: 一个结果落地以前，概率分布已经给所有圈得出的事一起记好了账

## 一、我们关心的从来不是单个结果

掷一个骰子，你很少真的关心"是不是正好出 3"。你关心的多半是这种问题：

- 点数**大于 4** 吗？
- 点数是**偶数**吗？
- **至少有一个 6** 吗？

这些都不只盯着结果单上的某一项，而是把**好几项拼成一堆**。

下一次骰子真正落地时，只会落在一项上；概率预测却不是抢先喊出那一项。它先给整张结果单分好份，再让你圈出"大于 4"、"是偶数"、"至少一个 6"这些不同的事。**在这一篇的有限结果单里，每一块都能从同一本账上查到一个数。**

BOX[remember]: 一件事 :: 在结果单上**圈出一块**——最后的结果落进圈里，这件事就发生；落在圈外，这件事就没发生。// **这样圈出来的一块，就叫一件事。**// "点数大于 4"圈住 5 和 6；"点数是偶数"圈住 2、4、6。// // 说严密一点：**随机试验落下一个结果；一件事只会发生或不发生。**别把"结果"和"事"混成一个词。

## 二、圈里的加起来

一件事的可能性怎么算？**把圈里每一项分到的那一份加起来。**就这么简单。

"点数大于 4"：圈住 5 和 6，各 [[1/6]]，加起来 **[[1/3]]**。

面积法也一样：**圈住的面积占多少，可能性就是多少。**转盘上把三个红格圈起来，圈住半个盘面，可能性就是 [[1/2]]。

BOX[key]: 为什么"加起来"是合法的 :: 因为结果单上**每一项只属于自己**——1 就是 1，它不会同时又是 2。// 你在圈里挨个把份数收起来，**不会有哪一份被收两次，也不会有哪一份漏收**。// 第三篇的两条家规，管的正是这件事：那个 1 被**不重不漏**地分了下去。

BOX[key]: 一份分布，不是一条预言 :: 掷以前，你可以圈**出 6**，也可以圈**出偶数**，还可以圈**不是 1**——圈法很多，最后却都从第三篇**同一张分法**里收份数。// 所以概率分布不是抢先宣布下一次就是 4；它一次交出的是**所有这些事各有多大可能**，而这些数必须合起来不打架。// 实际结果只来一个，预测的账却管着一整家事件。

## 三、两件事凑一起：先看它们重不重叠

现在麻烦来了。**"甲或者乙"的可能性，是不是把两个可能性加起来？**

看两个例子。

**例子一：**"点数大于 4"（圈住 5、6）**或者**"点数等于 1"（圈住 1）。
两个圈**不重叠**。合起来圈住 1、5、6 三项，可能性 [[1/2]]。而 [[1/3]] ＋ [[1/6]] 也正好是 [[1/2]]。**加对了。**

**例子二：**"点数是偶数"（圈住 2、4、6）**或者**"点数大于 3"（圈住 4、5、6）。
按上面的办法：[[1/2]] ＋ [[1/2]] ＝ 1。**意思是这件事一定发生？**可掷出 1 的时候，它既不是偶数也不大于 3——**根本没发生。**算错了。

BOX[key]: 错在哪儿 :: 两个圈**重叠**了：4 和 6 同时在两个圈里。// 你加两遍可能性，就把 4 和 6 那两份**收了两次**。// 真正圈住的是 2、4、5、6 四项，可能性是 [[2/3]]，不是 1。

BOX[remember]: 互斥 :: 两件事**不可能同时发生**——也就是两个圈**一点不重叠**——就说它们**互斥**。// **只有互斥的两件事，可能性才能直接相加。**// 不互斥就得老老实实回结果单上去数，别耍聪明。

**这是这一篇的翻车点，而且是全书最常见的一种。**孩子（还有大人）看见"或"就想加，可"或"允许两件事一起发生，加法却把重叠的部分算了两回。

BOX[dialog]: 妹妹想救那个加法 :: **妹妹：**"那我把多加的减掉不就行了？加两个圈，再减掉重叠的那一块。"// **姐姐：**"对，这一手是对的。偶数圈是 [[1/2]]，大于 3 的圈是 [[1/2]]，重叠的是 4 和 6，一共 [[1/3]]。// [[1/2]] 加 [[1/2]] 再减 [[1/3]]，是 [[2/3]]——和数出来的一样。"// **妹妹：**"那三个圈呢？"// **姐姐：**"三个圈就得先减掉三块两两重叠的，再把多减掉的那块公共部分加回来……**越来越绕。**// 所以这一册的办法是：**能回结果单上数，就回去数。**减来减去那一套留给长大以后。"

## 四、反面：1 减掉它

还有一手非常好用，而且从来不会错。

BOX[remember]: 反面 :: 一件事**不发生**的可能性，就是 **1 减掉它发生的可能性**。// 凭什么？因为"发生"和"不发生"这两个圈：**一点不重叠**（互斥），而且**合起来正好是整张结果单**（加起来是 1，家规二）。// 所以两者之和是 1，知道一个就知道另一个。

这一手专治一类题：**问句里带"至少"的。**

掷两枚硬币，"**至少有一个正面**"的可能性是多少？

正面硬算：结果单四格，正正、正反、反正三格都算，[[3/4]]。
走反面："至少一个正面"的反面是"**一个正面都没有**"，也就是反反，只有一格，[[1/4]]。所以答案是 1 减 [[1/4]] ＝ **[[3/4]]**。

两条路一样。可要是掷**十枚**硬币问"至少一个正面"，正面硬算要数 1023 格，走反面只要数一格。

BOX[key]: "至少"两个字，就是叫你走反面 :: "至少有一个"的反面是"**一个都没有**"——**一句话就说完了**。// 而"至少有一个"本身要拆成"恰好一个""恰好两个""恰好三个"……一长串。// **看见"至少"，先想反面。**// （十枚硬币那道题这一篇还算不了，得等第六篇；但**这个念头现在就要有**。）

## 五、习题
