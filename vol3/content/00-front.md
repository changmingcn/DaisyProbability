# 给大人的话

第一册《给小学生讲微积分（上）》立起了 ε–N 那套语言；第二册《给小学生讲微积分（下）》用它量了变化和面积。这一册讲**线性代数**。

主角是一只**用点名单造出来的兔子**。全书只做一件事：把兔子交给各种机器去变，然后死死盯住一个问题——**变了什么，什么没变。**

BOX[key]: 这一册为什么从一只兔子开始 :: 线性代数最容易教砸的地方，是**一上来就给定义**：向量空间、线性无关、基……// 孩子背得下来，脑子里却什么也没有。// // 这一册反过来：**先让她亲手把一只兔子变成 38 串数**，// 再让她**亲手**把这些数放大、压扁、照镜子、拉斜。// 每一个概念，都是在她**已经做过的事情**上起个名字：// 账本（矩阵）是她记过的账，核是她亲眼看着被压没的那个方向，// 换基是她第一篇就问过的"同一只兔子能不能有两张名单"。// // **抽象是最后才起的名字，不是开头就下的定义。**// // （第一篇确实当场给"一串数"起了名字，叫**向量**——// 可那是给她**刚刚亲手做完的事**贴一张标签，// 和劈头盖脸先下一个定义，是两回事。）

沿用前两册的一切：妹妹出招、姐姐接招；四种盒子（蓝色**必须记住**、绿色**关键的一步**、橙色**留给姐姐妹妹和习题**、灰色**长大以后的写法**）；每篇末尾有「长大以后的写法」；**蓝盒里的话要么已经证过，要么明写着在赊账，并指到还账的地方**。

## 这一册要什么、不要什么

TABLE:
| 做的事 | 为什么 |
| 只用**平面**（外加第七篇一篇三维） | 平面上的一切都能在方格纸上亲手验；三维只开个头 |
| 旋转只做 **90°** 和 **180°** | 任意角度要三角函数，这一册整个排除三角 |
| 函数一律叫**机器** | 第二册的老朋友；这一册的机器投进一个点、吐出一个点 |
| 矩阵一律叫**账本** | 它就是两个基本向量落点的记录；"矩阵"放在「长大以后」 |
| **向量就讲成"一串数"** | 一串排定了顺序的数，能算就够了——**不谈大小、不谈方向**；"有大小和方向的量"那条路只在第一篇灰盒里点一句 |
| 兔子有**两只眼睛（第 37、38 号），不连线**；**尾巴长在左边** | 尾巴只有一条又偏在一侧——照镜子它跑到右边去，一眼看得出翻面 |
| 特征值**只教"会验"，不教"会算"** | 算它要解二次方程；这一册教孩子"给一个方向，你能验它歪不歪"（第九篇） |

## 目录

TABLE:
| 篇 | 讲什么 | 一句话 |
| 第一篇 | 用点名单造一只兔子 | 指挥一个没见过兔子的孩子画兔子——只能报数；坐标系是人定的 |
| 第二篇 | 最老实的几台变换机 | 放大、压扁、镜子、转 90°、斜拉；每台当场记一本账 |
| 第三篇 | 两串数定乾坤 | 两条家规；账本就是整台机器；直线仍是直线；平移翻车 |
| 第四篇 | 连着做两次：乘法 | 流水线接力就是矩阵乘法；**先转再压不等于先压再转** |
| 第五篇 | 面积的放大率 | ad − bc：大小管地皮，正负管翻面 |
| 第六篇 | 压扁与倒带 | 压没了就回不来；**核**就是被吃掉的方向 |
| 第七篇 | 立起来：三维兔子和它的影子 | 手影就是投影；核是光线方向；维数守恒 |
| 第八篇 | 配得出的天地：子空间与基 | 子空间、基、维数、换一套基看同一只兔子 |
| 第九篇 | 不歪的方向 | 机器掰不歪的那几个方向；换到那套格子里，账本只剩对角线 |
| 第十篇 | 收官：机器也是一串数 | 多项式机器也住在这块地板上；求导机器的核就是常数 |
| 附录 A–D | 符号 · 名词 · 习题 · 跳过了什么 | 随时翻回来查 |

BOX[key]: 这十篇是怎么排的 :: **第一、二篇是地基**：把图变成数，再造几台机器动它——**全是手上的活，一条定理也没有。**// **第三篇是心脏**：两条家规一立，账本从"一张记录"变成"整台机器"。// **第四到第七篇，一篇问一个问题**：连做两次怎么算（乘法）／地皮变几倍（放大率）／回不回得去（核）／降一维会丢掉什么（投影）。// **第八篇收网**：子空间、基、维数——顺便还掉第三篇赊的那笔账。// **第九篇是全书最有用的一招**：找出机器掰不歪的方向，换到那套格子里，账本只剩对角线上两个数。// **第十篇揭底**：兔子住的那块地板，第二册的机器也站在上面。

BOX[remember]: 请留意这三处"先赊后还" :: **一、第二篇**记账本时明说：**眼下它只是一张记录**；凭什么四个数就等于整台机器，**第三篇回答**。// **二、第三篇**用"每个点的配方只有一种"时明说：**这里赊了一笔**，**第八篇第四节还**。// **三、第一篇**刚说完"向量就是一串数"，妹妹当场追问"到底是哪一串"；姐姐认下这笔账——**第八篇第六节还**（换一套基，同一个点换一串数）。// // 这三处不是疏忽，是**故意设计的**：// 让孩子先把工具用顺手，再回头问"凭什么"——// 和第二册第五、六篇还账是同一个安排。

BOX[remember]: 和第二册接得最紧的三处 :: **一、家规二就是第二册的"成正比"**（第二册讲微分时立的），只是这一册的机器有**两个方向**都要成正比。// **二、第六篇的核，答的是第二册第一篇那句话**："倒过来那个方向，机器没答应过你什么。"// **三、第十篇把牛顿–莱布尼兹重讲了一遍**：那句"一减就抵掉了"，抵掉的正是**求导机器的核**。// // 没读过第二册也能读这一册；读过的，会在这三处**听见回声**。
