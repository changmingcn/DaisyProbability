# 第四篇　连着做两次：乘法

CENTER: 机器排成流水线；交换律死在这一篇

一台机器不过瘾。把兔子**先**送进转 90° 机，出来**再**送进压扁机——两台接力。这一篇问两件事：接力出来的算什么？以及，**换个先后，出来的一样吗？**

## 一、流水线也是一台机器

两台机器接力，从外面看还是"投进一个点、吐出一个点"——**流水线本身就是一台机器**。

BOX[key]: 而且它也老实 :: 两台**老实**机器接力，流水线也守家规：// 拼好的箭头进流水线——第一台守家规一，出来还是拼好的；// 再进第二台，又守一遍——**到头还是拼好的**。家规二同理，倍数一路原样传。// **老实传得下去。**所以流水线也有自己的账本。

BOX[remember]: 流水线的写法：兔子从右边进 :: 接力写成两本账**并排**：// **压扁账本 × 转弯账本**// 读法是：**先做的写在右边，贴着兔子**——兔子从右边进流水线，先过转弯机，再过压扁机。// 这个"从右往左读"的怪规矩，「长大以后」会告诉你它是怎么来的；// 眼下先记口诀：**贴着兔子的先干活。**

## 二、接力的账本怎么算

流水线是老实机器，那么按第三篇的定理，**它的全部秘密还是两支箭头的落点**。追一遍就有了。

两台机器先记好账（第二篇量过、第三篇练过）：

- **转 90° 机**（逆时针）：横箭头去 (0, 1)，竖箭头去 (−1, 0)——账本 **[[m:0,-1;1,0]]**
- **压扁机**（上下压成一半）：横箭头不动，竖箭头去 (0, [[1/2]])——账本 **[[m:1,0;0,\frac{1}{2}]]**

现在追"先转再压"这条流水线上的两支箭头：

BOX[key]: 追箭头 :: **横箭头：**过转弯机，落在 (0, 1)；这个落点再过压扁机——按压扁账本兑配方：// 零份第一列拼一份第二列，落在 **(0, [[1/2]])**。// **竖箭头：**过转弯机，落在 (−1, 0)；再过压扁机，兑出 **(−1, 0)**。// // 两支箭头的最终落点各占一列，流水线的账本出炉：// **[[m:1,0;0,\frac{1}{2}]] × [[m:0,-1;1,0]] ＝ [[m:0,-1;\frac{1}{2},0]]**

BOX[remember]: 这就是矩阵乘法 :: 两本账"相乘"，算法只有一句：// **拿右边账本的每一列，去左边账本按配方兑换；兑出来的，就是新账本的对应列。**// 没有别的口诀，没有要背的公式——**乘法，就是账本的接力**。// （课本上那张 abcd 的通用公式表，就是把这句话写开，见「长大以后」。）

### 再算两对，手就熟了

算法只有一句，可只算过一对，手还是生的。再算两对——**机器都是第二篇那五台，一台新的也不添**。

BOX[key]: 放大机 × 压扁机 :: 放大机账本 **[[m:1.5,0;0,1.5]]**，压扁机账本 **[[m:1,0;0,\frac{1}{2}]]**。// 拿右边（压扁）的每一列，去左边（放大）按配方兑：// **第一列** (1, 0)：一份第一列拼零份第二列，得 **(1.5, 0)**。// **第二列** (0, [[1/2]])：零份第一列拼半份第二列，得 **(0, [[3/4]])**。// 两个落点各占一列：// **[[m:1.5,0;0,1.5]] × [[m:1,0;0,\frac{1}{2}]] ＝ [[m:1.5,0;0,\frac{3}{4}]]**// // 看出规律没有？**两本账都只有斜对角上有数**，乘出来还是只有斜对角上有数，而且就是**对应的两个数各自相乘**。// 这一对**换个先后再算一遍**——你会发现它们**能**交换。（第四节姐姐说的"确实有能交换的"，就是这一种。）

BOX[key]: 斜拉机 × 压扁机，再反过来 :: 斜拉机账本 **[[m:1,1;0,1]]**。// // **先压再拉**（先做的写右边，所以压扁在右）：// 右边第一列 (1, 0) 去斜拉机兑，得 **(1, 0)**；第二列 (0, [[1/2]]) 兑，得 **([[1/2]], [[1/2]])**。// **[[m:1,1;0,1]] × [[m:1,0;0,\frac{1}{2}]] ＝ [[m:1,\frac{1}{2};0,\frac{1}{2}]]**// // **先拉再压**（斜拉在右）：// 右边第一列 (1, 0) 去压扁机兑，得 **(1, 0)**；第二列 (1, 1) 兑，得 **(1, [[1/2]])**。// **[[m:1,0;0,\frac{1}{2}]] × [[m:1,1;0,1]] ＝ [[m:1,1;0,\frac{1}{2}]]**// // 又一对**换不得**的。两本账第一列一样，**第二列差了一截**——那一截就是先后颠倒的代价。

### 拿一个真点对账：两条路，同一个落点

账本是算出来了，可它**真的就等于那条流水线吗**？挑兔子身上一个认得出的点验一遍：**右耳尖，17 号点 (3, 8.5)**。用第二节那条"先转再压"的流水线。

BOX[key]: 两条路，同一个落点 :: **路一：一台一台地过。**// 过转弯机：三份 (0, 1) 拼 8.5 份 (−1, 0)，也就是 (0, 3) 拼 (−8.5, 0)，落在 **(−8.5, 3)**。// 再过压扁机：横坐标不动，竖坐标减半，落在 **(−8.5, 1.5)**。// // **路二：先把两本账乘成一本，再兑一次。**// 那本账第二节算过，是 **[[m:0,-1;\frac{1}{2},0]]**。// 三份第一列 (0, [[1/2]]) 拼 8.5 份第二列 (−1, 0)，也就是 (0, 1.5) 拼 (−8.5, 0)，落在 **(−8.5, 1.5)**。// // **两条路，同一个落点。**

BOX[remember]: 这一步对账，值两件事 :: 一，**乘出来的那本账，真的就是那条流水线**——不是纸面上的把戏，是能拿点验的。// 二，**先乘账本、后兑名单，是合法的省事办法。**// // 兔子有 36 个点。一台一台过，要兑 72 次（每个点过两台）；// 先把两本账乘成一本（只兑 2 次），再拿它兑 36 个点，总共 38 次——**省下一半还多**。// 点越多，省得越狠。「长大以后」那句"屏幕上每一帧画面"，靠的就是这一步。// // **算不动的时候，就用这一招自己查作业：两条路必须落在同一处。**

## 三、换个顺序：兔子亲自作证

妹妹的第一反应一定是：**数的乘法能交换（3 × 5 ＝ 5 × 3），账本的乘法也能吧？**

**不能。**这是本篇要抓的那条刺——而且这次让兔子亲自出庭。

把顺序倒过来，"先压再转"，同样追两支箭头：

BOX[key]: 再追一遍 :: **横箭头：**过压扁机，纹丝不动 (1, 0)；再过转弯机，落在 **(0, 1)**。// **竖箭头：**过压扁机，落在 (0, [[1/2]])；再过转弯机——半份的竖箭头转过去，落在 **(−[[1/2]], 0)**。// // **[[m:0,-1;1,0]] × [[m:1,0;0,\frac{1}{2}]] ＝ [[m:0,-\frac{1}{2};1,0]]**// // 和第二节的账本**对不上**：一个是"上下压半"，一个是"左右压半"。

FIG: fig-r06-order.png | 左：原样。中：先转再压——一只趴着的宽兔子。右：先压再转——一只立着的瘦兔子。**同样两台机器，先后一换，出来的是两只完全不同的兔子。**

BOX[remember]: 交换律死了 :: 同样两台机器，先后一换，**账本不同，兔子也不同**——数字和图互相作证。// **数的乘法能交换，是数的特权；机器的世界里，先后是要命的。**// 第二册抓过一根同款的刺："一条规矩在加法上成立，不等于在乘法上也成立。"// 这一册再进一步：**一条规矩在数上成立，不等于在机器上也成立。**// 每换一个世界，老规矩都要重新验一遍资格。

## 五、倒过来问：这台机器是怎么拼出来的

乘法是**把两台机器合成一台**。现在把这句话倒过来问：

CENTER: **给你一台机器，它是哪几台接力做出来的？**

这件事叫**分解**。它和乘法是同一件事的两头——一个往前拼，一个往回拆。下面三台都拆得干干净净，**用的还是第二篇那几个动作**。

BOX[key]: 拆法一：横竖分家 :: 要拆的账本 **[[m:2,0;0,3]]**：横向拉 2 倍，竖向拉 3 倍。// **一台机器干了两件事**，那就分给两台，每台只管一个方向：// **只拉横的 [[m:2,0;0,1]]**，**只拉竖的 [[m:1,0;0,3]]**。// // 乘一遍验：右边第一列 (1, 0) 去左边兑，得 **(2, 0)**；第二列 (0, 3) 兑，得 **(0, 3)**。// **[[m:2,0;0,1]] × [[m:1,0;0,3]] ＝ [[m:2,0;0,3]]**// 对上了。// // 这一对**换个先后也一样**——一个只管横、一个只管竖，互不干涉。

BOX[key]: 拆法二：有交叉项也拆得开 :: 要拆的账本 **[[m:2,1;0,1]]**。第二列不干不净，看着不好拆。// 试试**先横拉 2 倍，再斜拉一次**（先做的写右边）：// 右边第一列 (2, 0) 去斜拉机兑，得 **(2, 0)**；第二列 (0, 1) 兑，得 **(1, 1)**。// **[[m:1,1;0,1]] × [[m:2,0;0,1]] ＝ [[m:2,1;0,1]]**// 正是要拆的那一本。// // **顺序要紧。**把这两台倒过来接力：// **[[m:2,0;0,1]] × [[m:1,1;0,1]] ＝ [[m:2,2;0,1]]**// **不是同一台机器。**所以分解不光要说"拆成哪几台"，还得说**谁先谁后**。

BOX[key]: 拆法三：转 180° 就是照两次镜子 :: 要拆的账本 **[[m:-1,0;0,-1]]**：每个点被送到出发点的正对面——**这就是转 180°**。// 拆成 **镜子机 [[m:-1,0;0,1]]**（左右翻）接力 **上下翻转机 [[m:1,0;0,-1]]**。// 乘一遍：右边第一列 (1, 0) 兑得 **(−1, 0)**；第二列 (0, −1) 兑得 **(0, −1)**。对上了。// // 妙在哪？**两台各把兔子翻了一次面；翻两次，就翻回来了**——// 转 180° 的兔子，尾巴**还在左边**（拿第一篇那只兔子比一比就知道）。// 第五篇会给"翻面"配一个数，到那时你会看见：**两个负号乘起来，正好变正。**

BOX[remember]: 一台机器，往往不止一种拆法 :: 12 能拆成 3 × 4，也能拆成 2 × 6。**账本也一样。**// 但每一种拆法都在回答同一个问题：// **这台机器，到底是由哪几个动作、按什么顺序拼出来的。**// // 往后你会遇到一次特别漂亮的拆法：第九篇会把一台看不懂的机器，// 拆成"**换个格子 → 只管拉伸 → 换回来**"三步。

BOX[task]: 留给姐姐妹妹 :: **（1）**照拆法一，把 **[[m:3,0;0,2]]** 拆成两台，每台只管一个方向。// **（2）** **[[m:1,3;0,1]]** 能不能由**斜拉机自己**接力做出来？做几次？（先猜，再乘一遍验。）// **（3）**拆法二里那两台倒过来乘出的是 **[[m:2,2;0,1]]**。它和 **[[m:2,1;0,1]]** 到底哪儿不一样？// 　各拿右耳尖 (3, 8.5) 兑一个落点，比一比。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 账本乘法的通用公式：[[m:a,b;c,d]] × [[m:p,q;r,s]] ＝ [[m:ap+br,aq+bs;cp+dr,cq+ds]]——把"右边每列拿去左边兑配方"逐格写开，就是它。// "先做的写右边"来自记号 f(g(点))：g 贴着点先干活。矩阵接力写成 AB，念"A 乘 B"，意思是**先 B 后 A**。// 交换律不成立的正式说法：矩阵乘法**不可交换**（AB 一般不等于 BA）；但**结合律成立**：(AB)C ＝ A(BC)——道理正是 C2 那句"流水线本身没有括号"。// "什么都不做机"的账本叫**单位矩阵**；转 90° 连做四次回到它，这类"转回原样"的账本家族，大学里叫**旋转群**——"群"就是一族能接力、能倒带的变换。// 顺带一句实话：屏幕上每一帧 3D 画面，都是几本账先乘成一本，再一口气兑给几万个点——**先乘账本、后兑名单**，这个省钱的顺序，靠的正是结合律。// // **第五节那件事叫分解。**那三台是特意挑的好拆的，但有一条大定理管着一般情形：**只要是倒得回去的账本，都能拆成"只拉一个方向"和"斜拉"这几样的接力**（还允许把两行对调）。课本上那几样叫**初等矩阵**，那套拆法叫**高斯消元**，是解方程组的主力。这一册不证它——写在这儿，是让你知道**那三个例子不是碰巧**。
