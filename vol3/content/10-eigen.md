# 第十篇　不歪的方向

CENTER: 大多数向量进了机器都会被掰弯。可有些方向，机器只把它拉长，不肯把它掰歪

第九篇末尾，姐姐说过一句没往下讲的话：**"有的机器在斜格子里看，账本会变得特别简单。"**

这一篇就去找那套斜格子。**找它的办法，是先找到机器"掰不歪"的那几个方向。**

## 一、大多数向量都会歪

拿老朋友**斜拉机**（账本 [[m:1,1;0,1]]，横坐标加上竖坐标）。挑几个向量投进去：

TABLE:
| 投进去 | 吐出来 | 方向变了吗 |
| (0, 1)　竖向量 | (1, 1) | **歪了**——本来朝上，出来朝右上 |
| (1, 1) | (2, 1) | **歪了** |
| (−1, 2) | (1, 2) | **歪了**，而且歪到另一边去了 |
| (1, 0)　横向量 | (1, 0) | **没歪**——一动没动 |

FIG: fig-r23-fixed-direction.png | 斜拉机把大多数向量都掰歪了，只有横着的那一个纹丝不动。兔子也一样：整只被拉斜了，可**脚底下那条线一步没挪**。

BOX[key]: 兔子的脚给了同一个答案 :: 回头看第三篇斜拉机那张图：兔子被拉得往右倒，// 耳朵尖跑出去老远——**可它脚底下那条线，一动不动。**// // 为什么？脚踩在横轴上，竖坐标是 0；// 斜拉机干的是"横坐标加上竖坐标"，加的是 0，**等于没加**。// **横着的那个方向，这台机器掰不动它。**

## 二、给它起个名字

BOX[remember]: 不歪的方向 :: 一个向量进了机器，要是出来**还落在原来那条线上**，// 就说这个方向**不歪**。// // 它可以**变长**（拉 3 倍）、**变短**（缩一半），// 甚至**掉头**（乘 −1，还在同一条线上，只是朝反了）——// **都算不歪。只有"转到别的方向去"才叫歪。**// // 拉长的那个倍数，就叫**这个方向上的倍数**。

有一件事得说清楚：**不歪说的是"一条线"，不是一个向量。**

BOX[key]: 一个不歪，整条线都不歪 :: 横向量 (1, 0) 在斜拉机里不歪。那 (2, 0) 呢？(−3, 0) 呢？// **也都不歪**——按**家规二**，它们是 (1, 0) 的几倍，// 出来也就是"(1, 0) 的落点"的几倍，还在同一条线上。// // 所以我们说的是**一整条过出发点的直线**。// 第九篇给过这种东西一个名字：**这条线是一个子空间。**

## 三、几台老朋友，各有几个不歪的方向

TABLE:
| 机器 | 账本 | 不歪的方向 | 那个方向上的倍数 |
| 什么都不做机 | [[m:1,0;0,1]] | **每一个方向** | 都是 1 |
| 放大机 | [[m:1.5,0;0,1.5]] | **每一个方向** | 都是 1.5 |
| 压扁机 | [[m:1,0;0,\frac{1}{2}]] | 横着的 ／ 竖着的 | 1 ／ [[1/2]] |
| 镜子机 | [[m:-1,0;0,1]] | 横着的 ／ 竖着的 | **−1** ／ 1 |
| 斜拉机 | [[m:1,1;0,1]] | **只有横着的** | 1 |
| 压过头那台 | [[m:1,0;0,0]] | 横着的 ／ 竖着的 | 1 ／ **0** |

BOX[remember]: 两个数字特别值得看 :: **镜子机的横方向，倍数是 −1。**// 负号不是"长度是负的"——是**掉了个头**：// 那个向量还在横轴上，只是从朝右变成了朝左。// // **压过头那台，竖方向的倍数是 0。**// 倍数是 0，就是**被压到出发点上**——// 那正是第七篇说的**核**！// **倍数为 0 的那个方向，就是被机器吃掉的方向。**

## 四、一台要动脑的：先猜后证

上面几台一眼就看出来了，因为它们太规矩。看一台不那么规矩的：

CENTER: **[[m:2,1;1,2]]**

也就是：横向量落在 (2, 1)，竖向量落在 (1, 2)。

BOX[dialog]: 妹妹先猜，姐姐来验 :: **妹妹：**"横向量总该不歪吧？"// **姐姐：**"验一验。(1, 0) 兑出来是 (2, 1)——**歪了**，它跑到斜上方去了。"// **妹妹：**"那斜着的呢？我猜 (1, 1)。"// **姐姐：**"兑：一份第一列拼一份第二列，得 (2 ＋ 1, 1 ＋ 2)，也就是 **(3, 3)**。// **(3, 3) 正好是 (1, 1) 的 3 倍**——**不歪！倍数是 3。**"// **妹妹：**"还有别的吗？我再猜 (1, −1)。"// **姐姐：**"兑：一份第一列减一份第二列，得 (2 − 1, 1 − 2)，也就是 **(1, −1)**。// **原样不动**——**不歪，倍数是 1。**"

BOX[remember]: 这一招你早就学过 :: 妹妹猜、姐姐验——这就是**先猜后证**（第一册命名过的老动作）。// // **一般的机器怎么把不歪的方向"算"出来**，要解一个方程，// 这一册不讲（附录 D 记着）。// 但你已经会做最要紧的那一半：**给你一个方向，你能验它歪不歪。**// 验法只有一句：**兑出来的落点，是不是原来那个向量的整倍数？**

## 五、有什么用：换到"不歪的格子"里去看

现在兑现第九篇那句话。

BOX[key]: 拿两个不歪的方向当基 :: 上面那台机器有两个不歪的方向：**(1, 1)** 和 **(1, −1)**。// 它们不平行，所以**是一套合法的基**（第九篇第三节）。// // 换到这套格子里，这台机器在干什么？// **第一个向量拉 3 倍，第二个向量拉 1 倍。**// // **这就是第五篇第五节说的分解**，而且是全册最漂亮的一次：// 一台看不懂的机器，被拆成 **换个格子 → 只管拉伸 → 换回来** 三步。完了。// // 在新格子里，它的账本是// **[[m:3,0;0,1]]**// **只剩对角线上两个数，别处全是 0。**

FIG: fig-r24-eigen-basis.png | 左：那台机器把大多数向量掰歪了，只有 (1, 1) 和 (1, −1) 两个方向没歪——一个拉 3 倍，一个原样不动。右：换成这两个向量当格子，机器就只是"一个方向拉 3 倍，另一个不动"。

BOX[remember]: 这就是"换个格子看，账本变简单"的意思 :: 同一台机器：// 在横平竖直的老格子里，账本是 [[m:2,1;1,2]]——四个数，看不出它在干什么。// 在两个不歪的方向搭起来的新格子里，账本是 [[m:3,0;0,1]]——// **一眼就看出：一个方向拉 3 倍，另一个方向不动。**// // **机器一点没变，变的只是我们从哪套格子去看它。**// 第一篇那句"坐标系是人定的"，到这里是第三次兑现，也是最有用的一次。

BOX[key]: 连做很多次，好处才真正显出来 :: 问一个吓人的问题：**这台机器连做十次，账本是什么？**// 在老格子里，你得把 [[m:2,1;1,2]] 自乘十次——**算到手软。**// 在新格子里，一眼可知：// **一个方向拉了十个 3 倍，另一个方向十次都不动。**// // 所以聪明的做法是：**换到不歪的格子里算，算完再换回来。**// 长大以后你会看到，天气预报、网页排名、人口预测，// **都要把一台机器连做很多很多次**——靠的就是这一招。

## 六、放大率就是两个倍数相乘

新账本 [[m:3,0;0,1]] 的放大率，一眼就看得出：3 × 1 − 0 × 0，**是 3**。

回去算老账本 [[m:2,1;1,2]]：2 × 2 − 1 × 1，**也是 3**。

BOX[remember]: 对上了，而且不是巧合 :: **两个方向上的倍数相乘，正好是这台机器的放大率。**// 想一想也合理：// 一个方向拉 3 倍、另一个方向不动，// 那么这块地皮当然变成 **3 × 1** 倍。// // （严格说，这里还借了一句"**换一套基，放大率不变**"——// 这一册没证，附录 D 记着这笔账。）

## 七、直观翻车：不歪的方向，不是每台机器都有

妹妹该挑刺了：**是不是每台机器都能换到"不歪的格子"里去？**

**不是。**这是本篇要抓的那条刺，而且它翻得很彻底。

BOX[key]: 两个反例，一个比一个狠 :: **第一个反例：斜拉机只有一个。**// 它不歪的方向只有横着那一条——**再没有第二条**。// 一条线撑不起一套基（第九篇：平面要两个不平行的向量）。// **所以斜拉机换不到对角格子里去。**// // **第二个反例：转 90° 机一个都没有。**// 它把**每一个**向量都转走了四分之一圈——// 转完还落在原来那条线上的，**一个也找不出**。// （只有零向量原地不动，可它不指任何方向，不算。）// // 所以"总能换到不歪的格子里"这句话，// **是假的。**

BOX[remember]: 这根刺和前面几根是同一种 :: **第四篇**：平移看着无辜，却不是老实机器。// **第六篇**：面积没变，不等于什么都没变。// **第九篇**：多带一个向量，一点好处也没有。// **本篇**：不歪的方向，不是每台机器都有。// // 每一次都是同一件事：// **"看起来总该成立"的地方，先找一个反例试试。**

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: "不歪的方向"上的向量，正式叫**特征向量**（eigenvector）；那个倍数叫**特征值**（eigenvalue）。课本写作 **Av ＝ λv**——那个 λ 念"拉姆达"，就是本篇说的倍数。// 第五节那件事叫**对角化**：找到一套由特征向量组成的基，矩阵在这套基下变成**对角矩阵**。第七节的两个反例说明**不是每个矩阵都能对角化**（斜拉机那种叫**亏损矩阵**；转 90° 那种在实数范围里没有特征值，**要到复数里才有**——那是另一座山）。// 怎么把特征值算出来：解**特征方程** det(A − λI) ＝ 0。对二阶矩阵它是一个一元二次方程，所以**要等学了二次方程才做得了**——这一册只教"给你一个方向，你会验"。// 第五节"连做很多次"那一段是**幂法**的思想；它是**谷歌 PageRank**（把网页排名算成一台巨大机器反复作用的结果）和**主成分分析**的核心。**特征值是线性代数在真实世界里用得最多的一件东西**——你现在见到它了。
