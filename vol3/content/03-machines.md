# 第三篇　最老实的几台变换机

CENTER: 造五台机器，每台都亲手画一遍兔子，每台都当场记一笔账

第一篇把兔子变成了一串数。这一篇开始动它。

我们要造五台**变换机**：投进一个点，吐出一个点。规矩还是第一篇那句咒语——**对名单上的每一个点，做同一件事**（眼睛也在名单上，它也得一起走）。

每造一台，顺手记一笔账：**它把横向量和竖向量，分别搬到了哪儿。**

BOX[remember]: 先认识两个基本向量 :: **横向量**：从出发点往右一格，就是那一串数 **(1, 0)**。// **竖向量**：从出发点往上一格，就是 **(0, 1)**。// // 这两个向量往后处处都是主角。// 每台机器，我们都问它同一个问题：// **"你把这两个向量搬到哪儿去了？"**

## 一、放大机

最简单的一台：**两个坐标都乘 1.5**。

投进 (4, 2)，吐出 (6, 3)。兔子怎么了？第一篇画过——**从出发点吹气球**：越吹越大，也越吹越远。

（第一篇那次乘的是 2，这里乘 1.5。**乘几倍随你挑，账本跟着变**——这里挑一个不大不小的，好把前后摆在一起比。）

记账：横向量 (1, 0) 变成 (1.5, 0)；竖向量 (0, 1) 变成 (0, 1.5)。

CENTER: **放大机的账本：[[m:1.5,0;0,1.5]]**

把 1.5 换成 **[[2/3]]**，就是**缩小机**，账本是 [[m:\frac{2}{3},0;0,\frac{2}{3}]]。

## 二、压扁机

**横坐标不动，竖坐标减半。**投进 (3, 2)，吐出 (3, 1)。

兔子被压矮了：耳朵没那么长了，身子变扁了，可它还是朝左坐着。

记账：横向量**纹丝不动**，还在 (1, 0)；竖向量从 (0, 1) 落到 (0, [[1/2]])。

CENTER: **压扁机的账本：[[m:1,0;0,\frac{1}{2}]]**

## 三、镜子机

**横坐标变号，竖坐标不动。**投进 (3, 2)，吐出 (−3, 2)。

这台机器把兔子照到了竖轴的另一边——**而且兔子翻过来了，改成朝右坐着**。

BOX[key]: 尾巴在这里立功 :: 光看轮廓，你多半分不清"照了镜子"和"整只搬到左边去了"——// 两种情形下兔子都跑到了左边。// **可你一看尾巴就知道**：// 搬过去的兔子，尾巴还在**左边**；// 照了镜子的兔子，尾巴**跑到右边去了**。// // 第一篇特意让你记住尾巴在哪一边，就是为了这一刻。

记账：横向量从 (1, 0) 落到 (−1, 0)；竖向量不动。

CENTER: **镜子机的账本：[[m:-1,0;0,1]]**

## 四、转 90° 机

**整张纸绕着出发点，逆时针转四分之一圈。**

这台机器的账本不用算，**用眼睛就看得出来**：横向量 (1, 0) 是往右一格，转完变成往上一格，落在 (0, 1)；竖向量 (0, 1) 是往上一格，转完变成往左一格，落在 (−1, 0)。

CENTER: **转 90° 机的账本：[[m:0,-1;1,0]]**

BOX[dialog]: 妹妹要验一验 :: **妹妹：**"你光转了那两个向量。兔子的右耳尖 (3, 8.5) 转到哪儿去了？"// **姐姐：**"照这台机器的规矩：转完以后，横坐标和竖坐标换个位置，再把新的横坐标变号——// 落在 **(−8.5, 3)**。你在方格纸上量一量，正好是把它绕着出发点扳过去四分之一圈。"// **妹妹：**"那我怎么知道**别的点**也都对？"// **姐姐：**"问得好——**这正是第四篇要证的事**。"

## 五、斜拉机

**竖坐标不动，横坐标加上竖坐标。**投进 (3, 2)，吐出 (5, 2)。

越高的点，往右挪得越多；贴着横轴的点，一动不动。整只兔子像被一只手从上面往右推，**歪成了斜的**——像一叠扑克牌，捏住底下那张，把上面的推开。

记账：横向量贴着横轴，**不动**；竖向量从 (0, 1) 落到 (1, 1)。

CENTER: **斜拉机的账本：[[m:1,1;0,1]]**

FIG: fig-r10-five-machines.png | 同一只兔子，过五台机器。灰色是原样，彩色是出来以后。盯住眼睛，你一眼就看得出哪台把兔子翻了过来。

## 六、把五本账摆在一起

TABLE:
| 这台机器 | 它干什么 | 横向量去哪 | 竖向量去哪 | 账本 |
| 放大机 | 两个坐标都乘 1.5 | (1.5, 0) | (0, 1.5) | [[m:1.5,0;0,1.5]] |
| 压扁机 | 竖坐标减半 | (1, 0) | (0, [[1/2]]) | [[m:1,0;0,\frac{1}{2}]] |
| 镜子机 | 横坐标变号 | (−1, 0) | (0, 1) | [[m:-1,0;0,1]] |
| 转 90° 机 | 逆时针转四分之一圈 | (0, 1) | (−1, 0) | [[m:0,-1;1,0]] |
| 斜拉机 | 横坐标加上竖坐标 | (1, 0) | (1, 1) | [[m:1,1;0,1]] |

BOX[remember]: 账本怎么读 :: **第一列，是横向量的落点；第二列，是竖向量的落点。**// 每一列**竖着读**：上面那个数是落点的横坐标，下面那个是竖坐标。// // 还有一台机器不能忘：**什么都不做机**。// 它把横向量留在 (1, 0)、竖向量留在 (0, 1)，账本是 **[[m:1,0;0,1]]**。// 看着没用，第五篇你会发现它其实很要紧。

BOX[key]: 说句老实话：眼下它只是一张记录 :: 这五本账，眼下**只是记下了两件事**：横向量去哪、竖向量去哪。// 我们**还没有权利**说"这四个数就是整台机器"——// 万一有别的点不听这两个向量的话呢？// // 妹妹上面问的正是这个。// **第四篇会把它证出来**：只要机器守两条家规，// **四个数就真的等于整台机器。**// 在那之前，请把账本当成一张老实的记录，别当成结论。

## 七、直观翻车：压过了头，就回不来了

先离开方格纸一分钟。

桌上摆着三只兔子玩偶：一只厚墩墩的，一只薄一点，还有一只薄得像纸片。**正面看，它们一模一样。**给它们各拍一张照片——

FIG: fig-r25-toy-photo.png | 厚的、薄一点的、最薄的，正面一模一样，拍出来还是同一张照片。相机把"厚"这个方向整个吃掉了。

三张照片，一模一样。

现在把照片递给妹妹："照着它，**把玩偶捏回来**。"她捏不出来——**厚墩墩的那只和纸片那只，在照片上根本分不出谁是谁**。

相机并没有做坏事，它只是**把"厚"这个方向乘了 0**。乘 0 的代价是：那个方向上原来的差别，**从此一点痕迹也不剩**。

纸上的兔子，也有这么一台机器。

压扁机把竖坐标减半。**减一半可以，那减到 0 呢？**

BOX[key]: 一台压过头的机器 :: 规矩：**横坐标不动，竖坐标乘 0。**账本是 **[[m:1,0;0,0]]**。// // 投进 (3, 2)，吐出 (3, 0)；投进 (3, 5)，吐出 **(3, 0)**；投进 (3, −1)，还是 **(3, 0)**。// **整只兔子被压成了横轴上的一条线段。**// // 现在轮到妹妹为难姐姐了：// **"我手里有个落点 (3, 0)。它原来是兔子身上的哪一个点？"**// 姐姐答不上来——**(3, 2)、(3, 5)、(3, −1) 都会落在这儿**。// 谁也说不出它原来是谁。

FIG: fig-r11-squash-flat.png | 竖坐标乘 0：整只兔子被压成一条线段。一竖排的点全挤到了同一个落点上——从此再也分不开。这就是刚才那台相机，搬到了方格纸上：一竖排，正是玩偶的"厚"。

BOX[remember]: 这根刺扎得很深 :: **压扁一点点**（乘 [[1/2]]），兔子矮了，可**每个点还认得出自己**，// 把竖坐标乘回 2 就复原了。// **压到 0**，一整竖排的点撞在一起，**再也分不开**。// // "压一点"和"压没了"，看着只差一个数，**结果差了一整个世界**：// 一个能倒回去，一个永远回不去。// **第七篇整篇就在讲这件事**，那时被吃掉的那一竖排会有个名字，叫**核**。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 这些机器正式叫**线性变换**；账本叫**矩阵**；"什么都不做机"的账本叫**单位矩阵**，常记作 I。// 放大机叫**数乘**（或位似）；压扁机叫**沿一个方向的伸缩**；镜子机叫**反射**；转 90° 机叫**旋转**；斜拉机叫**剪切**（shear）——排版软件把字母压斜成"斜体"，用的就是它。// 第七节那台把竖坐标乘 0 的机器，正式叫**投影**（投到横轴上）；它被压掉的那一竖排叫**核**，第七篇会讲。// 转任意角度也有账本，可那四个数要用三角函数才写得出来——这一册只做 90° 和 180°，**斜着转的只画图，不给式子**。
