# 第五篇　面积的放大率

CENTER: 一台机器把地皮放大几倍？四个数就能算出来

前四篇一直在问"点落到哪儿"。这一篇换个问法：

CENTER: **兔子占的那块地，过了机器以后，变大了还是变小了？变了几倍？**

答案出人意料地干脆：**每台机器都有一个固定的倍数**，不管你送什么形状进去，都按这个倍数放大。而这个倍数，**从账本的四个数就算得出来**。

## 一、先只看一个小方格

要量"地皮变了几倍"，先挑一块最好量的地皮：**横向量和竖向量张开的那个方格**——边长都是 1，面积正好是 1。叫它**单位方格**。

把它送进机器。四个角会去哪？

- 出发点 (0, 0)：**不动**（第三篇第二节那颗钉子：老实机器必把出发点留在原地）。
- 横向量 (1, 0) 那个角：落到账本第一列。
- 竖向量 (0, 1) 那个角：落到账本第二列。
- 第四个角：它是"一份横向量拼一份竖向量"，按家规，落点就是**两个落点拼起来**。

于是方格变成了一个**平行四边形**——两组对边各自平行，因为它们本来就是同一个向量搬过去的。

FIG: fig-r12-unit-square.png | 左：横竖两个向量张开的单位方格，面积是 1。右：过了斜拉机，它变成一个平行四边形——底和高都没变，所以面积还是 1。

BOX[remember]: 放大率 :: **单位方格的面积是 1。它变成的那个平行四边形，面积是几，机器的放大率就是几。**// 这个数记作账本的**放大率**。

## 二、放大率管的不只是那个方格

一个小方格好办，可我们要问的是**兔子**那块奇形怪状的地皮。凭什么它也按同一个倍数变？

BOX[key]: 一句话：所有地皮都是小方格拼出来的 :: 把纸上的格子画得**再细一点、再细一点**——// 兔子那块地，就能被一堆小方格盖得越来越准。// **每一个小方格，过机器都按同一个倍数变**（它们全是单位方格缩小以后的样子）。// 那么把它们加起来的兔子，**当然也按这个倍数变**。// // 这个念头你**在第二册第十篇见过**：那里把曲线底下的地切成小条，一条条加起来，越切越细。// **两处是同一招**：**难量的东西，先切成好量的，再加回去。**

BOX[remember]: 所以放大率是机器的脾气，不是图形的脾气 :: **同一台机器，放大兔子和放大方格，倍数一模一样。**// 你不必重算——**量一次单位方格就够了。**

## 三、四个数怎么算出这个倍数

现在动手算平行四边形的面积。设账本是

CENTER: **[[m:a,b;c,d]]**

也就是横向量落在 (a, c)，竖向量落在 (b, d)。**先只算两个向量都指向右上方的情形**（a、b、c、d 都不是负数），别的情形照样能算，图要另画。

BOX[key]: 剪拼：一个大长方形，减掉四块 :: 把平行四边形装进一个**大长方形**里：宽是 a ＋ b，高是 c ＋ d，面积是 **(a ＋ b) × (c ＋ d)**。// 展开：**ac ＋ ad ＋ bc ＋ bd**。// // 大长方形里，除了要的那个平行四边形，还剩下：// **两个一样的直角三角形**（直角边 a 和 c），合起来是一个长方形，面积 **ac**；// **两个一样的直角三角形**（直角边 b 和 d），合起来面积 **bd**；// **两个一样的小长方形**（边 b 和 c），合起来面积 **2bc**。// // 减掉它们：// **ac ＋ ad ＋ bc ＋ bd − ac − bd − 2bc**// 剩下 **ad − bc**。

FIG: fig-r13-shoelace.png | 大长方形里，平行四边形之外正好剩四块：两个三角形拼成一个长方形（面积 ac），另两个拼成 bd，中间两块长方形合起来是 2bc。减完剩下的，就是 ad − bc。

BOX[remember]: 放大率的算法 :: 账本 [[m:a,b;c,d]] 的放大率是// **ad − bc**// **左上乘右下，减去右上乘左下。**// 这个数一算出来，机器把任何地皮放大几倍，就全知道了。

拿第二篇那五本账验一验：

TABLE:
| 机器 | 账本 | ad − bc | 说得通吗 |
| 放大机 | [[m:1.5,0;0,1.5]] | 1.5 × 1.5 − 0，得 2.25 | 长宽各变 1.5 倍，面积变 2.25 倍 ✓ |
| 压扁机 | [[m:1,0;0,\frac{1}{2}]] | 1 × [[1/2]] − 0，得 [[1/2]] | 只压矮一半，面积也一半 ✓ |
| 斜拉机 | [[m:1,1;0,1]] | 1 × 1 − 1 × 0，得 1 | 歪了，可**面积没变** ✓ |
| 转 90° 机 | [[m:0,-1;1,0]] | 0 × 0 − (−1) × 1，得 1 | 转一转，面积当然不变 ✓ |
| 什么都不做机 | [[m:1,0;0,1]] | 1 × 1 − 0，得 1 | 什么都没变 ✓ |

BOX[key]: 顺便算一个整数的 :: 要是两个坐标**都乘 2**（第一篇第三节那次“吹气球”），放大率就是// **2 × 2 − 0，得 4**。// **长宽各翻一倍，面积翻四倍**——这件事第二册第十二篇算刹车距离时也遇到过一次。// **地皮的倍数，是长度倍数的两次方。**

## 四、负号是什么意思

只剩镜子机没验。它的账本是 [[m:-1,0;0,1]]，算出来是 **−1**。

**面积怎么会是负的？**

BOX[key]: 负号说的不是大小，是"翻没翻面" :: 面积当然不会是负的。**这个负号说的是另一件事：兔子被翻过来了。**// // 镜子机把兔子照到了另一边，**尾巴跑到另一边去了**——// 这一次不是我们眼尖看出来的，是**账本自己报出来的**：// **放大率是负的，就是翻了面。**// // 大小仍旧看那个数的**大小**：−1 的大小是 1，所以镜子机**面积一点没变**，只是翻了个面。

BOX[remember]: 一个数，两件事 :: **它的大小**：地皮放大几倍。// **它的正负**：翻没翻面（正的没翻，负的翻了）。// // 第二篇里我们靠**盯着尾巴**才认得出翻面；// 现在**算一下账本就知道**——这就是把图形变成数的好处。

## 五、直观翻车：面积没变，不等于什么都没变

妹妹这时候该挑刺了：**放大率是 1，是不是就说明机器什么都没干？**

**不是。**这是本篇要抓的那条刺。

BOX[key]: 一个例子就够了 :: **斜拉机**的放大率正好是 1。// 可你看看那只兔子：**它歪得连耳朵都要倒了。**// 地皮一寸没少，**形状全变了**。// // 转 90° 机的放大率也是 1，兔子转得四脚朝天。// // 所以：**放大率只管地皮的大小，不管形状。**// 它是一台机器的**一个**侧面，不是全部。// 一个数说不尽一台机器——**一台机器要四个数才说得清**，第三篇早就告诉过你了。

## 六、放大率是 0 的那一天

还有一个数我们一直躲着没提：**放大率要是 0 呢？**

BOX[key]: 那就是第二篇那台"压过头"的机器 :: 它的账本是 [[m:1,0;0,0]]，算一算：1 × 0 − 0 × 0，**放大率正好是 0**。// // 说的是什么？**兔子那块地皮的面积变成了 0。**// 一条线段没有面积——**兔子确实被压成了一条线**。// // **放大率是 0，就是"压没了"的意思。**// 第二篇说过压没了就再也回不来；// **下一篇专讲这件事**：为什么回不来，以及怎么一眼看出一台机器回不回得来。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 放大率正式叫**行列式**（determinant），账本 A 的行列式记作 det A 或 |A|。二阶行列式的公式正是 ad − bc。// 第五节那条"面积没变不等于什么都没变"，说的是**行列式只是矩阵的一个数值特征**；行列式为 1 的那一族矩阵叫**特殊线性群**。// 第六节"行列式为 0 就压没了"，正式说法是：**行列式为 0 ⟺ 矩阵不可逆**（下一篇会用孩子的话讲一遍）。// C1 那条规律叫**行列式的乘法定理**：det(AB) ＝ det A × det B——两台机器接力，放大率相乘。// 三维空间里，行列式量的是**体积**放大几倍；负号还是同一个意思——把左手变成了右手。
