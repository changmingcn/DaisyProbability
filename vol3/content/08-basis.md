# 第八篇　配得出的天地：子空间与基

CENTER: 给你两支箭头，你能配出多大一片天地？第三篇赊的那笔账，这一篇还

第三篇有一句话，我们一直用着，可从来没证过：**每个点的配方只有一种。**当时姐姐说了实话——"**先记下：这里赊了一笔。**"

这一篇还账。而在还账之前，先得把一个问题问清楚：**手里的箭头，到底能配出多少东西？**

## 一、两支箭头，配得出多大一片天地

给你两支箭头，你可以取几份这个、几份那个，拼起来。**所有拼得出来的点，凑成一片地方。**

三种情形，差别大得吓人：

BOX[key]: 三种情形 :: **一、两支箭头不平行**（比如横箭头和竖箭头）。// 配得出**整个平面**——第三篇第一节说过，任何一个点的坐标就是它的配方。// // **二、两支箭头平行**（比如 (1, 1) 和 (2, 2)）。// 不管怎么配，**永远走不出那一条斜线**：// 几份 (1, 1) 拼几份 (2, 2)，横坐标和竖坐标**总是一样大**。// 配得出的只有**一条过出发点的直线**。// // **三、两支都是空箭头。**// 配来配去只有**出发点**一个点。

FIG: fig-r19-span.png | 左：两支不平行的箭头，配得出整个平面。右：两支平行的箭头，无论怎么配都跑不出那一条线。

BOX[dialog]: 妹妹不服 :: **妹妹：**"我不信。给我 (1, 1) 和 (2, 2)，我非配出 (1, 0) 来不可。"// **姐姐：**"你试试。取 a 份第一支、b 份第二支，拼出来是 **(a ＋ 2b, a ＋ 2b)**——// **两个坐标永远一样大。**可 (1, 0) 的两个坐标一个是 1、一个是 0。"// **妹妹：**"……那我取负的份数呢？"// **姐姐：**"负的也一样：**不管 a 和 b 是什么，两个坐标都还是同一个数。**// 你想跑出那条线，**手里根本没有第二个方向。**"

## 二、这些"天地"有个名字

上面配出来的三种地方——**整个平面、一条过出发点的直线、只有出发点**——都有一个共同的名字。

BOX[remember]: 子空间 :: 一片地方，要是**里面的箭头怎么加、怎么乘倍数，都还落在这片地方里**，// 就叫一个**子空间**。// // 平面里的子空间只有三种：// **整个平面**、**一条过出发点的直线**、**只有出发点**。

BOX[key]: 为什么必须过出发点 :: 一条**不过**出发点的直线，能不能算子空间？// **不能。**取里面任何一支箭头，**乘 0 份**——落到出发点上，// 可出发点不在那条线上，**跑出去了**。// // 所以：**子空间必须过出发点，一个例外也没有。**// 这和第三篇第二节那颗钉子是同一件事——**出发点是钉死的**。

BOX[remember]: 你其实早就见过子空间 :: **核**就是一个子空间（第六篇 C3 让你想过：v 在核里，2v、3v、−v 也都在）。// **像**也是一个子空间（第七篇那个影子住的地面）。// 这一篇给它们起了共同的名字。

## 三、基：够用，而且不多余

要描述一片天地，得挑几支箭头当"料"。挑多少支合适？

BOX[remember]: 基 :: 一套箭头，要是同时满足两条，就叫这片天地的一套**基**：// **一、够用**——这片天地里每一个点，都配得出来。// **二、不多余**——里面谁也配不出谁（两支箭头就是**不平行**）。// // 横箭头和竖箭头，就是整个平面最顺手的一套基。

少一条都不行：

- 只有 (1, 1) 一支？**不够用**——配不出整个平面。
- 拿 (1, 0)、(0, 1)、(1, 1) 三支？**多余**——第三支是前两支配出来的，白带。

## 四、还账：配方只有一种

现在可以还第三篇那笔账了。

BOX[key]: 定理与证明 :: **一套基定下来以后，每个点的配方只有一种。**// // 设同一个点有两种配方：// 一种是 **a 份第一支 ＋ b 份第二支**，另一种是 **a′ 份 ＋ b′ 份**。// // 两式**相减**：**(a − a′) 份第一支，拼上 (b − b′) 份第二支，结果是空箭头。**// // 现在看 a − a′。**假如它不是 0**，把式子挪一挪：// 第一支箭头就等于第二支的某个倍数——**两支平行了**。// 可基的第二条说好了**不平行**。**矛盾。**// 所以 **a − a′ 就是 0**，也就是 a 和 a′ 一样。// 同样的话对 b 再说一遍。// // **两个配方本来就是同一个。证毕。**

BOX[remember]: 这笔账还得干净 :: 第三篇姐姐说"用料清单是死的"，当时只是**断言**。// 现在你看见它的**根**了：// **清单唯一，靠的是两支箭头不平行。**// 要是有人拿两支平行的箭头当基，// 这条定理**当场就垮**——那时候有的点一种配方也没有，有的点却有无穷多种。

## 五、维数：数一数要几支箭头

BOX[remember]: 维数 :: 一片天地的一套基里有**几支箭头**，就说它是**几维**的。// **整个平面：2 维**（要两支）。// **一条过出发点的直线：1 维**（一支就够）。// **只有出发点：0 维**（一支也不要）。// // 换一套基，**支数不会变**——这一条这一册不证（附录 D 记着这笔账），// 可你想想也知道：一条线上无论怎么挑，一支就够、两支必多余。

现在，**第七篇那笔"维数守恒"的账，可以正经写出来了**：

CENTER: **核的维数，加上像的维数，正好是出发时的维数**

投影机吃掉一条线（1 维），影子铺满地面（2 维），出发时是空间（3 维）：**1 加 2 等于 3。**

## 六、换一套基：同一只兔子，两张点名单

第一篇埋过一颗种子：**坐标系是人定的——换一张，坐标全变，兔子没变。**现在它长出来了。

**换一套基，就是换一张坐标图纸。**

BOX[key]: 用斜的格子看兔子 :: 不用横竖两支箭头，改用这两支：// **第一支还是 (1, 0)；第二支换成 (1, 1)**（斜着朝右上方）。// 它们不平行，够用也不多余——**是一套合法的基。**// // 现在报兔子的**右脚外**那个点 (3.5, 0.5)。用新料怎么配？// 取 a 份第一支、b 份第二支，拼出来是 **(a ＋ b, b)**。// 要它等于 (3.5, 0.5)：**b 是 0.5**，**a 是 3**。// // **同一个点：老名单上写着 (3.5, 0.5)，新名单上写着 (3, 0.5)。**// 左耳尖 (1, 8.5) 换到新名单上是 **(−7.5, 8.5)**（你自己验一验）。

FIG: fig-r20-newbasis.png | 同一只兔子，两套格子。左边是横平竖直的老格子，右边是斜着的新格子——兔子一根毛都没动，可名单上的数全变了。

BOX[remember]: 这就是第一篇那句话的兑现 :: 第一篇说：**"东西没变，说法变了。"**// 那时只是给你看了个念头，现在它是一件**做得出来的事**：// **换一套基，重报一遍名单。**// // 兔子没变。变的是我们**用哪两支箭头当尺**。// // 这也回答了第一篇 C5 那个问题：// **同一只兔子，能不能有两张不一样的点名单？**// **能。有多少套基，就有多少张名单。**

BOX[dialog]: 妹妹问一句要紧的 :: **妹妹：**"那哪一张名单是**对**的？"// **姐姐：**"**都对。**它们说的是同一只兔子。"// **妹妹：**"那为什么大家都用横竖那一套？"// **姐姐：**"因为它最顺手——格子方方正正，量长度、量角度都好算。// 可**换一套基常常更省事**：// 有的机器在斜格子里看，账本会变得特别简单，// 那时候聪明人就换过去算，算完再换回来。"// **妹妹：**"哪种斜格子？"// **姐姐：**"**下一篇专门去找它。**"

## 七、直观翻车：多带一支箭头，一点好处也没有

妹妹最后一刺：**多给我一支箭头，我是不是就能配出更多东西？**

**一点也不能。**

BOX[key]: 平面上三支箭头，必有一支是多余的 :: 手里已经有不平行的两支了——**它们已经配得出整个平面**。// 你再添第三支，它本来就在平面上，**当然也配得出来**。// 添了等于没添：**能配的东西一个没多，配方倒不唯一了。**// // 拿 (1, 0)、(0, 1)、(1, 1) 试试配 (2, 1)：// 可以是"2 份第一支 ＋ 1 份第二支"，// 也可以是"1 份第一支 ＋ 0 份第二支 ＋ 1 份第三支"。// **两种配方，一样对。**// // **多余的料，买的不是本事，是麻烦。**// 这就是基为什么要求"不多余"。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: "配得出的那片天地"正式叫**张成**（span）；一套箭头"不多余"叫**线性无关**，"够用"叫**张成整个空间**；两条合起来就是**基**。**维数**就是基里向量的个数。// 第四节那条定理是基的**根本用处**：基一定，每个向量的坐标唯一。// 第五节那条"换一套基支数不变"，课本会郑重其事地证一遍（要用**替换定理**），这一册只当约定接受。// 第六节的换基，正式叫**基变换**；把老坐标换成新坐标的那台机器，账本叫**过渡矩阵**。C3 的答案值得记住：**换基不改变兔子，可"面积"和"垂直"这些说法本身就要靠格子才有意义**——斜格子里量出来的"面积"和老格子里不一样。要谈长度和角度，得再给空间配一件东西，叫**内积**。// 子空间、基、维数这一套，往上还能装下**函数**——**第十篇就把它们装进去**。而**下一篇**先用这一套去做一件最有用的事：找出机器掰不歪的方向。
