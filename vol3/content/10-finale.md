# 第十篇　收官：机器也是一串数

CENTER: 兔子住的那块地板，第二册的机器也站在上面

九篇下来，我们一直在跟**向量**打交道：一串数，能拼、能取几份、能配方、能被机器搬。

这一篇要说一件出人意料的事：**第二册那些"机器"，其实也是一串数。**

## 一、向量的全部本事，只有两样

先把话说清楚：**这一册从头到尾，只用过向量的哪些本事？**

翻回去数一数。第一篇：坐标相加、乘倍数。第三篇的配方：**取几份，拼起来**。家规一、家规二：**拼**和**几倍**。第八篇的基和维数：还是**拼**和**几倍**。第九篇那句"不歪"：说的也只是**出来的向量是进去的几倍**。

BOX[remember]: 就这两样 :: **一、两个向量能加起来。**// **二、一个向量能乘一个倍数。**// // 我们**从来没用过别的**——没量过长度，没量过角度，没说过谁比谁长。// **前八篇的每一条道理，都只踩在这两样本事上。**

这一条一旦看清楚，一个念头就冒出来了：

CENTER: **凡是"能加、能乘倍数"的东西，是不是都能照这一册的办法处理？**

## 二、多项式机器也能加，也能乘倍数

回第二册去找一样东西：**次数不超过 2 的多项式机器**，比如

CENTER: **f(a) ＝ 3a^2^ ＋ 5a − 1**

两台这样的机器，能不能"加起来"？当然能——**把它们吐出来的数加起来**，就是一台新机器。乘倍数也一样：**把它吐出来的数乘 3**。

BOX[key]: 验一验它守不守规矩 :: 加起来的还是"次数不超过 2 的多项式"吗？// **是**：a^2^ 那一项加 a^2^ 那一项，还是 a^2^ 那一项，次数不会涨上去。// 乘倍数呢？**也是。**// // 所以这些机器**关起门来自己就够用**——加也好、乘倍数也好，// **永远跑不出这一族**。// 第八篇说过，这样的一片地方叫**子空间**；// 而这一族机器**自己就是一整片天地**。

## 三、这一族机器的一套基

既然能加、能乘倍数，第八篇那一套就全能用上：**它有基吗？几维？**

BOX[key]: 三个"向量" :: 挑这三台最简单的机器当料：// **1**（投什么都吐 1）、**a**（投什么吐什么）、**a^2^**（投 a 吐 a 的平方）。// // 任何一台"次数不超过 2 的多项式机器"，都是它们的配方：// **3a^2^ ＋ 5a − 1** 就是"3 份 a^2^，加 5 份 a，减 1 份 1"。// // **够用**（每台都配得出）；**不多余**（谁也配不出谁）。// **所以它们是一套基——这一族机器是三维的。**

BOX[remember]: 请把这句话读两遍 :: **一台机器，是那片天地里的一个"点"。**// f(a) ＝ 3a^2^ ＋ 5a − 1 这台机器，在那套基下的坐标是 **(3, 5, −1)**。// // 兔子的一个点要三个数，这台机器也要三个数。// **在"能加、能乘倍数"这件事上，机器和向量没有分别。**

## 四、求导也是一台老实机器

更妙的还在后面。第二册第四篇教过**求导**：投进一台机器，吐出它的导数。

**求导本身，也是一台机器**——只不过它吃的不是数，是**机器**。

BOX[key]: 它守两条家规吗 :: **家规一（拼法不变）：**两台机器先加起来再求导，和各自求导再加起来，一样吗？// **一样。**第二册第四篇第六节那三条规矩，第一条正是 **(f ＋ g)′ ＝ f′ ＋ g′**。// // **家规二（几倍就几倍）：**一台机器乘 5 再求导，是不是等于求导以后再乘 5？// **是。**那正是第二条规矩 **(5f)′ ＝ 5f′**。// // 两条都过。**求导是一台老实机器**——// 而且它老实这件事，**第二册早就证过了**，我们一个字都不用重证。

BOX[remember]: 账本也记得出来 :: 求导对那三个"向量"做了什么？// **1 的导数是 0**；**a 的导数是 1**；**a^2^ 的导数是 2a**。// 用坐标写（还是那套基 1、a、a^2^）：// (1, 0, 0) 送到 **(0, 0, 0)**；(0, 1, 0) 送到 **(1, 0, 0)**；(0, 0, 1) 送到 **(0, 2, 0)**。// // 三个向量的落点记下来，就是**求导机器的账本**。// **第三篇那条"知道基本向量的落点，就知道一切"，在这里照样管用。**

## 五、求导机器的核，就是常数

现在到了这一册和第二册**真正接上**的地方。

BOX[key]: 问一句第六篇的老问题 :: **求导机器的核是什么？**// 也就是：**哪些机器，求导以后变成了"处处是 0"那台？**// // 答案孩子都答得上：**常数机器**（投什么都吐同一个数）。// 5 的导数是 0，−7 的导数是 0。// // **所以求导机器的核，就是所有的常数机器**——// 用坐标说，是 (c, 0, 0) 这样的点，**一条过出发点的直线，1 维。**

BOX[remember]: 第二册那句最要紧的话，原来是这个意思 :: 第二册第六篇第六节有一条**推论二**：// **导数处处是 0 的机器，只能是一条平线**（也就是常数）。// 第二册用它证了**推论三**：**两台机器导数一样，就只差一个常数**；// 而牛顿–莱布尼兹公式**整个踩在推论三上**。// // 现在用这一册的话再说一遍那件事：// **推论二说的是：求导机器的核，只有常数。**// **推论三说的是：两台机器落点相同，它们的差就在核里**（第六篇第四节那个证明！）。// // **一模一样的道理，两册书各说了一遍。**// 第二册说它的时候用的是中值定理；这一册说它的时候用的是核。// **牛顿–莱布尼兹公式那句"一减就抵掉了"，抵掉的正是核里的东西。**

BOX[dialog]: 妹妹把两册接上了 :: **妹妹：**"照这么说，第二册找'导数是 √a 的那台机器'，答案不止一个？"// **姐姐：**"对。**找到一台，加上任何常数都还是**——差的就在核里。"// **妹妹：**"那算面积的时候怎么不出错？"// **姐姐：**"因为最后要**一减**。核里的那点差别，**减法把它抵掉了**。// 第二册第十篇管这个叫'一层层抵消'——// 现在你知道被抵掉的是什么了：**是核。**"

## 六、地板的名字

到这里，可以给这块地板起名字了。

BOX[remember]: 线性空间 :: 一堆东西，只要**能加起来、能乘倍数**，而且加和乘规规矩矩（加了还在这堆里，乘了也还在），// 这堆东西就叫一个**线性空间**。// // 你已经见过好几个了：// **纸上的所有向量**（第一篇起就住在里面）；// **空间里的所有向量**（第七篇）；// **次数不超过 2 的多项式机器**（这一篇）；// **一台机器的核**、**一台机器的像**（第六、七篇）。// // 它们长得一点也不像。可**这一册讲的每一条道理，对它们全都成立**——// 配方、基、维数、核、像、维数守恒，**一条都不用改**。

BOX[key]: 这就是为什么值得把话说得这么泛 :: 有人会问：干吗不老老实实只讲纸上的向量？// 因为**同一套道理，说一遍就管一大片**。// // 你为兔子学的东西，**顺手就能用在多项式机器上**——// 而多项式机器和兔子，**看起来毫不相干**。// // 这一册最后要交给你的不是兔子，是这句话：// **认出两样东西"守同一套家规"，就等于白得了一整套道理。**

## 七、回头看：变了什么，什么没变

这一册从头到尾问的是同一句话：**兔子变了，什么没变？**收尾了，把账结一结。

TABLE:
| 兔子被怎么变的 | 变了什么 | 什么没变 |
| 放大、压扁、斜拉、转、照镜子 | 位置、形状、朝向 | **直线还是直线**（第三篇第五节） |
| 任何老实机器 | 大部分点都挪了窝 | **出发点一步没动**（第三篇第二节） |
| 斜拉、转 90° | 形状歪了、转了 | **地皮的大小**（第五篇：放大率是 1） |
| 压扁到 0 | 一整个方向被吃掉 | ——**这一次真的丢了东西**（第六篇：核） |
| 换一套基 | 名单上的数全变 | **兔子一根毛都没动**（第八篇） |
| 换到"不歪的格子"里 | 账本只剩对角线上两个数 | **机器一点没变**，变的只是我们从哪套格子看它（第九篇） |

BOX[remember]: 这一册的一句话 :: 学数学，常常不是学"东西怎么变"，// 而是学**"变来变去，什么东西不变"**。// // 不变的那些，才是这个东西**真正的样子**。// // 第一册问的是"做不完的事怎么谈"；// 第二册问的是"变化有多快、面积有多大"；// 这一册问的是"**变了什么，什么没变**"。// **三本书，三个问题，一套本事。**

**妹妹出题，姐姐证明——往后也是这样。**

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: **线性空间**也叫**向量空间**；课本会把"能加、能乘倍数"拆成**八条公理**（加法交换、结合、有零元、有相反数，数乘的四条），一条条列出来——**说的就是第六节那一句话**。// 第一篇给"一串数"起的那个名字**向量**，管的地方比你想的宽得多——**一台多项式机器也是一个向量，一个函数也是一个向量。**这件事第一次听见都别扭，可你已经验过了：**它守同一套家规。**// 求导那台机器叫**微分算子**，常记作 D；"吃机器、吐机器"的机器统称**算子**。第五节那条"核是常数"，正式写作 ker D，它就是常函数那一族。// 第六节那份名单还能一直列下去：所有连续函数、所有数列、所有解某个微分方程的函数……都是线性空间。**最有名的一件事**：一个声音可以拆成许多个纯音"配方"配出来——那是**傅里叶分析**，用的正是基和坐标这一套，只不过基里有**无穷多个向量**。// 你手机里的每一张照片、每一段音乐，压缩的时候都在做同一件事：**换一套基，让大部分坐标变得很小，然后把小的扔掉。**
