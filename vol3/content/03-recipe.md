# 第三篇　两串数定乾坤

CENTER: 只要知道那两串数去哪，整只兔子的落点就全定了

第二篇造了几台变换机：压扁机、镜子机、斜拉机、转 90° 机。它们各有各的脾气，但都守着同两条家规。这一篇就把家规挑明——然后收获一件大礼：**凡守家规的机器，全部秘密只有两个向量那么大。**

## 一、一串数能拼起来

第一篇说过，一个点就是**一串数**——(3, 2)，横 3 竖 2；这样一串排定了顺序的数，正式名字叫**向量**。

这一节只做一件事：**让你看见一串数能拼。**

BOX[remember]: 配方 :: 备两个最简单的向量：**横向量 (1, 0)**（往右一格）和**竖向量 (0, 1)**（往上一格）。// // 那么 (3, 2) 是什么？**三份 (1, 0)，加上两份 (0, 1)。**// 横的跟横的算、竖的跟竖的算：**3 ＋ 0 ＝ 3**，**0 ＋ 2 ＝ 2**——// 拼出来正好是 **(3, 2)**。// // 纸上**任何**一个向量都这么配得出来。// 每个点的坐标，本来就是它的**配方**：横坐标说要几份横向量，竖坐标说要几份竖向量。

BOX[key]: 画出来是一支箭，可它不是一支箭 :: 一串数画在纸上，习惯画成**一支从出发点射出去的带尖线段**：// (3, 2) 就是往右 3、往上 2，尖正好停在 (3, 2)。// 一份接一份地画，**首尾相接**，你一眼就看见"拼"是怎么回事——// 下面这张图就是这么画的。// // **但请记住：那只是画法。**// 向量是什么？**还是那一串数。**// 画成箭，是为了让眼睛帮上忙；真要算，算的始终是**横的跟横的、竖的跟竖的**。

FIG: fig-r03-recipe.png | 三份 (1, 0) 接两份 (0, 1)，尖落在 (3, 2)。坐标就是配方——画成箭只是为了看得见"拼"。

BOX[dialog]: 配方就一种吗 :: **妹妹：**"我偏不这么配。先上再右，或者右一步上一步交替走，行不行？"// **姐姐：**"走的路线随你，**用料清单是死的**：不管什么顺序，横着的总共 3 份、竖着的总共 2 份。"// **妹妹：**"要是拿别的向量当基本向量呢？"// **姐姐：**"问到点子上了——那是第八篇的正题。在那之前，基本向量就是横、竖这两个，// 而'清单只有一种'这句话，第八篇会正式审判。**先记下：这里赊了一笔。**"

## 二、老实机器的两条家规

第二篇那几台机器，好脾气全在这两条：

BOX[remember]: 家规（"老实机器"的定义） :: **家规一（拼法不变）：**两个向量先拼好再进机器，和各自进机器再拼，**落点一样**。// **家规二（几倍就几倍）：**一个向量的 3 倍进机器，出来正好是"它出来的样子"的 3 倍。// // 家规二你在第二册见过——就是**成正比**。// 那时机器吃一个数，"成正比"只有一个方向；// 现在机器吃一个点，横竖**两个方向都得成正比**，还得允许两个方向拼在一起。// **守这两条家规的机器，叫老实机器。**

BOX[remember]: 别把"好"和"老实"混成一件事 :: 第二册第一篇分过**好机器**和**破机器**：守诺言的是好机器。// 这一册的机器**全都是好机器**——投一个点进去，吐出来的点是说死了的。// **"老实"说的是另一件事：守不守上面那两条家规。**// 第六节你会看到一台**又好又不老实**的机器（平移）：// 它守诺言，可它不守家规。// **一个词管一件事，别混。**

先验一台。压扁机（竖坐标减半）：两个向量拼好再压，和各自压完再拼，你在方格纸上各走一遍，落点重合；3 倍进去，出来正好 3 倍。**守规。**

BOX[task]: 留给妹妹 :: 照同样的办法验**镜子机**（横坐标变号）：// 拿 (2, 1) 和 (1, 3) 两个向量，先拼再照镜子、先照镜子再拼，落点一样吗？// 再拿 (1, 2) 的 3 倍试家规二。

BOX[key]: 家规的一个小推论：出发点是钉死的 :: 一个向量的 **0 倍**，是 **(0, 0)**——两个数都是 0，正好停在出发点。// 它有个正式名字，叫**零向量**。// 按家规二，零向量进机器，出来是"它出来的样子"的 0 倍——**还是零向量**。// 所以：**老实机器必把出发点留在原地。**出发点挪了窝的，一定不老实。// 这颗小钉子，第六节马上用上。

## 三、这一篇的定理：两串数定乾坤

现在收大礼。

BOX[key]: 定理与证明 :: **只要知道横向量、竖向量进机器后各落在哪，纸上每一个向量的落点就全定了。**// // 证明就是家规连用。拿 (3, 2) 说：// 它是"三份横向量拼两份竖向量"。// 按**家规一**，拼好再进机器，和各自进机器再拼，落点相同；// 按**家规二**，"三份横向量"出来 ＝ 三份"横向量出来的样子"。// 所以：**(3, 2) 的落点，就是三份"横向量的落点"，拼上两份"竖向量的落点"。**// 配方不换，**换料**。对任何一个点都是这一句。**证毕。**

BOX[remember]: 这句话有多值钱 :: 兔子有 38 个点，纸上有无穷多个点。// 可一台老实机器的**全部秘密**，只是**那两个向量的落点**——两串数，四个数字。// **知道四个数，就知道它对整张纸做的一切。**

## 四、账本：把两个向量的落点记下来

四个数，记成一个小方块，叫这台机器的**账本**——**第一篇末尾亮过相，第二篇每造一台机器都记过一笔**。当时它只是**一张记录**；上一节那条定理一证完，它的身份就变了：**记录变成了整台机器本身**。

BOX[remember]: 账本的规矩 :: **第一列：横向量去哪。第二列：竖向量去哪。**// 例：斜拉机把横向量留在 (1, 0)，把竖向量推到 (1, 1)，账本就是// **[[m:1,1;0,1]]**// （每一列**竖着读**：上面是落点的横坐标，下面是竖坐标。）

FIG: fig-r05-basis.png | 账本的本体：斜拉机让横向量留在 (1, 0)，把竖向量斜到 (1, 1)。两个落点，四个数。

FIG: fig-r04-shear.png | 退远了看：格子整齐地歪过去，兔子跟着歪——全都被那两个向量带着走。

有了账本，算任何点的落点就是**按配方兑换**：

BOX[key]: 按配方兑换（账本乘点） :: 点 (3, 2) 过斜拉机：// **落点就是：三份第一列，拼两份第二列**——// 三份 (1, 0) 拼两份 (1, 1)，先算出 (3, 0) 和 (2, 2)，再拼在一起：**(5, 2)**。// // 第二册第四篇第五节有一台**兑换机**：投多少，按一个率给多少。// 这里是它的升级版——**多路兑换机**：率不再是一个数，是一小方块数；// 横坐标按第一列兑，竖坐标按第二列兑，兑出来的拼在一起。

BOX[task]: 留给姐姐 :: 用斜拉机的账本兑这三户：(1, 1)、(0, 3)、(2, −1)。// 兑完在方格纸上点出来，和图里歪掉的格子对得上吗？// 再给**转 90° 机**记账本：横向量去 (0, 1)，竖向量去 (−1, 0)——写出那个小方块。

## 五、为什么连点成画还管用

有一件事从第一篇起就被我们**默默占着便宜**：变换兔子时，我们只搬 38 个点，然后**按原来的连线单连线**。凭什么线上的点会乖乖跟着？

BOX[key]: 老实机器把中点送到中点 :: 两个点 u、v 的**中点**，配方正好是"半份 u 拼半份 v"。// 过机器：按家规一拆开、按家规二折半——// **中点的落点，正是两个落点的中点。**// 中点如此，三七开的分点也如此（把"半份"换成"三份七份"，同一笔账）。// 线段上的每一个点都是两端的某种"几几开"，所以：// **整条线段的落点，还是一条线段——直线仍是直线。**

BOX[remember]: 连点成画的合法证 :: 所以只搬 38 个点、按原单连线，得到的**就是**变换后的兔子——// 线上的点确实都落在新线上，一个也没跑。// **这不是运气，是家规给的**：不守家规的变法（比如每点各行其是），线就不跟点走了。// "变了什么，什么没变"——这一册的书名，第一笔答案在这儿：**直线这件事，没变。**

## 六、直观翻车：平移居然不老实

第一篇最早做的动作——**右移 3**——现在用家规一验货。

**不合格。**这是本篇要抓的那条刺。

BOX[key]: 验货过程 :: 最快的一刀是第二节那颗小钉子：**老实机器必把出发点钉在原地**，// 可右移机把出发点搬去了 (3, 0)。**当场露馅。**// 不服的话再验家规二：(2, 0) 是 (1, 0) 的 2 倍；// 右移后它们落在 (5, 0) 和 (4, 0)——可 (4, 0) 的 2 倍是 (8, 0)，**不是** (5, 0)。// 两条家规，条条过不了。

BOX[remember]: 这一刺的教训 :: "平移"看着最无辜，却**不是老实机器**——它没有 2×2 的账本。// 定义不是摆设：**"老实"是道门槛，不是句客气话**，// 连平移都进不来，这道门槛才算真的立在那里。// （游戏引擎怎么把平移也收编进账本，见「长大以后」。）

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 配方叫**线性组合**，横竖两个基本向量叫**标准基**（常记作 e~1~、e~2~）；第二节那个 (0, 0) 叫**零向量**。家规一、二合起来叫**线性**——所以老实机器的学名是**线性映射**，账本叫**矩阵**，按配方兑换就是**矩阵乘向量**。// 第二册灰盒里说过一句"微分是一个线性映射"——现在能接上了：**一维的账本就是一个数 f′(a)，一乘了事；二维的账本是 2×2 的小方块。**两册在这里握手。// 平移的收编：图形学用 3×3 账本处理平面（**齐次坐标**），把"挪出发点"也塞进乘法——游戏引擎里就是这么搬兔子的。// 显卡（GPU）的本职工作，就是把几万个点的名单**成批**做"按配方兑换"，每秒亿万次。
