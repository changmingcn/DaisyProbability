# 第一篇　用点名单造一只兔子

CENTER: 兔子不是"画"出来的，是"报"出来的

先出一道难题。

**有个孩子从没见过兔子。你要指挥他画一只出来——可你不许给他看图，也不许自己动笔，只能说话。怎么办？**

先试试形容词："耳朵长长的，身子圆圆的，尾巴短短的。"

他照着画，交上来的多半是个怪物。也怪不得他：**长是多长？圆是多圆？耳朵从身子的哪儿长出来？**这些话里一个数都没有，他只能自己猜——**猜出来的当然不是你那只兔子。**

办法其实很笨，可是很灵：

BOX[key]: 让他找一张方格纸，你只报数 :: "从这个角上数起。往右 1 格、往上 0 格——点一个点。"// "往右 2 格、往上 0 格——再点一个点。"// "往右 2 格半、往上 半格——再点一个……"// // 三十多个点报完，再报一遍**连线的顺序**：1 连 2、2 连 3……最后连回 1。// 他一笔一笔连下去——// **兔子出来了，和你那只一模一样。**

他从头到尾没见过兔子。**兔子是被一串数送过去的。**

BOX[remember]: 这一册全部的起点 :: **把一张图变成一串数，它就能被搬运、被存起来、被算。**// 用嘴说得出去，用电报发得出去，存得进电脑，// **也就交得给机器去改它。**// // 这一册后面所有的事——放大、压扁、转、照镜子——// **全是在这串数上做的算术。**// 先把图变成数，剩下的就都好办了。

这也正是"连点成画"那个老游戏在干的事。只不过从今天起，我们要**认真说一句它从来没说的话：那只兔子到底"是"什么。**

不过且慢——刚才那句"从这个角上数起，往右 1 格"，其实还欠着交代：**从哪个角？一格多大？**他要是跟你想的不一样，画出来的兔子就走样了。

**所以第一件事，是把话说定。**

## 一、先铺一张坐标系

要"报"出一个点在哪儿，得先有一套说法。这套说法叫**坐标系**，铺它只要三件事：

BOX[remember]: 坐标系是三件事 :: **一、定一个出发点。**纸上随便挑一个点，说好"从这儿数起"。它有个正式名字叫**原点**。// **二、画两条轴。**一条往右，叫**横轴**；一条往上，叫**竖轴**。// **三、说定一格有多大。**一厘米？一个方格？说定了就不许改。// // 三件事齐了，纸上**每一个点**就都有了自己的两个数——照着这两个数走，就能走到它。

BOX[key]: 你早就用过坐标系——地图 :: 手机上的地图，用的就是这一套，三件事一件不缺：// **出发点**——地图中间那个"你在这里"的小点；// **两条轴**——横着是东西，竖着是南北；// **一格有多大**——地图角上那个**比例尺**："图上这么长，实际一百米"。// // 报一个地方在哪儿，你本来就会：// "**从校门口往东两个路口，再往北一个路口。**"// 这句话里的"东两个、北一个"，就是那个地方的**坐标**。// // 数学的图纸和地图只差一点：**地图上一般不出现负数**，// 而图纸上往左、往下就是负的——**往回走而已，没什么可怕。**

FIG: fig-r00-coord.png | 坐标系就是这三件事：出发点、两条轴、一格多大。有了它，(3, 2) 才有意思：从出发点先往右 3 格，再往上 2 格。

这两个数怎么念？**先横后竖**：

BOX[remember]: 坐标：把指路的话写成两个数 :: **(3, 2)** 念作"横 3 竖 2"，说的就是那句指路的话：// **从出发点先往右 3 格，再往上 2 格。**往左、往下就是负的。// // 这两个数，叫这个点的**坐标**：// 前一个管横着走多远，叫**横坐标**；后一个管竖着走多远，叫**竖坐标**。// // **先横后竖，顺序不能换。**// (3, 2) 和 (2, 3) 是**两个不同的点**——一个在右三上二，一个在右二上三。// **一个数说不清一个点在哪儿，得两个数**；哪个在前、哪个在后，得先说死。

现在到了这一节真正要紧的一句话：

BOX[key]: 坐标系是人定的，不是天生的 :: 纸上本来什么都没有——**出发点是我们挑的，一格多大是我们说的。**// 换一张坐标系会怎样？// **把出发点挪到别处**：同一个点，两个数全变。// **把一格定成原来的两倍大**：所有的数都变成一半。// // 可是请注意：// **兔子还是那只兔子。**它一根毛都没动，变的只是我们报数的方式。// // **"东西没变，说法变了"——这句话是这一册最深的一件事，**// 第九篇会专门讲它（那时它有个名字，叫**换一套基**）。// 现在只要记住：**坐标是相对于坐标系说的——换一张坐标系，同一个点就换一套数。**// // 地图也一样：**同一家店**，在以学校为中心的地图上和在以火车站为中心的地图上，// 报出来的两个数完全不同——**可店一步也没挪。**// // 开篇那个孩子就是活例子：他要是把出发点定在纸的另一个角上，// 照你报的数画出来，兔子会**挪个窝**；他要是把一格画成两倍大，兔子会**大一圈**。// **可那还是你那只兔子**——走样的不是兔子，是两个人没把坐标系说定。

外加一张**连线单**：1 连 2，2 连 3，……35 连 36，最后 **36 连回 1**。

还差最后一样东西——**两只眼睛**。它们是第 **37** 号 **(2.5, 5)** 和第 **38** 号 **(3.5, 5)**：

BOX[remember]: 眼睛不连线 :: 连线单里**没有**这两号——它们不连给任何点，**各画一个孤零零的点**。// // 再留意一样东西：**尾巴长在兔子的左边**（第 31 号那个尖）。// 这只兔子正面站着，左右看着差不多，可**尾巴只有一条，而且偏在一边**。// 后面兔子会被转、被照镜子；// **看一眼尾巴在左边还是右边，就知道它翻没翻过来。**

FIG: fig-r01-rabbit.png | 把 36 个点都点上，按连线单连起来，再补上眼睛——兔子。尾巴尖住在 (0.5, 2)，右耳尖住在 (3, 8.5)。

BOX[remember]: 兔子到底是什么 :: **兔子，就是点名单加上连线单。**// 纸上的图只是这两张单子的**照片**；单子才是本体。// 往后我们对兔子做的每一件事，其实都是**对名单做的**。

现在给名单上的那一行，起个名字。

BOX[remember]: 一串数，就叫向量 :: 名单上的每一行，都是**两个数排成一串**：(3, 2)。// 而且**先横后竖，顺序不能换**——(3, 2) 和 (2, 3) 是两个不同的点。// // 这样**一串排定了顺序的数**，有个正式名字，就叫**向量**。// // 所以开头那句话，现在可以说得更准：// **兔子，就是 38 个向量，加上一张连线单。**// // 请注意它是什么、又不是什么：// **向量就是一串数。**不是"带箭头的东西"，也不用先量长短、先分朝向——// **一串数，有先有后，能算，就够了。**// 这一册后面所有的事——放大、压扁、照镜子、转、拉斜——// **全是在这些向量上做的算术。**

BOX[dialog]: 那它到底是哪一串数 :: **妹妹：**"上一节你自己说的，坐标系是人定的。// 换一套格子，同一个点就换一串数——// 那这个点**到底是哪一串**？"// **姐姐：**"问到要害上了。'向量就是一串数'这句话，// 是**说定了一套格子之后**才算数的。// 换一套格子，同一个点换一串数，可**兔子一根毛都没动**。// 这笔账我当场记下——**第九篇第六节还。**"

BOX[dialog]: 少连一笔会怎样 :: **妹妹：**"要是我把连线单弄丢一行，比如 30 连 31 那行，会怎样？"// **姐姐：**"兔子的尾巴上就豁一个口。点一个不少，兔子却破了——// 所以连线单和点名单**一样要紧**：兔子不光是'哪些点'，还是'谁挨着谁'。"

BOX[key]: 从下一节起，书上印的是一张真正的兔子画 :: 上面那只兔子只有 **36 个点**，所以看着有点方。// **这不是缺点。**点少，你才照着画得出来；// 而"**一张图能用一串数报出去**"这件事，36 个点已经说得明明白白。// // 可往后我们要一遍遍地变它、看它，方棱方角的看着累。// 所以**从下一节起，书上印的是一张真正的兔子画**。// // **道理一个字都没变。**一张画说到底**也是一堆数**——// 它由几十万个小方格拼成，每个小方格记着一个颜色（这件事「长大以后」会细说）。// 机器变换它的时候，**整张画按同一本账搬过去**，// 和你对着 36 个点做的事，**是同一件事**。// // **你动手做题，仍旧用上面那 36 个点；书上的图，用那张画。**

FIG: fig-r22-two-rabbits.png | 左：36 个点的兔子，名单印在上面，你照着画得出来。右：书上往后要用的那张兔子画——它也是一堆数，只是数得太多，印不下。

## 三、搬动兔子，就是对名单做同一件事

兔子造好了，让它动起来。规矩只有一条：

BOX[key]: 一句咒语 :: **对名单上的每一个点，做同一件事。**// 每个点都往右挪 3 格，兔子整只右移；// 每个点都变个法子，兔子就变个样子。// 要是每个点**各行其是**——这个右移、那个上跳——// 点还是那些点，兔子就**散架**了。// （眼睛也得一起挪。**它也在名单上。**）

试两个：

- **每个点的横坐标都加 3**：全体右移，兔子平平地挪了个窝。
- **两个坐标都乘 2**：兔子变大了——**而且离出发点更远了**。像从出发点朝它吹气球：越吹越大，也越吹越远。

FIG: fig-r02-moves.png | 左：横坐标都加 3，整只右移。右：两个坐标都乘 2——变大，也被"吹"得离出发点更远。

BOX[remember]: 乘 2 的那个小惊喜 :: 很多人以为"乘 2"就是兔子原地变胖。**不是**：// 坐标是从**出发点**量起的，乘 2 是**从出发点吹气球**——// 兔子的每一个点，离出发点的距离都翻了一倍。// **出发点在哪儿，太要紧了。**这件事这一册会一说再说。

BOX[key]: 先看一眼这一册的主角 :: 这一册真正的主角，是一种**四个数摆成方块**的小东西——// **[[m:1,1;0,1]]**// 别看它其貌不扬：往后你会看见，**一台能变兔子的机器，全部家当就是这么四个数。**// // 不过路要一步一步走：// **下一篇**先学会这些数的**算术**——一串数怎么加、怎么乘倍数，这个方块怎么"吃"向量；// **第三篇**造出五台真正的机器——放大、压扁、照镜子、转 90°、斜拉，每台记一笔四个数的账；// **第四篇**兑现大话：**为什么四个数就是整台机器。**// // 眼下一个字都不用背——**记住它长这样就行**。

## 四、习题

BOX[task]: A 组：认一认 :: **A1.** 铺一张坐标系要说定哪三件事？少说一件会怎样？// **A2.** (2, 5) 和 (5, 2) 是同一个点吗？各自怎么走到？// **A3.** 兔子的尾巴尖住在哪？两只耳朵尖呢？两只眼睛呢？（查表。）// **A4.** 坐标 (0, 0) 是哪个点？坐标里出现负数是什么意思？// **A5.** "兔子就是点名单加连线单"——为什么少了哪一张都不行？

BOX[task]: B 组：动动手 :: **B1.** 拿一张方格纸，照点名单把 36 个点全点上，按连线单连出兔子，别忘了补上眼睛。（这是全书第一件手工，值得做。）// **B2.** 把每个点的**竖坐标加 2**，重新画。兔子怎么了？// **B3.** 把每个点的两个坐标**都乘 [[1/2]]**，重新画。兔子怎么了？离出发点近了还是远了？// **B4.** 把每个点的**横坐标乘 2、竖坐标不动**，画出来。这还像兔子吗？像什么样的兔子？// **B5.** 画一张**你家到学校的地图**：先定出发点（就用你家），说定一格代表多远，再把学校、小卖部、公交站三个地方的坐标报出来。拿给家里人看看，他能照着你的坐标把这三个地方点回原处吗？// **B6.** 换一张坐标系试试：**把出发点挪到兔子的左眼上**（也就是给每个横坐标减 2.5、竖坐标减 5），重新报一遍名单。// 　这时候左眼的坐标是多少？兔子看上去变了吗？

BOX[task]: C 组：想一想 :: **C1.** 把每个点的两个坐标**都乘 −1**，先猜兔子会去哪、朝哪，再动手画。（**盯住眼睛**，它会告诉你答案。）// **C2.** 连线单不变，把点名单里 31 号（尾巴尖）和 21 号（左耳尖）的坐标**互换**，兔子会怎样？这说明号码和坐标是什么关系？// **C3.** "对每个点做同一件事"——要是只对耳朵上的点右移 3，别的点不动，会出现什么？什么时候我们会**故意**这么干？（提示：想想动画片里兔子摇耳朵。）// **C4.** 有没有一种"对每个点做同一件事"，做完兔子**一点都没变**？它配叫"做了一件事"吗？// **C5.** B5 里换了坐标系，**兔子本身有没有变**？那"点名单"变了没有？——同一只兔子，能不能有两张不一样的点名单？

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 这一节铺的东西正式叫**直角坐标系**（也叫**笛卡儿坐标系**——笛卡儿是四百年前的法国人，据说他躺在床上看见天花板上的苍蝇，才想到用两个数报出位置）。这一册说的**横坐标、竖坐标**，课本上叫**横坐标、纵坐标**（"纵"就是竖）；出发点叫**原点**；那两条线叫 x 轴和 y 轴（课本用 x、y 当那两个数的名字；这一册说"横坐标、竖坐标"，为的是让"哪个管横、哪个管竖"自带在名字里）。// "一格有多大"正式叫**单位长度**；第一节说的"换一套坐标系"，正式叫**坐标变换**，第九篇会讲它的真名字：**换基**。// 第二节起的名字**向量**，课本上写法不止一种：横着写 (3, 2)，也常竖着写成一列（叫**列向量**）；这一册一律横着写。**计算机里管"一串排好顺序的数"叫数组**（array）——你以后写程序，第一个学会的就是它，和这里说的是同一件东西。// 还有一种说法你迟早会撞见：有些书把向量讲成"**有大小和方向的量**"，画成一支带尖的箭。那是从物理来的入口（力、速度是那么用的）。**这一册不走那条路**：向量就是一串数。两条路说的是同一件东西，只是从哪儿进门不一样——而"一串数"这个入口，**算得动、也不用先学量角器**。// **整个地球也铺着一张坐标系**：**经度**和**纬度**。纬度的零线是赤道（那是地球自己定的），可**经度的零线是人挑的**——一百多年前开了个会，投票决定让它穿过英国格林尼治的一座天文台。当年要是投给了巴黎，今天全世界每个地方的经度数字都会不一样，**而地面上什么都不会变**。**这就是"坐标系是人定的"最硬的一个证据。**// 屏幕上的一切都是这一套：图片文件本质上就是一张巨大的数字表；游戏里的角色是几万个点的点名单加连线单（连出来的是一片片小三角形，叫**网格**）。// 美术师改的是名单，显卡搬的是名单——**第三篇造几台"搬名单"的机器，第四篇你会看到显卡搬名单的真办法。**
