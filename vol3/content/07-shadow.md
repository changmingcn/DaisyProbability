# 第七篇　立起来：三维兔子和它的影子

CENTER: 手影游戏就是一台机器：三维进去，二维出来。丢掉的那一维，正是核

前六篇，兔子一直躺在纸上。这一篇让它**立起来**。

## 一、第三个数

纸上一个点要两个数。**空间里的一个点要三个数**：

BOX[remember]: 三个数定一个点 :: 在房间里报一个位置，你会说：// **"从门角起，往右 2 米，往里 3 米，再往上 1 米。"**// 三句话，三个数：**(2, 3, 1)**。// **还是一串数，还是一个向量**——只是这一串比平面上的长了一个数。// // 坐标系还是那三件事，只是**轴多了一条**：// 横轴、竖轴，再加一条**朝天的轴**。// 基本向量也从两个变成三个：**往右一格、往里一格、往上一格**。

一台空间里的老实机器，账本自然也长了：**三个向量，三列**。

BOX[key]: 家规一个字都不用改 :: 第三篇那两条家规，说的是"拼"和"几倍"——// **它们从头到尾没提过"两个数"这件事**。// 所以搬到空间里，一个字都不用改：// 拼好再进机器，和各自进机器再拼，落点一样；3 倍进去，3 倍出来。// // **"两串数定乾坤"也跟着长大成"三串数定乾坤"**：// 只要知道三个基本向量各落在哪儿，空间里每一点的落点就全定了。// 证明和第三篇第三节**一字不差**，只是配方从两份变成三份。

## 二、手影：一台三维进、二维出的机器

晚上关了灯，用手在墙上做兔子——这个游戏你一定玩过。

**那就是一台机器**：投进去的是**空间里的一只手**（三个数），吐出来的是**墙上的一个影子**（两个数）。

BOX[remember]: 投影机 :: 最简单的一台：**把第三个数扔掉。**// 投进 (2, 3, 1)，吐出 **(2, 3)**。// 就像太阳从正上方照下来，东西在地上落一个影子——// **左右前后照旧，高低没了。**// // 这台机器的账本有**三列**（三个向量各去哪），可每一列只有**两个数**（落点在平面上）。// 三个基本向量分别落在 (1, 0)、(0, 1)、**(0, 0)**。

## 三、核就是光线的方向

第六篇教过：问一台机器**吃掉了什么**，就问**哪些向量被送到了出发点**。

投进 (0, 0, 1)——**朝天的那个向量**——吐出 (0, 0)。投进 (0, 0, 5)、(0, 0, −2)，还是 (0, 0)。

BOX[key]: 影子看不见的那个方向 :: 这台投影机的核，是**整条朝天的轴**——也就是**光线的方向**。// // 说得再白一点：**把手沿着光线上下挪，影子一动不动。**// 高低这件事，影子**根本不知道**。// // 第六篇说"核是机器吃掉的方向"。// 这里那个方向**看得见摸得着**：它就是光射过来的那条路。

BOX[dialog]: 妹妹的实验 :: **妹妹：**"那我把手举高一点，影子会变大呀，怎么会一动不动？"// **姐姐：**"那是因为真的灯是**一盏点灯**，光是散开的。// 这一篇说的是**太阳那样的光**——光线彼此平行，直上直下照下来。// 你想验的话，太阳底下试：中午把手抬高一点、放低一点，// **地上的影子只挪不变大。**"// **妹妹：**"那点灯的影子，也有账本吗？"// **姐姐：**"有，可它**不是老实机器**——它连出发点都保不住。// 那种变换叫'透视'，**画画和拍照全靠它**，要等长大以后才讲。"

## 四、像：影子住在哪儿

核回答的是"什么被吃掉了"。还得问一句：**吐出来的那些点，凑成了什么？**

BOX[remember]: 像 :: 一台机器**所有落点凑成的那一片**，叫它的**像**。// 上面那台投影机的像，是**整个地面**——平面上每个点都有东西落在那儿。// // 可像不一定那么大。把投影机改狠一点：// 先把影子投到地上，**再把地上的影子压到一条线上**。// 这一台的像就只剩**一条线**了。

## 五、维数守恒：吃掉的加上剩下的

现在把两件事摆在一起数一数。

BOX[key]: 一笔账，三个数 :: 空间有 **3** 个方向可以走。// 投影机吃掉了 **1** 个方向（上下，也就是核）。// 影子住的地面有 **2** 个方向。// // **1 ＋ 2 ＝ 3。**// // 换那台"投到一条线上"的狠机器：// 它吃掉的是**一整个平面**（2 个方向），像是**一条线**（1 个方向）。// **2 ＋ 1 ＝ 3。**// // 什么时候都对：// **吃掉的方向数，加上影子的方向数，等于出发时的方向数。**

BOX[remember]: 为什么必须对 :: 空间里的三个方向，进了机器只有两种下场：// **要么被吃掉**（落到出发点上，进核），// **要么活下来**（在影子里还看得见）。// **一个方向不会既被吃掉又活下来，也不会两头都不沾。**// 所以两边一数，当然对得上。// // （这句话听着理所当然，可要把"方向数"说准，得先说清什么叫"方向数"——// **那正是下一篇的正题**。这里先记住这笔账。）

## 六、直观翻车：影子一样，手可不一定一样

妹妹该挑刺了：**两只手的影子一模一样，能不能断定这两只手摆的姿势也一样？**

**不能。**这是本篇要抓的那条刺。

BOX[key]: 一个例子就够了 :: 把手**沿着光线抬高十厘米**——影子一动不动。// 可手明明换了位置。// **影子一样，手不一样。**// // 这正是"核"的意思：**差在核里的两个东西，机器分不出来。**// 第六篇那台压扁机，(3, 2) 和 (3, 5) 落点相同——**它们的差 (0, 3) 正在核里**。// 这一篇的手，两个位置的差正好指着光线方向——**也在核里**。// **一模一样的毛病，换了个身子而已。**

BOX[remember]: 所以医生要拍两张片子 :: 拍一张 X 光片，就是给身体照一个影子——**深浅方向的信息丢了**。// 所以医生常常要**换个方向再拍一张**。// 两张影子合起来，才把丢掉的那一维补回来。// **核吃掉的东西，只能靠换一台机器再看一次找回来。**

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: 三个数的点叫**三维向量**，写成 (x, y, z)；三个基本向量是三维的**标准基**。三维到二维的机器，矩阵是 2 行 3 列——**行数是出去的维数，列数是进来的维数**。// **核**（kernel）也叫零空间，**像**（image）也叫值域或列空间。// 第五节那笔账正式叫**秩–零化度定理**（也叫维数公式）：**核的维数加上像的维数，正好是出发空间的维数**。像的维数还有个更常听见的名字，叫**秩**。// 第三节那种"光线平行"的投影叫**平行投影**（正投影）；点光源那种叫**中心投影**或**透视投影**——它不是线性映射，得用第三篇灰盒里说的**齐次坐标**才装得进矩阵里。文艺复兴的画家把透视琢磨明白，比数学家还早几百年。// 第六节那个"换个方向再拍一张"的念头，正是 **CT** 的原理：绕着身体拍上千张影子，再由计算机把三维的样子解回来。这门手艺叫**层析成像**。
