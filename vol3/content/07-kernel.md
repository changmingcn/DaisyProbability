# 第七篇　压扁与倒带

CENTER: 什么时候能把兔子变回去？答案藏在"被吃掉的那个方向"里

第三篇留了一根刺：把竖坐标乘 [[1/2]]，兔子还能变回来；乘 0，就**再也回不来了**。第六篇又发现，回不来的那台机器，放大率正好是 0。

这一篇把这件事讲透：**什么样的机器倒得回去，什么样的倒不回去，凭什么。**

## 一、倒带机

有些机器，做完能撤销。

- 放大 1.5 倍 → 缩小到 [[2/3]] 倍，兔子回来了（1.5 × [[2/3]] 正好是 1）。
- 转 90° → 再转 −90°（也就是顺时针转四分之一圈），兔子回来了。
- 斜拉（横坐标加上竖坐标）→ 横坐标**减去**竖坐标，兔子回来了。

BOX[remember]: 倒带机 :: 一台机器 A，要是**另有一台机器 B**，能把 A 送出去的每一个点**原样送回来**，// 就说 A **倒得回去**，B 是它的**倒带机**。// // 用账本说：两台接力（第五篇的乘法）**正好等于"什么都不做机"**：// **[[m:1,0;0,1]]**// 这就是"做了等于没做"。

BOX[task]: 留给姐姐 :: 用第五篇的乘法验一验：// （1）放大机 [[m:1.5,0;0,1.5]] 和缩小机 [[m:\frac{2}{3},0;0,\frac{2}{3}]] 接力，得到的是不是"什么都不做机"？// （2）斜拉机 [[m:1,1;0,1]] 和 [[m:1,-1;0,1]] 呢？// （3）转 90° 机 [[m:0,-1;1,0]] 连做**四次**呢？（第五篇 C3 猜过。）

## 二、回不来的那台

现在看那台"压过头"的：**横坐标不动，竖坐标乘 0**，账本 [[m:1,0;0,0]]。

BOX[dialog]: 妹妹的刁难 :: **妹妹：**"我手里有个落点 **(3, 0)**。你告诉我，它原来是哪个点。"// **姐姐：**"我说不出。(3, 2)、(3, 5)、(3, −1)——**它们全落在 (3, 0)**。// 拿到落点，我认不出它是谁变来的。"// **妹妹：**"那你就是倒不回去。"// **姐姐：**"对。**不是我笨，是那台机器把话说死了**——// 一整竖排的点被它挤成了一个点，**挤掉的东西找不回来。**"

BOX[key]: 这件事你在第二册见过 :: 第二册第一篇讲过**好机器的诺言**：**一个输入，只许有一个输出**。// 当时姐姐特意说过一句：// **"倒过来那个方向，机器没答应过你什么。"**// // 现在你看见那句话的分量了：// 一台机器可以**规规矩矩地守诺言**（每个点都有确定的落点），// **却仍然倒不回去**——因为**好几个点落到了同一个地方**。// // 第二册第二篇的开方也遇到过这个坎：平方机把 3 和 −3 都送到 9，// 反过来只好**说好只吐正的那个**。// **这一篇要问的是：什么时候连"挑一个"都救不了。**

## 三、核：被吃掉的那个方向

再看一遍那台机器压掉了什么。

**哪些向量，被它送到了出发点？**投进 (0, 1)，吐出 (0, 0)；投进 (0, 5)、(0, −3)，还是 (0, 0)。

**整条竖轴，全被压到了出发点上。**

BOX[remember]: 核 :: 一台机器的**核**，就是**被它送到出发点的那些向量**。// 压过头那台机器的核，是**整条竖轴**。// // 白话：**核就是这台机器吃掉的方向。**// 沿着核的方向挪动，机器**看不见**——挪多远，落点都不变。// // 第三篇第七节说过：给三只厚薄不同的玩偶拍照，照片一模一样，**照片捏不回玩偶**。// 被相机吃掉的那个"厚"，**现在有名字了——它就是那台相机的核**。

FIG: fig-r15-kernel.png | 竖坐标乘 0：一整条竖线上的点，全被送到横轴上的同一个落点。那条竖线就是这台机器的核——它被吃掉了。

BOX[key]: 核里永远有出发点 :: 任何老实机器，都把出发点送到出发点（第四篇第二节那颗钉子）。// 所以**核从来不空，至少装着出发点**。// // 于是问题变得很干脆：// **核里除了出发点，还有没有别人？**

## 四、判据：核里只有出发点，就倒得回去

BOX[key]: 定理与证明 :: **一台老实机器倒得回去，当且仅当它的核里只有出发点。**// // **先证一半（核里有别人，就倒不回去）。**// 设核里除了出发点，还有一个向量 v。// 那么 v 和出发点**都落在出发点上**——两个不同的点，同一个落点。// 姐姐拿到那个落点，认不出它是谁。**倒不回去。**// // **再证另一半（核里只有出发点，就倒得回去）。**// 要证的是：**两个不同的点，绝不会落到同一个地方。**// 反过来想：假设 u 和 v 落点相同。// 看 **u − v** 这个向量（横的减横的、竖的减竖的；画出来，就是从 v 的尖指到 u 的尖）。// 按**家规一**，它的落点正是"u 的落点减去 v 的落点"，也就是**出发点**。// 那么 u − v 在核里！可核里只有出发点，所以 **u − v 就是零向量**，// 也就是 **u 和 v 本来就是同一个点**。// 说好了它们不同，矛盾。// **所以落点各不相同，每个落点都认得出唯一的来源——倒得回去。证毕。**

BOX[remember]: 请看清楚这个证明借了什么 :: 第二步整个踩在**家规一**上：// **"先减再进机器"和"先进机器再减"，落点一样。**// 没有这条家规，"u − v 落在出发点"这一句就写不出来。// // 第四篇立那两条家规时，它们看着像客气话。// **这里是它们第一次真正干重活。**

## 五、和放大率对上了

第六篇算过：那台压过头的机器，放大率是 0。这不是巧合。

BOX[key]: 三句话说的是同一件事 :: **一、**机器把地皮压没了（**放大率是 0**）。// **二、**机器吃掉了一个方向（**核里不只有出发点**）。// **三、**兔子**倒不回去**。// // 为什么一是二？地皮被压没，就是说**那两个向量的落点挤到了一条线上**// （两个向量张开的平行四边形，扁成了一条线，面积是 0）。// 那么**一定有一个向量被送到了出发点**——核里有别人了。// 反过来也一样。// // 所以判一台机器回不回得来，**只要算一个数**：// **ad − bc 不是 0，就倒得回去；是 0，就永远回不去。**

BOX[dialog]: 妹妹追一句 :: **妹妹：**"照这么说，放大率是 0.0001 的机器，也倒得回去？兔子都快压成一条线了。"// **姐姐：**"倒得回去。**压得再扁，只要没压到 0，每个点还认得出自己。**// 倒带机会把它拉回来——只是要拉一万倍，费点劲罢了。"// **妹妹：**"那 0 和 0.0001，差别真有那么大？"// **姐姐：**"这就是这一篇最要紧的一句话：// **不是'差不多'和'差一点'的区别，是'能'和'不能'的区别。**"

## 六、直观翻车：缩小不等于压扁

顺着妹妹那一问，正好抓这一篇的刺。

BOX[key]: 两台看着都在"变小"的机器 :: **缩小机** [[m:\frac{2}{3},0;0,\frac{2}{3}]]：兔子整体缩到 [[2/3]]。放大率是 [[4|9]]，**不是 0**。// **压过头那台** [[m:1,0;0,0]]：兔子压成一条线。放大率**正好是 0**。// // 两只兔子都"变小"了，可：// 缩小的那只**每个点都还在自己的位置上**，乘回 1.5 就复原；// 压扁的那只，**一整竖排的点已经撞死在一起了**。// // **"越来越小"和"变成 0"，永远是两回事。**// 这个教训第一册讲过一整本：**比任何正数都小的距离只能是 0**——// 可只要它还不是 0，它就**还是个正数**，什么都没丢。

## 长大以后的写法

BOX[grown]: 课本上会这样写 :: **核**正式就叫**核**（kernel），也叫**零空间**；"倒得回去"叫**可逆**，倒带机叫**逆矩阵**，记作 A 的 −1 次方。// 第四节那条定理是线性代数的骨干之一：**线性映射是单射，当且仅当核只含零向量**。// 第五节那串等价说法，课本上会一口气列成一长条：矩阵可逆 ⟺ 行列式不为 0 ⟺ 核只含零向量 ⟺ 两列线性无关 ⟺ 满秩——**说的全是同一件事**。// B4 那本倒带机是照公式来的：[[m:a,b;c,d]] 的逆，是把 a 和 d 对调、b 和 c 变号，再整个除以 ad − bc。**分母正是放大率——它一为 0，公式当场垮掉**，这就是"压没了就回不来"在公式里的样子。// C3 的答案：核是一个**子空间**（一条过原点的直线，或者只有原点，或者整个平面）。"子空间"是第九篇的正题。
