## 二、开篇《同一个圆，三个答案》

在圆里随便画一条弦，问：**它比这个圆的内接正三角形的边长的可能性有多大？**

三种"看起来都很自然"的画法，三个不同的答案：

| 怎么随机画这条弦 | 孩子的动手做法 | 答案 |
|---|---|---|
| 先在圆周上定一个端点，另一端随便落 | 圆周等分标 36 个点，转两次转盘选两点连线 | **[[1/3]]** |
| 随便挑一条半径，在它上面随便点一个中点 | 转一次定半径，尺子上随便点一个位置，作垂直于半径的弦 | **[[1/2]]** |
| 在整个圆面上随便撒一个点当中点 | 往画着圆的纸上撒米粒 | **[[1/4]]** |

**开篇的定位是"动手＋提出问题"，不是证明**——照搬第一册开篇"数格子"的路子（那一篇也是只数不证）。孩子亲手做三十次，三个频率就摆在那儿，冲突是**实感的**，不是听说的。

**作者自己要能核对的三件事**（正文不写，孩子六年级还没学垂径定理）：

- 内接正三角形的边长 ＝ **√3 × 半径**；
- 一条弦比它长 **⟺** 弦的中点到圆心的距离 **小于半径的一半**；
- 于是：端点法看的是对面那段 120° 的弧 → [[1/3]]；半径法看的是半径上靠内的一半 → [[1/2]]；面积法看的是半径减半的那个小圆，**面积**只有 [[1/4]] → [[1/4]]。

BOX 定调：开篇**不解决**这个冲突，只立目标。第九篇结案。

**主线装置「回头望一眼那个圆」**（模仿第一册那块地的七个绿盒），沿途兑现五次：

| 在哪 | 兑现什么 |
|---|---|
| 一篇 | 三种画法＝**三个不同的样本空间**，这才是它们不同的地方 |
| 三篇 | "圆上均匀"有三种意思——**等可能是假设，不是天上掉下来的** |
| 六篇 | 三种取法下，"弦有多长"的**公平价也不一样** |
| 七篇 | 开篇那三十次实验**本身就是大数定律的现场**：频率挤向可能性 |
| 九篇 | 结案：三个答案**都对**，因为你问了三个不同的问题 |

## 五、这一册特有的设计判断

**① 测度论绕得过去，而且必须绕。**
Bertrand 悖论**不需要**测度论来解释——它需要的只是"你得先说清楚怎么取"。所以：**全册在有限世界里把概率空间、期望、条件期望统统讲完**；圆是唯一的连续对象，用"长度比／面积比"处理。σ-代数、不可测集**只进灰盒当传说**——沿用第一册"不可测集只能当传说、正文用零公理平替"那次的定案（那次用户判过"过重"并回滚，别重蹈）。

**② 连续情形只做均匀。**一段上的均匀、圆周上的均匀、圆面上的均匀，就这三样。任何"密度函数"都不出现。面积的可加性**是借来的**（第二册第八篇做过面积），附录 D 记账。

**③ 期望是一台老实机器——这是四册之间第一次三向回响。**
第三册讲过"老实机器"（能拼、能乘倍数）。**期望正好是一台老实机器**：把两个赌局合起来的公平价，等于两份公平价相加；赌注翻三倍，公平价也翻三倍。而且**加法这一条不需要两者独立**——这是最反直觉又最有用的一条。第六篇直接还第三册的账，写明"这就是那两条家规"。

**④ 等可能是假设，不是定理**（第三篇）——它是全册的枢纽，因为它正是 Bertrand 的病根。骰子六面等可能，靠的是**对称**这个假定；圆上"均匀"却有三种不同的对称可讲，于是三种答案。**第三篇讲不透，第九篇就结不了案。**

**⑤ 条件概率先于条件期望，且中间必须隔着期望与大数定律。**第五篇（条件概率）到第八篇（条件期望）之间隔着六、七两篇不是拖沓：孩子得先把"期望＝公平价"坐实，"知道消息后的新公平价"才有东西可改。

## 七、欠账政策（附录 D 预定清单）

开写前就该知道这一册要借什么，免得写着写着糊过去：

- **测度论整块没讲**（σ-代数、可测性、不可测集）——只在灰盒提一句。

- **条件期望只在有限世界里定义**；一般情形要用测度论。
- **可数无穷样本空间**（比如"一直掷到出正面为止"）要用级数——**若第六篇用了，就得当场写欠条**，指到第一册第二篇的部分和。**建议第一版整册回避可数无穷**，只做有限。

**赊账三件套照旧：先猜并明说是猜 → 当场写下欠条（欠哪一句、到哪里还）→ 还账时明写在还哪一笔并回填附录 D。**本册大量内容是"借了不还"（如测度论），那就**不叫赊账，叫借用**，必须在附录 D 里明确写"这一册不还"。

## 八、工程：怎么把 vol4 建起来

源码在 `~/math-notes/`，四册共用一棵树，已建 git 库。**Drive 只是交付出口，不是源头。**

> **铁规矩（2026-08-02 用户当面定下，三本手册同款）：改完就推，每一次都推。**
> 只要正文／插图／手册动过一个字、并且校验是绿的，**当轮就 `./publish.sh --upload`**，不许攒批。
> **用户只在 Drive 的 Doc 上看稿**——没推上去 ＝ 他看不见 ＝ 这一轮的活等于没干。
> 固定动作：**改完 → 校验绿 → 立刻 `--upload` → 只核"件数齐 ＋ 各册 Doc 的 id 没变"**。
> （校验没绿**不许**上传，这两条不冲突。）

**下面这六处 08-02 已经全部做完了**（留着是给"再开第五册"的人抄，也给你核对用；判据：源码包件数 49 → 53）：

1. `vol4/TITLE` —— 一行书名，**docx 文件名由它定**（`OUTPUT = TITLE + '.docx'`）。
2. `vol4/content/*.md` —— `00-front.md`（TITLE:／SUB:／给大人的话／目录）＋ `00b-intro.md`（开篇，不编号）＋ `01-…` 起九篇 ＋ `10-appendix.md`（附录 A–D）。
3. `vol4/figs.py` —— 照 `vol3/figs.py` 抄头部约定：中文用 **Hiragino Sans GB**，数学走 **mathtext**，**两者绝不混在同一个字符串里**；**中文字体缺 U+2212**，图里的减号要用"减"字或 ASCII 连字符。
4. `publish.sh` 三处：`VOLS` 加 vol4；`FILES=(…)` 加 `vol4/TITLE vol4/figs.py vol4/content/*.md`（**判据：源码包件数要涨**，不涨就是没打进去）；`ITEMS` 加两行（第四册 Doc ＋ 第四份稿件），并把件数文案与 `-eq` 那个数字一起改。
5. `export_manuscript.py` 的 `PART` 映射加 `'vol4': '第四册'` —— **不加就会拿 `sys.argv[1]` 当名字**，历史上 vol3 差点覆盖第二册的稿件。
6. `verify_docx.py`：**一个字都没动，也不需要动**（原因见 §六那条勘误）。

**件数**：现在是**十二件**（四册 Doc ＋ 四份稿件 ＋ 源码包 ＋ 三本手册）。`publish.sh` 会自己点数，不齐当场中止；`trap` 那道安全网的数字也要跟着改——**它藏在下面，08-02 差点漏掉一次**。

**日常一条命令**：`./publish.sh --vol vol4`（生成图 → 构建 → 校验 → 导稿件）。手工跑**顺序不能乱**：`figs.py` → `build_docx.py vol4` → `verify_docx.py vol4` → `export_manuscript.py vol4`（并发跑过一次，校验读到写了一半的 docx）。

**交叉引用语义对账**：`python3 audit_refs.py --vol vol4`。它是给人过目的工具，不是闸。**基线对差要按"记录"比、不能按行比**（把每条嫌疑的抬头去掉行号、再和它的缩进明细拼成一行，然后比计数）。另外记牢两条：**引号里的句子会被当成"对被引处的承诺"，加粗不算**——所以自己换的说法一律用加粗；**[3.96] 搬家哨兵按邻近配对**，同一个盒子里别处的篇引用会被拉来配你的公式串，遇到就**改文字、不动闸**。

## 九、开工顺序（建议）

**别直接开写第一篇。**按这个顺序，每一步都拿到"可以"再走下一步：

1. **先写开篇**（`00b-intro.md`）＋ 它要的两三张图。开篇是全册的成败手：三个动手实验必须真的可做、真的能数出 [[1/3]]／[[1/2]]／[[1/4]]。**先把这一篇给用户看。**
2. **再写第一、三篇**（概率空间 ＋ 等可能是假设）。这两篇立住了，全册的地基就有了；第三篇没讲透，第九篇结不了案。
3. **然后第五篇**（条件概率／三门问题）单独出一版——它是全册最容易写砸也最出彩的一篇。
4. **六 → 七 → 八** 连着写，因为它们是一条链（公平价 → 频率挤向可能性 → 新公平价）。
5. **最后二、四、九篇**收口（事件、独立、结案）。
6. 附录 A–D 与前言目录**最后写**，写完立刻回头核一遍："附录说某词出自某篇，正文真的讲过吗"——**前三册在这上头栽过两次**。

## 十、怎么和用户共事

- 他要的是**一起设计**。大结构先给方案，拿到"OK/可以"再动手；阶段性成果发单向汇报，不停等。
- 他会问很尖的具体问题。**先去查，不要先辩解。**查出来是错就认，改掉，并**尽量把它变成一条能自动失败的检查**——"用户指出一个具体错误 → 修 → 做成检查 → 检查立刻再抓出同类的"，这个循环在前三册跑了五轮。
- 他改方向时改得很彻底。**不要心疼已写的内容**，按新方向重做。
- 汇报时**先说没做到的、没验的、最可能出错的**，再说做了什么。
- **他随口用的大学术语，不等于要写进书里**（08-02 他说"无理数次方"，而"无理数"正是第一册明令回避的词——照办意图、换掉词，并在汇报里说一声）。
- **排版不归你验，用户自己看**（分页、盒子底色、分数垂直位置）。**每次交付仍要明说这一项没验**，别含糊过去。本机没有 LibreOffice，`--headless` 渲 PDF 是死路，别再试。
- 每一轮结尾给一条**具体的减负建议**（"如果读着还是重，最容易切的是 X，因为它不伤主线"）——用户多次据此做决定。
