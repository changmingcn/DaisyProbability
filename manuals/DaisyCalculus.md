**1. 妹妹出招，姐姐接招。** 妹妹提误差 ε、负责挑刺；姐姐负责写证明。这不是为了可爱——它把 ∀∃ 的**逻辑顺序变成对话顺序**，孩子天然懂"她先出招、我再接招"，量词顺序就不会倒。**全套书最值钱的装置。**

## 二、教训（都是真金白银换的）

> 不写条数了：写死"十二条"以后加了六条也没人回来改，和"手册说 13 项、脚本早就 17 项"是同一种过期。编号只保证唯一、不保证连续（历史上按加入顺序编的）。

**1. 抽象要由"它回答了哪个问题"来挣得。** 第一册初稿把点集拓扑写到紧致、拓扑空间、同胚、咖啡杯与甜甜圈，用户判词：**"我似乎把方向走错了，越走越抽象"**——六章推倒。自检问句：**这个概念回答了哪个孩子会真的问出口的问题？**答不上来就砍，不管它多漂亮。

**2. 每篇只做一件事。** 拆章按目的，不按长度。第一册第三篇一度膨胀到八节，拆成三篇后每篇才有了自己的一件事。**08-01 第二册第一篇同样办法拆掉**（它同时干四件事：什么算机器／用哪种机器／怎么画／开方）→「好机器和坏机器」＋「这一册用哪种机器」。

**改号作业的完整打法（259 处引用，这次一遍做对，务必照抄）**：①先 grep 清点每个篇号出现数与"第一册"前缀数；②**扫出间接跨册写法**——本次抓到 `第一册翻到第五篇`、`第一册只在第四篇`，**单字符 lookbehind 挡不住**，要把跨册串逐条列成保护名单、先替换成占位符；③从大到小位移（十→十一、九→十…二→三），绝不重复改号；④**复合引用是最大暗坑**：`第二、三篇`／`第三到第七篇`／`第五、六篇`／vol1 的 `第二册 七、八篇` 整串替换全躲过去了，必须单独 grep `第X、`、`第X到第` 收尾；⑤**三册联动**：vol1 的方法表、vol3 的 `第二册第X篇` 都要跟着改；⑥**最后写对账脚本**——把每条 `第X篇第Y节` 与它实际指到的小节标题并排打出来人工过目（校验只能查"存在"，查不出"指向了存在却错误的节"）。

**3. 命名反复出现的"动作"，比多讲一条定理值钱。** 已命名并反复回指：**取靠后的那个关口**、**把 ε 掰成两半**、**比任何正数都小的距离只能是 0**、**夹逼**、**先猜后证**、**一层层抵消**。新写的东西要回指这些名字。

**4. 公式里只许有数学符号，不许夹中文。** 病根是**用 ＝／≤ 把符号接到中文短语上**（"不到 ε 的一半 ＋ ε 的一半 ＝ ε"、"低估 ≤ 真面积"）。两条出路：**先给那个量命名再写公式**（低估记作 L~n~……于是 **L~n~ ≤ A ≤ U~n~**，顺带教会"想写公式就得先造符号"），**或整句写成句子、不带关系符**。中文可以**包着**公式，不能**长在**公式里。谈论符号本身时要**加引号**（"＜"何时退化成"≤"），否则检查会误报。→ 检查 **[3.95]**

**5. 极限要用极限的语言说。** 凡"它很小所以不管它""一趋于 0 就没了""可以忽略"，一律改写成：**先写出一个对每个 h ≠ 0 都成立的等式，再说"考虑等式左右两边在 h 趋于 0 时的极限"，然后逐块交代每一块奔向什么。**被扔掉的那项不说"扔掉"，要说**它奔向 0**，并指出**它藏在哪个因子里**。范例是乘积法则（那一小块藏在 g(a+h) 里，取极限时 g(a+h) 奔向 g(a)，顺带用上"多项式连续"）。→ 检查 **[3.97]**

**6. 术语要么是标准的，要么是自带解释的。** "差商"其实是标准术语，但读着像行话 → 改叫**平均变化率**（中学课本叫法）。**但用户同时问"能不能改叫微分"——那是数学错误，必须顶回去**：微分是另一个对象（df ≈ f′·h）。**正确做法不是改名，是把微分真正引进来**（第二册第三篇第五节，三个词一次说清分工）。**用户的改动里若含数学错误：先说清楚，再给出既满足他意图、又不出错的做法**——不照单执行，也不只是拒绝。**同一条也管"用户随口用了书里的禁用词"**：08-02 他说"一个数的无理数次方"，可"无理数"正是前言第一条取舍明令回避的词——**照办意图、换掉词**（正文一律"不是分数的数／不循环的小数"，"无理数""指数函数"只进灰盒），并在汇报里说一声换了。**用户拿大学词汇描述需求，不等于要把那个词写进书里。**

**7. 先证存在，再算是多少。** 用户点名“这是高等数学中极其重要的方法”。反例：对 1＋2＋4＋8 用“设和为 S”解出 **S ＝ −1**——错的是**“设它是 S”已经假设了存在**。正例：牛顿开平方（第一册第五篇第五节），**第一步用②断定有极限，第二步才两边取极限**。该节末尾有一张表，列出这个方法在两册里的全部出场。**八大定理从不告诉你答案是多少，只告诉你答案存在**——第二册现行第十篇第七节就靠②断定“√x 的面积存在”，而那块面积是直接加不出来的。

**8. 取极限是一种运算。** （第一册第四篇第六节。）它和别的运算**能不能换次序**——这个框架把那一篇的五个例子统一起来：**"＋"能过关、"≤"能过关、"＞"过不了关**；最狠的一次是**连"是分数"都过不了关**（每一项是分数，极限 √2 不是），**那就是"不完备"长什么样**。**08-02 用户抓出一处越位并已改**：篇四原有"八条定理在分数世界统统是假的"枚举盒（用②⑦③编号点反例）——名单第五篇才发，判词"把后面的话提到前面说了"；现改**欠条制**：篇四只"收好这队分数"一个字不剧透（顺带解决了它剧透五篇 C3、提前引用牛顿开平方两桩旧病），清算在五篇八句话表后"子弹兑现句"＋C3 亲手打三枪；篇四 C7 改用上确界词汇。**同类自检：早篇提到后篇专有的编号/名单/术语，就是越位信号。**用交换方框画图。**"两边取极限"就是把 lim 同时作用在两边，合法性由完备性担保。**

**9. 反例和"直观翻车"是最好的内容，每章至少一处。** 已有：调和级数（每步变小整队却涨到无穷）、"＜"取极限退化成"≤"、(fg)′ ≠ f′g′、导数为 0 不一定是极值、有定义≠有极限（会跳的机器）、有极限≠有定义（差商在 h＝0）。

**10. 把“回头解答”提前设计。** 第一册第五篇还第二篇的欠条；第三篇回答第二篇的问号；第二册第三篇第五节回答第一篇 C4；**第二册第六篇 C4 故意把“正确陡度为何够像”留到第七篇第三节回答。**这种结构快感是设计出来的，不是碰巧。

**11. 点集／聚点那类题最容易上手，是教学入口。** 用户原话："这些地方逻辑简单，小孩子容易感兴趣。"这类题**不要求写证明，只要求摆出一队数、指出聚点在哪**，答案具体、能画出来。孩子若对 ε–N 发怵，**先做第一册第二篇第七节那组**。附录 C 里写明了这条路径。出这类题时优先考虑：找聚点、造出指定聚点集合的数列、判断开闭集、"再添上哪个点就成闭集"、造一个没有有限子覆盖的开覆盖。

**17. 比喻要有名字，定义要能判真假。** 用户 08-01 追加两条：①"我们的函数叫**好机器**，与老虎机这样的**坏机器**相对比"——给概念**起对立的名字**比只说性质更好记，且给了坏的一类一个位置（不是"没资格"，是"归概率管"）；②"**多项式你没定义**"——原稿只说"只用加法和乘法"，例子里却写着 2a²＋5a−1，**定义和例子自相矛盾**。教训：**凡书里当术语用的词，都要有一条能拿去判真假的定义**（原料·允许的手·有限次），并配一张含反例的判别表；写完自问"孩子拿这条定义能判出 1÷a 吗"。三个褒义词分轴也要写明：**好**（守诺言＝函数，二册）／**老实**（守家规＝线性，三册）各管一件事，三册已加盒钉开。

**16. 比喻立住了，就要把它的"边界"也讲出来——反例才是比喻真正的教学力。** 用户 08-01："既然用机器比喻函数，就强化它：**老虎机显然不是函数机器**，因为相同输入输出不一样；可以用'信守诺言'来比喻。"落法＝第一篇第一节先立诺言（单值性），再用老虎机划边界，再用妹妹的追问把方向讲清（多对一合法、一对多非法）。收益是全书性的：**竖线检验**（画像）、**√ 只取正根**（反函数要挑一个）、**会跳的机器守诺言但不连续**，三处原本各说各的，现在统一挂在同一条诺言上。**新立任何比喻，同时问一句"什么东西看着像但不是？"——那个反例值一整节。**

**15. 抽象概念要挂在孩子已经相信的东西上。** 用户 08-01："介绍速度的过程中就可以提到极限，**大家对速度的概念是很熟的**。"这条比"举例子"更深一层：**孩子从不怀疑速度表指着一个准数——那等于她早就相信那个极限存在**，我们只是给它起名字。落法＝第三篇第一节从仪表盘开门，用真数据表让极限自己浮出来，再把 ε–δ 演成"妹妹要准头、姐姐掐时间"。**新写任何抽象概念，先找一件孩子已经无条件相信的日常事，让概念从那里长出来**（同款可用：连点成画之于线性、找零之于逆运算）。工程注意：插入点选**已有小节内部**（第三篇第一节扩写），不新增节号——第三篇第四/五节被多处跨篇引用，改号即灾。

**18. 赊账–还账制度：鼓励先凭直觉猜，允许当时不严，但必须"预先提醒 ＋ 后文收尾"。**

用户 08-01 两次校准，原话照抄：**"一开始我们允许一些基于直觉的想法，然后利用严密论证补充。如果一开始就要求严密性，孩子跟不上。"**／**"我们鼓励基于直觉的猜测，然后再利用工具严密化。基于直觉猜测时，可以省掉一些严密性论证，但是要预先提醒，并且在之后的篇章中收尾。"**

这是这套书的**默认写法，不是例外通道**。它管的是**顺序**，不是标准——铁律 2、3 一个字不松。

**三件套，缺一不可：**

1. **先猜，并且明说这是猜。**直觉负责发现（铁律 2）。这一步**可以省掉严密论证——省掉是被允许的，藏起来不是**（铁律 3）。
2. **当场写下欠条。**欠条要写清两件事：**欠的是哪一句**（原话照抄，别含糊成"这里还不太严格"）、**到哪里还**（指到篇，最好到节）。"以后会证"不算欠条，那叫含糊过去。
3. **到了还账的地方，明写自己在还哪一笔，并回填附录 D。**账不还，铁律 3 当场就破了。

**写完自问三句：**这一段省掉的严密性，**孩子读得出来它被省了吗**？读不出来＝欠条没写到位。／欠条**指到哪一节**？指不出来，就要么现在证，要么这段内容还不该出现在这里。／还账那一节**说了自己在还账吗**？不说，孩子不会把两处连起来，教训 10 那种结构快感也就没了。

### 交叉引用语义对账（`audit_refs.py`，08-01 加）

`verify_docx.py` 的 [3.8]/[3.9]/[3.91]/[3.92]/[3.93] 只能查"**目标存不存在**"，查不出"**指到了一个存在、但东西已经不在那儿的地方**"。搬家必然制造这一类，而且不会报错。

```bash
python3 audit_refs.py            # 三册；--vol vol2 单册；--all 连 ok 也打印
```

做法：把引用句里**引号中的那句话**当成"承诺"，拿去它所指的小节里找；找不到就按"在那一篇别的节／在别的篇／全书都没有"分三档报嫌疑。**它是给人过目的工具，不是闸**——08-01 首跑 739 处引用、197 句可对账承诺，25 处"书里有但不在那儿"里**只有 1 处真错**（第二册第十篇把第二篇的"越来越近"安在了第一册第一篇头上；第一篇的说法是"到达"）。写它时踩的三个坑，都已经修在脚本里，改它之前先看：**①自我命中**（引用句自己加粗的话当然出现在本篇——必须把引用句从语料里挖掉）；**②引用串当承诺**（「第五篇第五节」这种要滤掉）；**③标点差一个逗号就假报**（C 组习题引用原文常漏逗号——norm 要抹标点）。**加粗一律不算承诺**，那是本句的强调，不是对目标的转述。

**基线对差要按"记录"比，不能按行比**（08-02 第二次踩到）：一条嫌疑是**多行**的（`✗/⚠` 抬头 ＋ 两行缩进明细），`sort | comm` 逐行对差会把配对拆散，只能看到"多了 2 条 ✗ 全书找不到 03-reals.md"这种没法判断的结果。正确做法是**先把每条嫌疑合并成一行再对差**（抬头去掉 `:行号`，用 ` | ` 接上它的缩进明细行），然后 `Counter(new) - Counter(old)`。这次这么一比，新增 4 条里有 3 条能和"消失"的 3 条一一对上（就是同一条误报的改号版），剩下 1 条手核是转述误报——**结论当场就定了**。

### 节号对账（`audit_sections.py`，08-03 加，**是闸，不过就中止**）

`audit_refs` 的盲区正下方还有一块：**引用的节号指错了，可被引的那个词是加粗的**——于是"引号＝承诺"那套查不到它。08-03 就抓到一处真错：第四篇 C7 写着"第三篇第五节认识了**上确界**"，而上确界在**第六节**。

```bash
python3 audit_sections.py            # 四册；--vol vol1 单册；-v 连 ok 也打印
```

两道检查：**[S1] 存在性**（指到的篇、节在不在）；**[S2] 走错门**——紧挨着引用的那个加粗词，**在目标篇里找得到、却不在你指的那一节**，这时才报。

**[S2] 的判据是试错试出来的，改它之前先读这两条：**
- 第一版判"加粗词必须出现在目标小节里"，**19 处误报**——因为本册体例规定**转述也用加粗**（"列个方程""又出现了""最容易上手"都是转述，目标小节里当然没有原词）。**加上"这个词在本篇别处找得到"才把转述滤干净**：转述在整篇里都找不到，走错门的术语只在隔壁那一节找得到。
- 第二版还剩 1 处误报：取加粗词的 ±12 字窗口**跨过了盒子里的 `//`**，把上一句的词捞了进来。**窗口必须卡在同一分句内。**

现行四册共 **148 处册内节号引用、全部指对**（vol1 59／vol2 56／vol3 28／vol4 5）；反向测试（植入不存在的小节）会当场 FAIL。**跨册引用（第一册第二篇第三节）本脚本不管**，前面紧挨着“册”字的一律跳过。

**再往下一层的盲区：不带节号的"预告式"引用，四道闸一道都查不到。**08-03 抓到一处真的：第十一篇第一节写着「答案**第四篇**已经备好，这里正式立字据」，可**第四篇从头到尾没提过那支箭**——[3.9] 不管（没有"第X篇第Y节"）、[3.96] 不管（旁边没有公式串）、`audit_refs` 不管（没有引号，"备好"是自己的说法）、`audit_sections` 不管（没有节号）。**这类句子是写的时候许下、指望后来兑现的愿**，兑现不了也不会有任何东西响，是最容易烂在书里的一类。这次是用户从内容角度提问才顺手捞出来的，不是闸捞的。**暂时没做成检查**（"第X篇"＋"已经/会/将/备好"这类模式的误报率没试过，按教训"装一条不可信的检查比没有更坏"，不轻易上）。**规矩：写下任何"某篇已经……／某篇会……"的预告，当场去那一篇 grep 一次**；反过来，新写一段内容时也该想想有没有别处早就替它许过愿。

**写的时候就按"引号＝承诺"办，别等 audit 抓。**`audit_refs` 把**引号里的句子**当成对被引处的承诺，**加粗一律不算**。所以新写转述时的固定动作是：**逐字引用才用引号，自己换的说法一律用加粗**。08-02 我一天之内在这上头被抓了四次（附录 A 的"它不是分数"、附录 D 的"连量一个圆…"、习题里的"一直加下去、结果加出一个负数"、附录 D 的"哪一步用到了 2 或平方本身"）——全是同一个毛病，全靠改成加粗解决，一次正文都不用动。

**[3.96] 搬家哨兵是按"邻近"配对的，同一个盒子里别处的篇引用会被拉来配你的公式串。**08-02 在第五篇 C 组加 C5，写了公式串「1 ＋ 2 ＋ 4 ＋ 8」，而同一个盒子的 C4 里有"第一篇"三个字——哨兵当场判"说这个式子在第一篇里，可第一篇没有"。**它不是错的，是配对窗口够不着盒子内部的结构。**处置：**改文字，不动闸**（把公式串换成中文描述）。一条闸为了排版上的方便被放松一次，下次就拦不住真的悬空。

**删掉别处的一句原话，会让引用它的转述在全书失去落点。**这次改前言时把"数轴上有没有洞"那句删了，正文里"第七节要问'数轴上有没有洞'"当场变成 `✗ 全书找不到`——[3.9] 一声不吭（它只查节号在不在）。这是**搬家哨兵那条教训的反面**：搬家是目标换了地方，这是**目标那句话被删了**。改任何一处带引号的原话之前，先 grep 一下有没有别处正引着它；实在不好改，就把引号改成加粗（**加粗不算承诺**）。

**基线对差要先去掉行号**（08-02 踩到）：`audit_refs` 每行末尾带 `文件:行号`，你只要在正文插了几行，所有下游嫌疑的行号全变，`comm` 就会把它们当成"新增"报给你——**假警报**。正确写法是先 `sed -E 's/:[0-9]+$//'` 再排序对比。顺带：**BSD sed 不认 `\+`**，必须 `-E`（用 `\+` 会静静地什么都不替换，于是假警报照旧）。

判嫌疑时的固定动作：**先看目标小节的标题**。80% 的嫌疑是转述——第八篇第一节标题就叫“正的在涨，负的在跌”，第九篇第三节标题就叫“顶上为什么是平的”，正文换个说法而已。

## 七、怎么和用户共事

- 他要的是**一起设计**。大结构先给方案，拿到"OK/可以"再动手；阶段性成果发单向汇报，不停等。
- 他会问很尖的具体问题（"第二节末尾有提到夹逼吗？"）。**先去查，不要先辩解。** 查出来是错就认，改掉，并**尽量把它变成一条能自动失败的检查**。
- 他改方向时改得很彻底。**不要心疼已写的内容**，按新方向重做。
- 汇报时**先说没做到的、没验的、最可能出错的**，再说做了什么。
- **排版验不了，也不用你验——用户自己看。** 结构、字形、交叉引用照旧自动验；**分页、盒子底色、分数的垂直位置，请用户翻一遍 Doc**（2026-08-02 用户原话："也不用验排版了，我自己来。"）。**每次交付仍要明说这一项没验**，别含糊过去。试过用 LibreOffice 自动渲 PDF，是死路，见 §四那个提示框。
- 每一轮结尾给一条**具体的减负建议**（"如果读着还是重，最容易切的是 X，因为它不伤主线"）——用户多次据此做决定。
